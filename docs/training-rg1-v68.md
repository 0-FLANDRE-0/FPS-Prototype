# RG1 / v68 — 래그돌 비용·시체 관통·정착 고정

v67 `515cdd1` 위 3D 작업. Rapier0.21.0·원본2D·의료/탄도/관통/방호 수식·손가락 자산은 그대로다. 분류/수치/2D 역이식 후보는 [대장](rg1-ledger.json)에 있다.

## 구현과 원인 확인

코드에서 추가 솔버64회가 활성 내내 유지되는 것과 플레이어 이동/물리 캡슐의 시체 접촉 경로를 확인했다. 기존 정착은 접지·누운 자세·관절 오차·극저속을 모두 요구해 잔떨림이 남으면 계속 계산됐다. 사용자 제보의 시체 전체 바닥 관통은 기존 빌드의 이번30초 자동 동선에서 재현되지 않았다. 그 현상을 재현했다고 주장하지 않는다.

플레이어 접촉과 이동 쿼리에서 시체만 제외한다. M6 장비·무기는 기존 상호작용을 유지하도록 전용 그룹에 새 플레이어 비트를 허용한다. 자기 래그돌의 이동 캡슐 비활성은 v52 그대로다.

추가64회는 첫1.5초, 이후0회로 내려 **기존 월드 기본 솔버**를 쓴다. 최종 접지/누운 자세의 잔운동에 감쇠를 더한 뒤 전17분절의 속도가0.15m/s·0.5rad/s 아래1초 유지되면 고정한다. 누운 채 안정 접촉과 후기 감쇠를 확인한 뒤에는 수치 잔진동 문턱0.2m/s·1.5rad/s 아래1초를 쓴다(튜닝·게임 허용). 공중/근육 목표 활성 상태에는 이 완화 문턱을 쓰지 않는다. 고정 뒤 실제 각속도는0이다. 기존10도 ROM초과는 계속 측정하지만 정착 감쇠를 영구 차단하지 않는다. 현재 자세를 마지막 한 번 센서/뼈에 반영하고17강체를 비활성화한다. 근육·골격·겉 피격·디버그 내부형상 갱신을 중단하며, 실제 내부 교차는 기존 정확한 자세 캐시를 사용한다. 렌더에 필요한 GPU 스키닝은 계속된다.

총에 맞으면 같은 강체를 켜고 원래 감쇠를 복구한 뒤 기존 실제 충격량을 적용한다. M7 수색·판 창·장비 분리는 그대로다. 활성 상한은4구(튜닝)로, 한 팀4명의 동시 쓰러짐을 유지한다. P01까지5구면 플레이어 머리 시점 쓰러짐을 보호하면서 가장 오래된 적을 현재 자세로 고정하므로 아주 이른 중간 자세가 남을 수 있다.17강체·16관절 사전 생성은 기존에 양쪽 모두 있었으며 쓰러짐 순간 추가 생성0이다. CCD는 전17분절, 비정상 속도 상한과 실제 유한 바닥 상자 아래 복구/횟수도 추가했다.

## Rapier 조사

확인 시 npm 최신 정식은 0.21.0, 설치 버전과 같다. 공식 JS 문서와 설치/latest 타입 선언 및 raw multibody 메서드에 각도 제한·PD 모터·프레임 설정이 없다. Rust/C 기능이나 비정식 canary를 JS 정식 지원으로 간주하지 않았다. 버전업 API차이는없고 WASM차이0B(현재3082103B). 향후 이동 컨트롤러·충돌/캐스트·관절rawAPI·이벤트·장비 물리 영향 목록과 다시 세울 회귀 목록은 rapier-research.json에 있다. 실제 업그레이드/멀티바디 전환은 하지 않았다.

## 회귀와 실행

검증 결과/전체 테스트 수/최종 HTML해시는 downloads/verification-rg1-v68.json이 기준이다. 원본2D 바이트/600틱6발·S0240·684채널·젤라틴·28실제 단일 피격은v67과 동일. 플레이어6상황×2화면은 실제 뇌간/대퇴골 사격→머리 시점→착지/기존 상한 후 UI를 확인했다. 손가락 자산·근육/의료 수식은 보존하고 CCD 범위/솔버 수명에 맞춰 옛 물리 기대만 명시적으로 갱신했다. 최종 단일 HTML 오프라인·포인터잠금·터치/키보드도 별도 검사한다.

ZIP은20,000,000B미만, 압축 해제 후 dist/CQB_Training.html 실행. GitHub Actions없이 로컬검증하고 같은 개발 브랜치에만 전달한다. 실제 폰 성능과 위 관절10도 목표의 미달은 남아 있다.

원시 JSON.gz/플레이어 전체 시트는 저장소 checks-rg1-v68에 보존한다. 20MB ZIP에는 전후 래그돌 전체 시트·수치표·요약·수색 화면을 넣으며 원시 압축 타임라인과 플레이어 전체 시트는 중복 포함하지 않는다.
