# v37: 적 병사 Mixamo 애니메이션 적용

v36 위에서 작업한다. 같이 보내는 `Mixamo_Rifle_Anims.zip`을 쓴다.

다음은 그대로 둔다.
- 의료·탄도·관통·방호 수식
- v36 래그돌 물리(관절 범위, 관성 하한, 솔버, 정착 보조기)
- 손가락 고정 AK 그립
- 플레이어 대리 몸(P01)
- AI 판단 로직

## 0. 자산

- zip 내용은 다음과 같다(클립별 길이와 루트 이동 여부는 `목록.txt`).
  - 뼈 구성: mixamorig 65본, 뼈만 들어 있음(Without Skin).
  - 샘플링: 30 fps이고, 장전 클립 2개만 더 촘촘하다.
  - 기준 뼈대: `X Bot.fbx`(T포즈).
- 출처는 Adobe Mixamo(mixamo.com)이고 로열티 프리다. 대장에 자산 출처로 기록한다.
- Mixamo 자동 리깅은 쓰지 않는다.
  - 기존 적 병사 모델, 스킨, 뼈대(24본 + 손가락 30본)를 그대로 쓴다.
  - 애니메이션만 기존 뼈대로 리타깃한다.

## 1. 리타깃

- Mixamo 뼈 → 기존 병사 뼈 대응표를 만들어 대장에 남긴다.
  - 몸통처럼 Mixamo 쪽 뼈가 더 많은 구간(Spine/Spine1/Spine2)은 회전을 합쳐서 대응 뼈에 넘긴다.
  - 기존 뼈대에 쇄골이 없으면 Shoulder 회전을 위팔에 합친다.
  - 손가락 트랙은 버린다. 손가락은 지금처럼 AK 그립 자세로 고정한다.
- 휴지 자세 차이(X Bot T포즈 ↔ 병사 휴지 자세)는 뼈별 휴지 회전 보정으로 맞춘다.
- Hips 높이 이동은 다리 길이 비율로 환산한다.
- 클립은 빌드할 때 미리 변환해서 내장한다. 실행 중에 FBX를 읽지 않는다.
- 점프와 사망 클립은 넣지 않는다. 사망은 래그돌이 담당한다.

## 2. 제자리 처리와 발 미끄러짐

- 루트 이동이 있는 클립은 Hips의 수평 이동만 빼서 제자리 클립으로 만든다. 위아래 출렁임은 남긴다.
- 빼기 전에 한 주기의 이동 거리로 각 클립의 원래 속도를 재서 저장한다.
  - 재생 속도 = 실제 이동 속도 ÷ 클립 원래 속도.
  - 배율 허용 범위는 0.7–1.4(튜닝)다. 이 범위를 넘으면 걷기 ↔ 뛰기 클립으로 바꾼다.
- 몸 방향 대비 이동 방향으로 8방향 클립을 섞는다. Pro Rifle Pack의 걷기·뛰기·전력질주·앉아 걷기가 8방향이다.
- 발이 땅을 디딘 구간의 발 미끄러짐을 측정해 보고한다.

## 3. AI 상태별 클립 연결

AI 판단 로직은 바꾸지 않는다. 기존 상태에 클립만 붙인다.

| 기존 상태 | 클립 |
|---|---|
| 서서 대기 | `idle` |
| 서서 조준 | `idle aiming` |
| 앉기 / 앉아 조준 | `idle crouching` / `idle crouching aiming` |
| 걷기(투입·이동) | `walk *` 8방향 |
| 앉아 이동 | `walk crouching *` 8방향 |
| 제자리 회전(있으면) | `turn 90 left/right`, 앉았으면 `crouching turn 90` |
| 사격 | `fire_single_stand`를 발사 1회마다 상체 반동으로 덧씌움 |
| 장전 | 서서는 `reload_stand`, 앉아서는 `reload_kneel` |

- 장전 클립은 기존 AK 장전 시간에 맞춰 재생 속도를 조절한다.
  - 기존 장전 시간은 빈 탄창 3.498 s, 전술 장전 2.648 s다.
  - 탄 수가 바뀌는 시점은 기존 그대로 둔다.
  - Mixamo 장전은 AK 전용 동작이 아니므로 대장에 "근사"로 적는다.
- 앉은 자세와 무릎 장전 자세의 차이가 커서 어색하면 억지로 맞추지 말고 보고한다.
- 지금 AI가 쓰지 않는 동작은 클립만 내장해 두고, 다음 AI 고도화(P3)에서 쓴다.
  - 해당 클립: 뛰기, 전력질주, 무릎 쏴 관련(`stand_to_kneel`, `kneel_idle`, `kneel_to_aim`), 이동 사격(`walk_fire_forward`), 옆걸음.
- 클립 사이 전환 혼합 시간은 0.15–0.25 s(튜닝)다.

## 4. 총과 손

- 총은 지금처럼 오른손에 붙는다.
- 왼손은 기존 팔 IK로 핸드가드에 붙인다.
  - 장전 중에는 왼손 IK를 풀어 클립 동작을 따른다.
  - 탄창이 빠지는 연출은 이번에 하지 않는다.
- 조준 중에는 AI가 노리는 방향으로 총구가 향하도록, 클립 위에 상체(몸통·가슴) 조준 보정을 얹는다.
- 탄의 발사 원점과 방향 계산은 바꾸지 않는다.
  - 화면의 총구 방향과 실제 탄 방향이 어긋나는 각도를 재서 보고한다.
  - 2°(튜닝)를 넘으면 탄 계산이 아니라 조준 보정 쪽을 고친다.

## 5. 피격 판정과 래그돌

- 몸 판정 영역(21개 부위와 내부 해부)이 새 자세에서도 몸에 맞게 붙는지 확인한다. 앉기, 장전, 회전 자세를 시트로 남긴다.
- 쓰러질 때 근력 래그돌의 목표 자세는 고정된 걷기 클립이 아니라 쓰러지는 순간 재생 중이던 클립(혼합 결과)으로 한다.
  - 이동 중이면 그 이동 클립을 계속 재생한다.
  - 멈춰 있으면 마지막 자세를 유지한다.
- v36의 7개 시나리오를 새 클립으로 다시 돌려 v36과 나란히 보고한다. 기준은 v36과 같다.

## 6. 용량

- HTML이 얼마나 늘었는지 보고한다.
- 실행 zip은 20 MB 미만을 유지한다.
  - 빠듯하면 zip에서 검증 이미지와 기록부터 빼서 따로 보관한다.
  - 게임 HTML의 자산은 줄이지 않는다.

## 7. 검증

- 상태별 0.1 s 간격 시트를 남긴다.
  - 대상: 서기, 조준, 앉기, 회전, 사격, 장전, 걷기(앞·옆·뒤).
- 다음 수치를 잰다.
  - 발 미끄러짐(디딘 구간의 발 수평 속도)
  - 발이 바닥에 파고드는 깊이
  - 총구와 탄 방향의 각도 차이
  - 왼손과 핸드가드 사이 거리
- 실제 투입 플레이를 한 번에 시트로 남긴다. 문으로 들어오기 → 조준 → 사격 → 장전 → 피격 → 쓰러짐까지다.
- 성능은 기존 방식으로 본다. 투입·첫 사격·쓰러짐이 평소 프레임 대비 1.5배 이하여야 한다.
- 기존 회귀 검사를 그대로 돌린다. 전체 테스트, 2D baseline 바이트 비교, 600틱 비교, 두 화면 오프라인 실행이다.
