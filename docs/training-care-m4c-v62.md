# M4c/v62 — 손 동작과 고정 처치 시간

v61 `5eeffa97d950586c8c5fea5a5cff09549d3792fc` 위의 3D 변경이다. 손 동작에만 부상 배율을 적용한다. 거즈 압박·수혈 주입·약효 시작·OTFC 용해는 해당 모드의 고정 시간이다. 현실 압박은180초다. 채우기와 압박의 경계를 한 틱이 넘어도 각각의 속도로 계산하며, 중단/재개와 남은 시간 표시도 같은 규칙을 쓴다.

부상 배율은 게임1.2/리얼리스틱1.5, 한 손 포함 총1.5/2.2로 제한한다. 현실의 곱셈 순서와 손 동작 시간은 v61 그대로다. 등 씰의 위치 배율은 부상 상한을 적용한 뒤 별도로 곱한다.

현재 v61의 실효 시간은 리얼리스틱 바늘4.8초·TXA8초·폼12초였다. 이번 명시값을 우선하므로 바늘은4.8→8초로 늘고, TXA/폼은 이미 맞던 값을 유지한다. 게임 시간은 모든 단계에서 리얼리스틱의 변경 비율 이하로 정했다. 현실 이외 시간은 게임 허용이며 임상 실측값이 아니다.

한 손으로 실제 누른 시간 비율만큼 **완료 압박 효과**를 최대2%포인트 약화한다(튜닝). 게임은 약화하지 않는다. 완료 시 잔여 계수는 `원래 계수 + (1−원래 계수)×0.02×한 손 압박시간/고정 압박시간`이다. 두 손과 기존 기록은 원래 값을 그대로 반환한다. 현실 동맥 계수0.03→0.0494, 리얼리스틱0.00005→0.020049, 게임0 유지. 누르는 중의 수동 압박 계수는 그대로다.
