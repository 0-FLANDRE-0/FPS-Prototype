# S0: 부위별 피격 시험장 + 뇌·심장 손상

v37 위에서 작업한다. 애니메이션, 래그돌 물리, 탄도·관통·방호 수식은 이번에 건드리지 않는다.

## 0. 원칙 변경: 3D 의료를 2D에서 분리

이번부터 3D 의료는 2D 원본과 따로 간다. 브리프 2-4항과 Q·R의 "2D 수식 무수정" 원칙을 다음으로 바꾼다.

- 3D 의료(medical-v2)는 3D 전용 모듈이다. 출처를 달고 근거가 있으면 수식을 바꿀 수 있다.
- 2D 원본 `src/**`는 3D 작업에서 수정하지 않는다. 2D baseline 바이트 비교는 계속 돌린다.
- legacy 모드는 남겨 두되, 3D 변경을 막는 기준으로 쓰지 않는다.
- 3D에서 바꾼 항목은 대장에 계속 기록하고, 각 항목에 `2D 역이식 후보: 예/아니오`를 붙인다. 역이식은 사용자가 따로 지시할 때만 한다.
- 출처/원본/튜닝 구분, 정직한 보고, 지어낸 수치 금지는 그대로다.

브리프의 해당 항목도 이 내용으로 고친다.

## 1. 증상 (사용자 플레이)

- 뇌 판정이 노란색(피격)으로 강조됐는데도 적이 계속 서 있는 경우가 있다.
- 심장을 관통당했는데 오래 서 있는 경우가 있다.
- 머리에 맞고 사는 경우가 있다. 다만 얼굴만 맞거나 헬멧이 막은 경우라면 정상일 수 있으니 구분해야 한다.

참고: R2-4e에서 "뇌 손상 모델"을 범위 밖으로 뒀다. 뇌 교차가 기록만 되고 생리 효과로 이어지지 않을 가능성이 높다. 추측하지 말고 2번 진단으로 확인한다.

## 2. 진단 (코드 변경 전에 먼저)

실제 게임 경로(`traceShot` → 몸 판정 → 몸속 레이어 → 의료 → 쓰러짐 요약 → 래그돌)로 뇌 관통과 심장 관통을 재현한다. 그리고 각 단계의 값을 기록해 어디서 끊기는지 보고한다.

1. 맞은 몸속 도형과 통과 길이
2. 생성된 상처, 2D 식별자, 손상 타입
3. 바뀐 의료 필드: 부위 외상 HP, 의식 목표값, transientNeurologicDisruption, 심박출량·MAP, 출혈률
4. downed, 의식불명, 심정지 시각과 원인 코드
5. 쓰러짐 요약 인터페이스에 그 값이 전달됐는지

## 3. 부위별 피격 시험장

고정 표적(적 병사 모델, 서기·조준 자세)에 부위별로 쏘고, 아래 항목을 시간순으로 기록한다. 이 시험장은 계속 쓰는 회귀 시험으로 남긴다.

- **탄:** 5.45×39 7N6, 5.56×45 M855
- **거리:** 5 m, 50 m
- **방호:** 없음 / 기본 장비(6B45·Granit Br4·6B47)

| 표적 | 무엇을 보나 |
|---|---|
| 대뇌 관통 | 즉시 무력화 여부 |
| 뇌간 관통 | 즉시 무력화, 호흡·순환 정지 |
| 얼굴·턱만(뇌 교차 없음) | 즉시 무력화되지 않아야 함, 기도 위험 |
| 헬멧 정지 / 헬멧 스침 | 관통 여부, 몸 손상 없음 확인 |
| 심장 관통 | 무력화까지 걸린 시간 |
| 대동맥 | 무력화까지 걸린 시간 |
| 폐만 | 기흉 경로, 즉시 무력화 아님 |
| 간 | 출혈 경로 |
| 대퇴동맥 | R2 결과와 같은지 |
| 대퇴골 | 즉시 서지 못함, 의식 유지 |
| 척수 A / B 구간 | R2 결과와 같은지 |
| 팔·다리 근육만 | 무력화 없음 |

기록 항목:
- 교차 도형
- 상처
- 0.1 s 간격의 의식, MAP, 심박출량, 출혈률
- downed / 의식불명 / 심정지 시각과 원인
- 같은 상황 실제 플레이에서 쓰러지기까지 걸린 시간

수정 전과 후를 같은 표에 나란히 남긴다.

## 4. 기대 기준과 출처

아래는 기대 경향이다. 작업 전에 각 출처를 직접 열어 확인하고, 수치를 쓸 때는 원문 위치를 적는다. 확인하지 못한 것은 "설계 기대"로 표시한다.

- **대뇌·뇌간 관통:** 소총탄이 뇌를 관통하면 즉시 무력화된다. 닫힌 두개골 안에서 일시공동의 압력이 빠질 곳이 없어 손상이 크다. 뇌간은 즉시 호흡·순환 정지로 간다.
  - 출처 후보: DiMaio, *Gunshot Wounds*(뇌 총상 장), *Emergency War Surgery* 5th US Revision(2018, Borden Institute)의 탄도·두부 외상 장.
- **심장 관통:** 즉시 쓰러지지 않을 수 있다. 심장 기능이 멈춰도 뇌에 남은 산소로 약 10–15초 동안 의지에 따른 행동이 가능하다는 기준이 있다.
  - 출처 후보: Patrick, U.W., *Handgun Wounding Factors and Effectiveness*, FBI Firearms Training Unit, 1989.
  - 뇌혈류 차단 뒤 의식 소실 시간은 Q1-c에서 찾던 Rossen·Kabat·Anderson(1943)을 같이 확인한다.
  - 따라서 심장 관통 기대치는 수 초–약 15 s 안에 의식 소실·쓰러짐이다. 수십 초 이상 서 있으면 미달이다.
- **대동맥 등 흉강 대혈관:** 심장보다 약간 느리거나 비슷하다. 범위를 출처로 찾지 못하면 설계 기대로 둔다.
- **얼굴·턱(뇌 교차 없음):** 즉시 무력화가 아니다. 기도 위험 경로(R2-3)로 간다.
- **대퇴골 골절:** 체중을 못 버텨 바로 쓰러지지만 의식은 있다. 사격 가능 판정은 기존 식을 따른다.
- **나머지(폐, 간, 대퇴동맥, 척수, 근육):** Q·R·R2의 기존 기대를 유지한다.

## 5. 수정

2번 진단에서 끊긴 곳을 고친다. 최소 범위는 다음이다.

### 5-a 뇌 손상
- 대뇌 도형과 교차하면 의식을 즉시 0으로 보낸다. downed 원인은 새 코드 `brain_injury`다.
- 손상 정도(통과 길이 등)에 따른 사망 시간은 이번에 정하지 않는다. 기존 경로(심정지 → `ARREST_TO_DEATH_S`)를 따르되, 뇌 관통의 심정지 진입 조건을 출처나 튜닝으로 정해 대장에 적는다.
- 뇌간 도형과 교차하면 즉시 의식 0이고, 호흡과 순환이 정지한다. 심정지 원인은 `brainstem_injury`다.
- 뇌 교차가 없는 머리 피격(얼굴, 턱, 두피, 헬멧)은 이 경로를 타지 않는다.

### 5-b 심장 손상
- 심장 교차를 출혈로만 처리하고 있다면, 심박출량(펌프 기능) 저하 항을 추가한다.
- 통과 길이와 손상 정도에 따라 펌프 기능을 줄인다. 크게 손상되면 거의 0이 된다.
- 그러면 뇌 관류가 떨어지고, 기존 Q2 의식 곡선이 4번 기대 시간 안에 의식을 떨어뜨려야 한다. 그래도 못 맞추면 의식 경로 쪽을 최소로 고치고 이유를 적는다.
- 펌프 기능 저하량은 튜닝이다.

### 5-c 쓰러짐 연결
- 새 원인 코드도 기존 쓰러짐 요약 인터페이스(의식, 팔다리 기능, downed)로만 래그돌에 전달한다.
- 뇌·뇌간은 의식 소실 쓰러짐(손 짚기 없음)이다.
- 심장은 의식이 남아 있는 동안 서 있거나 움직일 수 있고, 의식이 떨어질 때 쓰러진다.

## 6. 이번에 하지 않는 것

- 일시공동, 탄종별 상처 모양, 장기별 계수(다음 S1에서 한다)
- 피격 순간 자세 흔들림, 심리적 쓰러짐
- 치료, 소생술
- 탄도·관통·방호 수식

## 7. 검증

1. 3번 시험장 표를 수정 전과 후로 비교한다. 4번 기대에서 벗어난 항목을 표시한다.
2. 실제 플레이로 재현한다.
   - 적 뇌 관통: 1 s 안에 쓰러짐 시작
   - 적 심장 관통: 4번 기대 범위 안에 쓰러짐
   - 얼굴만 맞은 경우: 즉시 쓰러지지 않음
3. 플레이어(P01)도 같은 경로를 쓰는지 확인한다. 뇌 피격이면 즉시 시야와 조작을 잃는 쪽으로 처리한다.
4. 기존 불변 조건을 유지한다. Q의 6개, R·R2 검증 항목, 근육 상처 비치명, 주요 동맥 치명이다.
5. 기존 회귀 검사를 돌린다. 전체 테스트, 2D baseline 바이트 비교, 600틱 비교, 두 화면 오프라인 실행이다.
6. 대장에는 새 원인 코드, 펌프 기능 항, 뇌 경로 조건, 출처 원문 위치, `2D 역이식 후보` 표시를 남긴다.
