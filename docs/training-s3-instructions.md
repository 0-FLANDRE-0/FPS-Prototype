# S3: 물리 피해 통일·부위 HP·5.56/5.45 세팅

v40 위에서 작업한다. 3D 의료는 2D와 분리된 상태다. 바꾼 항목은 대장에 출처/원본/튜닝/사용자 설계값과 `2D 역이식 후보`를 표시한다.

## 배경

v40 HP 보정 표에서 탄 위력이 두 번 들어갔다. 지금 식은 `레지스트리 데미지 × 조직 배율 × m`이다. 레지스트리 데미지(2D 게임 수치)와 m(공동 모델의 실제 손상)이 둘 다 탄 위력을 담는다. 그래서 PS가 허벅지에서 7N6보다 2.7배 세게 나왔고, 7N6 복부는 M855보다 8배 약하게 나왔다.

이번에는 5.56·5.45 탄의 몸 피해를 공동 모델 하나로 통일한다. 다른 구경은 이번에 손대지 않는다.

## 1. 부위 HP 변경 (사용자 설계값)

| 부위 | 기존 | 변경 |
|---|---:|---:|
| 가슴 | 85 | 240 |
| 복부 | 70 | 180 |
| 팔(각각) | 60 | 100 |
| 다리(각각) | 65 | 120 |
| 머리 | 35 | 85 |
| 목 | 기존값 | 60 |

- HP 0의 의미(S2)는 그대로다. 팔다리는 기능 0, 머리는 구조 파괴 기록만(생사는 뇌), 가슴·복부는 `torso_destroyed` 심정지, 목은 기존 효과다.
- 의료 탭 등 HP 표시도 새 값으로 바꾼다.

## 2. 물리 피해로 통일 (5.56·5.45만)

- **HP 감소 = 그 부위의 유효 손상량(cm³) × 공통 환산 계수 C(HP/cm³)**
  - 유효 손상량은 S1·S2 값 그대로다(영구 공동 + 파편 + Σ조직 계수×순간 공동 + 뼈 조각).
  - C는 전체 공통 하나다. 부위별 계수는 만들지 않는다.
- 5.56·5.45 탄은 HP 계산에서 레지스트리 `damage`·`tissueDamageMul`·m을 쓰지 않는다. m은 표시·기록용으로만 남긴다.
- 다른 구경 탄은 v40 식을 그대로 쓰고, 탄약표와 대장에 `미보정`으로 표시한다. 두 식이 섞여 있는 동안의 위력 차이는 보고만 한다.
- 레지스트리 데미지를 방호구 손상 등 다른 데서 쓰고 있으면 그대로 둔다. 어디서 쓰는지 목록으로 보고한다.
- 분쇄·절단 문턱, 장기 심각도, 출혈·생리 경로는 바꾸지 않는다.

### 2-a C 정하기

M855, 5 m, 무방호 기준으로 아래 목표에 가장 잘 맞는 C 하나를 찾는다. 각 부위는 대표 경로 여러 개(정면, 측면, 비스듬히)의 범위를 쓴다.

| 부위 | 목표 |
|---|---|
| 가슴 | 4–6발에 HP 0 |
| 복부 | 4–6발에 HP 0 |
| 팔(근육만, 뼈·주요 혈관 교차 없음) | 2–3발 |
| 다리(근육만, 뼈·주요 혈관 교차 없음) | 2–3발 |
| 머리 | 1–2발 |

C 하나로 다 맞지 않으면 억지로 맞추지 않는다. 어느 부위가 얼마나 벗어나는지 보고한다. 부위별 보정은 사용자가 정한다.

## 3. 탄별 설정: 원본 분류 + 유형 기본값

탄마다 개별 물리 자료를 조사하지 않는다. 2D 원본 `AMMO_TERMINAL_EFFECT`의 **유형(type)과 문턱 속도(thresholdVelocity)**를 그대로 읽고, 유형별 기본 동작을 하나씩 둔다. 탄별 차이는 레지스트리의 질량·구경·속도와 원본 문턱이 만든다. 원본 값은 수정하지 않는다.

### 3-b 유형별 기본 동작

| 원본 유형 | 회전 | 파편화·변형 | 기준 |
|---|---|---|---|
| yaw (5.45) | 7N6 도판 회전 깊이 | 없음 | 7N6 도판 |
| yaw (5.56) | M193 도판 회전 깊이 | 없음 | M193 도판 |
| fragment | M193 도판 | 문턱 이상이면 M193 도판 방식으로 파편화 | M193 도판 |
| controlled_fragment, barrier_blind | M193 도판 | 문턱 이상이면 파편화(fragment보다 일정하게) | M193 차용·튜닝 |
| penetrator, small_caliber_ap | 늦게 | 없음, 공동 작게 | 튜닝 |
| expand | 바로 | 문턱 이상이면 단면 확대, 이하면 yaw처럼 | 튜닝 |
| frangible | 바로 | 문턱 이상이면 얕은 깊이에서 분해 | 튜닝 |
| subsonic_standard | yaw와 같음 | 없음 | 낮은 속도로 저절로 약해짐 |

- 탄두 길이는 개별 조사하지 않는다. 옆으로 누운 단면 계산에만 쓰므로 "구경 × 유형별 평균 길이비"(튜닝)로 둔다.
- 심재 비율, 피갑 두께는 쓰지 않는다.
- 각 탄에 자료 등급을 붙인다. `plate`는 7N6·M193, `family`는 같은 구경의 도판 차용, `estimate`는 튜닝 기본값이다.

### 3-c M855

- 원본은 `yaw / 760`이다. 이번에는 원본대로 yaw로 둔다.
- 교범(EWS)은 M855를 M193과 비슷한 패턴(파편화 포함)으로 설명한다. 원본 설명문도 "100 m 이내 yaw 효과가 일관되지 않다는 비판"을 적고 있다.
- M855의 근거리 파편화 자료(공식·학술)를 찾아 보고만 한다. 유형 변경 여부는 사용자가 정한다.

## 4. 7N6 복부 이상값 확인

v40에서 7N6 복부 한 발 감소(3.457)가 M855(28.065)의 약 1/8이었다. 원인을 찾아 보고한다.
- 후보: 왼팔을 먼저 지나는 경로, 팔에서 이어받은 회전, m 바닥 0.1, 장기 교차 차이 등
- 버그면 고친다. 모델상 맞는 결과면 근거를 적는다.
- 팔을 거치지 않는 복부 정면 경로로도 비교한다.

## 5. 탄약표 피해 지수

디버그 AK 탄약표에 열을 추가한다. 값은 게임과 같은 모델로 로드할 때 자동 계산하며, 25종만 계산한다. 나머지 탄은 지수 칸을 비우고 `미보정`으로 표시한다.

| 열 | 정의 |
|---|---|
| 근거리 피해 지수 | 10 m 입사 속도로 표준 근육 등가 젤라틴 블록에 쏴서, 처음 30 cm 안의 유효 손상량. M855 = 100 기준 |
| 원거리 피해 지수 | 300 m 입사 속도로 같은 계산 |
| 회전 시작 깊이 | cm |
| 파편화·변형 | 함/안 함, 멈추는 거리(대략) |
| 총 관통 깊이 | 같은 블록에서 정지 깊이 |
| 자료 등급 | `plate` / `family` / `estimate` |
| 원본 데미지 | 회색 참고 표시. 몸 피해에 쓰지 않는다고 표시 |

## 6. 하지 않는 것

- 5.56·5.45 외 탄의 설정 변경
- 탄별 물리 자료 조사(M855 보고 제외)
- traceShot 성능 최적화, 산탄 펠릿 분리
- 디버프, 치료, 절단 화면 표현
- 벽·방호·외부 비행 수식, 2D 원본 값

## 7. 검증

1. **HP 보정 표:** 25종 중 M855, M193, 7N6, 7N22, 7N24, M995, 5.56 HP, 5.45 HP, 7U1으로 5/50/100 m에서 부위별 한 발 감소량과 HP 0까지 발 수를 낸다. 2-a 목표 충족 여부와 C 값을 보고한다.
2. **장기 경로와 비교:** 같은 조건에서 장기 손상만으로 쓰러지거나 심정지하는 시간을 낸다.
3. **4번 결과:** 7N6 복부 원인과 처리.
4. **지수 상식 확인:**
   - M855 근거리 > M855 원거리
   - 철갑(penetrator, small_caliber_ap)은 공동 작고 관통 깊음
   - expand는 근거리 공동 크고 관통 얕음
   - 7U1은 낮음
   - 결과 표를 첨부한다.
5. **젤라틴 재현 유지:** 7N6·M193 도판 결과가 S1·S2와 같다.
6. **S0 시험장 240개 재실행:** 심장 7–15 s, 대동맥 약 30 s 유지 여부와 v40 대비 변화.
7. **실제 플레이:** 디버그 AK로 M855, 7N6, 7N24를 같은 위치에 쏴서 HP 감소가 표와 같은지 확인한다. 의료 탭의 새 HP 표시도 확인한다.
8. **성능:** 피격당 계산 시간과 1200 RPM 부하 시험.
9. **기존 회귀 검사:** 전체 테스트, 2D baseline 바이트 비교, 600틱 비교, 두 화면 오프라인 실행, Q·R·R2·S0 불변 조건.
