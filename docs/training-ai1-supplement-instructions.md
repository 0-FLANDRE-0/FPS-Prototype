# v33 적용 지시와 후속 정정

사용자 요청: v32 위에서 쓰러짐 순간 끊김을 줄이고 병사 손가락 뼈/스키닝과 AK 그립을 구현한다. 다른 동작·피격 판정·의료 수식은 유지한다.

A: 투입 시17강체/16관절/콜라이더 사전 생성, 충돌 제외된 위치 기반 kinematic으로 뼈 추종, 쓰러짐 때 dynamic/두 틱 속도 인계. 추가 솔버32회를4–8부터 줄여 시험, CCD는 손·발·하퇴·머리. 정착 시 슬립/동기화 생략/피격 깨우기. `renderer.compile` 예열. v32 대비 fall/물리/렌더 ms와 전후10초 최대/중앙값·정착 비용 기록, 쓰러짐≤중앙값2배 목표.

B: 파생 GLB에 손당5×3=15개, 총30개 손가락 뼈 추가(24→54). 실제 형상 분할·마디/부드러운 가중치, 손바닥/손등 기존 손 뼈, 원본 GLB 보존. 분할 불가능하면 사실을 보고하고 그립 모프 대안을 사용. 뼈 이름/축/파일 크기 및 정면·측면·손 확대/쓰러진 손 화면 기록.

후속 정정1: 새 고정 그립을 만드는 요청을 철회. 공통 FPS AK Idle의 손가락 로컬 회전과 사격 검지 동작을 재사용하며 리그 기준축을 보정한다. 끝점 보정은 마디당 최대15° 튜닝. 손목·손바닥은 기존 AK 마커/공통 손 기준 방향. FPS 손 메시를 병사에 붙이지 않는다. 같은 각도의 FPS/적 손 비교 화면 추가.

후속 정정2: 래그돌 손가락 움직임/물리를 요구하지 않는다. 손가락은 손에 고정한다. 적용 해석은 기존 손 강체/손목 관절 유지, 손가락 강체/물리 관절0, 쓰러짐 시 이완 로컬 자세에 즉시 고정이다. 원래0.3초 이완 전환은 이 정정으로 대체한다.

결과 ZIP은 기존 배포 규칙대로20MB 미만, 출처/원본/튜닝 대장과 GitHub 불변 다운로드를 남긴다.
