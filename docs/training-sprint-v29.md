# v29 — 달리기 버튼·조이스틱·FPS 팔

작업 브랜치: `codex/mobile-3d-training-prototype`. v28의 광학·텍스처 경량화 위에 달리기를 추가했다. GitHub Actions 없이 로컬에서 빌드·검증·포장한다.

## 조작

- 이동 패드 위의 **달리기** 버튼은 달리기 입력을 켜고 끈다. 정지 중에는 `달리기 대기`, 이동 중에는 `달리는 중`으로 표시한다. 버튼으로 켜면 조준·앉기를 해제한다.
- 터치 패드를 전방으로 **88% 이상** 밀면 자동 달리기, **72% 이하**로 내리면 걷기. 사이 구간에서는 직전 상태를 유지해 경계에서 깜빡이지 않는다. 손을 떼거나 입력이 취소되면 자동 달리기를 해제한다.
- 자동 달리기 중 버튼으로 끄면 패드를 내렸다 올리기 전까지 자동으로 다시 켜지지 않는다. 키보드/버튼 달리기만 끈 경우에는 새로운 조이스틱 입력을 막지 않는다.
- PC는 **왼쪽/오른쪽 Shift 유지** 또는 화면 버튼 전환. 전진·전진 대각선에 적용하며 옆걸음·후진·정지에는 속도를 올리지 않는다.
- 조준·사격·앉기·장전·무기/부착물 동작 중에는 걷는다. 조작 후 달리기 입력이 남아 있으면 재개한다. 인벤토리·일시정지·화면 이탈·초기화에서는 달리기 입력과 예약 사격을 비운다.
- 달리는 중 짧은 사격 입력은 총을 다시 올린 뒤 한 번 발사한다. 터치 취소는 이 예약도 취소한다. 이동 손가락과 조준/앉기/장전/시점 손가락은 독립적으로 유지된다.

## 이동·자세

완전한 입력의 달리기 속도는 **5.4 m/s**, 걷기 2.7 m/s, 앉기 1.5 m/s. 아날로그 입력 크기를 유지하며 대각선으로 속도가 늘지 않는다. Rapier 충돌 이동과 기존 가감속을 사용한다. 애니메이션과 HUD는 실제 충돌 결과의 이동 속도를 읽는다.

제공된 AK 원본에 `Rig|AK_Run`(약 0.398초)이 있다. M4A4 팔 원본에는 Reload/Shoot/Take/Hide만 있고 별도 Run은 없다. AK Run의 총기 회전·주기적 이동을 공통 팔에 전달했다. M4는 M4A1 외형과 자체 손 접점·M4 손 자세를 유지하며 같은 Run 동작을 보정해 사용한다. AK는 기존 Idle/Walk/Run 및 손가락 전환도 유지한다.

원본의 높은 준비 자세를 현재 렌즈·어깨 좌표에 그대로 적용하면 팔이 화면을 가렸다. 총기별 개머리판을 회전축으로 삼고 원본 회전 50%, 피치 보정 −0.98 rad를 적용해 **총을 낮춰 드는 달리기 자세**로 맞췄다. 원본 이동은 첫 Run 프레임 대비 상대 흔들림만 사용한다. 팔 길이·손 연결·공통 메시를 유지하고 원본 머리/카메라 동작은 적용하지 않는다. 자세는 고정 시간 간격으로 부드럽게 전환하며, 총구의 논리 위치와 렌더 위치에 같은 변환을 적용한다.

보행 위상과 발걸음 충격도 실제 달리기 상태에 연결했다. 속도·입력 경계·회전 보정·발걸음 주기는 **게임 조정값**이다. 지구력 소모·보폭 모션 캡처·움직이는 적 캐릭터는 이번 범위에 없다.

## 자산·기존 기능

새 GLB·텍스처·중복 팔 자산은 추가하지 않았다. v28의 실제 내장 7개 자산을 그대로 사용한다. Run 샘플러는 기존 AK의 뼈 노드를 별도로 평가하고 메시·텍스처를 복제하지 않는다. 렌더되는 공통 팔은 하나다. 원본 CQB `src/**`, 탄도·관통·방호·의료·반동·네이티브 장전 시간 및 광학 구현은 유지했다. H01은 계속 A자 고정 표적이다.

## 검증과 실행

자동 검사: `npm test`, `npm run verify:baseline`.

브라우저 검사:

```sh
node scripts/check-training-sprint-regression.mjs
node scripts/check-training-sprint-offline.mjs
node scripts/check-training-sprint-transitions.mjs
CQB_OFFLINE_OUT=downloads/checks-sprint-v29-optics node scripts/check-training-w-offline.mjs --flight --optic --lens --side-optics
```

- 원본/v28 비교: 600틱 이동·6발 사격의 시점/총구/반동/보행/충격 일치, 플레이트 저지·노출 팔·6B47 의료 결과 일치.
- 두 총기·두 화면 크기의 72자세에서 손 연결·어깨 끝 노출·근접 클리핑·반복 샘플 및 네이티브 장전 4종을 검사한다.
- 외부 통신을 막은 최종 HTML에서 실제 키보드와 여러 터치 손가락으로 자동 전환·버튼 취소·Shift·조준·앉기·장전·짧은 단발·입력 취소·일시정지를 검사한다. 기존 장거리·광학 장착/분리·확대 조작도 확인한다.
- 두 총기의 연속 고정 틱에서는 실제 터치 취소로 예약 사격이 취소되는지, 짧은 단발이 총을 올린 뒤 한 번 나가는지, 달리기/조준/장전 전환의 손 접점·총구 위치가 이어지는지도 확인한다. [전환 기록](../downloads/checks-sprint-v29-offline/transitions.json).
- 검사 결과는 [회귀](../downloads/checks-sprint-v29-regression/report.json), [달리기 조작](../downloads/checks-sprint-v29-offline/report.json), [기존 조작/광학](../downloads/checks-sprint-v29-optics/report.json), [최종 검증](../downloads/verification-sprint-v29.json)에 기록한다.

검증 환경은 Linux Chromium/SwiftShader, 844×390 및 1280×720이다. Android/iOS 실기기·지속 FPS는 측정하지 않았다. 광학의 영점/탄종별 BDC 등의 기존 제한과 자산 출처는 [v28 문서](training-side-optics-v28.md) 및 내장 크레딧에 있다.

실행 ZIP을 풀고 `dist/CQB_Training.html`을 브라우저에서 연다. HTML에 모델·텍스처·WASM이 내장되어 있다. [빌드 정보](../downloads/training-build-info-sprint-v29.json), [GitHub 재다운로드 확인](../downloads/delivery-sprint-v29.json). 증거 이미지와 중복 GLB는 실행 ZIP에서 제외하고 저장소에 보존한다.
