# RG1: 래그돌 렉·시체 관통·시체 고정

AI1 빌드 위에서 작업한다. 3D는 2D와 분리된 상태다. 2D 원본은 바꾸지 않는다. 바꾼 항목은 대장에 출처/원본/튜닝/사용자 설계값/게임 허용과 `2D 역이식 후보`를 표시한다.

**이번에는 Rapier 버전을 올리지 않는다.** 지금 버전 안에서 고친다. 버전 업 가능성은 8절 조사만 한다.

## 사용자 제보

1. 적이 죽어서 늘어지는 동안 렉이 계속된다.
2. 시체에 다가가 비비면 시체가 튕기면서 **몸 전체가 바닥을 뚫고 내려가** 심하게 떨리고 렉이 걸린다.
3. 손만 바닥에 걸친 채 걸려 있으면 나아진다.

## 추정 원인 (검수 담당, 코드로 확인할 것)

- **솔버 반복:** v36 기록에서 래그돌에 추가 솔버 반복 64회를 걸었다. 이 설정은 연결된 물리 덩어리 전체에 걸린다. 쓰러지는 동안의 렉에 크게 기여할 가능성이 높다.
- **관절 늘어짐:** 끈 관절(impulse joint)이 큰 힘·질량 차이에서 늘어나고, 솔버가 이를 맞추려고 계속 돈다.
- **플레이어가 시체를 짓누름:** 플레이어 이동 캡슐은 물리상 질량이 무한대다. 비비거나 올라타면 시체를 얇은 바닥 판정(0.3 m) 아래로 밀어 넣는다. 바닥 밑에서 관절과 바닥 접촉이 서로 싸우며 떨리고 계산이 폭주한다.
- **잠들지 않는 시체:** 미세하게 떨면서 물리·근육(PD) 제어·판정 도형 갱신이 계속 돈다.

작업 전에 위 추정이 실제 코드와 맞는지 확인하고, 다르면 실제 원인을 보고한다.

## 1. 먼저 측정

고치기 전에, 다음 단계별 프레임 시간을 잰다. 1280×720과 844×390 둘 다:
- Rapier 스텝, 근육(PD) 제어, 뼈 동기화, 스키닝, 몸속 판정 도형 갱신, 렌더

**측정 장면**
- 적 1명 사망 → 쓰러짐 → 정지
- 적 4명 동시 사망
- 플레이어가 시체에 30 s 비비기·올라타기

## 2. 플레이어가 시체를 밀지 않게

- 플레이어 이동 캡슐과 래그돌(시체·쓰러진 적) 사이 충돌을 끈다(충돌 그룹 또는 필터). 플레이어는 시체를 밟고 지나간다. 짓누르는 힘 자체를 없앤다.
- 바닥에 떨어진 장비·무기(M6)는 기존 충돌을 유지한다.
- 플레이어 자신의 래그돌(v52)에도 같은 문제가 없는지 확인한다.

## 3. 시체 고정 (렉 감소의 핵심)

- **고정 조건:** 래그돌 모든 조각의 선속도·각속도가 문턱 아래로 일정 시간(예: 1 s, 튜닝) 유지되면.
- **고정하면**
  - 현재 자세를 그대로 굳힌다(고정·키네마틱 또는 물리 몸 비활성화, 시각 자세는 유지).
  - 근육 제어, 추가 솔버, 몸속 판정 도형 매 프레임 갱신을 멈춘다.
  - 판정 도형은 굳힌 자세로 한 번 갱신하고 유지한다.
- **깨우기**
  - 총에 맞으면 다시 물리를 켜고 충격을 준 뒤 다시 정지·고정을 기다린다.
  - 플레이어 접촉으로는 깨우지 않는다.
- **고정된 시체에서도 그대로 되어야 하는 것:** M7 수색, M6·M7 헬멧·리그 벗기기, 플레이트 창. 메시 분리는 시각 처리라 영향이 없어야 한다.
- **동시 활성 래그돌 상한:** 예: 2구(튜닝). 넘으면 가장 오래된 것부터 빨리 고정한다.

## 4. 솔버 반복 줄이기

- 추가 솔버 64회는 쓰러지기 시작한 짧은 구간(예: 처음 1–2 s, 튜닝)에만 쓴다. 이후 기본값으로 내리고, 3절 고정으로 넘어간다.
- 늘어짐이 심해지면 조각 간 질량·관성 비율(극단적 차이)을 보고하고, 늘어짐을 줄이는 최소 조정을 제안한다. v36의 관성 하한 값은 유지한다.

## 5. 안전장치

- **CCD:** 래그돌 조각에 연속 충돌 감지(CCD)를 켠다(이미 있으면 범위 확인).
- **속도 상한:** 조각 하나가 비정상 속도에 도달하지 않게 상한을 둔다(튜닝).
- **바닥 밑 복구:** 조각이 바닥 콜라이더 아래로 일정 거리 이상 내려가면 감지한다. 바닥 위로 되돌리거나 그 자리에서 고정한다. 발생 횟수를 기록한다.

## 6. 미리 만들어 둔 래그돌

- 플레이어는 구역 진입 때 래그돌을 미리 만든다(v52). 적도 같은지 확인한다.
- 사망 순간에 물리 몸을 새로 만들지 않게, 투입 때 미리 만들어 비활성으로 두고 켜기만 한다.

## 7. 하지 않는 것

- Rapier 버전 업, 멀티바디 관절 전환
- 근육 래그돌의 동작·쓰러짐 판정 변경(v34, 의료 쓰러짐 판정)
- 탄도·관통·방호·의료 식

## 8. 조사만: 최신 Rapier JS의 멀티바디

v36에서 고정 Rapier 0.21 JS 바인딩은 멀티바디 관절에 각도 제한·PD 모터·프레임 설정 함수가 없었고, 범용 관절은 계산 중 터졌다(step trap). 다음만 조사해서 보고한다. **코드는 바꾸지 않는다.**

1. 최신 `@dimforge/rapier3d`(또는 `-compat`) JS에서 멀티바디 관절의 각도 제한·모터·프레임 설정 지원 여부. 공식 문서·변경 이력을 출처로 단다.
2. 현재 버전에서 최신으로 올릴 때 바뀌는 API 목록과 영향받는 이 프로젝트 코드(이동 캡슐, 충돌, 관절, 레이캐스트, 이벤트).
3. WASM 크기 변화(20 MB 제한).
4. 버전 업 시 다시 기준을 잡아야 하는 기존 검증 목록(600틱 비교, 래그돌 시험 등).

## 9. 검증

1. **1절 측정을 고친 뒤 다시** 해서 전후 표를 낸다(두 화면 크기).
2. **비비기·올라타기:** 시체에 30 s 비비기·올라타기를 해도 바닥 관통 0, 떨림 0, 렉 없음. 바닥 밑 복구 발생 횟수.
3. **고정과 깨우기:** 정지 후 고정까지 시간, 고정 시체에 사격 → 깨어나 반응 → 다시 고정.
4. **4명 동시 사망:** 활성 상한, 프레임 시간.
5. **고정 시체 기능:** 수색, 헬멧·리그 벗기기, 플레이트 창이 정상인지.
6. **쓰러짐 모양:** 서기·걷기·앉기 사격 사망을 이전 빌드와 나란히 캡처한다. 늘어짐이 줄었는지 본다.
7. **기존 회귀:** 기존 래그돌 시험(v34·v52 계열), 전체 테스트, 2D baseline 바이트 비교, S0 240조건·684채널, 600틱, 포인터 잠금, 두 화면 오프라인 실행. 래그돌 수치가 바뀌는 시험은 차이와 이유를 표로 낸다.
