# AI-1 보완 v33 — 쓰러짐 비용·공통 AK 손 자세

기준은 v32 `39362cb4b54f57173114f6c77cc8e4e3c0cbeb79`다. 사용자 후속 정정을 반영했다: AK 그립은 새로 만들지 않고 기존 공통 FPS 리그에서 가져오며, 래그돌 손가락은 이완 자세에 즉시 고정한다. 손가락 물리나 0.3초 이완 애니메이션은 넣지 않는다.

## 래그돌

투입 시 17강체·17콜라이더·16관절과 낙하 AK 강체/콜라이더를 만든다. 비활성 상태는 위치 기반 kinematic, 충돌 그룹0·sensor다. 기존 인체 피격 센서를 대신하지 않는다. 매 틱 뼈를 따라가고, 쓰러질 때 객체를 새로 만들지 않고 dynamic으로 바꾼다. 두 틱의 뼈별 선·각속도와 `v_COM = v_bone + ω × (COM − bone)`를 넘긴다. 콜라이더 형상·질량·관성은 사전 생성 값을 유지하고 관절 중립 프레임만 현재 자세로 맞춘다.

추가 솔버는32→8회다.4/6/8의 걷기·조준·앉기 시험에서8회가 세 자세의 정착/슬립 기준을 통과했다. 바닥 접촉 안정화에 기존에 예약돼 있던3mm `contactSkinM`을 적용했다. 이 값은 래그돌 접촉 튜닝이며 탄/인체 피격 형상의 두께가 아니다. CCD는 머리·양 손·양 발·양 하퇴7개에만 적용한다. 마찰1.1·감쇠·질량·ROM·근력0은 v32 값이다.

정착 후 슬립을 허용하고 잠든 래그돌의 뼈/센서/시각 동기화를 생략한다. 추가 피격은 연결된17개 몸을 깨운다. GPU 재질은 투입 시 `renderer.compile`로 준비한다. 최초 동적 솔버/접촉 경로도 별도 Rapier 월드에서 예열하며 실제 게임 월드·시계·의료를 진행시키지 않는다. 투입 비용을 없앤 것이 아니라 쓰러짐 순간에서 옮긴 것이다.

질량은 그대로다: 인체80kg + 원본 보호 장비13.7kg =93.7kg, AK3.6kg을 포함하면97.3kg. 손가락 뼈30개는 질량·강체·관절을 늘리지 않는다. Winter/AAOS 공개 재인용/DSHS 출처와 장비 원본은 [v32 대장](combat-ai1-ledger.json)을 따른다.

## 손

원본 업로드 GLB(9,723,700B, SHA `f38f736aa92ca01564cbc3d6526655fc639677eedd2e0b7f939eb4ca3e0d978a`)는 보존한다. v9/v13/텍스처 정본도 유지하고 최종 내장용 파생본만54본으로 확장한다. 기존24개의 순서·이름·클립 및 그 외 가중치와 원본 토폴로지/UV/노멀/이미지를 보존하며, 손가락과 장갑 끝 연결부984정점의 가중치만 다시 준다. 손바닥·손등은 기존 손 뼈다. 폴리곤과 텍스처는 추가하지 않는다.

1µm 위치 용접 그래프에서 네 손가락의 분리된 말단과 엄지를 확인했다. 네 손가락은 손목부터 전완 방향의 연장축으로70mm 절단, 엄지는 별도 측면/전방 절단으로 분리한다. 관절은 형상 단면 중심을 사용하되45%/75% 마디 분할, 엄지 CMC 배치, 연결부 혼합은 튜닝이다. 손가락을 새로 만들거나 붙이지 않았고 모프 대안은 필요하지 않았다. [형상/뼈 이름/축/가중치](soldier-finger-layout.json).

공통 FPS AK Idle@0와 기존 네이티브 `TriggerOnly` 사격11시점의 손목·손바닥 기준·손가락 로컬 회전을 추출했다. 메타카팔을 제외한 Index/Middle/Ring/Pinky 각3개, Thumb3개를 병사에 대응한다. 손 공간의 회전과 측정한 손바닥 기준 프레임으로 두 리그의 축 차이를 보정한다. 새 AK 그립·검지 안전 자세는 만들지 않는다. 1인칭 메시를 병사에 붙이지 않고, 기존 공통 FPS 리그/애니메이션 코드도 바꾸지 않는다.

손가락 끝의 FK 보정은 마디마다 추출 자세 대비 총15° 이내다(반복마다15°가 아니다). 정지 자세/사격 키 샘플을 배우 생성 시 캐시하고 매 프레임에는 보간/적용만 한다. 두 모델의 손 비례가 달라 공통 FPS 끝점과 정확한 위치 일치를 보장하지 않는다. 손가락별 남은 끝점 오차는 `grip-initial.json`에 기록하며, 이는 총 표면과의 틈 측정값이 아니다. 새끼손가락의 노출 부분은 원본 형상에서 약22mm로 특히 짧다. [공통 리그 추출 원본](soldier-common-ak-grip-source.json), [대응/보정 대장](soldier-ak-grip-ledger.json).

비무장 H01·P01과 쓰러진 적은18/25/15°의 이완 각을 사용한다(좌우 부호 보정, 튜닝). 쓰러진 후 손가락 로컬 회전은 고정하고 손 강체를 따라간다. 기존 손목 물리 관절은 v32 그대로다. 피격 구역은 기존21개/손 전체 체적을 유지하며 개별 손가락 피격·새 인체 판정을 추가하지 않는다. 대리 몸 손목과 FPS 손목의3cm 기준, 눈=카메라, 숨김 레이어4는 그대로 검증한다.

## 검증·측정

`downloads/checks-ai1-supplement-v33`의 JSON/이미지를 따른다. 실제 플레이어 사격, 적8발/플레이어 의료7건,12자세·두 화면의 대리 몸, 쓰러짐/낙하/추가 피격/정리/재시작을 검사한다. 비전투600틱·6발의 카메라·총구·탄 방향·반동은 v32와 정확히 비교한다. 원본2D baseline 및 탄 비행·관통·방호·의료 수식/데이터/기존 FPS 코드는 바이트 보존 대상이다.

성능은 같은 Chromium/SwiftShader에서 기존/신규 버전을 각각 실행한다. 고정60Hz 시뮬레이션의 전후10초(각600프레임), GPU 완료 대기 포함 `fall`/`world.step`/렌더/전체 작업 시간과 최대/중앙값을 기록한다. 실제 모바일 FPS 수치가 아니다. **전체 작업 시간의 쓰러짐/중앙값≤2 목표는 아직 미달이며 통과로 표시하지 않는다.** 결과 표는 아래 측정 JSON과 요약 대장을 따른다. 최초 활성화 접촉/CCD 및 드라이버/GC의 잔여 비용이 있다.

별도 네이티브 rAF 측정은 최초 표시가 약27초 지연되고 이후 약200ms 간격으로 제한되어 전10초 표본이 부족했다. 이 자료는 무효 측정으로 남기며 목표 달성 증거로 사용하지 않는다. 투입 때의 셰이더/물리 예열 비용, 실기기 지속FPS/발열은 별도 한계다.

실행: ZIP을 풀고 `dist/CQB_Training.html`을 연다. GitHub Actions를 사용하지 않는다. 최종 ZIP·SHA·불변 GitHub 다운로드는 배송 영수증을 따른다.
