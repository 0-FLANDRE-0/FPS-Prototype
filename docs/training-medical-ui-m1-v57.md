# M1 / v57: 읽기 전용 본인 의료 화면

기준: v56 `4065fc745ed155251c2043a47ee8566e9da1f0e7`. 구현: `82402e9`.
사용자 M1 지시가 참고 UX A/기술 B보다 우선한다. 첨부 원문은 `training-m1-*` 세 문서로 보존했다. M2–M6와 처치 효과는 구현 범위 밖이다.

## 사용

상단 가방 버튼으로 장비 화면, `✚`로 본인 의료 화면을 연다. 공통 탭 `[장비/인벤토리][의료]`, `환자: 나`, 일시정지 `Ⅱ`, 닫기 `X`를 둔다. 두 화면 크기 모두 25/35/40% 3열을 유지한다. 열마다 독립 스크롤이 있고, 탭 전환과 닫았다 열기에 부위·상처·앞뒤 및 스크롤이 유지된다. 본문 SVG는 D2의8부위 경로/HP 색을 분리해서 재사용한다. 작은 화면에서도 몸 전체를 먼저 볼 수 있도록 그림 높이를 화면 높이−165px, 최대380px로 제한했다(튜닝).

의료 화면은 왼쪽 신체/앞뒤/부위, 가운데 상처와 관찰 증상, 오른쪽 기존6×5가방이다. `playerStorage/playerGrid` DOM을 통째로 옮겨 기존 InventoryUI를 쓴다. 원래 탄창/탄약/조준경 이동·장착·장전 명령은 같다. 드래그가 클릭을 만들지 않았을 때 다음 독립 제어 클릭을 삼키던 suppressClick 범위만 격자/장비 대상으로 제한했다.

훈련 중 두 탭에서는 출혈·생리·적AI·소리가 진행된다. 이동·사격·새로운 ADS/시야 입력을 막고 기존 서기/앉기·시선·기울이기 자세는 유지한다. 가려진3D 그리기만 건너뛰며 물리/AI/의료를 다음 프레임으로 미루지 않는다. `Ⅱ`는 정지하고, 쓰러진 뒤 나의 의료 상태도 정지한 채 연다. H01/적의 기존 전체 의료 검사는 몸속 판정 설정을 켠 디버그로 남긴다. 일반 의료는 본인만이다.

## 상처 위치 기록 감사

기존 `bodyTrajectory.exitAddress`는 진입 주소의 복사에 `_exit:true`만 붙인 값이었다. 실제 출구 위치로 사용할 수 없으므로 원본 기록을 보존하고 별도 표시용 WeakMap을 추가했다. 동일한 trace part의 `entryDistance/exitDistance`와 원래 피격 센서 삼각형의 법선을 짧은3mm probe로 읽어 입출구를 구한다. 기존 `resolveBodyAddress`와 rig.delta 역변환으로 자세 독립 bindActorPoint/bindNormal을 만든다. 앞뒤는 bind 법선 z의 부호이고 뒤 그림의 x를 거울 반전한다. 팔다리는 원본 뼈와 파생 중지 뼈의 bind 체인, 몸통은 구역 경계로2D 도식에 투영한다. 이 투영은 사진상 정합이 아닌 튜닝된 도식이다.

이 추가 자료는 상처/의료 snapshot과 trace JSON에 넣지 않는다. RNG/상처/HP/출혈/탄도/방호 수식과 원래 주소를 수정하지 않았다. 초기화 때 함께 제거한다. 피부를 실제로 못 찾은 방호 둔상이나 불완전 사거리에는 가짜 출구를 만들지 않고 `피부 위치 확인 불가`/`위치 확인 불가`로 표시한다. 사거리 종료를 맹관상으로 추정하지 않는다.

- 관통: 입구 점 + 출구 원, woundId로 쌍 선택. 서로 다른 앞뒤면에서도 강조 유지.
- 맹관: 원래 탄 정지 정보가 있는 입구만 점.
- 스침: 통로≤40mm, 법선 내적 절댓값≤0.35, 통로25/50/75%의 최근접 피부 깊이≤4mm일 때 선. 표시 전용 튜닝이며 손상 모델을 바꾸지 않는다.
- 겹침: 병합하지 않고10SVG단위 내 선택 목록. 앞뒤와 목록을 왕복 선택한다.
- 상태: 모든 상처/부위 미처치. 분홍/청록/보라의 미처치·처치됨·중단됨 스키마와 비활성 처치 버튼만 있다. HP 색과 구분한다.

## 관찰 정보와 후속 자리

겉 출혈은 `bleedSourceIds`로 연결된 **external** 출혈원만 중복 없이 합산한다. 동맥이 구획 안으로 피를 보내면 뿜는 피부 출혈로 표시하지 않는다. 전신 요약도 각 출혈원을 한 번만 센다. 팔다리 부종은 해당 부위 귀속 누적량을 실제 남은 limb_compartment pool로 제한해서 읽는다. 가슴 공기/거품은 chestWallOpen, 숨 어려움은 호흡 효율/기존 tensionAir, 뼈 이상은 S2 상태, 통증은 D1 masking을 적용한 부위 통증, 어지러움/시야/귀 울림은 기존 의식·관류/피드백·청력·뇌진탕을 읽는다.

정확한HP·혈압·혈액량·장기 손상량과 심전도는 일반 화면에 없다. 설정의 몸속 판정을 켜야 기존 의료 디버그가 아래에 나타난다. 변환 문턱/배색/투영/업데이트4Hz는 [대장](medical-ui-m1-ledger.json)에 모두 튜닝으로 기록했다. `2D 역이식 후보`는 공통 탭/시간 정책·관찰 표시·상태 스키마이며, 3D 피부 역변환은 후보가 아니다. 원본2D는 이번에 수정하지 않았다.

물품 출처는 `[나]`만 활성, `[환자][주변]`은 비활성이다. 의료 아이템/IFAK/치료와 효과/다른 장비별 격자는 없다. `wristPulse/responsiveness`는 null 자리이고 런타임에 사용하지 않는다.

역사적 촉지 맥박−혈압 규칙의 radial>80mmHg는 Deakin/Low(BMJ2000, DOI10.1136/bmj.321.7262.673)의 침습 혈압 비교에서 신뢰 문제가 보고됐다. Russell2001은 그 규칙의 ATLS 귀속 주장에 반론을 제기했다. 서지·색인 원문/초록은 확인했지만 접근 차단으로 모든 본문을 읽지 못했다. 보편적 문턱으로 채택하지 않았다. [출처와 접근 한계](medical-ui-m1-sources.json).

- 원래 격자의 마우스/터치 드래그, 탄창 장전·조준경 장착/분리, 선택/스크롤 유지, 디버그 기본 숨김을 확인했다. CDP 드래그 이후 독립 탭을500ms 분리해서 Chromium 제스처 합성을 구분했다. 실제 휴대폰은 미검수다.
- 최종 단일HTML을 두 화면에서 네트워크 오프라인/실제RAF로 실행한다. 기본 키·터치 적 투입→자연 사격/피격→기존 쓰러짐→정지한 나의 의료→닫기→재시작, 외부 요청과 브라우저 오류0을 확인한다. 배포 검증은 HTML SHA256이 같은 실행 파일을 대상으로 한다.

성능 표는 적1명·고정60Hz·4Hz UI 업데이트·강제 layout을 포함한 CPU tick+render/UI 시간이다. 완전히 가려진3D 장면의 그리기는 생략된다. SwiftShader/에뮬레이션 값이며 GPU완료 시간이나 폰 FPS를 뜻하지 않는다. 전체 원시JSON.gz와 개별PNG는 저장소에 보존하고 ZIP에는 보고·비교 시트·CSV/요약을 담는다.
