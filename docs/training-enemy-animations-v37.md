# v37: 적 병사 Mixamo 애니메이션

**애니메이션 연결과 조준·손 위치는 확인했지만 물리 결과는 시험판이다.** 동일 기준 쓰러짐은 v36의4/7에서 v37의2/7로 내려갔고, 앉기↔무릎 장전 혼합에서 오른발이 최대35.680mm 들어간다. 새 자세의 미달을 물리 계수 변경으로 숨기지 않았다.

기준은 v36 `422cbbc13a171e8a8a8b7f7449c505859022714a`다. 기존 병사 메시·스킨·54본에 애니메이션만 리타깃한다. P01은 기존 `CombatPose`와 네이티브4클립을 유지하며, AI 판단·감각·행동·사격 계산과 의료·탄도·관통·방호 수식은 바꾸지 않는다. 원문은 [지시서](training-enemy-animations-v37-instructions.md), 전체 수치·매핑·구분은 [대장](enemy-animation-ledger.json)이다.

## 자산과 변환

사용자가 제공한 `Mixamo_Rifle_Anims.zip`은 Adobe [Mixamo](https://www.mixamo.com/)의 Without Skin 애니메이션이다. 로열티 프리라는 사용자 제공 정보를 기록하고 [Adobe Mixamo FAQ](https://helpx.adobe.com/creative-cloud/faq/mixamo-faq.html)를 연결했다. 원본 ZIP은 `apps/training/assets/source/Mixamo_Rifle_Anims.zip`에 보존하고 [크레딧](../apps/training/assets/mixamo-animations-credits.json)에 출처를 남겼다. 전체 FBX65개는 X Bot 기준1개와 애니메이션64개이며, 아래의 소스 뼈65본과는 별개의 개수다. 자동 리깅이나1인칭 팔 메시 이식은 하지 않는다.

원본 SHA256은 `eb4badc8cba82f5d02cc1428e639c083c3dbd251d22eb79ed1ded70e6cc91cc8`, 크기는5272852바이트다. 소스의65본에서 기존 구조24본으로 변환하며, 기존 손가락30본의 애니메이션 트랙은 버린다. 고정 AK 그립·이완 자세와 스킨 가중치는 원본 그대로다. 빌드 시 미리 변환한55클립을 내장하며 실행 중 FBX를 읽지 않는다. 점프3개·사망6개는 제외하고 사망은 기존 물리가 담당한다.

`X Bot.fbx` T포즈와 기존1.8m 병사 A포즈의 뼈별 휴지 회전 차이를 보정한다. 소스 Spine은 `spine`, Spine1+Spine2의 누적 회전은 `chest`로 합친다. 기존24본에 쇄골이 실제로 있으므로 Left/RightShoulder는 `leftClavicle`/`rightClavicle`로 대응하며 위팔에 가상의 쇄골을 새로 만들지 않는다. 무릎 보호대는 기존 대퇴/하퇴 회전 중간 보조 규칙을 유지한다.

소스 다리 길이0.888993m, 대상0.726183m, 비율0.816860706로 Hips 높이 이동을 환산한다. 대상 발목 기준으로 고정 골반 기준을+0.030473m 보정하며, 이는 클립마다 몸을 들었다 내리는 임의 root 보정과 구분한다. Hips 수평 X/Z 이동만 제거하고 높이 출렁임·원래 회전은 보존한다. 제자리90° 회전은 클립의 원래 회전량을 기록하고 기존 actor heading과 중복 회전하지 않게 합성한다. 원래 키 시각에 빌드 시60Hz 다리 IK 표본을 추가하고, 보간 중 실제 밑창이1mm 미만으로 내려가면 중간 키를 적응적으로 보강한다. 1μs 이내의 FBX 중복 시각은 Float32 중복을 막도록 합치고 모션 키를 줄이지 않는다. JSON 반올림은 성분 소수7자리(최대5×10⁻⁸)다.

빌드 시 두 뼈 다리 IK는 원본 발목 궤적을 Hips 기준으로 환산하고 기존 병사의 대퇴·하퇴 길이와 원본 무릎 평면을 사용한다. 발의 월드 회전은 보존한다. 변형하지 않은 기존 부츠 밑창 정점(좌/우54개씩)으로 지면 여유3mm를 잡고, 닿지 못하는 목표 오차를 측정한다. 뼈 길이·메시·스킨을 바꾸거나 순간마다 Hips를 올려 오차를 숨기지 않는다. **55개 단일 클립의 실제 Three FK120Hz 표본에서 최저 밑창 높이는+1.0006mm**였다. [원본 클립 밑창 검사](../downloads/checks-enemy-animation-v37/source-clips-sole-120hz.json)는 클립 사이 혼합이나 장전 IK를 적용한 런타임 전체가 침투0이라는 주장이 아니다.

일부 FBX7700의202바이트 footer를 Three r180이 잘못 종료 판정하는 문제는 빌드 시 파서 입력의 footer 처리로 우회한다. 원래 FBX 노드 바이트와 ZIP을 수정하지 않는다. 완전한 뼈 대응/휴지 보정 쿼터니언과 클립별 소스 SHA는 대장과 생성 매핑 자료에 남긴다.

## 상태와 총·손

| 상태 | 연결 클립/동작 |
|---|---|

전환 혼합0.20초와 재생 배율0.7–1.4는 튜닝이다. 원래 한 주기의 수평 이동 거리÷길이로 속도를 측정한 뒤 대상 다리 길이에 맞춰 환산한다. 실제 이동 속도÷환산 원래 속도로 재생하며 배율 범위를 벗어나면 걷기/뛰기 계열을 선택한다. 현재 AI의 이동 속도는 그대로1.4m/s다. 속도가 다른 P3의 달리기·전력질주 행동을 새로 만들지 않는다.

장전은 기존 전술2.648초/빈 탄창3.498초에 클립을 맞춘다. **일반 소총용 Mixamo 동작을 AK에 붙인 근사**이며 탄이 바뀌는 원래 시점과 사격 계산을 보존한다. 탄창을 떼는 별도 연출은 없다. 앉기에서 무릎 장전으로 내려가는 높이·자세 차이도 실제 시트와 침투 수치에 포함한다.

총은 애니메이션 오른손에 붙고 왼손은 기존 팔 IK로 핸드가드에 맞춘다. 장전 중에는 왼손 IK를 풀어 원래 클립을 따른다. 상체 조준 보정으로 총구를 목표로 맞추며, 성공한 실제 발사 이벤트의 방향과 화면 총구 차이도 따로 측정한다. 발사 원점·방향·무작위 분산 자체는 바꾸지 않는다. 손가락은 공통 AK의 고정 그립을 유지한다.

뛰기8방향·전력질주8방향·무릎 전환3개·`walk_fire_forward`·별도 `strafe_left/right` 등 현재 AI가 쓰지 않는 동작은 내장만 하고 P3에 남긴다. 테스트의 앉기/회전/옆·뒤 이동 표본은 클립 지원을 검사하는 입력이며 AI에 새 전술 판단을 추가했다는 뜻이 아니다.

## 쓰러짐·검증 범위

쓰러질 때 보이는 혼합 자세를 캡처한다. 이동 중이면 해당 혼합의 위상·속도를 이어 재생하며, 정지 상태면 조준/IK를 포함한 마지막 자세를 고정한다. 애니메이션 목표 공급기만 추가하고 v36의 ROM·질량·관성 하한·솔버·감쇠·마찰·정착·손 짚기 수식은 보존한다. 공급기가 없는 기존 경로는 v36와7사례×360틱 동일성 검사를 따로 한다. 새 자세에서 결과가 달라진 경우를 물리 계수 변경이라고 부르지 않는다.

최종 자세 시트는0.1초 간격으로 서기·조준·앉기·회전·사격·장전·앞/옆/뒤 걷기를 남긴다. 실제 스킨의 부츠 밑창 정점으로 디딘 구간 수평 속도와 지면 침투를 측정하며 발목 높이로 대신하지 않는다. 장전 중 풀린 왼손 거리와 정상 IK 유지 중 거리를 나눈다. 이 거리는 손목 뼈에서 공통 AK 핸드가드의 손목 기준 마커까지이며 손바닥 스킨의 비관통을 직접 증명하는 수치는 아니다. 실제 탄 이벤트의 총구 오차도 명시한다. 총열의 방향은 가져온 AK의 로컬−Z 축으로 재며, 약실/배출구 마커를 총열 축으로 대신하지 않는다.

발 디딤은 평평한 밑창 구간(정점 높이 폭≤60mm, 최소 높이≤30mm, 중심 수직속도≤0.18m/s)과, 기울어진 발끝/뒤꿈치를 포함하는 최저 밑창 정점의 근접 지면 구간(높이≤10mm, 같은 정점 수직속도≤0.18m/s)을 별도로 측정한다. 표본이 없는 구간은 `null`로 적고 미끄러짐0으로 합격 처리하지 않는다. 애니메이션 발 미끄러짐은 보고값이며 별도의 새 엄격한 합격 상한을 만들지 않는다. 기존 쓰러짐의 Rapier 접촉점 미끄러짐0.15m 기준과는 다른 측정이다.

v36의7쓰러짐 사례는 같은 단일 바닥·의료 출력 표본·기존 물리로 v36/v37을 다시 비교한다. 0.05초 간격3초61프레임과6초 자세, 관절 잔차·미끄러짐·COM·실제 sleep을 기록한다. 기존 미달 기준은 그대로 공개하며 새 클립이 불리한 결과를 만들면 숨기지 않는다.
