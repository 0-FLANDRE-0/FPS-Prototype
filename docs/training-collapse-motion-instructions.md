# CQB Training 지시서 R-2 수정: 서 있을 때 근력 반응 제거 + 이동 중 쓰러짐

아래는 사용자가 제공한 이번 작업 지시의 원문이다. 구현과 측정 결과는 `training-collapse-motion-v35.md`에 구분해서 기록한다.

v34 위에서 작업한다. 의료·탄도·방호 수식과 손가락 자산은 그대로 둔다.

## 1. 제거
- 서 있는(쓰러짐 판정 전) 상태의 근력 모드를 없앤다. 골반 스프링으로 버티기, 피격 후 dynamic 전환과 애니메이션 복귀를 모두 제거한다.
  서 있을 때는 100% 애니메이션이다. 피격 움찔은 v33의 짧은 코드 충격으로 되돌린다.
- 서 있는 상태에서 팔 근력 저하로 총을 떨어뜨리는 것을 제거한다. **총은 쓰러질 때만 놓친다.**
- 근력 래그돌은 의료가 쓰러짐(의식 소실, 다리 기능 상실, 심정지, 사망)을 판정한 순간부터만 쓴다.

## 2. 이동 중 쓰러짐
- 걷는 중에 쓰러지면 걷기 클립을 그대로 이어 재생해서 다리 관절의 근력 목표로 쓴다(재생 속도는 쓰러지기 직전 이동 속도에 맞춘다).
  - 근력은 의식 소실 0.3–0.6 s, 다리 기능 상실 0.2–0.4 s에 걸쳐 0으로 줄인다(튜닝).
  - 관성으로 진행 방향으로 쏠리면서 다리가 몇 걸음 버티다가, 근력이 빠지며 앞으로 넘어져야 한다.
  - 상체는 의식 수준만큼 자세를 유지하다 같이 빠진다.
- 근력이 0이 된 뒤에는 앉기 클립 혼합을 포함한 모든 목표를 끈다. 웅크린 채 굳지 않고, 무게에 따라 옆이나 앞으로 넘어가 바닥에 눕게 한다.
- 정지 상태(조준, 앉기)에서 쓰러지는 경우는 v34 방식 그대로 무릎부터 접히되, 근력이 0이 된 뒤 같은 규칙으로 목표를 끈다.

## 3. 측정 확인
- 관절 가동 범위 위반 수(시나리오당 수천 건)가 실제 위반인지 측정 기준 오류인지 확인한다.
  순수 애니메이션(kinematic) 프레임에도 같은 측정을 돌려서, 애니메이션 자체가 위반으로 잡히면 기준 프레임을 고친 뒤 다시 잰다.
- 성능 목표는 절대 16.7 ms가 아니라 **"쓰러짐·투입·첫 사격 프레임이 평소 프레임의 1.5배 이하"**로 바꾼다(테스트 환경이 소프트웨어 렌더이므로).

## 4. 검증
- 걷는 중 쓰러짐(의식 소실, 다리 기능 상실), 문 통과 중 쓰러짐, 조준 중 쓰러짐의 연속 프레임 시트(0.05 s 간격, **3 s**)를 v34와 나란히 남긴다.
- 체크: 버티는 걸음 수, 넘어진 방향과 진행 방향의 일치, 최종 자세가 누운 자세인지, 미끄러짐, 날아감(질량중심 수평 이동은 이동 중 쓰러짐에서 진행 속도 × 0.8 s 이하).
- 서 있는 상태 피격 시 총을 놓치지 않고 애니메이션이 유지되는지 확인한다.
