# CQB Training 지시서 R — 몸속 판정 레이어·출혈 모델·출혈 내성

Oct 11, 2026 · @다고쿠

## 개요와 원칙

R은 상처가 어떤 혈관·장기·뼈를 건드렸는지를 확률이 아니라 **3D 실제 교차**로 정한다. 그 결과로 출혈 속도와 지혈을 다시 연결하고, 느린 출혈이 빠른 출혈보다 먼저 죽는 역전을 고친다. 지금은 혈관을 안 건드린 팔뚝 관통상이 3.2 ml/s로 멈추지 않고 13분 만에 죽고, 팔뚝과 허벅지가 같은 결과를 낸다.

1. **Q 구조 유지.** 변경은 medical-v2에만 넣는다. legacy 모드는 v17 legacy와 완전히 같아야 한다. 원본 `src/**`와 생성된 원문 선언은 무수정이다.
2. **변경 장부 이어 쓰기.** `medical-v2-ledger`에 R 항목을 같은 형식으로 추가한다. 원본 함수·줄, 전/후 수식, 이유, 근거 구분, 2D 이식 시 의존 필드를 적는다.
3. **2D 파이프라인에 입력만 바꾼다.** 2D는 이미 `vascularEvidence`(none / risk\_only / candidate / probable / confirmed), `vesselClass`, 상처별 출혈 프로파일, 자연 감소, 응고 계수를 갖고 있다. 새 출혈 엔진을 따로 만들지 않고, 이 파이프라인이 읽는 입력(confirmed/probable/candidate 손상 목록, physiologicInjuries, 골절 판정 등)을 기하 결과로 채운다. 고쳐야 하는 수식만 v2 슬롯으로 교체한다.
4. **근거 구분.** 해부 치수·생리 수치는 출처(직접 연 페이지, 확인일), 원본 값, 튜닝값 중 하나로 표시한다. 원문을 못 열었으면 튜닝값으로 적는다(Q에서 한 방식 그대로).
5. **탄도·방호·인체 바깥 판정은 그대로다.** 몸속 레이어는 기존 인체 관통 구간 안에서만 조회한다. 탄의 속도·잔여탄·관통 여부를 바꾸지 않는다. 조직별 저항 차이는 S 범위다.
6. H01은 A자 고정, 쓰러짐·치료는 없다.

## R0 사전 조사 (코드 변경 없이 먼저 보고)

검수 쪽에서 v17 번들을 읽고 아래처럼 추정했다. 원본 소스에서 함수명·줄과 함께 확인하고 `docs/training-r0-diagnosis.md`에 기록한다. 다르면 실제 구조를 적고, 같은 원칙을 실제 구조에 적용한다.

| 항목 | 추정 (v17 번들) | 보고할 것 |
| --- | --- | --- |
| 혈관 손상 결정 | 주소의 구역 힌트(femoral\_triangle 등 `majorVesselRiskHint`)와 `vesselRisk`%에서 candidate/probable/confirmed 손상 목록이 만들어지고, 그걸 `vascularEvidence`가 읽는다. 기하 정보는 없다. | 목록이 만들어지는 정확한 경로, 난수 사용 여부, P3 5건의 실제 vascularEvidence 값 |
| 출혈 자연 감소 | 대혈관이 아니면 `naturalReductionTargetExternal = sustained × 0.55`(강 0.6, 접합부 0.7)로, **0이 아닌 바닥에서 멈춘다**. selfReductionRate 0.25, clottingFactor 0.6/0.3/0. 팔뚝 3.2 ml/s 지속의 원인으로 보인다. | 팔뚝·대퇴 상처의 initial/sustained/naturalReductionTarget/clotting 실제 값과 시간별 출혈률 |
| 혈압과 출혈 | `bleedingPulseModel.pressureModifier` 등이 있다. 실제로 MAP에 따라 출혈률이 얼마나 변하는지는 미확인. | 수식과 P3 사례의 변화폭 |
| 골절 | 구역 문자열로 뼈 종류를 고르고, 탄 골절 확률 × 구역 위험도 × …로 **난수 굴림**한다. 팔다리는 구역이 없으면 humerus/femur로 대체한다. | 어느 RNG를 쓰는지(샷 로컬 seed인지), 팔뚝이 humerus로 분류되는지 |

또한 2D가 인식하는 혈관·장기 식별자 목록(주요 명명 혈관 정규식, 분지 정규식, `solid_organ_injury` 등 physiologicInjuries 타입)을 뜯어서 표로 만든다. R1의 도형 이름은 이 목록에 맞춘다.

## R1 몸속 판정 레이어

보이지 않는 판정용 도형으로 혈관·장기·뼈를 넣는다. 얼굴·메시 모델이 아니라 캡슐·타원체의 단순 도형을 직접 저작하므로 외부 모델 라이선스가 필요 없다.

- **R1-a 형태.** 혈관과 긴 뼈는 여러 마디의 캡슐 사슬(점 목록 + 반지름), 장기는 타원체 또는 캡슐 몇 개의 합으로 만든다. 각 도형은 24개 리그 뼈 중 하나에 뼈 로컬 좌표로 붙어 자세를 따라간다. 관절을 가로지르는 혈관(오금·사타구니 등)은 양쪽 뼈에 나눠 붙인다.
- **R1-b 목록 (최소).**
  - 혈관(좌우 각각, 동맥/정맥 구분): 경동맥, 내경정맥, 쇄골하, 액와, 상완, 요골·척골 동맥, 장골, 대퇴 동맥·정맥, 오금, 대동맥(흉부·복부), 대정맥.
  - 장기: 뇌, 심장, 폐(좌우), 간, 비장, 신장(좌우), 장관 묶음 1개, 척수.
  - 뼈: 두개골, 경추·흉추·요추, 쇄골, 상완골, 요골·척골, 골반, 대퇴골, 경골·비골. 갈비뼈는 넣지 않고 2D의 흉벽 구역 판정을 유지한다.
- **R1-c 치수 근거.** 혈관 지름과 장기 크기는 해부학 교과서나 영상의학 리뷰에서 성인 남성 대표값을 찾아 출처와 함께 적는다. 위치·경로는 R1-g의 뼈 기준 비율 좌표로 저작한 값(튜닝)이며, H01에서 맞춰 보되 H01 절대 좌표로 박지 않는다. 모든 도형은 기존 21개 인체 닫힌 메시 안에 들어와 있어야 하며, 밖으로 나간 부분은 검사에서 실패다.
- **R1-d 이름.** 각 도형은 R0에서 뜯은 2D 식별자에 대응되어야 한다(예: 대퇴 동맥 → 2D 주요 명명 혈관 정규식에 걸리는 이름). 대응표를 장부에 둔다. 2D에 없는 분류가 필요하면 새 필드로 추가만 한다(예: `vesselKind: artery | vein`).
- **R1-e 진단 표시.** 설정에 “몸속 판정 표시”를 추가하고 기본값은 끈다. 켜면 반투명 색으로 도형을 보여주고, 마지막 피격에서 맞은 도형을 강조한다. 표시 여부는 계산에 영향을 주지 않는다.
- **R1-f 용량.** 도형 데이터는 JSON 수십 KB 수준이어야 한다. 새 텍스처나 GLB는 넣지 않는다.
- **R1-g 새 캐릭터 대응 (뼈 기준 비율 좌표).** 모든 도형은 24관절 리그의 뼈 길이와 부위 굵기에 대한 **비율**로 정의한다. 예: "대퇴 동맥은 대퇴 뼈 길이의 0\~85% 구간, 허벅지 단면 반경의 몇 % 지점 전내측", "간은 몸통 높이·너비의 몇 % 위치". 부위 굵기는 해당 캐릭터의 인체 피격 메시에서 뼈 단면 반경으로 측정한다. 같은 리그로 리타겟된 새 캐릭터는 뼈 길이와 굵기만 다시 재서 도형이 자동으로 맞춰져야 한다. H01 전용 절대 좌표나 H01 전용 상수는 금지한다. 캐릭터별로 필요한 값은 측정값 몇 개(뼈 길이, 단면 반경)뿐이어야 하며, 그 목록을 장부에 적는다.

## R2 실제 교차로 상처 만들기

v2에서는 상처의 혈관·장기·뼈 입력을 구역 힌트와 확률이 아니라 몸속 레이어 교차로 만든다.

- **R2-a 교차 계산.** 기존 인체 관통 구간(연속 구간 합집합, 체내 정지 지점까지)을 탄두 반지름(탄종 구경/2)만큼 두께를 가진 선분으로 보고 몸속 도형과 교차한다. 교차한 도형마다 진입 깊이, 통과 길이, 중심선까지 최단 거리를 기록한다. 교차하지 않았지만 틀정 거리(기본 20 mm, 튜닝값) 안의 혈관·장기도 거리와 함께 기록만 한다. 근접 피해는 S(일시공동) 범위다.
- **R2-b 혈관.** 교차한 혈관은 confirmed 손상으로 넣는다. 2D의 `vascularEvidence`가 기존 방식대로 major\_named / named\_branch를 고르게 한다. 교차한 혈관이 없으면 근육 조직만 다친 것이다. 이때는 2D 식으로 `capillary_muscle`/none이 되게 하고, 구역 힌트·vesselRisk% 기반의 candidate/probable/risk\_only 생성은 v2에서 끈다.
- **R2-c 장기.** 교차한 장기는 2D가 이미 아는 손상 타입(예: `solid_organ_injury`)으로 넣는다. 심각도는 2D에 있는 규칙을 쓰고, 통과 길이가 입력으로 필요하면 그 변환식을 튜닝값으로 적는다. 흉부 내 폐 교차는 기존 흉부 외상 모델(기흉 등)의 입력 플래그에 연결한다.
- **R2-d 뼈.** 골절 난수 굴림은 뼈 도형과 교차했을 때만 한다. 뼈 종류는 교차한 도형으로 정해서 팔뚝이 humerus로 대체되는 일을 없앤다. 굴림 확률 수식과 RNG는 2D 그대로다(뼈에 맞았다는 조건만 추가).
- **R2-e 기록.** `trace.bodyHits`에 `internalHits`(도형 이름, 종류, 2D 식별자, 깊이, 길이, 거리)와 `nearMisses`를 추가한다. 의료 상처에는 어떤 교차가 어떤 2D 입력으로 들어갔는지 남긴다.
- **R2-f legacy.** legacy 모드는 몸속 레이어를 조회만 하고(기록용) 의료 입력은 기존대로 구역 힌트에서 만든다.

## R3 출혈 모델: 혈관 등급·지혈·혈압 의존

대혈관을 안 건드린 근육 상처는 시간이 지나면 거의 멈추게 하고, 동맥 출혈은 혈압에 따라 줄게 한다. 2D의 초기 출혈·지속 출혈 계산은 그대로 두고, 감소 목표와 혈압 연결만 v2로 바꾼다.

- **R3-a 근육·모세혈관 (none / capillary\_muscle / small\_branch).** 자연 감소 목표를 sustained×0.55 같은 0이 아닌 바닥에서 0에 가까운 값으로 바꾼다. 멈추는 속도(시간 상수)는 튜닝값이며 수 분 안에 대부분 멈추는 쪽으로 잡는다. 골절 출혈 보너스(대퇴골 골절 등)는 2D 원본 그대로다. 골절이 있으면 바닥이 더 높을 수 있다.
- **R3-b 명명 분지 (named\_branch).** 동맥은 일부 자연 감소를 허용하되 0까지는 안 간다. 정맥은 동맥보다 더 많이 줄어든다. 감소율은 튜닝값이다.
- **R3-c 주요 명명 혈관 (major\_named).** 2D처럼 자연 지혈은 없다(majorVesselLocked). 정맥은 동맥보다 낮은 출혈률을 갖도록 `vesselKind`를 반영한다.
- **R3-d 혈압 의존.** 동맥 출혈률은 MAP에 비례해 줄고(기준 MAP 93은 원본 값), 정맥은 덜 민감하게 한다. 이미 있는 `bleedingPulseModel.pressureModifier`와 중복되지 않게, R0에서 확인한 기존 수식을 교체하는 방식으로 넣는다. 심정지 중 ×0.05(Q1-c)는 유지한다.
- **R3-e 기대 경향.** 혈관을 안 건드린 팔다리 관통상은 치료 없이도 대개 치명적이지 않고, 대퇴 동맥 같은 주요 동맥 손상은 치료 없이 치명적이다. 이 두 문장에 대해서는 외상 출혈 문헌을 찾아 출처를 단다. 못 찾으면 “설계 기대”로 적는다. 구체 시간을 맞추는 튜닝은 하지 않는다.

## R4 출혈 내성: 느린/빠른 출혈 역전 수리

Q 결과에서 팔뚝(약 3 ml/s)은 손실 39%, 목(약 22 ml/s)은 63%에서 심정지가 왔다. 천천히 잃을수록 더 많이 버티는 쪽이 현실적이다. 보상 피로가 혈량 3500 ml 아래에 머문 **시간**만으로 쌓이는 구조가 원인으로 보인다(R0에서 확인).

- **R4-a 출혈률 스윕 하네스.** 새 주체에 고정 외부 출혈률 1, 2, 4, 8, 16, 32 ml/s를 걸고(통증·내부 손상 없음) 심정지까지 돌린다. 최대 3600초. 출혈률별 심정지 시각, 그때 손실%, SBP·MAP·피로 시계열을 표와 그래프로 남긴다. 수정 전(Q v2)과 수정 후를 둘 다 돌린다.
- **R4-b 수정 범위.** 보상 피로의 누적을 머문 시간이 아니라 혈량 결손 정도와 보상 부하의 함수로 바꾼다. 결손이 작으면 거의 쌓이지 않고 회복도 가능하다. 다른 혈역학 수식은 건드리지 않는 것이 기본이다. 그것만으로 아래 조건을 못 맞추면 무엇을 바꾼지 장부에 이유와 함께 적고 최소한으로 더 고친다.
- **R4-c 통과 조건.**
  1. 출혈률이 낮아질수록 심정지 시점 손실%가 줄어들지 않는다(허용 오차 1%p).
  2. 출혈만 있는 경우 손실 40% 이하에서 심정지가 오지 않는다. ATLS10에서 40% 이하(III등급)는 혈압 유지\~감소, IV등급(>40%)이 가장 위험한 구간이라는 경향을 근거로 한 설계 기준이다.
  3. 16–32 ml/s 같은 빠른 출혈의 심정지 손실%는 보고만 한다. 원본 exsanguination 기준(잔여 1200 ml)은 그대로다.
- Q의 6개 불변 조건은 계속 통과해야 한다.

## R5 M4 ORM 텍스처 되돌리기

Q6에서 검수가 요구한 SSIM ≥ 0.97 기준은 여러 채널을 합친 ORM 텍스처에 맞지 않는 기준이었다. weapon/1이 무손실이 되면서 HTML이 약 1.25 MB 늘었지만, 렌더 화면에서는 차이가 없다.

- weapon/1과 weapon/4를 P1 선택(q85) 바이트로 되돌린다. 다른 텍스처는 그대로다.
- ORM 품질은 텍스처 SSIM이 아니라 **렌더 화면 비교**로 판정한다. Q6의 M4 4상태(비조준/조준 × 렌즈 0/70)를 v13 원본 텍스처와 되돌린 텍스처로 찍고, 총기 영역의 화면 SSIM과 최대 픽셀 차이를 기록한다. 화면 SSIM ≥ 0.97이면 통과, 미달이면 해당 텍스처만 q를 올린다.
- P1 문서의 기준 설명과 용량 표를 정정하고 HTML 용량을 기록한다.

## 검증

기하로 만든 상처가 실제로 다른 결과를 내는지 production 사격으로 확인한다. legacy와 탄도·방호 결과는 바뀌면 안 된다.

신규 fixture는 맨살 A자 자세에서 저작한 조준점으로 총을 쏜다. 기존 14개 fixture의 좌표는 바꾸지 않는다. 각 시나리오의 교차 목록, vascularEvidence, 출혈률 시계열, Q 전환 표(손실 15/30/40%, 의식, downed, unconscious, arrest, dead)를 남기고, 몸속 판정 표시를 켜고 맞은 도형을 보여주는 화면을 한 장씩 찍는다.

**v2 불변 조건 (어기면 실패)**

1. 신규 fixture는 기대 도형과 실제로 교차하고, 그 상처의 vascularEvidence는 confirmed다. thigh-lateral-muscle은 혈관 교차가 없고 none/capillary\_muscle이다.
2. 혈관을 안 건드린 팔다리 상처(골절 없음)는 1800초 안에 downed·arrest가 없다.
3. 주요 동맥(대퇴 동맥, 경동맥) 손상은 치료 없이 1800초 안에 arrest에 이른다.
4. 뼈와 교차하지 않은 상처에는 골절이 없다. 팔뚝 골절은 요골/척골로 분류된다.
5. 몸속 도형은 A자와 native 5자세에서 모두 인체 닫힌 메시 안에 있다. H01을 변형한 가짜 체형 2종(키 0.9배·팔다리 굵기 1.15배, 키 1.1배·팔다리 굵기 0.9배; 리그와 피격 메시를 함께 변형)에서도 R1-g 비율만으로 다시 맞춘 도형이 메시 안에 있고, 신규 fixture와 같은 상대 위치를 쏘면 같은 도형과 교차한다.
6. R4-c 1–2번과 Q의 불변 조건 6개.
