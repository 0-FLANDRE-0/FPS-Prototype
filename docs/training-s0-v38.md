## 진단과 수정

코드 변경 전 실제 `traceShot → occupied body → internalGeometry → TrainingMedical → medicalMuscleStrength` 기록을 먼저 남겼다([압축 원본](../downloads/checks-s0-v38/diagnosis-before.json.gz)). 헬멧을 통과한 7N6이 대뇌를105.615mm 통과했는데 머리 외상HP12.523/의식60으로 서 있었다. `brain_injury`는 확인 식별자에만 있고, 생리 손상 모델은 비어 있었다. 맨머리 중심 사격은 합산35HP가0이 되어 즉시 죽으므로 이 단절을 가렸다. 심장은 `heart_hook_only`/`heart_candidate`, monitorOnly/rhythm risk에 그쳐 펌프 기능을 줄이지 않았다. 초기 진단의 심장 중심선은 폐도 통과했으므로 그 쓰러짐 시간을 심장 단독 효과로 해석하지 않았다. 아래 시험은 실제 심장 단독 내부 교차를 다시 선택했다.

양의 실제 통과 길이가 있는 대뇌는 의식/목표0과 `brain_injury`를 유지한다. 뇌간은 별도 도형을 추가해 의식0·호흡0·즉시 심정지 `brainstem_injury`다. 스침/근접/통과 길이0은 해당 효과를 만들지 않는다. 실제 얼굴·턱만 통과하면 외상HP는 그대로 기록하면서 합산 머리HP0이라는 이유만으로 즉사시키지 않는다. 헬멧 둔상이나 위치 정보 없는 호환 입력의 기존 경로는 유지한다.

심장은 실제 통과 길이와 원래 잔여 에너지 배율로 펌프 손실을 계산한다. 정규화40mm, 최대 손실.99, 에너지 하한.25는 **튜닝**이다. 새 펌프 배율을 매 틱 새로 계산한 CO/SV/맥압/MAP에 한 번 적용한다. 뇌 관류 예비 상태가 실제 MAP/O2를4초 시정수로 따르고 기존 Q 의식 곡선이 이를 읽게 했다. 이4초도 임상 상수가 아닌 게임 튜닝이다. 의식이 남아 있는 짧은 구간에는 원래 팔다리 기능이 허용하는 활동을 유지하지만, 대퇴골 골절/척수 기능 상실을 복구하지 않는다.

대퇴골의 실제 골절이 확인되면 해당 다리 기능과 보행을0으로 하고 `weight_bearing_fracture`를 전달한다. 모든 새 결과는 원래 요약 인터페이스를 거쳐 기존 래그돌과 무기 낙하를 작동시킨다. 애니메이션·PD/래그돌·탄도·관통·방호 계산은 바꾸지 않았다. 이전75개 내부 도형도 그대로이며 뇌간 하나만 추가했다. 손가락·모델·내장 자산도 보존했다.

대뇌만 관통한 경우에 별도의 고정 심정지/사망 타이머를 만들지 않았다. 기존 출혈/저산소 심정지 조건을 유지하므로120초 시험 끝에도 의식 없이 생존하는 사례가 있다. 뇌간은 즉시 심정지 후 기존300초 경로로 사망한다. 뇌 통과 길이에 따른 사망 시간을 주장하지 않는다.

## 같은 조건의 전후 시험

서기/조준2자세 × 부위15종 × 탄2종(7N6/M855) × 거리5/50m × 무방호/기본방호 = **버전당240개**다. 기본방호는 기존 H01과 같은6B45·Granit Br4·6B47이다. 시험선·탄속/RK4·총알/부위/방호 판정은 동일하다. 순수 부위 시험에서는 사격장 구조물만 contact 쿼리에서 제외한다. 조준 자세의 낮은 각도 시험선이 기존 바닥에 막히거나50m 시험선이 레인 벽에 막힌 예비 시험을 발견해, 최종 전후 자료를 모두 같은 전용 조건으로 다시 만들었다. 환경 충돌을 제외하는 코드는 시험 도구에만 있고 게임에는 없다.

원시 자료는0.1초 간격이며 일반120초, 대동맥/대퇴동맥900초다. 사망300초도 별도 불변 검사에 포함했다. 헬멧 가장자리 시험은 같은 실측 위치에서 RNG.999/.0001로 정지/도탄 분기를 고정했다. 무방호 조건에는 헬멧이 없으므로 그 행의 실제 인체 교차를 그대로 기록한다. v37에는 뇌간 도형이 없어 동일한 선언된 위치를 쏘되, 변경 전 뇌간 교차를 지어내지 않았다.

### 기대에서 벗어난 항목

전체240행은 PASS193, 방호 등으로 목표 미교차29, 기대 미달18이다. 미교차를 장기 손상의 성공으로 세지 않았다.

- **대동맥8행:** 기존R2와 같은 수십 초의 저혈압/의식 소실이다. 심장과 비슷하거나 약간 느려야 한다는 설계 기대에 미달한다. 검증된 정량 기준이 없고 이번 최소 수정 대상이 아니어서 R2 수식을 그대로 두었다.
- **헬멧8행:** 관통하는 인체 경로와 새 CNS 효과는0이지만, 기존 둔상 되먹임으로 매우 작은 타박상/머리HP 감소가 남는다(예35→34.99118). ‘몸 손상도 완전히0’이라는 엄격한 기대는 미달이다. 방호 수식을 몰래 바꾸지 않았다.
- **조준/M855 척수B 무방호2행:**60초 의식26.28/27.07, 사격 가능true로 CC80 기대보다 낮다. 식도·척추·흉수 실제 동시 교차와 원래 상처/출혈의 결과다. v37과 시간 곡선이 바이트 수준으로 같으며 S0 회귀는 아니다. 별도7N6 서기 척수B는 의식100·사격true다.
- 대뇌 즉시 의식0, 뇌간 즉시 호흡/순환 정지는 **사용자 설계 기대/튜닝**이다. 모든 실제 뇌 총상이 임상적으로 같은 결과라는 주장은 하지 않는다.
- v37의 엄격 쓰러짐2/7, 일부 관절 초과/이동 방향/최종 접힘, 런타임 발 겹침과 일반 렌더 끊김은 그대로다. S0에서 해당 물리·애니메이션을 고쳤다고 주장하지 않는다.

## 실제 전투 연결과 화면

[실제 연속 틱 기록](../downloads/checks-s0-v38/live.json)은 변경 전/후 같은 정지 병사에 실탄 경로를 적용하고 `combat.tick/world.step`을60Hz로 돌린다. 환경 contact를 유지한다. 변경 후 헬멧 관통 대뇌와 뇌간은 각각0.016667초, 심장 단독은4.933333초에17강체가 활성화되고 총이 떨어진다. 얼굴·턱은15초 동안 쓰러지지 않는다. 의료 값을 주입하지 않았다.
