# M3: 지혈대·압박붕대·지혈거즈 처치

v58(M2) 위에서 작업한다. 3D는 2D와 분리된 상태다. 2D 원본은 바꾸지 않는다. 바꾼 항목은 대장에 출처/원본/튜닝/사용자 설계값/게임 허용과 `2D 역이식 후보`를 표시한다.

## 전체 순서

| 단계 | 내용 |
|---|---|
| M1, M2 | 완료 |
| **M3 (이번)** | 처치 1차: 지혈대·압박붕대·지혈거즈. IFAK 구성 변경, 포인터 잠금 |
| M4 | 처치 2차: 흉부 씰·바늘 감압·복부 |
| M5 | 타인 치료 |
| M6 | 장비별 격자 |

이번 처치 대상은 **본인만**이다.

## 0-1. IFAK 구성 변경 (사용자 설계값)

- 지혈대 CAT을 **2개**로 늘린다. 실제 미군 IFAK II도 CAT 2개다(M2 출처).
- 내부 격자를 **3×3**으로 되돌린다. 아이템 격자 크기를 줄인다.
  - 1×2: 흉부 씰(2개 1세트), 지혈거즈
  - 1×1: 지혈대 ×2, 압박붕대, 감압 바늘, NPA
  - 합계 9칸으로 빈칸 없이 꽉 찬다.
- 대장에 "내부 격자는 정리 공간의 추상화, 실제 크기 비례 아님(게임 허용)"으로 적는다.
- 무게는 M2의 제품 사양 그대로이고, CAT 1개분을 더한다.

## 0-2. 메뉴 닫은 뒤 바로 시점·사격 (PC 포인터 잠금)

- 인벤토리·의료 화면이나 일시정지 메뉴를 **클릭 또는 키 입력으로 닫는 순간** 같은 입력 처리 안에서 `requestPointerLock()`을 호출한다. 닫자마자 마우스 시점과 사격이 된다.
- **닫는 클릭은 사격으로 처리하지 않는다.** 그 다음 입력부터 사격이다.
- **Esc 예외**
  - Esc는 브라우저 잠금 해제 전용이라 Esc로 다시 잠글 수 없다.
  - 크롬은 Esc로 해제한 직후 짧은 시간 재잠금을 거부할 수 있다.
  - 실패하면(`pointerlockerror` 또는 Promise 거부) 다음 클릭에서 다시 시도하고, 그 클릭도 사격으로 처리하지 않는다.
- 터치 기기는 변경 없음.

## 1. 처치 공통 구조

### 지속 처치 상태
- 지금 B1은 매 틱 `s.controlFactor = 1`로 되돌린다(값을 한 번 넣으면 다음 틱에 사라짐).
- 환자 의료 상태에 지속 처치 목록(`appliedTreatments` 등, 이름은 구현 판단)을 둔다. 항목: 종류, 아이템 instanceId, 대상, 진행도, 상태.
- B1이 **매 틱** 이 목록을 읽어 출혈원별 계수를 계산한다.
  - 같은 출혈원에 처치가 여러 개면 계수를 곱한다.
  - 지혈대가 완전히 조여져 있으면 그 계수가 우선한다.
- 출혈원 유량식 자체는 바꾸지 않는다. 계수만 곱한다.
- M2의 `limbRouting`(sourceId별 밖/안 분배)은 계수가 곱해진 유량으로 그대로 나눈다.

### 처치 요청 경로 하나
- 아이템 드래그 → 대상에 놓기, 아이템 선택 → 대상 누르기 모두 **같은 함수**를 호출한다. 두 방식의 결과가 달라지면 안 된다.
- **적용 대상 강조**
  - 아이템을 고르거나 잡으면 적용 가능한 대상(마커, 상처 행, 팔다리 부위)을 강조한다.
  - 불가능한 대상을 누르면 이유를 짧게 보여준다(예: "몸통 안 출혈에는 효과 없음").
- **물품 처리**
  - 처치를 시작하면 아이템은 격자에서 나와 "사용 중" 상태가 된다(원자적, 복제·분실 금지).
  - 지혈대는 제거하면 가방(또는 원래 컨테이너 빈칸)으로 돌아온다. 빈칸이 없으면 보고된 규칙대로 처리한다.
  - 거즈·붕대는 포장을 뜯는 순간 소모된다. 제거하면 버려진다.

### 시간과 손
- 의료 화면이 열려 있어도 시간은 흐른다(M1). 처치는 실제 시간이 걸린다.
- 화면을 닫아도 진행 중인 처치는 계속된다. HUD에 작은 진행 막대를 표시한다.
- 한 번에 처치 하나만 가능하다(양손을 쓰므로).
- 처치 중에는 이동·사격·조준이 불가능하다. 시선은 자유롭다.
- **시간 배율**
  - 기본 시간은 출처 값이다(아래 각 절).
  - 다친 팔: 팔 기능·통증에 따라 느려진다. 분쇄·절단이 아니면 사용할 수 있다(사용자 설계값).
  - 한 팔이 분쇄·절단이면 남은 한 손으로 한다. 한 손 적용 시간은 출처를 찾고, 없으면 튜닝이다.
  - 두 팔 모두 분쇄·절단이면 자가 처치가 불가능하다.
  - 통증, D1 떨림, 의식 저하, 관류 저하가 시간을 더 늘린다(튜닝).
  - 의식 소실 상태에서는 처치할 수 없다.

### 중단
- **중단 조건:** 피격, 이동 입력, 달리기, 총 들기, 처치 취소 버튼. 피격 때 바로 중단할지 일정 통증 이상일 때만 중단할지는 튜닝이다.
- 중단되면 진행도를 유지하고, 해당 부위·마커를 "중단됨"(M1 색)으로 표시한다.
- `[마저 처치]`: 남은 시간만큼 이어 한다. 재개 준비 시간을 약간 더할 수 있다(튜닝).
- `[제거]`: 처치를 없앤다. 지혈대는 회수되고, 거즈·붕대는 버려진다.
- 중단된 상태의 효과는 각 절에 정의한다.

## 2. 지혈대 (CAT)

- **대상:** 팔다리 부위(위팔, 아래팔, 허벅지, 아래다리 구분).
- **감는 위치**
  - 놓을 때 두 가지 중 고른다(작은 선택지).
    - "높고 단단하게": 그 팔다리 가장 위쪽(위팔·허벅지 상단)
    - "상처 위": 상처보다 몸통 쪽으로 몇 cm 위
  - 근거는 TCCC 지침(긴급 상황 high & tight, 여유 있을 때 상처 위 5–8 cm)이다. 출처를 확인해 단다.
  - 위치는 출혈원 `position.proximalPoint` / `chainOrder` 체인 순서로 비교한다. 세계 y 좌표로 비교하지 않는다.
- **효과:** 감은 위치보다 먼 쪽(손끝·발끝 쪽)에 있는 그 팔다리의 출혈원에만 적용한다.
  - **완전히 조임(진행 100%):** 동맥·정맥 모두 막힌다. 계수는 거의 0이다. 남는 몫은 튜닝이고, 적용 성공률 같은 연구가 있으면 반영 방식을 보고한다.
  - **덜 조임(중단됨):** 정맥만 막히고 동맥은 남는다. 그 팔다리 출혈이 **늘어난다**(정맥성 지혈대 현상). 증가 정도는 출처를 찾고, 없으면 튜닝이다.
  - **통증:** 큰 통증이 더해진다. 출처 확인 또는 튜닝.
  - **기능:** 감은 동안 그 팔다리 기능은 0이다.
  - **2개 겹쳐 감기:** 첫 번째 바로 위에 두 번째를 감을 수 있다. 첫 번째가 덜 조여졌을 때 보완된다.
  - 장시간 압박 손상(약 2시간)은 하지 않는다. 감은 시각만 기록한다.
- **시간:** CAT 자가 적용 시간 연구(두 손/한 손, 팔/다리)를 출처로 쓴다.
- **제거하면** 다시 피가 흐른다.

## 3. 압박붕대 (이스라엘 붕대)

- **대상:** 상처(마커 또는 상처 행).
- **효과:** 그 상처에 연결된 출혈원 중 **밖으로 나오는 몫**에 적용한다.
  - 정맥·삼출: 크게 줄인다.
  - 동맥: 조금만 줄인다.
  - 계수는 튜닝이다. 압박 드레싱 효과 자료가 있으면 출처를 단다.
- 몸통 상처는 겉 삼출에만 효과가 있다. 흉강·복강 안 출혈에는 효과가 없다.
- **거즈 위에 덮기:** 지혈거즈 위에 감으면 거즈 효과를 유지시켜 준다(실제 순서: 채움 → 압박 붕대).
- **시간:** 감고 조이는 시간의 출처를 찾는다. 없으면 튜닝이다.
- **중단 시:** 진행도에 비례해 약한 효과만 낸다.

## 4. 지혈거즈 (QuikClot Combat Gauze)

- **대상:** 밖으로 열린 상처. 팔다리와 접합부(`junctional`: 사타구니, 겨드랑이, 목 등 지혈대를 감을 수 없는 곳)가 주 대상이다.
- **두 단계**
  1. 상처 통로에 채워 넣기(수십 초, 출처 또는 튜닝)
  2. 손으로 **3분간 압박**: 제조사 사용법이 3분 압박이다. 출처를 확인해 단다.
- **효과**
  - 3분을 다 채우면 그 상처 출혈원(동맥 포함)이 크게 줄어든다. 동물·임상 연구로 출처를 찾고, 계수는 튜닝이다.
  - 압박 중에는 손 압박만큼의 효과가 있다.
  - 3분 전에 중단하면 진행도에 비례해 약한 효과만 남는다.
- **중단 위험:** 압박하는 동안 양손이 묶인다. 이동·사격하면 중단된다.
- 몸통 안 출혈에는 효과가 없다.

## 5. 의료 화면 표시

- **처치 상태:** 마커와 상처 행에 상태 색(미처치 / 처치됨 / 중단됨)을 쓴다. 처치 아이콘도 표시한다(지혈대 위치는 팔다리 위에 띠로).
- **현황 문구:** 처치 후 실제 변화를 그대로 읽는다. 예: 지혈대 완전 조임 → 먼 쪽 상처 "멈춤". 덜 조임 → "더 많이 흐름".
- **진행 중:** 남은 시간, 단계(채우기 / 압박 중)를 표시한다.

## 6. 하지 않는 것

- 흉부 씰, 바늘 감압, 복부 처치, NPA(M4)
- 타인 치료(M5), 장비별 격자(M6)
- 지혈대 장시간 손상, 구획 증후군, 진통제, TXA
- AI의 처치 행동
- 탄도·관통·방호·HP·상처 수식, 출혈원 유량식

## 7. 검증

1. **대퇴동맥 관통상**
   - 처치 없음 / 지혈대 높고 단단하게 완전 조임 / 상처 위 / 덜 조임(중단) / 지혈대 2개
   - 각 경우 출혈원 유량, 혈액량, 의식, 심정지(또는 생존) 시간축
   - 완전 조임은 생존해야 하고, 덜 조임은 처치 없음보다 나빠야 한다.
2. **지혈대 위치 판정:** 아래팔 상처에 위팔 지혈대(효과 있음), 위팔 상처에 아래팔 지혈대(효과 없음)를 체인 순서로 확인한다.
3. **지혈거즈:** 접합부 출혈(사타구니 쪽 대퇴 근위 또는 겨드랑이) 사례에서 3분 완료와 1분에 중단을 비교한다. 거즈 + 압박붕대 조합도 확인한다.
4. **압박붕대:** 팔 근육 삼출, 동맥 상처 각각의 효과를 비교한다.
5. **시간 배율:** 건강한 팔 / 다친 팔 / 한 팔 분쇄(한 손) / 두 팔 분쇄(불가) / 높은 통증·떨림에서의 적용 시간.
6. **조작:** 드래그와 선택의 결과 동일, 빠른 연타 시 아이템 복제 없음, 실패 시 소모 없음, 중단·재개·제거, 지혈대 회수·거즈 폐기, 화면을 닫아도 처치 계속, HUD 진행 막대.
7. **불변:** 처치를 하지 않은 실사격 사례는 v58과 바이트 동일해야 한다(혈액량·의식·심정지·출혈원).
8. **IFAK:** 3×3에 9칸 구성이 꽉 차는지, 꺼내고 넣기, 무게 합산.
9. **포인터 잠금:** 인벤토리·의료 화면을 버튼과 키로 닫자마자 마우스 시점이 되는지, 닫는 클릭이 사격되지 않는지, Esc 일시정지 → 계속 직후의 재시도, 터치 변화 없음.
10. **화면:** 1280×720과 844×390에서 처치 중 화면, 중단 표시, 지혈대 띠, HUD 진행 막대를 캡처한다.
11. **기존 회귀:** 전체 테스트, 2D baseline 바이트 비교, 600틱 동일, S0 240조건·684채널 동일, 두 화면 오프라인 실행.
