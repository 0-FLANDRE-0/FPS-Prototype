# Vudu 렌즈 광학 — v27

**v27 당시 기록이다. 최신 사용자 번외 수정본 포팅은 [v28 변경·검증](training-side-optics-v28.md)을 따른다.**

2026-10-11. 사용자의 다음 단계 요청은 가능한 범위의 현실적인 렌즈 배율이다. v26의 1×2 M4 부착물·소유권·설치/분리 절차를 유지하고 렌즈 안 별도 영상, 1–6배 연속 조절, 눈 위치에 따른 그림자, 치수가 확인된 SR3 내부 조준선을 추가했다. 첨부 Z 전체 영점 로드맵의 완료 선언은 아니다.

## 사용

탄약상자에서 Vudu를 M4에 장착하고 조준한다. PC는 **Z를 누르는 동안 축소, X를 누르는 동안 확대**한다. 화면의 **−/＋ 44px 버튼도 누르는 동안** 동작하며 이동·사격 손가락과 소유권이 독립적이다. 전체 1→6 이동은 게임 조정값0.4초다. 배율은 같은 조준경 인스턴스에 보존되어 무기 전환·분리/재장착에도 유지된다. 마우스 휠은 기존 무기 전환이다.

배율 변화는 렌즈 안에만 적용된다. 기존 hip→ADS 바디캠 FOV 변화는 유지하고 배율로 전체 화면 FOV를 추가 변경하지 않는다. 장전·교체·부착 처리 중에는 조준을 풀고 렌즈 카메라를 중단한다. 메뉴에서는 직전 영상을 유지하며 재렌더하지 않는다. AK 전환/분리 시 렌즈 타깃을 해제한다.

## 제조사 자료와 광학 계산

[EOTECH 제품 페이지](https://www.eotechinc.com/products/eotech-vudu-1-6x24-ffp)를 HTTP200으로 확인했다. 공식 시야 폭은 **100yd=91.44m에서 1×31.2m, 6×5.09m**다. `2 atan(폭 / (2 거리))`로 렌즈 카메라의 실제 시야각을 계산한다.

| 배율 | 실제 시야각 | 눈에 보이는 각도 | 이상적 출사동 지름 |
| --- | ---: | ---: | ---: |
| 1× | 19.363317° | 19.363317° | 24mm |
| 6× | 3.188542° | 18.961222° | 4mm |

중간 배율은 눈에 보이는 시야각의 tangent를 보간하고 이를 배율로 나눈 값을 실제 시야각의 tangent로 사용한다. 제조사 끝점 두 개와 중심부의 tangent 배율을 동시에 맞춘다. 제조사 중간 배율 곡선은 공개되어 있지 않아 이 보간은 근사다. 이상적 출사동은 공식 대물24mm/배율이며 실제 렌즈·조리개의 상세 설계는 재현하지 않았다.

공식 아이릴리프는 1×83–100mm/6×82–100mm다. 정지 ADS 눈을 실제 접안 중심 뒤90mm에 맞추고 광학축을 따른다. 최대 ADS에서는 기존 무기 크기 설정이1로 복귀하므로 이 거리는 모델 좌표와 월드 좌표에서 같다. 호흡·걸음·총구 선행·반동·카메라 걸음 충격은 기존 동작을 유지하고 렌더 카메라의 실제 위치를 조준경 좌표로 변환해 그림자를 계산한다.

눈의 유효 동공3mm, 허용 범위 밖18mm에서의 축방향 감쇠, 투과율92%, 가장자리 감광8%는 **게임 조정값**이다. 출사동과 눈 동공의 겹침으로 가시성/렌더 필요를 판단하고 영상 평면의 광선 방향에 따라 검은 초승달을 만든다. 6×에서 옆으로2mm 이동하면 일부가 가려지고4mm에서 영상이 사라진다. 1×는 같은 이동에 더 관대하다. 실제 광선 전체를 추적한 렌즈 설계나 눈 생리 모델은 아니다.

## 렌더와 ADS 정렬

`optic-optics.js`는 공식 끝점·배율·출사동/동공 겹침을 계산한다. `optic-render.js`의 별도 PerspectiveCamera는 실제 대물 중심에서 −Z 광학축을 본다. PiP 렌더 동안 총기/팔 전체를 숨기고 완료 후 원래 가시성을 복원하므로 총기·팔·조준경이 확대 영상에 중복되지 않는다. HalfFloat linear RGB 타깃의 영상을 접안면 원형 셰이더로 표시하고 기존 ACES/노출1.15 및 바디캠 렌즈를 한 번 적용한다. 영상의 배율은 접안면과 눈 사이 광선 각도로 계산하며 단순 화면 텍스처 확대가 아니다.

원본 GLB의 앞/뒤 유리가 한 primitive에 있어 실행 중 geometry 인덱스를 복제해 대물 유리64삼각형만 남기고 접안 유리는 영상으로 대체한다. 저장된 원본/최적화 GLB의 정점·UV·이미지·바이트는 v26 그대로다. 접안 영상은 원래 접안면 z0에 있으며 카메라가 렌즈 안에 들어가는 방식은 사용하지 않는다.

렌즈 픽셀 지름과 실제 renderer DPR을 기준으로 타깃을128 이상2의 거듭제곱으로 정한다. 품질별 상한은 low384/balanced768/high1024다. 화면 밖·그림자 완전 차단·비조준·인벤토리·메뉴·처리 중에는 추가 월드 렌더를 생략한다. 타깃 버킷이 같으면 재사용한다. 조준 가이드/피격 표시도 렌즈의 확대된 투영 위치로 옮기고 가려진 위치에서는 숨긴다.

M4 장착 ADS는 접안/대물 실제 마커를 사용한다. 기존 기계식 마커의 −0.008065rad 기울기를 광학 조준에 겹치지 않는다. 광학축과 총열은 평행이며 **수치 영점은 아직 없다**. 기계식 M4/AK의 기존 정렬은 보존한다. 장착 상태의 비조준 위치/회전/총구 경로도 기존과 동일하다. 570g의 기존 질량 반동 항은 v26 그대로이며 별도 반동 수식을 추가하지 않았다.

## SR3 자료 정정과 적용 범위

공식 [SR2/SR3 Manual VD1905 RevB, April2021](https://cdn.shopify.com/s/files/1/0698/3044/3191/files/Vudu_Reticle_Manual_SR2-3_RevB_98e2cd9b-6729-466e-91da-e502b3c21fdc.pdf?v=1763358308)의8–9쪽을 확인했다. SR3 내부 링 외반지름2.15mrad·링 두께.30mrad·중심점 지름.44mrad·아래 틈2mrad, 수평4/6mrad, 세로2/3/4.1mrad를 각도 단위로 셰이더에 구현했다. 배율과 함께 커지는 FFP 방식이다. 짧은 막대 길이/폭.8mrad·문자 높이.7mrad와 최소1px 선 두께는 자료에 치수가 없어 명시적 튜닝이다. 1×의 약3px 내부 링은 화면 해상도/최소 선 두께로 외곽 크기 비율이 달라질 수 있다.

자료의4/5/6 표기는 **400/500/600야드**다. 기준은 **100야드 영점, 75gr 5.56 BTHP, 2900fps, BC.395, 조준 높이1.5인치**다. 첨부 Z의100m/M855 전제와 다르므로 현재 탄종에 맞는 사격 해법이라고 주장하지 않는다. 실제 게임 탄도와 영점/BDC 오차 검증은 후속이다. SR3 전체 외곽 speed ring의 각도 치수는 확보한 공식 SR2/3 및 SR1 매뉴얼에 없어서 추측해 추가하지 않았다. 따라서 현재 조준선은 **치수가 확인된 내부 SR3**이며 전체 SR3 복제 완료가 아니다.
