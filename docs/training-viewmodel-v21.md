# v21 반동·총구 선행·팔 배치 수정

2026-10-11 KST. 사용자가 v20의 반동 변화, 열린 어깨 단면이 보이는 팔, 비조준/조준 중 총구 선행을 지적한 후속 작업이다. 실제 최신 빌드는 `downloads/verification-viewmodel-follow-v21.json`과 `HANDOFF_KO.md`의 다운로드를 따른다. v20 기록은 당시 결과로 보존한다.

## 동작

- 개머리판을 절대 회전축으로 붙이던 v20의 AimState 위치 계산과 렌더 접점 보간을 제거했다. v19의 반동 축/후퇴/ADS 가늠자 지연 계산과 일반 위치·회전 보간을 복구했다. `recoil.js`의 충격량·복귀·입력 보정, 카메라 추종/걸음 충격 수치는 그대로다.
- 비조준에서는 회전 입력만 받는 별도 느린 마운트를 두었다. 총구·가늠쇠가 먼저 움직이고 가늠자 쪽과 카메라가 뒤따른다. 이 추가 위치 보정에 반동/호흡/보행 성분을 넣지 않으므로 회전 입력 없는 사격은 이전 위치·방향·반동과 같다. 조준에서는 원래의 가늠자 마운트를 이용한다. 정지하면 시선과 조준선이 다시 맞고, 장전/벽 앞에서는 기존 조작 공간으로 돌아간다. 보정 위치는 논리 총구와 화면 총구에 함께 적용한다.
- 팔의 어깨를 보간된 카메라의 몸 프레임에 연결하고 손은 실제 총기 접점/장전 경로에 연결한다. 양팔의 IK 어깨를 고정된 표시용 좌표에 놓고 원본의 짧은 체인을 상완2배/전완1.35배로 리타겟한다. 두 구간의 길이를 비슷하게 맞춰 손이 어깨 가까이 오는 장전 동작에도 손목이 떨어지지 않는다. 이 값과 어깨 위치는 1인칭 표시 튜닝이며 인체의 실제 측정값이 아니다. 모든 프레임에서 같은 길이 배율을 사용한다. 팔꿈치 방향도 몸 프레임의 아래/뒤쪽 힌트로 잡아, 짧은 AK 조준 거리에서 팔꿈치가 시야 앞쪽으로 접히는 현상을 줄였다. 손/손가락 크기는 유지하며 원본 메쉬·토폴로지·재질·클립 파일은 바꾸지 않는다.
- 손목 끝과 손 목표를 각각 측정해, 손만 총에 붙고 전완이 떨어지는 경우도 검출한다. 어깨의 실제 열린 경계는 UV/노멀 이음매를 용접한 기하 경계로 찾고 화면 밖인지 검사한다. 팔 전체를 숨기는 처리는 없다.

## 검증 방법과 증거

`npm test`, `npm run verify:baseline`, `npm run build:training`을 로컬 실행한다. Actions는 사용하지 않는다. 모든 커밋에 `[skip ci]`를 넣는다.

`node scripts/check-training-viewmodel.mjs`는 v19의 정확한 HTML/소스 기준과 현재 QA 번들을 비교한다. 두 의료 모드의 600틱/6발 이동은 카메라·방향·회전·반동·보행·걸음 스프링을 대조한다. 회전 입력 때 달라지는 총구 위치는 별도로 보고한다. 회전 입력 없는 600틱 사격은 총구와 사격 기록도 완전 일치를 요구한다. 기존 14개 M4 사격 fixture의 탄도·방호·인체·의료 필드는 전체 대조한다. 새 AK 재고를 추가한 W의 총 탄약 용량만 비교에서 제외한다. 의료·방호 코드 및 원본 게임 자산은 이번 수정 범위에 없다.

두 총기 × PC1280×720/모바일844×390 × 12상태(비조준·회전·ADS 렌즈0/70·반동·걷기·달리기·tactical/empty 장전·교체)의 실제 스킨을 검사한다. 화면에 들어오는 어깨 경계, 15mm near-plane 교차, 손과 전완 손목 끝의 거리, 정지 ADS 중심을 확인한다. 각 총기의 empty 장전은 추가로 60Hz 240프레임을 연속 검사한다. 최종 상세 값/화면은 `downloads/checks-viewmodel-v21/report.json`을 따른다.

`CQB_OFFLINE_OUT=downloads/checks-viewmodel-v21-offline node scripts/check-training-w-offline.mjs`는 QA 접근이 없는 실제 최종 HTML을 오프라인에서 연다. PC1/2·휠·조정간, 실제 CDP 멀티터치 이동 중 전환/사격/조준 게이트, 장전 중 전환 취소와 탄약 보존을 검사한다. 화면과 HTML 해시는 해당 폴더의 report에 기록한다.

## 로컬 결과

공식143/143, 원본 baseline 바이트 동일. 두 의료 모드 모두 회전 입력 없는600틱/6발의 카메라·총구·반동·사격 기록이 v19와 완전히 같고, 14fixture×2모드의 탄도·방호·인체·의료 필드도 같다. 이동/회전600틱에서 카메라·방향·반동·보행·걸음 스프링은 같다. 새 비조준 입력 보정의 최대 총구 위치 차이는 이 시나리오에서0.453mm다.

48상태의 화면 내 어깨 경계/near-plane 교차는0이다. 실제 전완 손목 끝과 손의 간격은1cm 허용값 이내다. 각 총기의 empty 장전240프레임은 최대0.00034mm 이내로 연결됐다. 정지 ADS의 렌즈0/70 중심은±1px 이내다.

## 유지한 범위와 한계

AK-74M과 M4의 장전 시간·클립 속도·인벤토리·관통·방호·의료 수식은 유지했다. 1024 WebP/무손실 노멀/동일 accessor 공유 최적화와 10,410,992B FPS GLB도 그대로다. 원본 15,131,564B GLB와 CC BY4 크레딧은 저장소에 보존한다.

실제 Android/S24·iOS Safari의 조작감/성능은 미검증이다. 직접 file:// 실행은 이 환경의 Chromium 관리 정책이 게임 부팅 전에 차단했고, 실제 최종 HTML의 네트워크 OFF 메모리 경로 실행으로 확인했다. M4에 AK용 손가락 포즈/장전 클립을 맞춘 기존 표현상 한계와 AK의 긴 장전 회복은 남아 있다. 어깨 절단면 노출과 손목 분리를 이것들과 혼동하지 않는다. 모든 스크린샷의 렌즈와 해상도는 report에서 확인할 수 있다.
