## 5.56 전용 3D 유지율

최적 R = **0.885562707019381 / 100m**. `flightProfile()`의 구경별 덮어쓰기에만 적용한다. `DRAG_RETENTION_PER_100M`, `getVelocityDragClass`, `getDistanceVelocityRetention`와 2D 출력은 변경하지 않는다. 모든 비5.56 프로필102종은 동일하다.

클래스 유지율 비율을 그대로 옮겼다: `R(class) = R(fit) × legacyR(class) / legacyR(rifle_light)`. 이는 유지율 비율 보존이며 로그 저항계수의 비율 보존을 뜻하지 않는다. Mk262도 원본 클래스는 rifle_light이므로 임의의 rifle_heavy 값을 만들지 않았다.

## 기울이기 조작과 튜닝

- PC Q/E=좌/우 기울이기. 우클릭은 기존 `mouseAdsMode`, 화면 조준은 토글이다. R/C/F/B/Z/X/Shift/1·2/휠 바인딩은 그대로다.
- `leanMode`: hold(누르는 동안, 기본) / toggle(토글). 저장·유효값 정리·설정 초기화에 포함한다. 같은 쪽 토글 재입력=중립, 반대쪽=그쪽. hold에서 여러 키/버튼은 마지막 입력을 우선하고 놓으면 남아 있는 입력으로 돌아간다.
- 좌우44×44px 버튼은 사격 버튼 위에 둔다. 이동/사격/시점 소유자, 배율 소유자, 린 소유자는 독립이다. 메뉴·인벤토리·달리기 시작은 의도를 비우고 자세를 중립으로 돌린다. 달리기 중 린 입력은 허용하지 않는다.
- 서기 골반 위 축1.0m, 눈1.43m 기준 머리 최대 옆 이동0.25m·롤12°. 골반 축 회전에 몸통 옆 이동을 합성해 두 목표를 맞춘다. 머리 높이 변화는 축 위 높이×(cos(roll)−1)이다. 앉기에서는 축/옆 이동이 실제 viewHeight/1.43 비례, 롤 비율은 같다. 이 몸통 옆 이동도 게임 튜닝이다.
- 지수 응답ln(10)/.25로0.25초에90%. 이동 속도0.6배·호흡/걷기 흔들림1.2배. 총·팔·눈·광학축·렌즈 카메라·레티클은 같은 월드 회전을 따른다.
- 머리는 중립 눈→목표 눈 반지름0.12m sphere cast. 최초 접촉 거리에서0.02m를 빼 제한하며 전체 목표를 검사한 뒤 안전 범위에서 감쇠한다. 총구는 기울인 안전한 견착점→목표 총구를0.03m 구체로 쓸어 여유0.02m 앞까지 총/팔을 당긴다. 중립 총구가 기존 엄폐물 뒤에 있어도 머리 린을 잠그지 않고, 경로가 열리면 조준 자세로 돌아간다. 견착점의 눈 아래0.07m는 v30 사격 판정의 원본 게임 기하를 재사용했다. 렌더 보간된 총구 경로도 별도로 검사한다. 센서·플레이어 자기 캡슐은 제외한다. 충돌 제한은 즉시 적용하고 렌더 보간도 이전의 더 큰 기울기로 넘어가지 않게 제한한다.
- 기존 `muzzleBlocked()`와 사격 직전 총구 판정에 기울인 견착/총구를 사용한다. 단일 플레이어 이동 캡슐은 기존 형상이며 플레이어 전용 머리·상체 피격/방호 볼륨은 아직 없다. 후속 PvP/NPC 피격 작업에서 추가할 항목으로 기록한다. 표적 H01은 그대로 A자 고정이다.
- `shotPose()`는 기존대로 총기 로컬 좌우축에 θ를 넣는다. 캔트 보정은 하지 않는다.
