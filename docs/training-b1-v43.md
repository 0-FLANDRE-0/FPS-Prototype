# B1 / v43 — 출혈원과 심박출량 상한

v42 `d2e3fa55a6d0f2c7fdd003bad35a412aafb6b000` 위 독립 3D 변경이다. 첨부 [원문](training-b1-instructions.md)을 구현한다. 메시지 본문에는 별도 지시가 없었다. 2D 자동 역이식은 하지 않는다.

출처와 수치는 [출처](medical-b1-sources.json)와 [대장](medical-b1-ledger.json)을 따른다. `intra_thoracic` 개인 처치 불가는 사용자 설계이며 치료는 구현하지 않는다.

## 계산과 치료 연결 자리

혈관 하나의 출혈원에 여러 상처의 lesion을 연결한다. 상처별 `bleedSourceIds`가 같은 전역 출혈원을 참조하므로 재피격해도 혈관을 복제하지 않는다. 장기 내부 혈관 나무는 모델에 없으므로 장기 손상을 **등가 미세혈관상**으로 표시한다. 이는 새로운 명명 혈관의 실제 교차가 아니다. 기존 S2 단발 에너지 기준 절단의 가상 혈관 절단도 별도 `modeled-severance` 출혈원으로 유지하고 실제 해부 교차라고 주장하지 않는다. 근육·모세혈관 삼출은 상처마다 하나이며 원래 R3-a의 작은 상처 초기값·지수 감소·바닥을 사용한다. 혈관/장기와 섞인 상처는 중복 원본 등급 출혈을 더하지 않고 0.5ml/s 삼출만 별도로 둔다(튜닝).

혈관 출혈은 Cd·A·√(2ΔP/ρ)를 SI로 계산한다. 원본 S1의 Cd0.62·ρ1060·mmHg133.322와 기준 CO5250ml/min을 사용한다. 동맥은 실제 현재 MAP, 정맥은5mmHg(튜닝)다. 정상 혈류를 확인하지 못한 게임 혈관은8mm에서350ml/min, 지름² 비례 추정이며 예비 배율1.7이다. 전체 출혈은 현재 **기존** `cardiacOutputMul×5250/60`에 비례 제한한다. 펌프/혈압/심박/쇼크/의식/심정지 판정 수식은 바꾸지 않는다. 심정지 CO0에는 출혈도0이다. 과거의 심정지 후 유효유량×0.05는 이 물리 상한으로 대체한다.

영구 공동 폭이 fitted 혈관 지름을 덮는 비율0.8부터 완전 절단이다(형상 근사·튜닝). 주요 동맥의 부분 손상은 자연 감소0, 완전 절단의 수축은8초 시상수·면적 하한35%다. 작은 동맥90초/정맥45초이며 낮은 MAP에서 더 빨리 줄인다. 감소 노출 시간 `clotExposureS`를 매 틱 적산하므로 혈압이 회복돼도 이미 줄어든 구멍이 저절로 다시 커지지 않는다. 혈관별 정상 혈류는 임상 실측표로 주장하지 않는다.

공동만 닿은 혈관은 `vesselContusions`로 기록하고 혈관 생리 프로필/출혈 증거에서 제외한다. 원래 S1/S2 유효 손상량과 혈관 조직계수0.12, 모든 HP·탄도·관통·방호는 보존한다.

출혈원 위치는 원래 body address를 unpose한 bind 좌표에서 실제 이름의 뼈 원점을 뺀 값이다. 팔다리는 원래24본의 근위 상완/대퇴 기점을 함께 저장한다. 후속 지혈대는 뼈 계열과 순서를 판정해야 하며 세계 y 비교로 구현하지 않는다.

## 혈흉과 공기

기존 `chestTraumaModel`에는 `openChestWound`, `pneumothoraxRisk`, `_pneumoProg`, `tensionPneumothoraxRisk`, `hemothoraxRisk`가 있다. 실제 공기 ml나 혈액 ml가 없었고 위험 기반0.05 호흡 drain도 존재한다. 이 원래 기흉 진행/호흡 코드는 보존하고 실제 혈흉 제한을 추가한다.

`bloodPoolsMl`의 흉강 좌/우, 복강, 후복막, 팔다리 구획, 외부량을 따로 적산한다. 좌/우 폐 효율은 `2250/(2250+그쪽 혈흉ml)`이며 기존 호흡 효율에 양폐 평균 상한으로 연결한다. 1500ml의 대량 혈흉 기준은 MSD 원문에서 확인했다. 곡선은 튜닝이며 1500ml 한쪽 혈흉에서 전체 호흡 상한80%다. 1500/2250/3000ml 반응 시상 곡선을 두 서기 대동맥 경로로 먼저 조사했고2250을 선택했다. 이는 대동맥 약30초 조건과 호흡 저하를 함께 유지하려는 게임 조정이며 임상 곡선 적합이 아니다.

`chestCompartments.left/right`의 `chestWallOpen`, `tensionAir`, `pneumothoraxProgress`, `hemothoraxMl`은 별개다. `tensionAir`는 **원래 정규화 위험값**, 단위는 공기 ml가 아님을 필드에 적는다. 없는 압력–부피 모델을 지어내지 않는다. 향후 실제 공기량 모델을 넣을 때 단위 이행이 필요하다. 바늘·씰·지혈제 등의 새 처치 효과는 없다.

## 표시

설정의 몸속 판정 표시를 켜면 화면 왼쪽의 접이식 출혈 디버그와 의료 기록의 목록에 현재 출혈/CO 상한/비례 배율, 혈관·종류·고이는 곳·처치 분류·ml/s, 고이는 곳별 누적량을 표시한다. 각 피격 기록에서 연결 출혈원ID와 혈관 타박을 확인한다. 기본 숨김이며 의료 대상 선택을 따른다.
