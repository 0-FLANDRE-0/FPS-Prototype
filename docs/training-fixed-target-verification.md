# H01 고정 A 자세 표적 v11

사용자가 자세를 바꾸면 방탄복 안쪽 몸통이 보이지 않고 무릎 보호대·어깨 끈이 분리되는 현상을 보고한 뒤, H01을 A 자세로 고정한 피격/의료 확인용 캐릭터로 사용하도록 변경했다. 이번 제출은 이 마지막 지시에 따른 고정 표적이다. 움직이는 자세의 리깅 문제를 수리한 버전으로 표현하지 않는다.

제품에서 자세 선택 UI와 제자리 걷기 재생을 제거했다. `cleanSettings`는 이전 `standing/aim/crouch/walk` 저장값을 모두 `rest`로 불러온다. 제품 초기화/설정은 고정 A 자세만 적용하고 tick마다 병사의 자세를 갱신하지 않는다. 표적 표지에도 용도를 표시한다. 플레이어의 앉기/이동과 카메라 설정은 기존 기능이다.

원본 모델과 파생 GLB, 스킨/클립, 피격 메시/방호 피복과 v10의 Br4 판 → 6B45 소프트 → 인체 판정, 6B47 헬멧, 내구도와 궤적은 그대로다. 편집용 GLB의 기존 클립은 보존하지만 제품에서 재생하지 않는다. 테스트용 공간 API에는 기존 자세 연산이 남아 있으며 제품 UI나 저장 설정으로 호출할 수 없다.

A 자세에서는 원본 외형을 사용한다. 모델의 방탄복 안쪽 완전한 몸통 시각 면을 추가하지 않았다. 기존 숨은 몸통 피격체는 저작 근사다. 원본 Vest의 무릎/어깨 부품 연결 문제는 앞으로 움직이는 NPC 모델을 만들 때 별도로 수정해야 한다. 고정 표적을 NPC 애니메이션 완료 모델로 간주하지 않는다.

의료 상태 확인은 앞으로 연결할 용도다. 현재 계산은 방호 저지·내구도·인체 저항/정지/출구와 피격 기록이며 상처·출혈·둔상/골절·생리·치료는 미구현이다. 원본 계산과 새 3D 튜닝 경계는 [v10 기록](training-protection-verification.md)을 따른다.

검증 하네스는 `scripts/check-training-fixed-target.mjs`다. 제품 HTML의 터치844×390/마우스1280×720에서 과거 crouch/walk 저장값 마이그레이션, 자세 선택 제거, 표시 설정/새로고침/reset과 이동/사격/장전/가방 중 고정 관절을 확인한다. 별도 QA 번들은 기존 원본 shot RNG·실제 인벤토리/발사·Rapier를 사용하며 A 자세 방호/인체10사례와 v9 기준600틱/6발 조작 비교, 정면/측면/후면 화면을 기록한다. QA HTML/가변 API는 전달물에 넣지 않는다.

```sh
npm test
npm run verify:baseline
npm run build:training
CQB_OFFLINE=1 node scripts/check-training-fixed-target.mjs
```

오프라인은 네트워크를 끄고 같은 HTML 바이트를 메모리에서 공급하는 방법이다. 이 환경의 file URL 제한 때문에 직접 파일 실행/실기기/S24/발열 검증은 아니다. 성공 범위·해시·실제 발사 수는 `downloads/verification-fixed-target-v11.json`, 실제 다운로드 ZIP 대조는 `downloads/delivery-fixed-target-v11.json`을 따른다. 이전 v10 및 모든 전달 기록을 보존한다.
