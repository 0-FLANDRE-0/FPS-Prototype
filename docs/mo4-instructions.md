# MO4: 심장 치명 · 속 빈 장기 감염 · MO3 보정

저장소 `0-FLANDRE-0/FPS-Prototype`, 브랜치 `feature/medical-overhaul`, 기준 `b52adf2`(MO3). 먼저 `docs/mo3-unified-bleeding.md`, `docs/mo3-sources.md`, 의료 개편 계약을 읽는다. 값에는 출처/원본/튜닝/사용자 설계값/게임 허용을 표시한다.

**이번에 안 하는 것:** 약물·항생제·수혈 재작성(MO5), 저혈량 HP 감소·위급 상태·사망 타이머·수술·블랙아웃 규칙(후속), 탄도·방호·상처 통로·손상량 계산.

## 1. MO3 보정

### 1.1 동맥 최소 상한 (사용자 설계값, 값은 튜닝)
- 문제: 혈관 상한이 "안정 혈류 × 6"이어서 팔다리 동맥이 너무 낮다. 상완 2.8, 요골·척골 1.1~1.4, 겨드랑이 9.9, 오금 7.2, 쇄골하 19.3 mL/s라서, 크게 끊겨도 일반 출혈(< 20)이 되고 붕대만으로 다 멎는다.
- **이름 붙은 동맥의 상한은 최소 25 mL/s로 한다.** `상한 = max(안정 혈류 × k, 25)`.
  - 정맥은 바꾸지 않는다.
  - 구멍 크기 식은 그대로라서, 살짝 손상된 동맥은 여전히 일반 출혈로 남을 수 있다.
  - 이미 25보다 큰 동맥(대퇴 28.4, 경동맥 46.5, 장골, 대동맥)은 그대로다.
- 혈관표를 다시 내고, 동맥별로 손상 크기에 따라 등급이 바뀌는 지점(구멍 면적)을 보고한다.
- `Qref` 분포표와 경계 20의 적절성을 다시 보고한다.

### 1.2 폐 불이익 세기 (사용자 설계값, 값은 튜닝)
- 문제: 폐 한쪽이 0.8 L라서 직접 관통 한 발도 손상 비율 `d` ≈ 0.09, 스태미나 −2%에 그친다.
- 한쪽 폐 불이익 = `min(25%, g × d)`로 바꾼다. 양쪽 합산 최대 −50%. 여러 발을 합치는 기존 식은 유지한다.
- `g`는 **직접 관통 한 발이 −10~15%**(목표 중앙 12.5%)가 되게 맞춘다. 대표 탄(5.45 PS, 5.56 M855, 7.62×51 M80)의 폐 직접 관통으로 각각의 `d`와 불이익을 표로 낸다. 공동만 스친 경우의 불이익도 같이 낸다.
- 다리 스태미나 최대치에 한 번 곱하는 방식(회복은 최대치 비례)은 MO3 그대로다.

## 2. 심장 치명

- **치명 판정은 기존 피격 기준을 쓴다.** 직접 관통 여부와 S0 펌프 손상 정도로, 지금 "펌프 실패"로 심정지에 들어가는 조건(`failedPumpThreshold` 등)이다. 실제 어떤 조건인지 코드에서 확인해 표로 보고한다.
- **치명이면 즉시 사망한다**(사용자 설계값). 기존 심정지 후 300초 대기를 거치지 않는다. 어떤 아이템·처치로도 되돌리지 않는다.
  - 화면은 기존 사망 처리를 따른다. 래그돌·시점 전환 등은 그대로다.
- **치명이 아닌 심장 피격**(공동만 스침, 작은 손상): 출혈·손상과 기존 리듬 이상 위험, 순환 계산을 그대로 둔다.
- **순환 계산(심박출량·혈압)은 전부 유지한다.** 출혈량이 그 위에서 돌아간다.
- 출혈·저혈량으로 생기는 심정지 → 300초 → 사망 경로는 이번에 바꾸지 않는다(후속 위급 상태 단계).
- 뇌간 등 기존 즉시 치명 경로도 그대로다.
- 검증: S0 240조건·단일 28건 중 심장 관련 경로를 치명 / 비치명으로 나눈 표. 치명 판정 직후 사망까지 걸린 시간(즉시여야 함).

## 3. 속 빈 장기 감염 (사용자 설계값, 수치는 튜닝)

### 대상
- 위·소장·대장·방광을 맞은 상처만 감염이 걸린다. 직접 관통과 공동 손상 모두 기존 장기 손상 판정을 쓴다.
- 모델에 있는 다른 속 빈 장기(식도, 담낭, 요관 등)가 있으면 목록을 보고하고, 이번에는 넣지 않는다.
- 간·비장·신장(고형 장기)은 감염 없이 출혈만 있다.

### 진행
- **감염 심각도 `s`(0~1):** 속 빈 장기의 손상량·심각도로 정한다. 여러 상처는 기존 합산 방식(`1−Π(1−s)` 등)으로 합친다.
- **잠복:** 피격 후 **5~10분** 뒤 증상이 시작된다. 심할수록 빠르다(`s`=1이면 5분, 작으면 10분 쪽).
  - 나중에 스킬 배율을 곱할 자리를 둔다. 지금은 1이다.
- **악화:** 증상이 시작되면 감염 수준이 시간에 따라 올라간다. 최대치까지 걸리는 시간은 튜닝이다(예: 10분).
- 처치(붕대·거즈 등)와 부위 HP 회복으로는 감염이 없어지지 않는다. 항생제는 MO5에서 만든다. 지금은 항생제가 감염을 멈추거나 낮출 수 있는 연결부만 둔다.
- 감염으로 직접 사망하지는 않는다. 레이드 사이로 이어지는 처리는 후속이다.

### 증상 (적게, 명확하게)
- **피로:** 다리 스태미나 최대치·회복 감소. 감염 수준 최대에서 −30%(튜닝). 폐 불이익과는 곱으로 합친다.
- **회복 저하:** 부위 HP 회복 속도 감소. 감염 수준 최대에서 ×0.5(튜닝).
- 그 밖의 증상(열, 시야 등)은 넣지 않는다.

### 표시
- 잠복 동안에는 표시하지 않는다(보이는 것만 보여주는 기존 원칙).
- 증상이 시작되면 의료탭 상태와 HUD에 "감염"과 진행 정도를 표시한다.

## 4. 검증

1. **동맥 상한:** 새 혈관표, 동맥별 일반/과다 전환 구멍 면적. 상완동맥 완전 손상이 과다가 되는지, 살짝 손상은 일반인지.
2. **분포:** `Qref` 분포, 경계 15/20/25/30.
3. **폐:** 대표 탄 3종의 직접 관통·공동 스침의 `d`와 불이익. `g` 값과 맞춘 과정.
4. **심장:** 치명/비치명 분류표, 치명 시 즉시 사망, 비치명 시 리듬 위험 유지.
5. **감염:** 장기별·심각도별 잠복 시간, 악화 곡선, 증상 수치 시간 그래프. 고형 장기만 맞은 경우 감염 0. 처치·HP 회복으로 감염이 안 없어지는지.
6. **화면:** 1280×720·844×390에서 잠복 중 표시 없음 → 증상 시작 후 의료탭·HUD 표시. 폐 손상 후 스태미나 막대.
7. **회귀:** 전체 테스트, 고정 2D 보존, MO3 기준(`tests/fixtures/mo3/golden.json`)에서 의도적으로 바뀐 채널과 그대로인 채널을 나눠 보고, M4/AK 600틱.
