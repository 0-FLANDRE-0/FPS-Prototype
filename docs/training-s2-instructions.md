# S2: 몸속 속도 통일·뼈 안 공동·부위 HP 의미

v39 위에서 작업한다. 3D 의료는 2D와 분리된 상태다. 바꾼 항목은 대장에 출처/원본/튜닝과 `2D 역이식 후보`를 표시한다.

## 목표

1. 몸 안에서는 S1 상처 모델 하나로 피해와 탄 속도를 함께 정한다. 지금은 피해(새 모델)와 실제 탄 속도(기존 인체 저항)가 따로 계산돼서 에너지가 이중으로 쓰인다.
2. 조직마다 저항을 다르게 준다(연조직, 폐, 뼈).
3. 뼈로 둘러싸인 구조(뇌, 뇌간, 척수)의 순간 공동 처리를 고친다.
4. 부위 HP 0의 의미를 부위별로 정하고, 분쇄·절단 단계를 넣는다.

탄 데미지 수치와 부위 HP 수치는 이번에도 바꾸지 않는다. 대신 보정용 표를 만든다(5번).

## 1. 몸 안 속도 통일

- 몸 안 구간에서는 S1 1D 모델이 탄의 속도, 질량, 회전각, 파편 상태를 정한다. 몸을 빠져나갈 때의 속도와 체내 정지 여부도 이 모델이 정한다.
- 몸을 빠져나간 뒤에는 그 속도로 기존 비행·벽·방호 계산이 이어진다. 벽·방호·재질 관통 수식은 바꾸지 않는다.
- 기존 인체 저항 계산은 몸 안에서 더 이상 쓰지 않는다. 지우지는 말고, 비교와 legacy용으로 남긴다.
- 여러 부위를 지날 때 다음 부위는 앞 부위의 새 모델 출구 상태(속도, 회전각, 파편)로 시작한다. S1에서 기존 입사 속도를 다시 넣던 부분을 바꾸는 것이다.
- 회전각을 이어받는 것이 맞는지 보고한다. 예: 팔을 지나며 이미 누운 탄이 몸통에 들어가는 경우.

### 1-a 조직별 저항

각 칸이 어느 조직 안에 있는지는 S1의 장기별 깊이 구간 캐시로 정한다. 칸마다 3D 조회는 하지 않는다.

| 조직 | 처리 |
|---|---|
| 근육·피부·지방·실질 장기·혈액 | 젤라틴 보정값 그대로(젤라틴은 근육 기준) |
| 폐 | 공기가 찬 폐의 실효 밀도로 저항을 줄인다. 실효 밀도는 출처를 찾고, 못 찾으면 튜닝으로 둔다. |
| 뼈(피질골·해면골) | 밀도로 저항을 키운다. 밀도는 S1에서 근육 밀도를 가져온 같은 공식 참조표에서 가져온다. |
| 몸속 빈 공간(장 속 공기 등, 도형이 있으면) | 저항을 아주 낮게 둔다. |

- **뼈 통과 시 추가 효과(튜닝):**
  - 회전 시작을 앞당긴다.
  - 탄이 변형되면 단면적이 늘어난다.
  - 뼈 조각이 2차 파편이 되어 뼈 주변 일정 반경에 영구 손상을 더한다.
  - 문헌에 정성적 설명이 있으면 출처로 달고, 수치는 튜닝으로 표시한다.
- 기존 뼈 골절 판정 로직은 유지한다.

### 1-b 성능

S1의 미리 계산한 표(균질 젤라틴 기준)를 계속 쓰기 위해 **환산 깊이** 방식을 우선 시험한다.
- 각 조직 구간을 젤라틴 기준 등가 깊이로 바꿔서 표를 조회한다. 환산 비율은 밀도와 저항 비율로 정한다.
- 뼈의 회전 앞당김, 변형, 2차 파편처럼 표로 표현할 수 없는 효과는 따로 처리한다.
- 같은 입력에서 칸마다 직접 계산한 결과와 환산 깊이 결과의 차이를 보고한다.
- 예산은 S1과 같다. 피격당 중앙값과 p95가 0.1 ms 이하여야 한다.

## 2. 뼈로 둘러싸인 구조의 순간 공동

- 뇌는 두개골, 뇌간과 척수는 두개골·척추뼈 안에 있다.
- **탄이 그 뼈 안으로 들어간 경우:**
  - 뼈를 뚫을 때 1-a의 뼈 저항으로 에너지를 잃는다.
  - 안쪽 뇌의 순간 공동 계수는 1이다(닫힌 공간).
  - S0의 직접 관통 즉시 무력화는 유지한다.
- **탄이 뼈 밖으로만 지나간 경우(얼굴, 턱, 목 근육 등):**
  - 뼈 안쪽 구조에 주는 순간 공동 피해를 크게 줄이거나 0으로 한다. 감쇠 계수는 튜닝이다.
  - 대신 새 필드 `concussionRisk`(0–1)로 기록한다. 이 값은 나중에 어지러움 디버프에 연결한다. 이번에는 생리 효과를 주지 않는다.
- v39 실제 화면 얼굴 경로(직접 뇌·뇌간 교차 0인데 0.58 s에 의식 소실)를 같은 조건으로 재실행한다. 즉시 쓰러지지 않아야 한다.

## 3. 부위 HP 0의 의미

부위 HP는 그 부위의 구조 내구도다. 0이 됐을 때의 결과를 부위별로 정한다.

| 부위 | HP 0일 때 |
|---|---|
| 팔·다리 | 해당 팔다리 기능 0(사용 불능). 의식·생명에는 직접 영향 없음. |
| 머리 | "머리 구조 파괴"로 기록한다. 생사는 뇌·뇌간 손상(S0)이 결정한다. 뇌 교차가 없으면 HP 0만으로 죽지 않는다. |
| 목 | 기존 효과를 유지한다. 바꾸려면 이유를 대장에 적는다. |
| 가슴·복부 | 심정지로 진입한다. 원인은 `torso_destroyed`다. 이후 기존 `ARREST_TO_DEATH_S` 경로를 따른다. |

- 머리 HP 합산 0으로 즉사하던 기존 경로가 위 규칙과 충돌하면 위 규칙을 따른다. 바꾼 지점을 대장에 적는다.
- 쓰러짐은 기존 요약 인터페이스로만 래그돌에 전달한다.

## 4. 분쇄·절단 단계

| 단계 | 조건(튜닝) | 결과 |
|---|---|---|
| 사용 불능 | 부위 HP 0 | 기능 0 |
| 분쇄 | 한 번의 피격에서 뼈 구간에 전달된 에너지가 문턱 이상 | 뼈 상태 `comminuted`. 기능 0. 치료 없이 회복 불가 표시. 기존 골절 출혈 적용. |
| 절단 | 한 번의 피격에서 그 팔다리 구간에 전달된 에너지가 높은 문턱 이상 | 상태 `amputated`. 기능 0. 출혈은 기존 주요 혈관 경로로 처리. |

- 소총탄은 팔다리를 거의 절단하지 못한다. 절단 문턱은 다음 조건을 만족하게 잡는다.
  - 레지스트리의 소총·권총탄(5.45, 5.56, 7.62×39, 7.62×51, 권총)은 어떤 거리에서도 절단에 도달하지 않는다.
  - 레지스트리에 대구경탄이 있으면 그 탄이 어디에 위치하는지 보고한다.
- 탄종별로 근거리 한 발이 팔다리에 전달하는 최대 에너지를 표로 남겨서 문턱과의 여유를 보여준다.
- 문턱은 여러 발이 누적돼서 넘는 방식이 아니다. 한 번의 피격 기준이다.
- 이번에는 상태와 기록만 넣는다. 절단의 화면 표현(메시 분리)은 하지 않는다.

## 5. HP·데미지 보정용 표 (수치 변경 없음)

통일된 모델로 S0 시험장을 다시 돌려 아래 표를 만든다. 사용자가 이 표를 보고 HP·데미지 조정 방향을 정한다.

- 7N6, M855, PS 각각, 5 m와 50 m에서 다음을 낸다.
  - 팔·다리·가슴·복부·머리별 한 발의 HP 감소량(대표 경로 몇 개의 범위)
  - HP 0까지 필요한 발 수
- 같은 조건에서 장기 손상만으로 쓰러지거나 심정지까지 가는 시간도 같이 낸다. HP 경로와 생리 경로 중 어느 쪽이 먼저 오는지 보기 위해서다.

## 6. 하지 않는 것

- 탄 데미지 수치, 부위 HP 수치 변경
- 기존 traceShot(몸·장기 판정) 성능 최적화. S1에서 한 발당 45–68 ms로 주병목이었다. 별도 작업으로 한다.
- 디버프(통증·어지러움 화면 효과), 치료, 절단 화면 표현
- 벽·방호·재질 관통 수식

## 7. 검증

1. **젤라틴 재현 유지:** 균질 블록 결과가 S1과 같아야 한다(연조직 기준값은 바뀌지 않음).
2. **기존 저항의 젤라틴 비교:** 기존 인체 저항 계산을 같은 젤라틴 블록에 적용해 총 관통 깊이를 도판과 비교하고 기록한다. 이번 교체의 근거로 남긴다.
3. **관통 비율·출구 속도:**
   - 7N6, M855, PS로 가슴(폐 포함), 복부, 허벅지(뼈 있음/없음), 팔을 5/50/100 m에서 쏜다.
   - 관통 여부, 출구 속도, 체내 정지 깊이를 기존 계산(v39)과 새 계산으로 나란히 보고한다.
   - 관통·체내 정지 경향에 대한 법의학·외상 문헌이 있으면 출처로 비교한다. 없으면 보고만 한다.
4. **관통 후 뒤쪽 결과:** 사람 뒤 벽·두 번째 표적 시나리오에서 v39와 결과가 어떻게 달라졌는지 보고한다.
5. **얼굴 경로 재실행(2번):** 즉시 쓰러지지 않음, `concussionRisk` 기록.
6. **HP 0 사례:**
   - 몸통 HP 0 → 심정지(`torso_destroyed`)
   - 머리 HP 0인데 뇌 교차 없음 → 생존
   - 팔다리 HP 0 → 기능 0
7. **분쇄·절단:** 4번의 탄종별 최대 에너지 표와 문턱 여유. 소총탄 절단 0건.
8. **S0 시험장 240개 재실행:** S1 대비 변화를 보고하고, 심장 7–15 s·대동맥 약 30 s가 유지되는지 확인한다.
9. **성능:** 피격당 계산 시간과 1200 RPM 부하 시험(S1과 같은 방식).
10. **기존 회귀 검사:** 전체 테스트, 2D baseline 바이트 비교, 600틱 비교, 두 화면 오프라인 실행, Q·R·R2·S0 불변 조건.


## 사용자 추가 요청 — 디버그 총기

아래 항목은 첨부 지시서 밖에서 사용자가 직접 추가한 요청이다.

- 기존 AK를 복제해 디버그 전용 총기를 만들고, 무기 3번 칸에 넣는다. 3번 칸은 디버그 전용이며, 일반 장비에는 쓰지 않는다.
- 화면 좌측 상단에 탄약 선택 탭을 둔다. 탭을 누르면 레지스트리의 모든 탄이 표로 나오고, 행을 눌러 바로 장전한다.
- 탄약 선택 표는 2D 원본의 탄약표 형식을 따른다. 탄 이름, 구경, 탄두 질량, 기준 총구 속도, 관통 스펙(관통력, 방호 등급별 관통 여부 등 원본 표에 있는 항목)을 보여준다. 항목과 수치는 레지스트리 값을 그대로 쓰고 새로 만들지 않는다.
- 현재 장전한 탄은 표에서 강조하고, 화면에는 탄 이름과 장탄수 ∞를 표시한다. 탄창은 무한이다.
- 총구 속도는 선택한 탄의 레지스트리 기준 속도를 쓴다. 속도를 직접 입력하는 옵션도 둔다(거리 효과 확인용).
- 가늠자 영점은 원래 AK 기준을 유지한다. "선택 탄 기준 자동 영점" 토글을 둔다(기본 끔).
- 반동·소리·모델은 원래 AK 그대로이며, 대장에 "디버그용, 현실값 아님"으로 표시한다.
- 사격은 일반 사격과 같은 traceShot·의료 경로를 탄다.
- 표는 휴대폰 가로 화면(844×390)에서 스크롤로 전부 볼 수 있고, 터치로 고를 수 있어야 한다.
- 후속 추가: 모바일에서도 디버그 총기를 선택할 수 있게 버튼을 적당하게 배치한다.
