# v23 중력·공기저항 탄도와 장거리 사격장

2026-10-11 KST. 실제 발사 경로와 궤적 표시를 함께 곡선으로 바꾸고, 100·200·300·400·500m 표적을 추가했다. 기존 AK 높이·원본 팔 접점·반동·총구 선행·탄피 이동 속도 상속은 유지한다.

## 사용

일시정지 메뉴의 **100–500 m 장거리**로 이동한다. **조작·화면·훈련 설정 → 탄 궤적 표시**를 켜고 사격하면 중력과 공기저항으로 휘는 경로가 보인다. 일반은 노랑, 장애물 관통은 청록, 도탄 후는 분홍, 방호구 관통은 주황, 인체 관통은 보라다. 관통·도탄 뒤에도 줄어든 속도와 바뀐 방향에서 곡선이 이어진다. 최근 5초·최대 24발을 표시하고 장애물 너머의 경로도 보인다.

레인 거리는 사격선 기준이다. HUD는 총구부터 실제 경로 길이·계산 비행 시간·초속과 충돌 속도·잔여 에너지를 표시하므로 표지 거리와 조금 다를 수 있다. 멀리 있는 표적은 위로 조준해 낙차를 보정한다. **근거리 사격장**으로 돌아올 수 있고, 두 사격장은 통로로도 연결된다. 이동 버튼은 탄약·방호구 내구도·의료 기록을 초기화하지 않는다.

## 원본 CQB와 새 계산의 경계

탄종·총기별 초속과 질량은 기존 catalog를 사용한다. `src/data/ammunition-legacy.js`의 `getCaliberEnergyClass`, `getVelocityDragClass`, `getDistanceVelocityRetention` 원문을 별도로 추출하고, 원본 `DRAG_RETENTION_PER_100M` 표를 사용한다. 기본 소총탄은 100m마다 속도94%, 유선형 AP는96% 등 원본 분류가 적용된다. 기존 방호·관통·도탄·인체 저항·의료 수식과 원본 파일은 변경하지 않았다.

새 외부 탄도는 `dx/dt=v`, `dv/dt=(0,-9.81,0)-k|v|v`, `k=-ln(100m당 유지율)/100`을 RK4로 계산한다. 중력이 없으면 원본 거리별 속도 유지식과 일치한다. 원본의 거리 근사값을 3D 공기저항으로 확장한 게임 모델이며 인증된 G1/G7·마하별 탄도 자료는 아니다. 중력·낙차·시간 적분과 실제 곡선 충돌 검사는 이번에 추가했다.

최대 1/120초·4m 단위로 경로를 만들고 매 구간 전체를 ray sweep하여 얇은 장애물을 건너뛰지 않는다. 공중 구간은 기존16회 고체 충돌 제한을 소모하지 않는다. 별도로 최대2048구간·12초·620m를 제한한다. 방호구·장애물·인체 안에서는 기존 실제 진입–출구 chord와 방호 순서를 유지하고, 고체 구간 시간은 평균 진입/출구 속도로 근사한다. 출구 뒤에는 실제 잔여 속도·관통 불안정·도탄 방향으로 공중 적분을 다시 시작한다.

공기저항으로 줄어든 충돌 속도는 기존 장애물 방호, 방호구 저지·잔여 에너지, 인체 에너지·의료 입력으로 전달한다. 인체의 명목 저항/관통 예산 공식을 새 에너지 관통 모델로 교체한 것은 아니다. 기존 저속 정지·잔여 에너지 제한이 적용되며 공중 구간 뒤에서 속도를 되살리지 않는다. 곡선과 충돌 속도가 달라지므로 기존 모든 피격/의료 결과가 바이트 단위로 같다는 주장은 하지 않는다.

발사 순간 고정된 장면의 전체 경로를 계산하고 피격을 즉시 처리한다. 기록의 비행 시간은 계산값이며 실제 피격 지연·비행 중 움직이는 표적과의 충돌은 아직 없다. 바람·환경별 공기 밀도·마하 전이·탄종별 영점/가늠자 보정도 이번 단계에는 없다.

## 곡선 표시

직선 하나로 총구와 도착점을 연결하지 않고, 실제 충돌 계산의 각 곡선 좌표를 이어 그린다. 500m 소총탄은 약125구간이므로 전 구간을 그대로 표시한다. 표시 상한은 한 발512구간·전체24발이다. 상한을 넘는 긴 경로만 공중 구간을 합치며 고체 구간과 관통/도탄 상태 경계는 보존한다. 이 표시 최적화는 충돌 좌표나 의료 입력을 바꾸지 않는다.
