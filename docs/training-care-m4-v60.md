# M4/v60 — 본인 처치 모드·흉부·복부

기준: v59 `ae2cedcc809ada1a4098cddb535cc697f27ec4f8`. [지시서](training-m4-instructions.md), [수치·분류 대장](care-m4-ledger.json), [확인한 출처와 공백](care-m4-sources.json). 3D 전용이며 원본2D는 보존한다.

## 구현

- 설정 ‘의료 처치’: 게임/리얼리스틱/현실, 기본 리얼리스틱. 기존 설정 저장·초기화 경로다. 처치 시작 시 정책을 기록하며 설정 변경과 재개 시에도 같은 모드를 쓴다. 재개할 때 기존 M3 손상/한 손/통증/떨림/의식/관류 배율만 다시 읽는다.
- M3 시간·계수의 현실 모드는 v59 그대로다. 게임의 올바른 지혈 처치는 계수0, 동맥에 붕대는.3이며 느슨한 CAT은 계수1이다. 리얼리스틱 동맥 붕대.5/완료 거즈.00005는 튜닝이다. 약하게 남는 중단 효과와 기존 이동·사격·피격 중단 규칙을 유지한다.
- 붕대/거즈/바늘 게임3·리얼리스틱2·현실1회, 씰4/2/2장. 사용 시작 시1회를 소비하며0회면 공간 아이템을 없앤다. 지출 이력은 별도로 유지해 모드를 되돌려도 쓴 횟수가 환급되지 않는다. 재생 가능한 차이는 새 최대−지출이다. CAT은 두 개의 독립 인스턴스/기존 소유·제거/회수다. 약물·폼 투여는 되돌릴 수 없다.
- IFAK은 M3의3×3/9칸/7인스턴스 그대로다. 새 위생병 파우치는 기존6×5가방의 남는1×2칸에 배치하며 기존 아이템/탄약 좌표와 수를 바꾸지 않는다. 내부2×2에 TXA·폼 각1×2다. 외형180×90×80mm, TXA100×30×20mm/약70g, 폼160×60×40mm/약300g, 파우치120g는 **판매 제품의 확인값이 아닌 프로토타입 튜닝**이다. 깊이 방향 적층을 추상화한 격자이며 약490g가 추가된다. D2 비교 입력13.7kg는 원래 값이다.
- 두 물품 모두 기존 IFAK과 같은 창/더블 탭/제목 이동/닫기/수납 제약을 사용한다. UI에는 남은 횟수, 구멍별 씰 아이콘, 두 감압 선택지 또는 앞/옆 그림 찍기, 전신 TXA/복부 폼 사용 버튼이 있다. 일반 화면에는 진단용 tension 수치를 표시하지 않는다.

## 흉부 입력 경로

`SelfCare.request` → 완료 기록 → `medical-care-chest` → `scripts/training-medical.mjs`가 생성하는 **3D 사본**의 `updateChestTrauma` 입력이다. 원래 진행률·상한·긴장·호흡 목표 수식을 두고, 열린 구멍 비율만 진행과 양의 긴장 입력에 곱한다. 통기 씰/유효 바늘은 긴장 공기 outflow 입력을 더한다. 혈흉을 빼거나 출혈원을 지우지 않는다. 혈역학 변화 때문에 출혈량이 간접적으로 달라질 수 있다.

확인된 M1 피부 구멍만 씰 대상이다. 입구/출구를 별도 물품으로 덮고 해당 쪽 열린 구멍 수로 비율을 계산한다. 새 상처가 생기면 분모도 바뀐다. 현실 등쪽은 거부/미소모, 리얼리스틱은1.8배, 게임은 허용한다. 구멍을 찾지 못했다고 추정 출구를 만들지 않는다.

양쪽 폐를 지나는 상처는 원래 의료 상처와 출혈원을 하나로 유지한다. 흉부 입력 track만 좌우로 나누어 **같은 원래 흉부 식**에 넣고, 구멍은 M1 바인드 좌표의 좌우로 배분한다. 반대쪽 바늘로 다른 쪽 압력을 빼지 않는다. `applyHemothoraxB1`의 읽기 위치만 이 좌우 track을 사용하며 혈흉/유량 수식은 그대로다. 처치가 없으면 원래 상처 배열/모델을 그대로 읽는다. 2D 비교 VM은 이 3D 어댑터를 설치하지 않는다.

바늘은 게임 자동/리얼리스틱 두 위치/현실 그림 좌표를 기록한다. 현실 허용 반경.065(정규화 좌표)는 임상 위치 판정기가 아닌 게임 튜닝이다. CT연구의5cm실패38%/13%를8.3cm키트에 재사용하지 않았다. 앞8%/옆2% 실패,35%가90–300초 뒤 막힘/꺾임은 튜닝이며 의료 난수 스트림을 추가로 소비하지 않는 결정론 파생 난수다. 새 키트가 없으면 재시술 불가다. 긴장 없는 현실 가슴에는 작은 기흉.12를 기존 흉부 출력에 넣되 HP/상처/출혈원은 만들지 않는다. 다른 모드의 불필요한 사용은 미효과/소모다.

## 복부와 목표 시간

TXA는 기록된 최초 부상 후10800초 안에 완료한 투여만 유효하다. 전신 정맥/실질/삼출, 게임 동맥에만 약한 효과를 준다. 현실600초 지연과5% 유량 감소는 튜닝이다. CRASH-2의 출혈 사망 RR0.85는 **유량 감소율이나 효과 발현 시각이 아니다**. 실제 연구는 IV1g/10분 후1g/8시간이며, 게임의 자가 투여 세트/작업20초는 접근·투여 과정을 단순화한 허용이다.

폼은 모든 모드에서 `destination==='peritoneal'`에만 작용한다. 후복막/신장/하대정맥은 계수1이다. 현실10% 감소는 사용자 하드코어 설계값이지 사람 임상 효과가 아니다. DARPA 계열 연구는 돼지/실험 기술 배경이며 복구·HP회복·확정 치료를 뜻하지 않는다. 복부 통증40은 튜닝이다.

리얼리스틱 폼의 실질/정맥 계수는 **0.0365869140625**다. 원래 중증7N6 간 중앙과 신장 동반 손상이 없는 M855 간 중심부(중심에서 위15mm)의 ‘폼+TXA 완료 → 원래 첫 전투불능’ 시간을 평균2700초로 맞추는 이분법(0.1초 탐색)으로 구한 뒤60Hz로 확인했다. 직접·간접 장기 손상을 제거한 인공 환자를 만들지 않았다. 탐색 원자료와 두 기준 탄의 실제 경로는 `abdomen-fit.json`에 있다.

정지 기준에서 완료 후 약52.12분(7N6),38.57분(M855)이다. 기존 D2를 그대로 쓰면 걷기 조건은 모두60분까지 전투불능이 없고, 달리기 요청은7N6에서60분 초과/M855 약30.91분이다. **정지 기준30–60분은 충족하지만 걷기에도 같은 상한이 생긴다는 목표는 충족하지 못한다.** 기존 운동 펌프·보상과 출혈/응고가 함께 작동한 결과이며 이를 맞추려고 D2를 바꾸지 않았다. `speed`는 요청 입력으로, 기존 스태미나/전투불능 제약을 거친다.

원래 v59 ‘M855 간 중앙’ 경로는 신장 공동 손상도 동반한다. 이를 숨기거나 폼을 후복막으로 확대하지 않았다. 그 복합상은 게임 모드도 무제한 활동 목표에 도달하지 못하며 별도 표로 남긴다. 약한 간 중심부7N6은 미처치도60분 생존할 수 있어 억지로45분에 쓰러지게 하지 않는다. 모든 숫자는 해당 실제 사격 경로에 대한 게임 결과다.

## 시간·환자 경계와 검증

처치 중 창을 닫아도 M3 HUD/시간은 이어진다. M4 지속 개입이 있는 환자는 쓰러진 뒤에도 의료 시간이 이어져 지연 약물/재발을 관찰할 수 있고, 일시정지 메뉴는 멈춘다. 구역 이동은 기존 구조상 환자를 폐기하므로 진행 중/적용 효과를 둔 이동은 거부해 처치 기록이 다른 환자로 옮겨가거나 사라지는 것을 막는다. 제거 불가능한 TXA/폼 뒤 구역을 바꾸려면 훈련 초기화가 필요하다. 실제 탈출·환자 인계는 이번 범위 밖이다.

- M3 현실: 공개v59 임상JSON(13사례,처치기록/관찰/시료 전체) 바이트 비교.
- 미처치7실사격×900초/60Hz,각0틱 포함378,007틱의 혈액/의식/출혈원/HP/D2/seed 정확 비교.
- 모드별M3 24사례,흉부19사례,복부96사례(최대3600초/사망 시 종료),현실 재발의 실제 난수 seed와 시계열.
- 긴장성 기흉은 실제 폐 관통상에 기존 흉부 모델의 위험.7/진행.9/긴장.5를 넣은 **명시적 경계 시험**이다. 새로운 상처나 혈관을 주입하지 않는다. UI시험의 처치 진도 빠른 진행은 `SelfCare.step`만 사용하며 생리 효과 수치는 별도60Hz 임상에서 잰다.
- S0 240조건/684채널/젤라틴/실제단발28표,600틱6발 카메라·총구·방향·반동·의료,포인터잠금/재시도 사격0,1280×720/844×390 네이티브마우스·터치/최종 독립HTML 오프라인 실행.

최종 집계/파일 SHA/화면과 미달 조건은 [보고서](../downloads/checks-care-m4-v60/report.html)에 남긴다. 모든 게임 자산을 내장하고20MB미만 ZIP을 GitHub Actions 없이 제공한다. 실제 휴대폰 하드웨어는 미검수다. NPA/기도·타인치료(M5),추가의료물품/AAJT/수혈/진통제/후송치료,M6,AI처치,장시간 CAT손상/구획증후군은 없다.
