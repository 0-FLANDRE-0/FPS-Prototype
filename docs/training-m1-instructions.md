# M1: 의료탭 화면 (읽기 전용)

최신 빌드(v56 이후) 위에서 작업한다. 3D는 2D와 분리된 상태다. 2D 원본은 바꾸지 않는다. 바꾼 항목은 대장에 출처/원본/튜닝/사용자 설계값/게임 허용과 `2D 역이식 후보`를 표시한다.

참고 문서인 UX 설계 A와 기술 참고 B를 같이 첨부한다. **이 지시서와 다르면 이 지시서가 우선이다.**

## 전체 순서 (사용자 확정)

| 단계 | 내용 |
|---|---|
| **M1 (이번)** | 의료탭 화면, 읽기 전용 |
| M2 | 의료 아이템, IFAK 창 |
| M3 | 처치 1차: 지혈대·압박붕대·지혈거즈 |
| M4 | 처치 2차: 흉부 씰·바늘 감압·복부 |
| M5 | 타인 치료 |
| M6 | 장비별 격자(조끼·벨트·배낭) |

이번에는 처치를 구현하지 않는다. 나중 단계가 붙을 **자리만** 만든다.

## 배경

- 지금 `renderMedicalPanel()`은 혈액·혈압·HP·피격 기록·디버그를 텍스트로 보여준다.
- D2의 HUD 부위 실루엣(8부위, HP 색)이 있다.
- 인벤토리는 가방 6×5 격자와 기존 선택·드래그(`InventoryUI`)가 있다.

## 1. 화면 골격

- **상단 바:** `[장비/인벤토리] [의료]` 탭, 환자 이름(이번에는 본인만), 닫기 `X`.
- **공통 3열**
  - 장비/인벤토리 탭은 지금 인벤토리 화면을 이 틀 안에 넣는다. 기능은 그대로다.
  - 의료 탭은 왼쪽 신체 / 가운데 상처·현황 / 오른쪽 물품이다.
- **열 폭:** 초기값 25% / 35% / 40%(튜닝). 844×390에서도 **3열을 유지**하고, 각 열은 따로 스크롤한다. 한 열로 쌓는 반응형 변형은 금지다.
- **탭 전환:** 선택한 부위·상처, 스크롤 위치를 초기화하지 않는다.
- **시간 (사용자 설계값)**
  - 장비/인벤토리 탭과 의료 탭이 열려 있어도 게임 시간이 흐른다. 출혈, 생리, 적 AI, 소리가 계속 진행된다.
  - 탭에 따라 정지 여부가 다르면 "인벤토리 열어서 출혈 멈추기"가 되므로 두 탭 모두 같게 한다.
  - 열려 있는 동안 이동·사격·조준 입력은 막는다. 시야와 몸은 그대로다.
  - 일시정지 메뉴(`Ⅱ`)는 지금처럼 멈춘다.
  - 쓰러진 뒤 "나의 의료 상태"는 지금처럼 멈춘 상태에서 연다.
- **열기:** 기존 인벤토리 버튼으로 열고 탭으로 전환한다. 의료 탭으로 바로 여는 버튼을 하나 둔다(위치는 기존 버튼 배치와 겹치지 않게).

## 2. 왼쪽: 신체

- D2 HUD 실루엣을 키워서 재사용한다. 나중에 고퀄 그림으로 바꿀 수 있게 그림과 데이터를 분리한다.
- **앞/뒤 전환** 버튼을 둔다.
- **8부위:** 머리, 목, 가슴, 복부, 왼팔, 오른팔, 왼다리, 오른다리. HUD와 같은 HP 색(초록 → 노랑 → 주황 → 빨강 → 검정)을 쓴다.
- 부위를 누르면 선택·강조되고, 가운데 목록이 그 부위로 바뀐다.

### 상처 마커
- **위치:** 상처의 3D 피부 위치를 실루엣 앞/뒤 그림 좌표로 투영한다.
  - 기존 출혈원·상처의 `bindActorPoint`처럼 자세와 무관한 좌표를 쓴다.
  - 앞/뒤는 피부 법선 방향으로 정한다.
- **모양은 종류를 나타낸다.**
  - 맹관상(탄이 몸 안에 남음): 꽉 찬 점
  - 관통상: 들어간 구멍은 꽉 찬 점, 나간 구멍은 테두리 원. 둘을 짝으로 묶어 하나를 누르면 짝도 강조된다.
  - 스침·기타: 짧은 선 등 다른 모양
- **색은 상태를 나타낸다:** 미처치 / 처치됨 / 중단됨.
  - 이번에는 모두 미처치다. 상태 필드와 색만 준비한다.
  - 마커 색은 부위 HP 색과 헷갈리지 않는 색으로 정한다(튜닝).
- 마커가 겹쳐도 합치지 않는다. 겹친 곳을 누르면 작은 선택 목록이 뜬다.
- 마커를 누르면 가운데 목록에서 그 상처가 선택된다. 목록에서 선택해도 마커가 강조된다.

## 3. 가운데: 상처 목록 + 현황

### 상처 목록 (위)
- 선택한 부위의 상처를 보여준다. 선택한 부위가 없으면 전체를 보여준다.
- 각 행은 짧게: `#번호 / 위치 / 종류 / 겉 출혈 / 처치 상태`. 예: `#01 상완 전면 / 관통 / 흐름 / 미처치`.
- 행을 누르면 그 상처의 정확한 정보가 펼쳐진다: 종류, 위치, 들어간·나간 구멍, 겉 출혈 정도, 처치 상태.

### 현황 (아래, 관찰 가능한 정보만)
사람이 직접 보고 느낄 수 있는 것만 보여준다. 장기 손상량, 정확한 혈압, HP 수치, 심전도는 보여주지 않는다. 변환 문턱은 모두 튜닝이며 대장에 표로 적는다.

| 표시 | 근거 데이터 |
|---|---|
| 겉 출혈: 뿜음 / 계속 흐름 / 스며나옴 / 멈춤 | 그 상처에 연결된 `external` 출혈원의 유량. 동맥 출혈은 "뿜음" |
| 부어오름 | `limb_compartment`에 고인 양. 겉으로 피는 안 보이지만 팔다리가 붓는다 |
| 가슴 상처에서 공기 새는 소리·거품 | `chestWallOpen` |
| 숨이 점점 힘듦 | 호흡 효율 저하, 긴장성 기흉 위험(`tensionAir`) |
| 뼈 변형·비정상 움직임 | S2 골 손상 |
| 통증 정도 | 부위별 느끼는 통증 단계 |
| 어지러움 / 시야 흐림 / 귀 울림 | 의식·관류, D1b 시야 단계, 청력 저하·뇌진탕 |

- 복부·흉강 안의 출혈은 직접 보여주지 않는다. 위의 증상으로만 드러난다.
- 환자가 남일 때 쓸 항목(손목 맥박이 잡히는지, 반응 여부)은 구조만 만들고 이번에는 쓰지 않는다. 손목 맥박 기준 혈압은 출처를 찾아 달고, 논란이 있으면 함께 적는다.
- **디버그:** 설정의 몸속 판정 표시가 켜져 있으면 기존 의료 디버그 내용(출혈원 유량, 장기, HP 수치 등)을 아래에 추가로 보여준다. 기본은 숨김이다.

### 처치 자리 (이번에는 표시만)
- 상처별·부위별 처치 상태 필드: 미처치 / 처치됨 / 중단됨.
- 중단 상태에서 쓸 `[마저 처치]`·`[제거]` 버튼 자리를 만든다. 동작은 M3에서 구현한다.

## 4. 오른쪽: 물품

- 지금 가방 6×5 격자를 그대로 보여준다. 선택·드래그는 기존 `InventoryUI` 경로를 재사용한다.
- 출처 탭 `[나] [환자] [주변]`은 자리만 두고, 이번에는 `[나]`만 활성이다.
- 의료 물품 강조는 의료 아이템이 생기는 M2부터 한다.

## 5. 상처 데이터 확인

- **관통 여부와 나간 구멍**
  - 기존 상처 기록에 탄이 몸을 빠져나간 위치(출구 주소·좌표)가 있는지 확인하고 보고한다.
  - 없으면 기존 사격 계산 결과에서 **기록만** 추가한다. 탄도·관통·상처·HP 결과는 바이트 단위로 같아야 한다.
- **종류 분류**
  - 맹관상: 진입만 있음
  - 관통상: 진입 + 출구
  - 스침상: 피부 근처를 얕게 지남. 기준(통로 깊이·길이)은 튜닝이다.
  - 분류 규칙을 대장에 적는다.
- **상처와 출혈원 연결:** `w.bleedSourceIds`를 쓴다. 한 출혈원이 여러 상처에 연결돼도 겉 출혈 표시가 중복 계산되지 않게 한다.

## 6. 하지 않는 것

- 의료 아이템, IFAK, 떠다니는 창
- 처치 동작, 처치 효과, 출혈원 `controlFactor` 연결
- 타인 치료, 환자·주변 인벤토리
- 장비별 격자, 단축키
- 의료·탄도·관통·방호·HP·출혈 수식

## 7. 검증

1. **화면:** 1280×720과 844×390에서 두 탭을 캡처한다. 3열 유지, 각 열 스크롤, 터치 선택을 확인한다.
2. **마커 사례:** 실제 사격으로 만든다.
   - 같은 팔에 상처 2개
   - 관통상(입구·출구 짝, 앞/뒤에 나뉨)
   - 맹관상
   - 스침상
   - 등 쪽 상처
   - 겹친 마커
   
   각 사례의 마커 위치, 모양, 연동을 캡처한다.
3. **현황 표시표:** 대퇴동맥, 팔 근육, 간, 가슴 개방창, 사지 구획 출혈 사례에서 원자료 → 표시 문구 변환을 표로 낸다.
4. **시간:** 의료탭·인벤토리탭을 연 채로 30 s 동안 출혈·생리·적 행동이 계속되는지 확인한다. 이동·사격 입력이 막히는지, 일시정지 메뉴는 멈추는지 확인한다.
5. **상태 유지:** 탭 전환, 닫았다 열기에서 선택 부위·상처가 유지되는지 확인한다.
6. **기존 기능:** 인벤토리 탄창·조준경 이동·장착, 장전, 쓰러진 뒤 "나의 의료 상태", 디버그 의료 표시.
7. **데이터 보존:** 출구 기록을 추가했다면 S0 240조건, 684채널, 단일 손상 표가 이전 빌드와 바이트 동일한지 확인한다.
8. **성능:** 의료탭을 연 상태의 프레임 시간(두 화면 크기).
9. **기존 회귀:** 전체 테스트, 2D baseline 바이트 비교, 600틱 동일, 두 화면 오프라인 실행.
