# R-2 근력 래그돌 시험판 작업 기준

사용자 지시 기준: v33 위 작업. 탄 비행·관통·방호·의료 v2 수식과 데이터는 보존하고 의료 결과를 읽어서 근력에만 사용한다. 손가락은 v33 그립/이완 고정이며 물리 없이 유지한다. 별도 설정 전환 없이 시험판을 제공한다. ZIP은 20,000,000바이트 미만이다.

먼저 적 총을 어깨에 놓고 팔 IK를 적용한다. 투입 준비는 구역 진입으로 옮긴다. AI, 시야, 사격 추적, 의료, 물리, 스키닝, 렌더, 효과/사운드 구간을 계측한다. 투입·첫 사격·쓰러짐 프레임 목표는 각각16.7ms이며 같은 장면 평소 프레임 대비 비율도 보고한다. 이전 중앙값2배 기준은 사용하지 않는다.

평소 kinematic 애니메이션, 피격/의료 악화 시 dynamic PD 관절과 골반 스프링, 조건 충족 시0.3–0.5초 애니메이션 복귀를 구현한다. 의식 소실은0.15–0.3초에 근력0, 척수/다리 기능 상실은 다리 힘0과 상체 근력 유지, 통증/MAP 저하는 약화, 팔 힘 부족/의식 소실은 무기 낙하, 사망/심정지는 수동 근력0이다. 충격은 실제 탄 질량×착탄 속도이고 움찔은 PD 목표 변형이다. 균형 스텝·손 짚기·쓰러진 채 사격·손가락 물리는 추가하지 않는다.

8개 기계 시나리오: 머리, 의식 유지 가슴, 척수 B대, 다리, 출혈 출력 누적, 걷기/조준/앉기 쓰러짐. v33과0.05초 간격2초/41프레임 시트로 비교한다. 실제 사격·의료 연결은 별도로 검증한다. 견착은 정면·측면·위, 접점/뺨 거리로 확인한다. 사로 baseline과600틱, 의료 원본 바이트 보존을 확인한다.

시험 기준: 정착/서 있는 근력 모드 각속도 진폭≤0.5rad/s, 접지 발 미끄러짐≤0.15m(서기≤0.05m), 골반 오차>0.08m 연속0.5초 금지, 근력 소실 중 팔다리 각속도≤동일 v33의1.5배, ROM 위반0·몸통 관통0, 쓰러짐 질량중심 수평 이동≤0.6m. 미달은 시나리오·시트와 함께 공개한다.
