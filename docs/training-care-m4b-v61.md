v60 `2b5a0c04632a926de48896fb214a0e34f8cdbcc0` 위의 3D 변경이다. 사용자 첨부 지시서는 `training-m4b-instructions.md`, 출처와 미확인 값은 `care-m4b-sources.json`, 수치 분류와 2D 역이식 후보는 `care-m4b-ledger.json`을 읽는다. 2D에 자동 역이식하지 않았다. GitHub Actions 없이 로컬 빌드한다.

## 조작

가방의 **위생병 파우치**를 두 번 누르면 내부 3×3 창이 열린다. 기존 IFAK과 복부 키트는 별도다. 약 팩1·OTFC2·케타민 IM2·전혈500mL1개다. 새 물품에는 모드별 추가 사용 횟수를 적용하지 않는다. 물품을 선택하고 의료 화면의 ‘나에게 … 사용’을 누르거나 기존 신체 처치 드래그 경로를 쓴다.

OTFC는 개수와 남은 퍼센트가 보인다. 사용한 스틱은 `treatment:<id>` 단일 소유로 보관되어 거래/복제로 복용을 늘릴 수 없다. ‘빼기’는 입력 흡수만 멈추고 이미 흡수된 약의 작용은 이어진다. ‘다시 물기’는 남은 같은 스틱에 짧은 M3 동작을 한다. 의식65 미만 또는 의식 소실·심정지·사망이면 같은 의료 틱 끝에 자동 중단한다. 모두 녹으면 아이템이 없어지고 모드 변경으로 돌아오지 않는다.

전혈은 두 손을 쓰는 연결 동작만 이동·사격을 막는다. 연결 후에는 다른 처치·조준·이동이 가능하다. HUD에 남은 mL와 현재 주입 속도를 보여 준다. 최초 쓰러짐/래그돌, 이후 의식 소실·심정지·사망 때 줄이 빠진다. 남은 양은 처치 기록에 보존되고, 의식이 있는 누운 상태에서는 ‘수혈 다시 연결’로 계속할 수 있다. 같은 누운 상태라는 이유로 매 틱 다시 빼지 않는다. 이미 들어간 혈액은 회수하지 못한다. 실제 사용량·혈액 상한 때문에 낭비된 양을 구분해 기록한다.

모드 변경/저장은 기존 M4 설정이다. 시작한 처치·약·팩은 시작 모드로 고정한다. 일시정지는 흡수·주입·생리 모두 멈춘다. 화면을 닫으면 계속된다. M4에서 남은 환자 폐기 구조 때문에 지속 처치/약물 이력이 있을 때 구역 이동을 막는 제한은 그대로이며, 훈련 초기화로 새 환자를 시작한다.

## 모드 정책과 물품

모든 시간·강도·곡선은 게임 정책/튜닝이다. 현실 모드도 사용자가 요청한 시작 시간 압축과 모든 자가 처치를 허용한다. 실제 TCCC/약품 자료의 범위와 차이를 출처 파일에 적었다.

M3 손상·통증·의식·관류·한 손 작업 배율은 적용/재개 시 고정한다. 수혈 연결은 두 손이 필요하다. 주입은 정지1/걷기0.85/달리기0.5다. 주입 시간과 약물 시작 시간은 적용 완료 시점 기준이다. 약 팩8h(게임10h), OTFC 약동학 감쇠 척도2h(게임2.5h), 케타민30min(게임40min)는 임상 예측치가 아닌 튜닝이다. OTFC는 제거 후에도 이미 흡수된 만큼 분포/감쇠하므로 시작 지연과 잔여 작용이 있다.

파우치 외형은 프로토타입200×160×100mm/180g, 가방 외부2×1/내부3×3이다. 실제 제품 확인치가 아니다. 외부/내부 격자는 물리적90mm 비례가 아닌 기존 IFAK과 같은 정리 공간 추상화다. 기존 가방6×5, 모든 총기·탄약·기존 물품 위치를 보존하고 빈 마지막 행에 새 파우치를 둔다. 약 팩 약9.92g, OTFC 약9.92g/개, 주사기 약15.03g/개, 전혈+세트 약599.88g은 포장 포함 튜닝이다. 포장 실측값을 확인했다고 주장하지 않는다. 기존 D2 장비 입력13.7kg은 바꾸지 않는다.

## 기존 의료 연결

`medical-care-drugs.js`는 `TrainingMedical`의 처치 생명주기와 3D 슬롯에 연결된다. 원래 actor의 `analgesiaLevel`/`painkillerActive`를 올려 `addPain` 누적 감소와 원래 `painMasking` 진통 몫×0.65/총 가림 상한0.85를 쓴다. 새 통증·HP·골절 회복 식은 없다. 부위 통증 관찰과 D1 흔들림·찡그림·절뚝임은 가려진 통증을 읽는다. 약 팩은 동시 합산하지 않고 지속을 갱신한다. OTFC는 부분 흡수량과 분포·소실을 기록한다. 케타민 반복은30min보다 이르면 표시하고, 추가 진통은 완전 중복보다 작게/부작용은 각각 합산한다. 전체 진통 입력 상한100을 유지한다.

OTFC 졸림/호흡 억제는 혈액 손실·낮은 MAP에 따라 커진다. 케타민은 복시·느린 화면 출렁임·색 변화·재생 음의 소폭 늘어짐과 작은 기존 교감 입력을 쓴다. 케타민 호흡 억제 없음은 사용자 진통용량 게임 정책이다. 실제 약품 라벨의 고용량/빠른 투여 위험이 없다는 뜻이 아니다. 모든 부작용 수치는 튜닝이다. 화면 효과 강도0은 시청각 표시를 없애지만 의식·호흡 변화는 없애지 않는다. 이중상/시야 출렁임은 렌더 패스에서만 하므로 몸이나 입력을 비틀지 않는다.

전혈은 실제 주입한 만큼만 `bloodMl`에 더하고 `bloodMax`에서 자른다. 기존 혈역학·B1 CO/혈압 의존 출혈이 반응하며 새로운 ‘수혈 시 출혈 증가’ 식은 없다. 같은 실제 대퇴동맥 사격에서10초에 주입32.22mL/출혈89.854mL/s·MAP101.299, 미수혈89.807mL/s·MAP101.195가 관찰됐다. 혈액형·저체온·수혈 반응·산소운반 농도는 추가하지 않았다.

## 흉부와 움직임

통기형 씰은 현재 같은 가슴의 실제 열린 구멍 수를 분모로 덮인 비율을 구한다. 부분 덮임에 비례해 진행 상한을 원래 위험+0.4에서 위험+0.1 쪽으로 옮기고, 현재 값이 높으면 초당0.006×덮임 비율로 서서히 낮춘다. 완료 순간 값을 덮어 쓰지 않는다. 10/35/60초 씰2장 전달 프로토콜 모두 기존 개방창 진행 약0.44→0.14와 호흡 회복을 확인했다. 배치 완료 시각을 고정한 생리 시험과 정상 M3 적용 시간을 구분했다. 현실 등 씰은 허용하고 기본25초에 등3배/원래 손상 배율을 적용한다(리얼리스틱 기존1.8배).

실제 폐 관통120회(6탄/6방향/위치 변화)의 초기 위험도는 모두0–0.1 구간이었다. v60 긴장0/120→v61 13/120, 감압 후보13/120이었다. 초기 손상이나 의료 RNG를 바꾸지 않고 실제 가슴 부위 폐 손상의10% 결정론 valve 성향/진행0.24 문턱을 쓴다. 개방창이 없는 폐 손상도 대상이다. 원래0.01/s 긴장 증가와 처치 감압 경로를 재사용한다. 팔 구간에 걸친 부수적인 폐 후보를 가슴 valve 사건으로 취급하지 않는다. 자연 발생 사례에서 세 모드 모두 실제 바늘 처치를 성공시켰다. **13/120은 조건부 게임 시험 비율이며 임상 발생률이 아니다.** 적합한 관통 폐 손상 임상 목표율을 확인하지 못했다. 합쳐진 단순/긴장성 기흉29%를 긴장 발생률로 잘못 쓰지 않았다.

움직임 추가 계수는 `1 + 1.0390625×min(1,I/0.18) + 0.015625×max(0,(I−0.18)/0.82)`이다. `I`는 기존 D2 강도다. 정맥·실질·삼출만 대상이고 동맥/완료 CAT 원위부는 제외한다. 정지에는 곱셈을 추가하지 않고 정확히1, 멈추면 즉시 원복한다. 원래 D2 장기 재분배·운동 혈역학은 바꾸지 않았다. raw 계수는 걷기 약2.039/달리기2.055이며, D2의 장기 재분배 계수와 함께 읽어야 한다. ‘모든 source의 raw 유량이 몇%만 는다’고 주장하지 않는다.

**걷기10–20% 단축은 세 검증 경로에서 달성했으나 달리기30% 단축 목표는 미달이다.** 원래 D2의 혈류 재분배·산소 수요와 정맥 출혈의 비선형 반응 때문에 같은 단조 계수로 둘을 함께 맞추지 못했다. 달리기 추가 계수를 거의0까지 낮춘 역산과 실패 값을 보고서에 남겼다. 폼의 후복막 효과를 임의로 늘리거나 D2/원래 출혈 식을 바꿔 맞추지 않았다. M855 기존 ‘간 중앙’은 신장/후복막 복합상이므로 깨끗한 간 참조 경로와 함께 별도 행으로 보고한다.
