# M7b: 사이드 플레이트 위치 수정
v65 위. 3D만.
- 좌우 사이드 판 중심 높이를 1.285 m → 1.135 m로 내린다(판 높이 0.2 m의 3/4인 0.15 m, 사용자 설계값).
- 근거: 병사 GLB Vest 메시 옆판(|x|>0.13, |z|<0.07, 몸통 뼈) 정점 높이 약 1.01–1.25 m. 기존 판 범위 1.185–1.385 m는 옆판보다 위(겨드랑이 틈)였다.
- 내린 뒤 판 전체가 6B45 측면 소프트 영역 안쪽에 들어가는지 확인한다. 벗어나면 x·z를 소프트 면에 맞춰 조정하고 값을 보고한다(튜닝).
- 크기 15×20 cm(세로)는 그대로 둔다.
- 검증: H01·적 앞·옆·뒤 판 표시 캡처(두 화면), 사이드 8직격 경로를 새 위치 기준으로 다시 잡아 전후 결과 표, S0 240·단일 피격 표·684채널 동일 여부(사이드 비접촉 조건), 기존 회귀.
