# AI1: 적 감각·반응·조준·자세·킬하우스 시험장

최신 빌드(M7b 사이드 판 위치 수정 반영) 위에서 작업한다. 3D는 2D와 분리된 상태다. 2D 원본은 바꾸지 않는다. 바꾼 항목은 대장에 출처/원본/튜닝/사용자 설계값/게임 허용과 `2D 역이식 후보`를 표시한다.

## 전체 순서 (사용자 확정)

| 단계 | 내용 |
|---|---|
| **AI1 (이번)** | 감각·반응·조준 모델, 조준 자세, 새 킬하우스 시험장, 명중률 측정 |
| AI2 | 2D AI 뇌(점수 기반 행동 선택, 기억·믿음, 엄폐, 사격 판단)를 기반으로 3D 행동 |
| AI3 | 여러 명 협동(콜아웃 지연 포함) |

이번 행동은 순찰·위치 지키기·발견하면 사격 정도로 단순하게 둔다. 진짜 판단은 AI2에서 한다.

## 기본 원칙: 치트 금지

- **AI는 감각으로 얻은 것만 안다.** 시야로 본 것, SND1 청각 증거, 마지막으로 본 위치뿐이다. 벽 너머 위치를 직접 읽지 않는다.
- **AI에게 별도 탄퍼짐·명중 확률 주사위를 두지 않는다.** 총알은 AI 몸이 실제로 들고 있는 총의 총구 방향으로, 플레이어와 같은 탄도·반동·총·탄 산포(MOA)로 나간다. 빗나가는 이유는 전부 "어디를 겨눴냐"에서 나온다.
- 모든 확률 요소는 기존 결정론 난수를 쓴다.

## 1. 감각

### 시야
- AI 눈에서 대상 몸의 여러 점(머리, 가슴, 골반, 양팔, 양다리 등)으로 시선 레이를 쏜다. 실제 벽·엄폐물·창틀에 가린 정도로 **보이는 비율**을 계산한다.
- **발견은 누적이다.** 다음 조건에 따라 발견 게이지가 차는 속도가 달라진다(튜닝, 근거 자료는 시각 탐지·주변시 연구에서 찾는다):
  - 보이는 비율, 시야에서 차지하는 크기(거리)
  - 시야 중심에서의 각도(주변시는 느림)
  - 움직임(움직이면 빠름)
  - 대상 자세(앉음·엎드림은 느림)
- 머리만 내민 대상은 늦게 발견한다.
- 기존 시야각 120°는 시작값이다. 주변시 영역의 느린 발견으로 표현한다.
- 조명 차이는 이번에 다루지 않는다(시험장 조명 균일).
- **성능:** 시야 판정은 AI별로 일정 주기(예: 10 Hz, 튜닝)로 하고, 레이 수에 상한을 둔다. 모바일 프레임 예산을 지킨다.

### 청각
- SND1 AI 청각을 그대로 쓴다. 소리로는 방향·거리대 증거만 얻는다.

### 기억
- 놓친 대상은 마지막으로 본 위치와 시각을 기억한다. 시간이 지나면 신뢰도가 떨어진다(2D `lastHeardNoise` 감쇠 방식 참고).

## 2. 반응

- 발견 → 알아봄 → 결정의 단계별 지연을 둔다. 사람 반응 시간 연구(단순 반응 약 0.2–0.25 s, 선택 반응·인지 0.3–0.7 s 등)를 출처로 찾는다.
- 주변시에서 발견하면 더 늦다. 놀람(기습)이면 첫 반응이 조금 더 늦다.
- 숙련도(4절)와 D1 상태(반응 배율, 아드레날린 적정 구간 향상)가 곱해진다.

## 3. 조준과 사격

### 조준 오차의 원인 (차례로 쌓음)
1. **인지 위치 오차:** 멀거나, 일부만 보이거나, 움직이는 대상의 위치를 "저기쯤"으로 본다.
2. **이동 표적 앞 보기 부족:** 사람은 이동 표적의 앞을 덜 보는 경향이 있다(출처 확인, 튜닝).
3. **총 돌리기 동작:** 피츠 법칙(목표 각도·표적 각크기 → 이동 시간) 계열로 조준 이동 시간을 정한다. 과회전 후 안착한다.
4. **총 흔들림:** 자세별(서기 > 앉기 > 거치), 숨, D1 떨림·부상. **플레이어 흔들림 모델을 공유한다.**
5. **반동:** 플레이어와 같은 반동이 AI 총에 걸린다. 숙련도가 높을수록 빨리 회복한다.
6. **제압:** 근처로 탄이 지나가면(SND1 크랙 포함) 움찔하고 오차가 커진다.
7. **총·탄 산포:** 레지스트리·탄약 데이터의 기존 값을 플레이어와 똑같이 적용한다.

### 사격 방식
| 방식 | 언제 | 특징 |
|---|---|---|
| 지향사격(조준경 안 봄) | 아주 가까움(약 7 m 이내), 기습 | 첫 발 가장 빠름, 오차 큼 |
| 빠른 견착 사격 | 중간 거리, 급할 때 | 중간 |
| 조준 사격 | 먼 거리, 여유 | 느리지만 정확 |

- AI는 거리와 급한 정도로 방식을 고른다. 경계는 숙련도에 따라 달라진다(튜닝).
- 지향사격 오차·속도는 근접 비조준 사격 연구를 출처로 찾는다.
- 플레이어는 이미 조준 안 하고 쏘는 것 자체가 지향사격이다. 플레이어 쪽은 바꾸지 않는다.

### 사격 리듬
- 가까우면 2발씩(발 사이 약 0.25 s, 출처 확인)
- 멀면 점사 사이에 재조준
- 아주 가까우면 연사
- AI는 자기 인벤토리 탄창(M7)을 실제로 쓰고, 다 쓰면 재장전한다(재장전 중 무방비).

## 4. 숙련도

- 2D 침착성 프로필(신병 / 일반 / 정예, `getUnitComposureProfile` 계열)을 쓴다.
- 숙련도가 바꾸는 것: 반응 지연, 조준 이동 속도·과회전, 반동 회복, 제압 저항, 사격 방식 경계, 앞 보기 정확도.
- 2D에 없는 항목의 값은 튜닝이다.
- 투입 패널에서 고르게 한다. 기본은 일반.

## 5. 조준 자세 (기존 "갱스터" 자세 수정)

- 견착 IK: 개머리판을 어깨 포켓에 붙이고, 조준 사격 때 조준경 광축을 눈에 맞춘다. 지향사격·이동 때는 낮은 준비 자세.
- 자세 종류: 서기, 앉기, 좌·우 기울이기.
- 총구 방향은 IK 결과의 실제 총 방향이다(3절의 총알 방향과 같음).
- 기존 래그돌·피격·방호 판정과 충돌이 없어야 한다.

## 6. 이동

- 새 시험장 안에서 경로 찾기를 한다. 방·포털 그래프(SND1)와 바닥 콜라이더를 쓴다(구현 방식은 보고).
- 행동은 순찰(지점 순회), 위치 지키기(각도 경계), 발견 시 정지·사격, 놓치면 마지막 위치 방향 경계만.
- 엄폐·빼꼼·수색은 AI2에서 한다.

## 7. 새 킬하우스 시험장 (Sector05)

```
        [창]              [창]
 ┌──────┬─────┬──────────────┐
 │ 방A  │ 방B │              │
 │4×4 m │3×4 m│   중앙 큰 방  │
 │      │     │    6×8 m     │
 ├─문──┴─문──┤              │
 │   L자 복도  ├문            │
 │  폭 1.2 m  │              │
 │      ┌─────┤              │
 │ 현관 │ 방C ├문            │
 │      │3×3 m│              │
 └─입구─┴─────┴──────────────┘
```

- **위치:** 기존 구역과 겹치지 않는 빈 공간. 메뉴·구역 선택에 추가한다.
- **벽:** 바깥은 콘크리트, 안쪽은 석고·합판(기존 장벽 재질). 벽 너머 사격 차이가 나게 한다.
- **천장:** 높이 2.7 m. 실제 천장 콜라이더를 둔다.
- **문:** 폭 0.9 m 개구부(문 오브젝트는 나중). **창:** 바깥 마당 쪽 몇 개, 아래턱 약 1 m.
- **엄폐물**
  - 낮은 엄폐(0.75–1.0 m): 탁자, 소파
  - 높은 엄폐(1.8 m 이상): 캐비닛, 기둥
  - 중앙 큰 방에 섞어서 배치
- **방·포털:** SND1 방식으로 저작한다. 소리와 AI가 같이 쓴다.
- **적 배치:** 1–4명, 위치 세트 몇 가지(예: 각 방 1명 / 중앙 집중 / 복도 끝). 투입 패널에서 인원·숙련도·위치 세트를 고른다.
- 크기·배치값은 튜닝이고 대장에 적는다.

## 8. 측정 (자동)

시험장에서 같은 조건을 반복 실행해 표로 낸다.
- **조건:** 거리(3 / 7 / 15 / 25 m 등), 대상 노출(전신 / 상체 / 머리만), 대상 이동(정지 / 걷기 / 달리기), AI 숙련도 3단계, 사격 방식
- **지표:** 발견 시간, 첫 사격까지 시간, 발당 명중률, 첫 명중까지 시간, 부위 분포
- **기준 비교**
  - 실제 총격전 명중률 자료를 찾아 비교한다. 예: 미국 경찰 총격전 약 18–30%(RAND의 NYPD 분석 등, 출처 확인).
  - 사격장 자격 사격과 실전은 다르므로 둘을 구분해 적는다.
- **"치트 아님" 확인**
  - 벽 뒤 대상을 감각 없이 아는 경우가 0건인지(로그)
  - 보자마자 첫 발 머리 명중 비율

## 9. 디버그 표시

설정에 "AI 표시"를 둔다. 기본은 숨김이다.
- 시야 범위, 레이(보이는 점 / 가린 점), 발견 게이지
- AI가 아는 정보(본 위치, 소리 증거, 마지막 위치)
- 현재 조준점, 오차 원인별 크기, 사격 방식

## 10. 하지 않는 것

- 2D 뇌 이식, 엄폐·빼꼼·수색·후퇴(AI2), 협동(AI3)
- 문 오브젝트, 조명·야간
- 플레이어 사격·흔들림 변경
- 탄도·관통·방호·의료 식

## 11. 검증

1. **8절 측정표 전체.** 숙련도별로 실제 기준과 비교하고 해석을 붙인다.
2. **감각:** 벽 뒤·창틀·낮은 엄폐 뒤 자세별 보이는 비율과 발견 시간. 머리만 노출된 경우.
3. **조준 자세:** 기존 갱스터 자세와 새 견착 자세를 비교 캡처(앞·옆, 두 화면 크기). 조준경 광축과 눈의 정렬.
4. **반동·재장전:** AI 연사 산포가 같은 총의 플레이어 산포와 같은 모델인지, 탄창 소모와 재장전.
5. **시험장:** 구역 캡처, 방·포털 표시, 벽 재질별 관통, 1–4명 배치 세트.
6. **성능:** 적 4명 + 연사 상황의 프레임 시간(두 화면 크기). 시야 레이 수·주기.
7. **기존 회귀:** 기존 구역 동작, 전체 테스트, 2D baseline 바이트 비교, S0 240조건·684채널, 600틱, 포인터 잠금, 두 화면 오프라인 실행.
