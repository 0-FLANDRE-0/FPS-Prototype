# v35 보완: 의식 있는 쓰러짐 손 짚기 + 관절 제한 + 정착 떨림

v35 위에서 작업한다. 의료·탄도·방호 수식, 손가락 자산, 서 있을 때 동작(애니메이션 + 짧은 움찔)은 그대로 둔다.

## 1. 의식이 있는 쓰러짐에서 손 짚기
- 쓰러지는 순간 의식이 남아 있으면(다리 기능 상실 등), 두 팔의 근력 목표를 "넘어지는 방향으로 팔을 뻗어 짚는 자세"로 바꾼다.
  - 방향은 쓰러지는 순간 질량중심이 기우는 방향으로 정한다.
  - 팔 근력은 의식 수준만큼 유지하다가, 손이 바닥에 닿은 뒤 0.3–0.6 s(튜닝)에 걸쳐 빠진다.
  - 머리가 손보다 먼저 바닥에 닿지 않는 것이 목표다.
- 균형 스텝은 하지 않는다. 팔 목표 자세 하나만 바꾼다.
- 의식 소실, 사망, 심정지는 지금처럼 손 짚기 없이 무너진다.

## 2. 관절 제한 위반 줄이기
- 현재 손목, 발목, 목, 상완, 대퇴에서 설정한 가동 범위를 최대 약 50–70° 넘는다.
- 래그돌 관절을 Rapier 멀티바디 관절(MultibodyJoint, 축소 좌표)로 바꾸는 방안을 먼저 시험한다.
  가동 범위, 질량, 마찰, 감쇠 값은 v35와 같게 둔다.
- 멀티바디가 Rapier 0.21 WASM에서 제약이 있거나 성능이 나쁘면 대안을 쓰고, 무엇을 왜 택했는지 대장에 적는다. 대안:
  - 손·발의 관성 하한 설정(질량은 유지)
  - 손목·발목 가동 범위를 좁힌 근사
  - 해당 관절에만 솔버 반복 추가
- v35 대비 관절별 최대 초과 각도와 2° 초과 프레임 수를 표로 보고한다. 목표는 모든 관절의 최대 초과 10° 이하다.

## 3. 정착 후 떨림
- 6초 시험 마지막 1초 각속도(현재 걷기·의식 소실 7.4, 걷기·다리 상실 15.2 rad/s)를 0.5 rad/s 이하로 줄이고, 물리 슬립에 들어가게 한다.
- 어느 강체가 떠는지 먼저 특정해서 보고한다. 2번 수정 뒤에도 남으면 정착 판정 시 각 감쇠를 올리거나 슬립 임계값을 조정한다(튜닝).

## 4. 기준 조정
- 정지(조준/앉기) 쓰러짐의 질량중심 수평 이동 기준을 0.6 m → 1.0 m로 바꾼다. 서 있다가 누우면 0.7–0.9 m 이동이 정상이다.
- 나머지 기준(이동 중 상한, 미끄러짐, 성능 1.5배)은 그대로다.

## 5. 검증
- v35의 5개 시나리오에 "걷기 중 다리 기능 상실 + 의식 유지 → 손 짚기"와 "조준 중 다리 기능 상실 + 의식 유지"를 추가한다.
- 0.05 s 간격 3 s 시트와 6 s 정착 자세를 v35와 나란히 남긴다.
- 손 짚기 시나리오에서는 손과 머리 중 어느 쪽이 먼저 바닥에 닿았는지, 그 시각을 기록한다.
