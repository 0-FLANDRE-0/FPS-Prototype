# v24 M4 전용 팔·견착과 원본 클립 기준 핸들링

2026-10-11. 사용자가 제공한 `animated_fps_m4a4.glb`에서 팔·손 뼈대와 애니메이션을 가져오고 기존 M4A1의 외형을 유지했다. 추가 요청에 따라 M4와 AK 모두 장전·탄창 교체·총기 넣기/꺼내기의 자세와 시간을 제공된 클립에 맞춘다. M4 왼손은 전방 가늠쇠/배럴 대신 핸드가드를 잡고, 오른손은 권총손잡이와 방아쇠에 맞춘다. 오른팔 시작점은 개머리판 뒤의 어깨 관절로 옮겼다.

## 모델과 손 접점

원본은 JUST의 [Animated FPS M4A4](https://sketchfab.com/3d-models/animated-fps-m4a4-a82fbbb731724390bc88d38940b8b01c), CC BY 4.0이다. `apps/training/assets/source/animated_fps_m4a4.glb`에 제공 파일을 그대로 보존했다. 13,228,236B, SHA-256 `0e0a35ce7405386725486159ec0b216fa94630523f8381f083c40b46a254faa0`.

네 개의 원본 팔 메시(장비·장갑·소매·피부), 24,744삼각형, 113관절과 Hide/Reload/Shoot/Take 클립을 사용한다. 첨부 모델의 M4A4 메시와 총기 텍스처를 제외하며 기존 M4A1 메시/UV/재질은 유지한다. 몸 프레임과 손 접점 사이에서 연결된 상완→전완→손을 IK로 맞추고 원본 손바닥/손가락 방향을 보존한다. M4 팔 길이를 늘리거나 손목을 별도 위치로 옮겨 분리하지 않는다. 원본의 주머니 쪽 동작이 새 어깨 위치에서 닿지 않을 때만 손 목표를 고정 팔 길이의98.5% 안으로 제한하고, 손에 들린 M4 탄창도 같은 보정을 적용한다. AK의 표시 동작에도 같은 도달 제한을 적용한다. 원본 동작 좌표를 그대로 복사한 것이 아니라 새 견착에 맞춰 retarget한 것이다. 반복 렌더링에서 IK가 수정한 뼈를 AnimationMixer 캐시가 건너뛰지 않도록 매 절대 시간 샘플을 재바인딩한다.

M4의 손목 마커는 총기 로컬 좌표에서 오른손 `[.018,-.055,.23]`, 왼손 `[-.024,.013,-.04]`다. 손목 좌표만 맞추지 않고 실제 스키닝된 장갑·손가락과 기존 M4A1을 옆면에서 함께 렌더링해 확인했다. 오른쪽 어깨 표면은 중립 개머리판 접점, 관절 중심은 그 표면보다 카메라 뒤로 6cm다. 왼쪽 어깨는 오른쪽에서 왼쪽으로34cm·앞으로13cm의 약간 비튼 자세다. 팔꿈치 방향도 몸 쪽 기준으로 지정했다. 비조준/조준에서 개머리판 표면과 어깨 표면은 일치하며, 장전/교체 때는 원본 총기 자세가 견착을 풀 수 있다. 별도 1인칭 몸통 메시나 어깨 충돌체를 추가한 것은 아니다.

AK도 같은 어깨 기준을 사용한다. AK 원본의 독립 손 컨트롤과 기존 상완2배/전완0.675배 보정은 유지한다. 어깨 위치·네이티브 핸들링·반복 샘플 보정 때문에 이전 AK 뼈 행렬이 동일하다고 주장하지 않는다.

## 핸들링 시간과 상태

| 총기/동작 | 클립 길이 | 탄창 분리 | 삽입 | 빈 약실 급탄 |
| --- | ---: | ---: | ---: | ---: |
| M4 일반/빈 약실 | Reload 2.083333초 | 0.416667초 | 1.208333초 | 1.583333초 |
| AK 일반 | Reload 2.648333초 | 1.15초 | 1.90초 | 해당 없음 |
| AK 빈 약실 | Reload_full 3.498333초 | 1.15초 | 1.90초 | 2.70초 |

M4 Hide/Take는 각각0.625초, AK Draw는0.648333초다. AK에 Hide가 없으므로 Draw를 역방향으로 재생한다. 총기 전환은 나가는 총의 Hide와 들어오는 총의 Draw가 끝나야 완료된다. M4는 일반/빈 약실 전용 Reload가 따로 없으므로 같은 클립을 사용하며, 일반 장전에도 원본의 노리쇠 조작 제스처가 보인다.

3D 실행에서 `Inventory({nativeHandling:true})`를 사용하고 `handling-animation.js`의 명시적 프로필로 동작을 지정한다. 원본 총기 레지스트리의 M4 2.0/2.6초와 AK 2.1/2.7초 필드는 변경하지 않는다. 프로필 시간은 원본 클립 길이·탄창/노리쇠 움직임에서 측정한 게임 상태 전환값이다. 장전 속도를 기존 시간으로 압축하지 않는다. 탄창만 삽입할 때는 해당 클립의 뒷부분, 분리만 할 때는 앞부분을 사용한다. 랙 조작용 새 클립은 제공되지 않아 기존 경로를 유지한다.

실제 탄창 소유권은 분리/삽입 이벤트에서 원자적으로 바뀌고, 취소해도 이미 완료된 이동을 되돌리지 않는다. 탄약을 새로 생성하지 않는다. 빈 약실 급탄은 별도 이벤트를 사용하며 동작 완료 전에는 발사가 제한된다. 기존 M4A1 탄창 메시도 원본 Mag 관절의 상대 위치/회전을 따르고 기존 인벤토리 상태에 따라 보인다.

장전·전환 중에는 원본 총기의 자세를 표시하고 기존 절차적 장전 기울임을 겹치지 않는다. 사격 때는 기존 게임의 반동·총구 선행·카메라·탄피·탄도가 기준이다. 첨부 모델의 총기/카메라 사격 반동을 다시 합산하지 않는다. M4 원본에는 별도 Idle/Walk/Run이 없어 Shoot@0을 기본 자세로 삼고 기존 보행 움직임을 사용한다. Shoot의 손가락 키는 고정 포즈이며 움직이는 방아쇠 손가락 애니메이션이 있다고 주장하지 않는다.

## 최적화

팔에 필요한 accessor와 원본 클립 데이터만 남기고 바이트가 같은 데이터는 공유한다. retained accessor1,197개를 바이트 단위로 대조하며 메쉬/스키닝/애니메이션 키 값을 축소하지 않는다. 팔 텍스처의 해상도는 보존한다. 색상 WebP는 SSIM≥0.97, 노멀은 무손실 RGB 동일, alpha도 동일하다. 최적화된 팔 GLB는 약4.62MB로 전체 제공 원본보다 약65% 작다. 소스 원본과 파생 GLB·내장 HTML의 정확한 크기/해시는 빌드 기록을 따른다. 원본 AK 및 기존 M4A1 최적화 자산은 그대로다.

## 검증과 제약

`npm test`, `npm run verify:baseline`, `node scripts/check-training-m4-arms.mjs`와 최종 HTML의 `CQB_OFFLINE_OUT=downloads/checks-m4-arms-v24-offline node scripts/check-training-w-offline.mjs --flight`를 사용한다. 공식158/158, 72상태의 열린 어깨 노출/near-plane 교차0·동일 시각 반복 뼈 행렬 일치·M4 팔 비신장·손 접점1mm 이내·ADS중심1px 이내를 확인했다. 일반/빈 약실 장전 각240프레임의 최대 손 이동은 M4 6.64cm, AK일반5.37cm·빈약실8.18cm/60Hz이며 잔여 도달 부족은0이다. 주머니/핸들링 좌표 보정은 최대 M4 16.18cm·AK9.66cm다. 최종 성공 결과는 `downloads/verification-m4-native-arms-v24.json`과 각 report를 따른다. 실행 HTML에는 QA용 `__CQBTest`를 넣지 않는다.

외부 QA는 v23과 M4의 이동·회전·6발 반동600틱을 전체 대조하고 근거리 판 저지/노출 전완/6B47 의료 기록을 대조한다. PC1280×720·터치 화면844×390에서 두 총기의18상태씩 총72상태를 검사한다. 실제 스키닝된 열린 어깨 단면 노출과 near-plane 교차, 같은 시간 반복 렌더링, M4의 연결된 손 뼈와 비신장, 손 접점, ADS 중심을 확인한다. 각 총기의 일반/빈 약실 장전을240프레임 연속 검사하고 탄약 보존을 확인한다. 최초 회전 검사에서 왼손의1.9cm 도달 부족을 발견해 왼쪽 어깨를앞으로13cm로 조정했고, 연속 사전 검사에서 M4 주머니 동작 최대15.2cm·AK 빈 약실 자세 최대8.7cm 도달 부족을 발견해 팔 길이 제한과 탄창 동반 보정을 적용했다. 최종 성공과 최초 실패를 구분한다.

별도로 계측하지 않은 최종 HTML을 외부 요청 차단 상태에서 실제 RAF·PC 키/휠·CDP 멀티터치로 조작해 전환/이동/사격/장전 취소·장거리 이동과 곡선 궤적·탄약 보존을 확인한다. 원본 src/**, v23 방호·의료·비행 및 자산 메타데이터는 대조한다. 장전/전환 시간과 팔 자세는 의도적으로 바뀌었다.

Linux Chromium/SwiftShader 검증이며 실제 S24/Android/iOS의 조작감·성능·발열은 미검증이다. 이 환경의 관리 정책으로 직접 file:// 대신 네트워크 OFF 메모리 경로에서 정확한 HTML 바이트를 검사한다. 손 접점과 어깨 위치는 제공 모델·기존 M4A1에 맞춘 프로토타입 보정이며 모든 설정 체형의 해부학적 견착을 인증한 것은 아니다.
