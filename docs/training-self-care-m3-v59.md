# M3 / v59 — 본인 출혈 처치

기준은 v58 `44942e7dac4701abf408a39eca6aba69a49b8e65`다. [사용자 지시](training-m3-instructions.md)를 구현한다. 원본 2D, 탄도·관통·방호·상처 통로·HP·생리 수식과 손가락 자산을 바꾸지 않는다. 처치를 안 한 사례의 출혈원/의료 JSON은 v58과 정확히 같아야 한다.

## 조작

의료 탭에서 IFAK을 두 번 눌러 연다. CAT·압박붕대·거즈를 골라 대상 부위/상처를 누르거나 같은 대상으로 끌어 놓는다. IFAK 기본 창 위치는 오른쪽으로 옮겨 처치 선택지를 가리지 않게 했고, 사용자가 옮긴 위치는 계속 기억한다. 양쪽 모두 `MedicalCareUI.choose → SelfCare.request`를 쓴다. CAT은 높고 단단하게/상처 위 위치를 고른다. 선택한 팔·다리에서 위·아래 구역도 고를 수 있다. 상처를 지정한 '상처 위'는 실제 피부의 바인드 좌표를 뼈 체인에 투영하고 65 mm 근위로 옮긴다. 부위만 지정했을 때는 높고 단단하게를 쓸 수 있다. 정확한 상처 위 위치는 해당 상처 마커/행을 지정해야 하며, 위치를 임의로 만들어내지 않는다. 체인 길이/순서를 비교하며 세계 y를 쓰지 않는다.

처치 중 이동·사격·ADS를 막고 1인칭 총기를 가린다. 시선은 움직인다. 화면을 닫아도 같은 고정 틱에서 계속되며 HUD에 진행 막대와 중단 버튼을 보인다. 이동·달리기·총기 동작/사격 시도·피격·취소로 중단한다. 피격은 방호구에 막힌 경우도 모두 중단시키는 튜닝이다. 진행도는 남고, 재개 준비 1.5초 뒤 남은 작업만 한다. 일시정지는 기존처럼 멈춘다. 쓰러진 뒤에도 진행 중인 처치가 있으면 시간을 계속 돌려 끝낼 수 있고, 처치가 없으면 기존 정지 화면을 유지한다. 의식 소실로 중단되면 다시 정지한다. 이는 M3의 실제 시간 처치를 위한 게임 흐름 보완이며 생리/래그돌 수식 변경이 아니다. 타인 처치는 없다.

중단/재개 버튼 교체 뒤 Chrome 호환 클릭이 새 버튼을 다시 누르는 실제 터치 문제를 재현했다. `ui-touch.js`에서 같은 포인터 종료 위치의 뒤따르는 호환 클릭만 막았다. 새로운 독립 터치의 명령과 기존 아이템 드래그 소유권은 유지한다. 의료 UI는 컨트롤을 누르고 있는 동안 버튼을 교체하지 않으며, 실제 RAF에서도 터치 종료까지 같은 노드가 유지된다.

## 지속 상태와 물품 거래

`m.appliedTreatments`는 첫 사용 시에만 생긴다. 항목은 종류/instanceId/대상/진행/단계/시간/상태/시간 배율/원래 소유 위치를 가진다. 미처치 스냅샷에는 새 키가 없다. B1은 매 틱 목록을 읽는다. 같은 상처의 계수는 곱하고, 해당 위치보다 먼 쪽에 완전히 조인 CAT이 있으면 CAT 계수를 우선한다. 공유 혈관은 병변의 기존 면적 가중치로 합산해 한 번만 센다. 상처별 문구/마커도 해당 병변 구간의 실제 외부 유량으로 나눈다. 같은 혈관의 근위 상처가 피를 흘려도 CAT 아래 원위 상처가 멈췄으면 그 상처는 멈춤으로 표시한다.

검증을 모두 통과한 요청만 원자적으로 물품을 `treatment:<id>` 소유로 옮긴다. 양손 동작 하나만 허용한다. CAT은 남은 개수 1을 유지하고 거즈/붕대는 개봉 즉시 0으로 표시한다. 사용 중 물품은 격자에 없다. 의식 소실/양팔 분쇄·절단 상태에서는 제거/회수도 할 수 없다. 제거한 CAT은 원래 가방 안 컨테이너의 원래 칸/다른 빈칸, 그다음 가방으로 돌아온다. 양쪽 모두 차면 **제거 자체를 거부하고 효과와 물품을 유지**한다. 거즈/붕대는 제거 시 인스턴스를 폐기한다. 로그의 removed 기록은 보존한다. 적용 중 물품을 둔 채 구역을 바꾸면 기존 환자 인스턴스가 폐기될 수 있으므로, 먼저 제거하거나 전체 훈련을 초기화하도록 구역 전환을 막는다. 실패한 구역 전환은 환자/물품을 바꾸지 않는다.

IFAK은 외부 2×2 그대로, 내부 3×3이다. 거즈/씰은 각각 1×2, CAT 두 개·붕대·바늘·NPA는 1×1로 9칸을 채운다. **내부 격자는 정리 공간의 추상화, 실제 크기 비례 아님(게임 허용)**이다. M2 제품 무게 그대로에 CAT 76.5437124375 g 하나를 더했다. 내용물 324.60203978125 g + 파우치 159 g = **483.60203978125 g**. D2의 기존 장비 입력 13.7 kg은 바꾸지 않는다.

## 계수와 의료 경계

구체 상수는 [대장](self-care-m3-ledger.json), 출처/한계는 [출처](self-care-m3-sources.json)에서 확인한다. 모든 계수와 증상 배율은 튜닝이다.

|처치|외부/혈관 계수|중단/제거|
|---|---|---|
|CAT 완전 조임|해당 사지 원위 출혈 0.00005|제거하면 기존 출혈원 계산으로 복귀|
|CAT 덜 조임|동맥 `1+0.35p`, 정맥 `1−0.85p`|진행 p 유지; 두 번째 완전 CAT 우선|
|압박붕대|동맥 0.8 / 정맥 0.15 / 삼출 0.1|중단은 완성 효과의 45%×진도만 적용|
|거즈 압박 중|열린 사지 통로 / 몸통 겉 0.15|중단 시 `1−0.25p`만 남음|
|거즈 완료|동맥 0.03 / 정맥 0.05 / 삼출 0.1|붕대 계수와 곱해 고정; 제거 시 효과 제거|

사지 혈관은 M2의 검증된 피부 통로와 구획 충만 비율을 먼저 읽는다. 압박붕대는 바깥 몫만 줄이고 안쪽 몫은 그대로 두도록, 총 계수 `f안+(1−f안)×C밖`와 제어 후 분배를 함께 계산한다. 열린 사지 통로에 채운 거즈는 해당 병변 유량 자체를 줄인 뒤 M2의 안/밖 비율로 나눈다. 몸통의 거즈는 외부 성분에만 작용한다. CAT은 원위 사지 혈관의 안/밖 모두에 작용한다. 체강 내부/접합부로 분류된 출혈원은 피부 진입 주소가 팔다리에 걸치더라도 CAT으로 막지 않는다. M2 구획 상한/압력은 유량으로 역입력하지 않는다.

흉강/복강/후복막의 직접 혈관·실질장기 출혈원은 붕대/거즈 계수 **1**이다. 몸통의 기존 복합 삼출원은 B1이 이미 계산한 external×외부 맥동 / internal×내부 맥동을 비공개 WeakMap에서 나누어 **외부 성분만** 줄인다. 이 source의 destination 및 과거 bloodPools 누적은 v58의 호환 분류를 유지하므로 true internal/external 성분과 혼동하지 않는다. 관찰 화면은 실제 외부 성분을 읽는다. 새로운 유량/손상 식을 만들지 않았다.

B1의 원래 구멍/응고/관류 식과 CO/가용 혈액 상한 식은 그대로다. 상한에 들어가는 합에 제어된 유량을 쓰므로 덜 조인 CAT의 증가 계수도 가용 혈액을 초과하지 않는다. 처치가 없으면 원래 덧셈/곱셈 순서 그대로다. CAT의 통증 70 및 해당 팔다리 기능 0은 **사용자 설계/게임 허용**이며 새 HP 손상이나 장시간 허혈 손상이 아니다. 제거하면 기능/부위 통증 오버레이를 해제하고 원래 상처 판정을 계속한다. 급성 통증은 기존 감쇠로 줄어든다.

## 시간과 출처

CAT 다리 기본 37.5초는 Beaven 등(2018, 24명 건강한 군인, 허벅지 자가 적용)의 중앙값이다. IQR 27–52초 및 성공 22/24(92%)도 기록했다. 게임의 완료는 올바르게 완전히 조인 상태로 정의했고, 이 성공률을 별도 무작위 실패 확률로 바꾸지 않았다. 팔 28초/한 손 배율 1.65는 정확히 대응하는 적용 시간 자료를 확인하지 못한 **튜닝**이다. 2023 남극 연구는 팔 한 손/다리 두 손 적용 가능성을 뒷받침하지만 적용 시간을 측정한 자료로 쓰지 않는다.

거즈 채우기 30초/붕대 30초는 튜닝이다. 거즈 압박 180초는 제조사 #200 IFU Rev D(2020)의 “Continue to apply pressure for 3 minutes or until bleeding stops”를 확인했다. IFU의 다음 단계인 붕대 고정도 확인했다. 2009 돼지 대퇴동맥 연구의 CG 8/10 안정 지혈은 배경 근거이며, 게임의 0.03 계수를 산출하는 실측 자료가 아니다.

시간표의 건강/손상/한 손/양팔 불가/심한 증상은 연속 입력과 분쇄·절단 플래그를 바꾸는 별도 시간 배율 프로브다. 상처/출혈 시나리오는 실제 사격으로 만든다. 시간 배율은 시작/재개 시점의 팔 기능, 부위/전신 통증, D1 흔들림 진폭, 의식, 관류에서 정해 고정한다. 진행 중 악화가 남은 시간을 끝없이 늘리는 것을 피한다. 분쇄/절단 이외의 기능 저하는 사용 금지가 아니라 시간 증가다. 한 팔만 남으면 한 손, 두 팔이 분쇄/절단이거나 의식 소실이면 불가다. 배율은 1 이상이고 실제 압박은 최소 180초다. 재개는 배율을 다시 평가한다.

## 포인터 잠금

PC에서 닫기 버튼·I/Tab·계속 버튼 입력 처리 안에서 동기적으로 `requestPointerLock()`을 호출한다. 닫는 클릭은 사격으로 가지 않는다. Esc에서는 요청하지 않는다. Promise 거부와 pointerlockerror를 처리하고, 다음 좌클릭을 재시도에만 사용한다. 브라우저가 아직 재잠금을 거부하면 재시도 상태를 유지한다. 터치/펜으로 닫으면 요청하지 않는다.

두 화면 1280×720/844×390에서 마우스/실제 터치 이벤트, 드래그와 선택, 중단·재개·회수·폐기·HUD를 확인한다. 독립 HTML의 오프라인 실제 RAF도 확인한다. 실제 휴대폰 검수는 별도다. 보호 파일/내장 자산·2D 원본, 전체 테스트, 미처치 7×900초, S0 240조건·684채널·젤라틴·단발28표·600틱 비교는 자동 검증한다.

M4(씰/바늘/복부/NPA), M5(타인), M6(장비 격자), 구획 증후군·2시간 지혈대 손상·진통제·TXA·AI 처치는 구현하지 않는다. 2D 역이식 후보는 대장에 표시하지만 자동 역이식하지 않는다.
