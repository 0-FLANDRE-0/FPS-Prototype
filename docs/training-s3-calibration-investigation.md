# S3 공통 HP 환산과 7N6 복부 조사

이 문서는 실제 게임의 고정 광선과 `traceShot()` 결과를 설명한다. 인체 손상 예측용 임상 계수가 아니다. 기준은 v40 `c4e608dfc2ea65b4ef94bbb7c7ce9301c3d28fd2`이며, 원본 2D 수치는 바꾸지 않는다.

## 대표 경로와 C

`downloads/checks-s3-v41/fixtures.json`에 C를 계산하기 전에 선택한 21개 경로와 기존 S0 경로 7개를 고정했다. 머리·가슴·복부, 양쪽 상완·대퇴에 각각 정면·측면·비스듬한 경로가 있다. 선택 순서는 메시에서 얻은 정규화 단면 중심과 가까운 좌표 순서다. 손상량이나 C 목표는 선택에 쓰지 않았다.

모든 새 경로는 지정한 부위에 먼저 들어간다. 팔·다리는 전체 광선에서 해당 팔다리만 지나고, 실제 뼈·혈관 직접 교차가 0인 경로를 사용한다. 일시 공동이 주변 장기·혈관에 미치는 효과는 제거하지 않고 별도로 기록한다. 가슴 비스듬한 경로는 가슴을 나온 뒤 오른팔에도 닿는다. 보정에는 가슴 구간의 유효 손상량만 들어간다. 기존 S0의 팔 선행 경로는 그대로 보존한다.

M855, M4 실제 총구 속도 879 m/s, 5 m, 무방호에서 새 유형별 모델을 실행했다. **C = 0.10996950326980938 HP/cm³**다. 분류는 게임 튜닝이며, 다섯 부위 범주에 같은 가중치, 각 범주 안에서 각 경로에 같은 가중치를 준다. 목적 함수는 `ceil(HP / (유효 cm³ × C))`가 목표 발 수 구간을 벗어나는 정도의 로그 제곱 평균이다. 목표 구간 안에는 벌점을 주지 않는다. 머리의 1발 초과 피해를 억지로 줄이는 벌점도 없다.

최종 실행은 소스 커밋 `a4fe65bf3217db63ffd0aa174bbbd3db8a7bbd60`에 연결했다. 런타임 파일 103개가 그 커밋의 바이트와 전부 같고, 다시 구한 C와 설치된 C의 IEEE754 64비트 바이트도 `01e8191cf626bc3f`로 일치한다. 21개 실제 의료 HP 감소와 계산식의 최대 오차는 7.1×10⁻¹⁵ HP다. 독립적으로 로그 공간의 양의 곡률 이차식을 풀면 C=0.10996950295752346이며, 설치 C와의 차이는 3.13×10⁻¹⁰이다. 이는 부동소수점 목적 함수 비교의 평탄한 반올림 구간 안의 차이다. 이 값의 자릿수가 인체 손상 예측 정확도를 뜻하지 않는다.

| 부위 범주 | 목표 HP 0 발 수 | 실제 고정 경로의 산술 발 수 | 목표 충족 경로 |
| --- | ---: | ---: | ---: |
| 머리 | 1–2 | 1 | 3/3 |
| 가슴 | 4–6 | 4–5 | 3/3 |
| 복부 | 4–6 | 2–3 | 0/3 |
| 팔 근육 | 2–3 | 5–6 | 0/6 |
| 다리 근육 | 2–3 | 2–3 | 6/6 |

하나의 C로 모두 맞출 수 없다. 가장 손상이 작은 팔 경로를 3발 안에 HP 0으로 만들려면 C가 약 0.203883 이상이어야 한다. 반면 가장 손상이 큰 복부 경로가 적어도 4발 걸리려면 C가 약 0.064308 미만이어야 한다. 두 조건의 교집합이 비어 있다. 부위별 계수나 인위적인 유효 손상량은 추가하지 않았다.

표의 발 수는 같은 단발 손상량을 반복한다는 산술 HP 값이다. 의식 소실·장기 손상·출혈·심정지 시각은 별도로 잰다. 머리는 HP가 85이므로 실제 단발 HP 감소는 최대 85이며, `유효량×C`의 제한 전 값과 구분한다.

## v40 7N6 복부 3.457의 원인

기존 S0 `liver` 경로는 복부 정면 단독 사격이 아니다. 실제 순서는 **왼팔 → 복부 → 오른팔**이다. v40 원본 작업 트리에서 같은 고정 광선을 다시 실행해 7N6 3.456946074018518, M855 28.064608220459924 HP 감소를 재현했다.

| v40 복부 입력/출력 | 7N6 | M855 |
| --- | ---: | ---: |
| 최초 왼팔 입사 속도, m/s | 887.460756 | 874.077781 |
| 왼팔을 나온 뒤 복부 입사 속도, m/s | 512.696047 | 751.640157 |
| 복부 최초 회전, rad | 1.199646 | 0 |
| 복부 `damageIn` | 16.354763 | 38.457005 |
| 복부 유효 손상량, cm³ | 222.497301 | 729.765832 |
| 복부 m | 0.222497 | 0.729766 |
| 원본 조직 배율 | 0.95 | 1 |
| 복부 HP 감소 | 3.456946 | 28.064608 |
| 복부 중 파편화 | 안 함 | 함 |

v40 HP 비율을 곱셈으로 분해하면 `49/52 × 0.451311 × 0.95 × 0.304889 = 0.123178`이다. 첫 항은 원본 데미지 비율, 둘째는 선행 왼팔 이후 `damageIn`의 에너지 유지 비율 차이, 셋째는 원본 조직 배율 비율, 마지막은 공동에서 계산한 m의 비율이다. 선행 팔에서 에너지가 크게 줄어든 7N6가 복부에서 다시 작은 m과 곱해졌다. 이 중복 경로가 약 1/8 차이를 확대했다.

**m 바닥 0.1은 복부 값의 원인이 아니다.** 두 탄의 복부 m은 모두 0.1보다 크다. 바닥은 그 뒤 거의 소진된 오른팔 구간에만 적용됐다. 두 탄 모두 원래 간을 직접 교차하며, 7N6의 간 심각도는 약 0.150463, M855는 0.512462다. M855의 더 큰 공동은 왼쪽 신장·식도에도 간접 영향을 주었다. 이 장기 차이는 실제 경로 결과이며, 간 교차를 누락한 오류가 아니다.

회전과 등가 깊이를 다음 부위로 넘기는 동작도 확인했다. 7N6는 왼팔에서 이미 회전해 복부에 들어온다. 회전 상태를 초기화하면 같은 탄이 앞 부위를 지난 이력을 지우므로 수정하지 않았다. v40 M855는 M193 차용 파편화가 켜져 있었으며, 이는 S3에서 원본 `yaw / 760`에 따라 파편화 없는 모델로 바뀐다.

팔을 거치지 않는 복부 정면 대조 경로도 실제 메시에서 실행했다. 이 경로는 지정된 복부 단면 중심을 향하며 간 중심을 그대로 통과한다고 주장하지 않는다. 실제 교차 장기 목록은 결과 파일에 남겼다.

| v40 복부 정면 단독 대조 | 7N6 | M855 |
| --- | ---: | ---: |
| 복부 입사 속도, m/s | 887.323167 | 873.813966 |
| 복부 유효 손상량, cm³ | 419.651891 | 910.088905 |
| 복부 HP 감소 | 19.534796 | 47.324623 |

팔이 없으면 HP 비율은 약 0.412783으로 올라간다. 이 대조는 선행 팔의 영향을 입증하지만, 두 탄의 공동이 같다는 뜻은 아니다. S3에서는 요청한 25종에 대해 `damageIn × tissueDamageMul × m`을 HP 계산에서 제거하고, 실제 해당 부위 유효량에 공통 C만 곱한다. 속도·질량·회전의 정상적인 부위 간 전달은 유지한다.

같은 광선을 최종 S3 유형 설정과 C로 다시 실행한 실제 HP 감소는 다음과 같다. 7N6의 공동량 자체는 v40과 같고, M855는 원본 yaw 유형에 따라 파편화 없이 다시 계산된다.

| S3 실제 복부 HP 감소 | 7N6 | M855 |
| --- | ---: | ---: |
| 기존 팔 선행 `liver` 경로 | 24.467918 | 81.568202 |
| 팔 없는 복부 정면 대조 | 46.148910 | 94.942277 |

이는 중복 곱셈 제거와 새 M855 설정의 결과다. 두 탄의 실제 공동량 차이까지 없앤 결과가 아니므로, 두 값이 같아지도록 C나 장기 결과를 조작하지 않았다.

재현 명령은 `node scripts/calibrate-training-s3.mjs --discover`, `--investigate`, 기본 C 계산, `--investigate-s3`다. 최종 배포 검증은 고정된 파일의 SHA와 원본 보존 검사까지 포함한다. 원시 결과는 `fixtures.json`, `calibration.json`, `7n6-abdomen-v40-investigation.json`, `7n6-abdomen-s3-comparison.json`이다.
