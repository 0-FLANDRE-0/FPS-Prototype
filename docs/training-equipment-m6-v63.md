# M6/v63 — 장비별 격자·착탈·바닥 물품·질량

v62 `b02c02b6904fddcca15b85abb3aefd075311814a` 위의 3D 변경이다. M5/타인 치료는 보류한다. 원본 2D, 탄도·관통·방호·출혈·흉부·생리 및 D2 수식은 유지하고, 장비의 실제 착용 여부와 질량 입력을 연결한다.

내장 GLB의 6개 메시/정점 수와 Head의 주 가중치3,639/145/119는 지시서와 일치한다. 현재 파생본은 손가락을 포함한54본이다. **실제 데이터는 문서 메모와 구별한다:** 6B45 본체에는 builtInProtection.neckGuard가 없고, 기존3D 프로필은 별도6b45_neck/6b45_shoulder 부속을 사용한다. accessorySlots의 어깨/목은 true다. 본체 기본 방호와 별도 부속 슬롯/장착은 다른 항목이다. 기존 판정/등급을 고치지 않고 리그 착탈 때 기존 부속 센서도 함께 분리한다.

런타임에서 정점 주 가중치의 삼각형 다수결로 헬멧/리그/벨트/몸을 나눈다. 목 보호대는 리그, 무릎 보호대는 몸에 남는다. 얼굴은 기존 해부 표면 범위와 얼굴 경계로 구별한다. 원본 정점/UV/웨이트/삼각형은 이동하지 않고 인덱스만 나눈다. 머리 윗면 부재는 **authored 바라클라바와 목 연결 천**으로 보완하며, 원본GLB/손가락/피격 형상은 바꾸지 않는다. 기존1인칭 머리 숨김도 적용한다. H01·적·플레이어가 같은 분리 함수를 쓴다.

리그는1×1 세 개/1×2 네 개/2×2 한 개, 벨트는1×1·1×2·1×2·1×1이며 파우치끼리 걸칠 수 없다. 배낭은 기존6×5다. M4 예비 탄창4개(30발2개·빈2개), AK 예비 탄창2개(각30발), IFAK을 지정 위치로 옮겼다. AK 예비1개는 원래 상자에 있었으므로 휴대 탄은870→900발, **전체 탄은 그대로**다. 기존68개 물품을 보존하고 기존 장착 장비를 나타내는4개 식별자를 추가한다. 장비 표현을 만든 뒤의 **순수 배치 변경은72→72개/전체 질량 동일**이다. 이전13.7kg은 방호 장비만의 D2 입력이며 완전한 인벤토리 질량이 아니었다.

재장전은 착용 중인 리그→벨트, 각 파우치 위/왼쪽 순서에서 탄이 든 호환 탄창을 고른다. 배낭/바닥/배낭 안 리그 탄창은 자동 장전에 쓰지 않는다. 직접 고른 빈 탄창은 장착 가능하다. 원래 탄창을 들어온 파우치로 돌려주며, 중간 취소는 삽입 전이면 원래 구성을 복원한다. 기존 네이티브 장전 클립과 시각은 유지한다.

배낭은 한 번 열면 계속 접근하며, 닫거나 이동 의도를 내면 닫힌다. 열린 동안 이동/사격을 막는다. 배낭 의료품은 열기 비용을 먼저 지불하며 이미 열었다면 중복 부과하지 않는다. 한 손 수혈은 M4c 배율/상한을 사용하고 연결 후 원래500mL 주입 속도는 같다. 자가 연결 허용은 사용자 설계/게임 허용이며 실제 IV/골내 주사 기법을 모사한다는 주장은 아니다.

헬멧/리그 벗기와 입기는 이동·사격·피격으로 중단되고, 메뉴는 시간을 멈춘다. 같은 아이템의 방호 손상과 리그 내용물을 보존한다. 바닥 리그는 장비·의료 양쪽 ‘주변’에서 열 수 있다. 헬멧/리그는 배낭에 보관하고 나중에 빈 장착 칸에 입힐 수도 있다. 배낭에 보관한 장비의 내용물 접근/자동 장전은 착용 중 리그와 구별한다.

무기·탄창·헬멧·리그는 실제 원본 메시를 베이크한 Rapier 동적 물체로 떨어진다. **충돌 상자와 중심은 인덱스가 참조하는 실제 정점만** 사용한다. AK 탄창도 총 전체 크기의 상자를 쓰지 않는다. 소스 무기/탄창과 장착 광학을 쓰며 임시 탄창 상자 대체는 현재 두 탄창에 필요하지 않았다. 약2m/시선 중앙/엄폐 확인 후 F·터치로 줍고, 빈칸이 없으면 이동을 거부한다. 무기 두 칸과 빈손 전환을 유지한다. 아이템은 초기화까지 남고 총알 판정에는 참여하지 않는다.

질량은 같은 인스턴스와 부모 소유 체인을 한 번만 센다. 방호13.7kg, M4 조립 질량3.07kg/AK3.6kg, 광학·의료품은 기존 자료를 쓴다. 벨트0.5kg/배낭0.8kg/빈STANAG0.11kg/빈AK탄창0.23kg, 완성탄 질량=탄두×3은 **튜닝**이다. 부분 OTFC와 수혈액 감소도 읽는다(액체1kg/L·포장 잔여 질량은 단순화). D2의 운동·회복 식은 그대로다. 준비된 래그돌 분절 질량은 v62 프리셋을 유지하며, M6의 총질량 연결 대상은 D2·발소리·낙하 물체다.
