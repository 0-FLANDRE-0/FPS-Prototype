# 의료 개편 — 치료 1: 붕대

작업 브랜치 `feature/medical-overhaul`, 기준 `e1efefa`의 계약 문서와 v69 런타임이다. [확정 계약](medical-overhaul-contract.md)을 적용한 첫 단계이며 의료 개편 완료판이 아니다. 직접 관통/공동 손상 구분, 손상량·탄도·방호·장기 후속 효과와 다른 의료품은 이번에 바꾸지 않는다.

## 이번 동작

기존 압박붕대 한 제품을 사용한다. 내 인벤토리/열린 IFAK에서 붕대를 선택한 뒤 의료탭의 명시적인 상처 한 개를 누른다. 적용 가능 범위는 기존처럼 피부 개구부가 확인된 겉 출혈이다. 몸통 체강 출혈과 사지 내부에 남는 유출은 붕대로 치료하지 않는다. 화면의 100%는 **그 상처의 겉 지혈 완료**이며 모든 내부 손상의 완치를 뜻하지 않는다. 범용 내부 지혈품은 후속 단계다.

붕대와 대상 상처를 예약하고 4초 후 필요한 자원과 지혈 진행을 함께 적용한다. 끝나기 전에는 자원·지혈·회복 효과가 없다. 잔량이 부족해도 같은 4초를 쓰고 남은 양에 비례해 겉 지혈한다. 진행은 상처에 남고 다음 붕대 인스턴스로 이어서 완료할 수 있다. 충분하면 필요한 만큼만 사용한다. 완료한 지혈 진행은 의료 기록 제거로 되돌릴 수 없다.

도중 취소·피격·이동·총기 동작 또는 사용 불가 상태에서는 자원과 효과가 모두 없다. 취소한 행동을 다시 선택하면 4초를 처음부터 쓴다. 예약한 물품과 이를 담은 파우치의 이동을 막고, 완료 시 물품·대상·소유·잔량을 다시 확인한다. 대상이 없어져도 다른 상처로 바꾸지 않는다. 이미 지혈이 완료됐다면 소비하지 않는다.

완료 후 해당 부위 HP 회복이 시작된다. 현재 HP가 같으면 같은 속도로 회복하며 처치를 여러 번 했다고 속도를 합산하지 않는다. 최대 HP에 가까울수록 느려지고 결국 현재 최대치에 정확히 도달한다. 부위 최대 HP는 쓰지 않는다. 혈액량·골절·절단·장기 손상과 기존 구조 파괴의 기능 상한은 복구하지 않는다. HP가 가득 차도 그 부상의 별도 기능 제한은 남는다.

## 착수 기본안에서 채택한 정책

- **사용자 설계값:** 고정 시간, 완료 시 자원/효과 동시 적용, 잔량 부족 시 부분 지혈, 상처별 영구 진행, 완료 후 점진 HP 회복, 현장 회복 상한 없음, 최대 HP 감소 없음.
- **튜닝:** 사용 4초, 제품 내구도 100점, 효율 1, 작업량 `min(400, 8 + HP 상한 적용 전 물리 손상량×0.6 + 접근 가능한 원래 혈관 개구 면적(mm²)×0.8)`. 순간 혈압·유량·현재 HP를 작업량 비용으로 사용하지 않는다. 최초 성공 완료 시 작업량을 상처에 고정한다.
- **튜닝:** 겉 출혈 계수 `1 − 누적 치료 작업량/필요 작업량`. 사지 내부/체강의 유량 성분은 유지한다. 완전히 제어한 기존 겉 성분은 움직임 배율이 있어도 0이다. 자연지혈과 공유 혈관/순환 제한은 기존 경로다.
- **튜닝:** 회복속도 `max(0.2, 3×남은 HP/현재 최대 HP)` HP/s, 고정 의료 틱에서 부족량만큼 제한한다. 회복 완료 전에는 부위의 기존 구조 손상에 따른 기능 상한을 유지한다.
- **첫 단계 정책:** 같은 부위에 새 피격/추가 HP 손실이 생기면 회복을 중단한다. 새 상처를 별도로 처치해야 다시 활성화된다. 이전 상처 지혈이 새 상처에 적용되지 않는다.
- **후속으로 남김:** HP 0 부위·절단은 붕대 HP 회복 대상에서 제외한다. 이미 확정된 사망/심정지를 취소하지 않으며 의식 상실 동안 회복하지 않는다. 해당 구조 복구·수술/다운 재설계는 후속 단계다.
- **게임 허용:** 내구도는 가상 자원점이며 실제 제품 성능/의료 소요시간이 아니다. 제품 무게·크기·물리 모델과 제조사 출처는 기존 값을 유지한다. 기존 다른 제품/모드 전환은 유지하되 붕대의 시간·내구도는 모든 모드에서 하나다. 새 모드를 추가하지 않았다.

## 코드 경계와 검증

정책/상처 진행은 `medical-bandage.js`, 회복은 `medical-part-recovery.js`, 재고의 유일한 자원 값은 물품 인스턴스의 `remaining`이다. stock의 이전 횟수 계산으로 붕대를 리필하거나 복원하지 않는다. 예약에는 행동/검증 정보만 두며 자원을 별도로 소유하지 않는다. 회복은 `bodyParts[part].hp`를 직접 갱신한 뒤 기존 의료 재계산을 실행한다.

선택 상처를 치료한 공유 혈관의 유량 귀속은 처치 후 기여분으로 합산한다. 실제 혈관 전체를 두 번 생성하거나 원래 미처치 손상량을 바꾸지 않는다. 치료하지 않은 경로에는 이 분배 변경이 들어가지 않는다.

검증은 전용 테스트, 기존 전체 테스트, 고정 2D 보존, v69 수치(S0 240·단일 28·684채널·젤 5종), M4/AK 600틱 및 두 화면에서 사용·취소·부분 지혈·회복을 포함한다. `verify-v69 --calculations-only`는 이번 의도적인 HTML 변경만 제외하고 원래 골든의 모든 수치 해시를 비교한다. 골든은 수정하지 않는다.

실측 결과와 대표 피격의 자원·유량·회복 완료 시간은 [구현 대장](medical-overhaul-bandage-ledger.json)에 기록한다. 브라우저 검증의 손상은 실제 `traceShot`으로 만들고, UI 동작은 PC 클릭/터치로 수행한다. 테스트용 고정 틱 제어와 게임 배포 코드는 구분한다. 실제 폰 성능은 미측정이다. GitHub Actions·main 병합·의료 개편 완료판 배포는 하지 않는다.
