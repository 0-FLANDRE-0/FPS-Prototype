# CQB Training 번외 업데이트: 조준경 3종 포팅 지시서

2026-10-11 작성. v27 배포 HTML(`dist/CQB_Training.html`, SHA256 `39101f96…cdc20e`)을 기준으로 다른 AI가 결과물 HTML을 직접 고친 번외 업데이트다. 이 문서의 목적은 그 변경을 **원본 소스(`src/**`)와 자산 파이프라인으로 옮기는 것**이다. 소스에 반영하지 않으면 다음 빌드에서 이 변경이 모두 사라진다.

같이 받는 파일은 다음과 같다.
- `CQB_Training.html`: 번외 업데이트가 적용된 결과물. 동작 기준이다.
- `patch.py`, `patch_optics.py`: v27 결과물에 적용한 **정확한 전후 문자열**. minified 식별자로 되어 있으므로 소스에서 같은 위치를 찾는 데 쓴다.
- `tools/`: 자산 재압축과 새 조준경 GLB 생성 스크립트.

## 원칙

- 기존 규칙(출처, 원본, 튜닝 값 구분 / 변경 대장 / legacy 동작 유지 / 의료·탄도·관통·방호 미변경)을 그대로 따른다.
- 이번 변경은 탄 비행, 관통, 방호, 의료, 탄약 레지스트리를 **건드리지 않았다**. 영점은 여전히 없다(`zeroing:false`).
- 결과물 HTML의 동작과 스크린샷이 기준이다. 소스로 옮긴 뒤 같은 장면에서 화면이 같게 나와야 한다.
- 아래 표의 "구분"은 원본(제조사 자료 값), 유도(제조사 도면 비율에서 읽은 값), 튜닝(게임 조정값)이다. 튜닝 값은 소스의 상수 옆에 그렇다고 주석을 단다.

## 1. 조준경 집중 시야 (배율 체감)

**문제:** 조준 중에도 바디캠 화각(가로 96°, 왜곡 포함)을 써서 접안 영상(겉보기 시야 약 19°)이 화면 높이의 약 30%밖에 안 됐다. 6배를 써도 체감 배율이 작았다.

**변경:**
- 배율 조준경을 들여다볼 때 메인 카메라 화각을 접안 영상 쪽으로 좁히고, 바디캠 렌즈 왜곡을 같은 비율로 줄인다.
- 집중량은 `F = ads × (scopeFocus/100) × ln(m)/ln(6)`. 1배는 집중이 없어 근접전 시야를 유지한다.
- 집중이 끝난 상태의 세로 화각은 `2·atan(apparentTan / focusFill)`, `focusFill = .62`(튜닝). 접안 영상이 화면 높이의 62%를 채우는 값이다.
- 렌즈 경로(바디캠 왜곡 ON)에서는 왜곡 세기를 `lensStrength·(1−F)`로 줄이고, 가로 화각을 기존 값과 목표 가로 화각 `2·atan(tan(V/2)·aspect)` 사이에서 F로 보간한다. 렌즈 OFF 경로는 세로 화각을 바로 보간한다.
- 조준 감도는 집중으로 화면이 확대된 비율 `tan(V/2)/tan(V0/2)`만큼만 보정한다(`r.opticLookScale`). 배율 자체로 영상이 흔들리는 것은 보정하지 않는다.
- 배율은 장착된 조준경 정의에서 가져온다. Vudu는 아이템의 현재 배율, ACOG는 고정 4배, 홀로그래픽은 1배(집중 없음)다.
- 설정에 `scopeFocus` 슬라이더(0–100%, 기본 100)를 추가했다. 기본값, 범위, 표시 형식, 설정 화면 행 모두 포함한다. 0이면 v27과 완전히 같다.

## 2. 배율 조절 곡선 (Vudu)

- 배율 변화를 로그 공간에서 한다: `m ← m·exp(dir·ln6·dt/zoomTravelSeconds)`. 1→6 전체 이동 시간 0.4초는 그대로다.
- 상수에 `zoomLaw:"log"`를 기록했다.

## 3. 렌즈 광학 표현 (Vudu, ACOG 공통 PiP 셰이더)

모든 값은 튜닝이다. 제조사 자료가 아니다.

| 항목 | 내용 | 값 |
| --- | --- | --- |
| 배율별 왜곡 | 출력 ndc에서 원본 텍스처를 `n·(1+k·r²)`로 샘플링한다. 화면 중앙 배율은 바뀌지 않는다 | Vudu 1×: +.035(어항 왜곡), 6×: −.015. ACOG: −.01 |
| 가장자리 색수차 | R/B를 `1±chroma·r²`로 다르게 샘플링 | Vudu .005, ACOG .004 |
| 가장자리 흐림 | 5탭, 반경 `edgeBlur·r⁴` | .006 |
| 주변 감광 | `1−vignette·r³` | Vudu .14, ACOG .18 |
| 시야 조리개 | 가장자리를 1.2% 폭으로 부드럽게 하고, R은 ×.997, B는 ×1.003 반경으로 얇은 색 테를 만든다 | |
| 사출동 그림자 | 광선 위치 `eye.xy + ndc·(pupil·.8 + apparentTan·|eye.z−exitPupilZ|)`, 폭 `pupil·.5`로 부드럽게 처리. 걷기나 사격으로 눈이 1–2 mm 흔들리면 그림자가 밀려 들어온다 | |
| 접안 유리 반사 | 코팅 색(초록)의 환경 반사(Fresnel)와 테두리 반짝임. 영상 위에는 절반 세기 | `glare` 2 |
| 조명 레티클 번짐 | 링·점 주변 가우시안 번짐 | |

- FFP 레티클은 왜곡된 좌표 `dn`으로 그린다(영상과 같은 면에 있다).
- `projectWorldPoint`(조준 가이드, 피격 표시 위치)도 같은 왜곡의 근사 역변환과 같은 사출동 판정을 쓴다.

## 4. 조준경 시스템 일반화

### 4-1. 정의 레지스트리

- XPS3와 ACOG의 장착 위치와 눈 거리는 조준 시 눈 위치가 기존 기계식(가늠자 z .155 + .075)과 Vudu(z .235)와 같은 z≈.23에 오도록 정했다.
- 레일 위치는 XPS3가 상부 리시버 앞쪽(앞끝 z≈−.005), ACOG가 접안부가 장전손잡이 위로 오는 위치다.

### 4-2. 조준 모델 (`ja` 클래스)

- `setOptic(def)`는 정의 객체를 받는다(기존은 boolean). `opticDef`를 저장하고, 조준 기하(rear/front/sightAxis)를 정의별로 만들어 캐시한다. Vudu는 기존 `Wk`를 그대로 쓴다.
- 조준 눈 거리는 `opticDef.adsEyeReliefM`이다.
- 최소 눈 거리 클램프: 기존 `max(.045, …)`는 ACOG(38.1 mm)를 45 mm로 밀어내 시야가 좁아진다. 광학 장착 시 `min(.045, eyeRelief·.8)`로 바꿨다.
- 호출부는 `r.setOptic(Ei(l.optic))`다. 배율 입력(`S1`)과 HUD 배율 버튼은 `variableZoom`일 때만 동작하고 표시한다.

### 4-3. PiP 렌더러 (`optic-render.js`의 `cS`)

- 전역 `wC` 대신 사양 객체 `P`를 받는다. Vudu 사양은 `wC`에 `sn`, `h1`, SR3 레티클, 유리 이름을 더한 것이다.
- 사양이 제공하는 것: `sn(m)`(시야와 출사동), `h1(eye,m)`(눈 위치와 사출동 겹침), `reticle` GLSL, `glassName`(접안 쪽 유리 삼각형 제거 대상, 없으면 건너뜀), `fixedMag`, 셰이더 튜닝 값.
- ACOG 사양 `sn`: 진시야 7°(원본), 겉보기 tan = 4·tan 3.5°, 출사동 8.13 mm(원본), 눈 거리 38.1 mm(원본), 축방향 감쇠 12 mm(튜닝), 접안 반지름 11.5 mm(모델).
- `h1` 일반형(`cqbOptH1`)은 기존 `h1`과 같은 식에 사양을 인자로 받는다.

### 4-4. 홀로그래픽 렌더러 (XPS3)

- 모델의 창 유리 메쉬(재질 `XPS3_Glass`)에 전용 셰이더를 씌운다. 투명하고 깊이를 쓰지 않으며 양면이다.
- 레티클은 **무한원 방향 기준**으로 그린다. 프래그먼트마다 카메라→프래그먼트 방향을 조준경 좌표로 돌려 각도(MOA)를 구한다. 그래서 시차가 없고, 시선이 창을 지나는 곳에서만 레티클이 보인다(창 가장자리에서 잘림).
- 뒤 유리에만 레티클을 그린다(조준경 좌표 z로 판정).
- 레티클 값:
  - 68 MOA 링, 1 MOA 점: 원본. EOTECH EXPS3 매뉴얼과 XPS3-0 표기. 구판 XPS 매뉴얼은 65 MOA로 적혀 있으니 대장에 차이를 기록한다.
  - 사분 눈금은 바깥쪽 8 MOA, 선 폭은 1 MOA: 튜닝. 매뉴얼에 치수가 없어 모델에 그려진 레티클 비율을 따랐다.
  - 밝기 1.5, 번짐, 레이저 스페클 그레인: 튜닝.
- 유리는 옅은 청회색 틴트에 Fresnel 하늘 반사를 더한다(튜닝).
- 인터페이스는 PiP와 같다(update/render/dispose/projectWorldPoint/snapshot). `render`는 아무것도 하지 않고, `projectWorldPoint`는 입력을 그대로 돌려준다. 스냅샷은 `pip:false`, `kind:"holo"`.
- 원래 기계식 가늠쇠는 보인다(앱솔루트 코위트니스). 뒤 가늠자는 모든 광학 장착 시 숨긴다.

### 4-5. 로더 (`hS`)와 디스패처

- 세 정의를 순서대로 읽어 각각 마운트 그룹, 마커, 렌더러를 만든다.
- `sync(inventory)`는 장착된 정의의 마운트만 보이게 한다.
- `optics` 디스패처는 기존 단일 객체와 같은 인터페이스다. update는 모두에게 호출하되 장착되지 않은 것은 `ads:0`. render는 모두에게 호출하는데, 각자 자격이 없으면 바로 끝난다. projectWorldPoint와 snapshot은 현재 장착된 것에 위임한다.

### 4-6. 인벤토리와 문구

- 탄약상자에 `optic-xps3-01`, `optic-acog-01`을 `findCell`로 추가한다(Vudu 위치는 그대로).
- 장착 실패 문구 "Vudu는 M4에만…"을 "이 조준경은 M4에만…"으로 바꿨다.
- 장착·분리 시간: XPS3 .8/.6 s, ACOG 1/.8 s(튜닝).

### 5-2. 새 조준경 GLB (`tools/build_new.py`)

**XPS3** (원본 `462ffce4…xps3…ver.4.0.glb`, Sketchfab Standard)
- 크기 0.09525 m / 9.3712 단위.
- 축: 모델 +x(뒤, 버튼 쪽) → 게임 +z.
- 기준점: 뒤 유리 x, 베이스 접촉면 y 5.66, 레티클 중심 z −.0247.
- 마커: `XPS3_window`(뒤 유리 레티클 중심), `XPS3_windowFront`, `XPS3_mountBottom`.
- 재질: 유리 메쉬는 `XPS3_Glass` 재질로 분리하고, 본체는 MASK .5.

**ACOG** (원본 `f742dc09-acog.glb`, CC BY-NC 4.0)
- RMR, rds mount, killflash(3만 삼각형), 모델 레티클, 접안 유리를 제거한다.
- 크기 0.15189 m / 2036.57 단위.
- 축: 모델 +x(대물) → 게임 −z.
- 기준점: 접안 x −1385, 레일 접촉 y −496(TA51 클램프 바닥에서 약 5.5 mm 위, 화면에서 안착 확인), z 5.
- 마커: `ACOG_ocular`, `ACOG_objective`, `ACOG_mountBottom`.
- 재질: 모든 재질에서 `KHR_materials_transmission`을 뺀다(투과 패스 비용 때문). 본체는 MASK .5, 대물 유리는 어두운 반투명.
- 공유 bufferView를 압축해 6.6 MB → 0.52 MB.

결과물 HTML의 `<script id="optic-xps3-data">`, `<script id="optic-acog-data">`, 그리고 재압축된 기존 5개 블롭을 base64로 디코드하면 기준 GLB가 나온다. 생성기를 새로 만들기 어렵다면 이 파일을 그대로 정본 파생 자산으로 써도 된다. SHA256은 대장에 기록한다.

3. Vudu 1/3/6배: 접안 원 지름(1280×720 기준 약 211/320/446 px)과 세로 화각(65.7/42.4/30.1°)이 번외 결과와 같아야 한다.
4. XPS3: 조준 시 레티클 중심이 광축과 일치해야 한다. 머리를 옆으로 옮겨도 레티클이 표적에 고정되고 창 가장자리에서 잘려야 한다. 가늠쇠 끝이 점 근처에 와야 한다(코위트니스).
5. ACOG: 눈 거리 38.1 mm에서 덮임 1.0, 세로 화각 약 47.6°. 사격 반동 중 축방향 감쇠로 일시 암전이 있어야 한다.
6. 탄약상자 → 장착 → 분리를 실제 UI로 확인한다. 무기 무게에 조준경 무게가 반영되어야 한다(ACOG 3.49 kg). AK 전환 시 M4 조준경이 숨겨져야 한다.
7. 셰이더 컴파일 오류가 없고 런타임 오류와 외부 요청이 0이어야 한다. 실기기(S24) 프레임은 따로 기록한다(PiP 15탭 샘플링으로 부하가 늘었다).
8. 결과 zip이 20 MB 미만이어야 한다.

## 8. 알려진 한계

- 영점과 BDC 정합이 없다. ACOG 셰브론과 SR3 눈금은 실물 값이고, 게임 탄도와의 거리별 오차는 아직 계산하지 않았다(Z0-d와 같이 할 것).
- 정적 1프레임 기준으로 조정했다. 소프트웨어 렌더(약 1 fps)에서만 확인했다.
- XPS3 레티클 밝기 조절, 배터리, NV 모드가 없다. ACOG 광섬유 밝기가 주변광에 따라 변하는 효과도 없다.
- AK 마운트가 없다. 세 조준경 모두 M4 전용이다.
