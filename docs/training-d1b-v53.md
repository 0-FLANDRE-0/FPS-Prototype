# D1b/v53 · 눈꺼풀·관류 시야·결정론 파형·아드레날린 화면

v52 `eca57299c7c798b8c3bc86aa7b62ba0f5efec74d` 위 런타임 `adeb0b617a0d95f4c16ac8830dc63612eff8d8f4`. [사용자 첨부 지시서](training-d1b-instructions.md), [대장](medical-d1b-v53-ledger.json), [원문 확인 범위/출처](medical-d1b-sources.json), [화면·그래프](../downloads/checks-d1b-v53/report.html).

위 눈꺼풀이 크게 처지고 아래가 조금 올라오는 흐린 곡선과, 위아래를 함께 조이는 통증 찡그림을 분리했다. 지속적인 느린 의식 하강만 졸음형6단계를 쓰며, 급성 하강은 억제한다. 느리게 감고 빠르게 뜨는 불규칙 결정론 FSM이다. 통증은 기존 perceivedPain과 상승 속도를 읽으므로 아드레날린 가림을 그대로 따른다.

흑백화/주변 어둠은 v52 혈액 부족률이다. 터널/암전은 부족률과 망막 관류 모델의 큰 쪽이다. 눈 높이 MAP에서 안압을 뺀 압력과 기존 관류/산소를 읽는다. 서기·앉기·래그돌의 눈–심장 높이는 실제 뼈/장기 중심에서 계산한다. 생리 값이나 쓰러짐·심정지 판정에 쓰지 않는다. 기립성 하얗게 날림도 별도로 유지한다.

떨림은8–12Hz 대역 합성과 느린 진폭 변조다. 플레이어의 아드레날린 채널은 연속값이며 잔떨림은 서보 밖에 더한다. 큰 흔들림은3옥타브, 숨은 들숨38%/날숨62%, 심박은 작은 불규칙 간격의 짧은 펄스다. 숨·심박·공황·아드레날린의 느린 교란도 조준 유지에 들어간다. ADS 입력을 강제로 해제하거나 탄 분산을 추가하지 않는다.

아드레날린 화면은 기존 렌즈 한 패스에서 중심 샤프닝/밝은 테두리/미세 이동을 합친다. PiP에도 적용된다. 화면 강도0/50/100%는 시야만 바꾸고 몸의 흔들림/동작/탄 방향은 바꾸지 않는다. 효과0은 샤프닝 추가4탭을 생략한다. 중심 회색 경계 실험의 밝은 넘침 12/255·어두운 넘침 10/255를 확인했다.

## 보존·확인 한계

보호 소스185개·자산35개·내장8블록 바이트 동일. 의료/AI/소리 경로의 기존 대응 입력 95,343개에서 AI·청각 배제·동작 배율이 v52와 정확히 같다. 2D 원본·생리/HP·탄도/관통/방호·손가락·래그돌 수식은 바꾸지 않았다. 최종 테스트/600틱/오프라인 검증은 아래 배송 검증 JSON을 따른다.

- Lempert와 Prkachin은 원저 PubMed 초록을 확인했다. Lempert 출판사 본문은403이다. Caffier 출판사 원저 초록은 확인했으나 본문 실측 ms값은 구독 미리보기라 확보하지 못했다. 모든 게임 시간은 튜닝이다.
- Artwohl(2002) FBI 원문은 공식 경로들에서403으로 미확보했다. 명료도 보고 비율을 지어내거나 다른 연구의 비율로 대체하지 않았다. 아드레날린 샤프닝은 사용자 요청/튜닝이다.
- 망막 관류 논문은 원문을 확인했다. 고G에서 눈 높이 MAP가 IOP보다 낮으면 망막 관류가 멈춘다는 원리와 IOP14.1±1.6mmHg 관찰값을 사용한다. 외상·출혈의 보편적 눈 높이 회색시야/암전 mmHg 문턱은 확보하지 못해 튜닝으로 둔다.
- 의식 하강 분류는 선택된7N6 단발 고정 경로에 맞춘 게임 튜닝이다. 통증·쇼크·뼈·후속 생리 반응을 제거하지 않은 실제 traceShot 결과다. 전체 인구나 다른 부상 경로에서의 임상적 민감도/특이도를 검증한 것이 아니다.
- 뇌간 피격은 기존 엔진이 같은 순간 의식/순환을 정지시킨다. 미래 피격을 예상하지 않으므로 암전이 의식 소실보다 먼저 올 수 없다(선행0s). 이 사실을 바꾸기 위해 의료 판정을 지연하지 않았다.
- 대동맥 사례는 흉강 출혈을 함께 만든다. 관류 시야 표의 혈흉 사례로 사용한다. 약한 폐 단독 사례는900s 내 의식 소실/블랙아웃이 없어 선행 시간을 계산하지 않는다. 암전 시각은 최초 >=.99이며, 일시 회복 여부는 전체 시간축에 보존한다.
- 눈–심장 높이는 현재 fitted organ center와 실제 눈 좌표의 y차다. 카메라의 절대 월드 높이를 빼지 않는다. 한 틱 전 자세를 읽어 다음 물리/스키닝 단계로 넘어가는60Hz 지연이 있다.
- 주파수/진폭/각도/마스크 형상/서보·호흡·심박·화면 효과는 게임 연출이다. 스펙트럼의 최대 bin 비율은 Welch2048/120Hz 기준이며, 유한48성분 합성의 수학적 백색 잡음과 구별한다.
- 전체 RMS에는 새 잔떨림과 기존 부상 저주파가 같이 들어간다. 팔1발 약+14%, 심한 팔 부상 약−2%로 선택 QA 범위±20% 안이다. 저주파 자기상관은.25/.5/1s를 모두 기록하며 모든 지연에서 감소했다고 주장하지 않는다.
- 프레임 시간은 Chromium/SwiftShader에서 동일6x PiP 장면을 렌더하고 gl.finish+1px readPixels로 완료를 강제한24샘플/조건이다. 실제 기기 FPS나60Hz 달성을 뜻하지 않으며 소프트웨어 렌더의 큰 절대값/p95도 그대로 공개한다.
- 임상 시간축 CSV는0.1s 표본/소수6자리이며, 이벤트 최초 시각은 원래60Hz 자료에서 검출한다. 원시JSON.gz에는 전체60Hz/원래 부동소수점 정밀도를 보존하며 RMS/스펙트럼/극값을 반올림 CSV에서 다시 계산하지 않는다.
- 원시JSON.gz/개별PNG는 저장소에 보존하고 실행 ZIP에는 요약표/CSV/SVG와 선택 비교 시트를 넣는다. 실제 Android/iOS 기기 청감·조작감·GPU 성능은 미검증이다.
