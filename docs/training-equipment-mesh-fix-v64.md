# v64 — 얼굴·안구·피부의 장비 분리 오류 수정

v63 `38dcd9fc7e9fcc1f9eebe3e864facb76f48da921` 위의 시각 수정이다. 사용자 보고대로 헬멧에 얼굴·눈이 붙고, 리그에 턱 아래 천과 피부처럼 보이는 조각이 섞였다. 기존 뼈 가중치는 애니메이션 부착 기준이며 장비의 의미를 식별하는 기준으로 충분하지 않았다. 이전 검수의 얼굴 범위도 일부만 포함했다.

원본 GLB의 연결 조각과 UV 텍스처를 다시 렌더해 확인했다. **이전 지시서/구현의 `material = 고글 렌즈` 설명은 실제 메시와 달랐다.** 이 메시는 255정점/404삼각형이며 양쪽 안구와 눈 가장자리로 구성된다. 고글 렌즈/프레임은 `Head` 쪽이다. `Head`에는 눈 주변 피부, 얼굴 덮개, 안쪽 머리 윗면과 목 피부도 함께 들어 있다. 리그에 붙였던 후면 내부14삼각형도 피부 텍스처가 매핑돼 있어 몸에 남긴다. 이 조각을 실제 해부학적 장기로 해석하지 않는다.

수정은 `equipment-head-layout.js`의 검수된 시각 분리 표를 사용한다. 안구·눈 주변·얼굴 덮개·안쪽 머리·목/후면 피부 조각은 몸, 헬멧 껍데기·고글·헤드셋·턱끈은 헬멧이다. 목 보호대의 검수된 위장무늬 표면만 리그에 남긴다. 주 가중치 다수결은 몸통/벨트/무릎의 기존 분리에 유지한다.

목 보호대 윗단은 기존 표면 위의 경계 `y = 1.535 + 0.038(x/0.116)² m`에서 양쪽을 상보적으로 나눈다. 경계점의 UV·노멀·웨이트를 보간하므로 뼈별 삼각형 선택으로 생긴 톱니가 줄고, 전체 원본 표면 면적은 보존된다. 이 경계는 이전 시각/콜라이더 조사에서 사용한 튜닝 기준이다. **콜라이더 자체는 바꾸지 않는다.** 새 삼각형은 시각 메시의 분할이며 원본 GLB나 손가락 자산을 편집하지 않는다.

헬멧을 떨어뜨릴 때 전체 얼굴을 함께 베이크하던 문제도 같은 분리 결과로 고쳐진다. 실제 물리 드롭·줍기·재착용, 방호 소속·내구도·내용물·질량은 v63 경로를 유지한다. 기존 바라클라바 보완 메시와1인칭 머리 숨김도 유지한다.

검증은 실제 원본 표면/UV의 피부 조각이 장비에 남지 않는지, 안구404삼각형이 전부 몸에 있는지, 목 보호대 상보 분리의 면적/경계/웨이트를 확인한다. v63/v64 같은 카메라의 정면·측면·안쪽 비교와 분리18뷰, 실제 낙하 물체를 남긴다. 전체 테스트, 2D baseline, 정지600틱6발과 착용 P01 헬멧/가슴 실사격2건의 trace/의료 JSON 동일성을 검증한다. 단일HTML의1280×720 PC/844×390 터치 오프라인 착탈·줍기도 다시 확인한다. 결과는 [검증 보고](../downloads/checks-equipment-mesh-fix-v64/report.html)에 있다.

의료·탄도·관통·방호·D2·인벤토리 식과 데이터는 v63 바이트 그대로다. 기존 재출혈 목표 미달과 임상 출처의 미확인 사항은 이 시각 수정으로 바뀌지 않는다. 실제 휴대폰 하드웨어는 미검수다.
