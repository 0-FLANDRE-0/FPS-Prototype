# CQB 의료 개편 확정 규칙과 구현 순서

기존 3D 피격 계산을 기반으로 치료를 짧은 고정 시간의 아이템 사용으로 바꾼다. 상처별 지혈·의료품 자원·처치 후 부위 회복을 먼저 연결하고, 다른 아이템과 흉부 단순화는 작은 단계로 이어서 적용한다.

- 작업 저장소: `0-FLANDRE-0/FPS-Prototype`
- 작업 브랜치: `feature/medical-overhaul`
- 기준 코드: `31277925afa25a01a2781544ff2472551f29049c`의 v69 이관판
- 합의 기준일: 2026-10-25 KST
- 현재 상태: 구현 준비. 이 문서 작성으로 게임 코드나 의료 동작이 바뀐 것은 아니다.
- 값의 구분: **확정 규칙**은 사용자 결정, **착수 기본안**은 첫 구현을 위한 제안, **튜닝 미정**은 아직 정하지 않은 수치다.

최신 HP 회복 합의가 이전의 현장 회복 상한 제안을 대체한다. 일반 처치 뒤에도 결국 현재 최대 HP까지 회복할 수 있다. 일반 치료 때문에 최대 HP가 줄어들지 않는다.

## 1 확정 규칙

### 1.1 유지할 피해 기반

탄도·방호·관통 경로·신체 부위와 혈관 피격·상처 생성은 기존 3D 기반을 사용한다. 같은 부위에 여러 상처가 존재하며 각각의 지혈 상태를 관리한다. 다만 아래에서 명시한 폐 손상·기흉 계통은 제거 대상이다.

상처별 유량에서 일반 출혈·과다출혈을 파생한다. 등급은 고정된 피해 종류가 아니며, 실제 유량이 줄면 변경될 수 있다. 여러 상처의 실제 유출은 전신 혈액량에 합산한다.

같은 혈관에 여러 lesion이 연결돼도 혈관 전체 유량을 중복 계산하지 않는다. 치료는 개별 손상에 반영한 뒤 기존 혈관·장기 집계와 순환 제한에 연결한다.

### 1.2 사용시간과 효과 시점

- 아이템마다 짧은 고정 사용시간을 둔다. 모든 제품이 같은 시간을 쓰는 것은 아니다.
- 부상·통증·관류 등에 따라 사용시간을 늘리는 기존 배율은 새 치료 규칙에서 사용하지 않는다.
- 사용 완료 시 실제 소비 자원에 해당하는 지혈·약물 등의 효과를 적용한다.
- 부위 HP 회복은 사용 완료 후 시간에 따라 진행한다. 사용하는 도중 HP가 차는 방식은 채택하지 않는다.
- 사용시간, 효과 발현 지연, 회복속도, 약효 지속시간은 서로 다른 값이다.

의식상실·사망 등 사용 자체가 불가능한 상태의 실행 차단은 고정 사용시간과 별개다.

### 1.3 내구도와 부분 지혈

붕대·거즈·주입기·폼 같은 치료 소모품은 상처의 남은 치료 필요량과 물품 효율에 따라 자원을 소비한다. 잔량 부족만으로 사용을 거부하지 않는다.

부족한 자원으로 완료한 사용도 그 양만큼 지혈하며, 진행은 상처에 남는다. 다른 물품으로 이어서 치료할 수 있다. 완전히 제어한 기존 손상은 더 이상 출혈하지 않는다.

필요량보다 많은 자원이 있으면 필요한 양만 소비한다. 현재 저혈압으로 유량이 감소했다는 이유만으로 중상의 치료 비용이 급감하지 않도록, 순간 유량만을 비용의 근거로 쓰지 않는다.

### 1.4 부위 HP 회복

- 처치 후 부위 HP가 서서히 회복된다.
- 최대 HP에 가까워질수록 회복속도가 느려진다.
- 일반 치료의 별도 현장 회복 상한을 두지 않는다.
- 시간이 지나면 현재 최대 HP에 정확히 도달할 수 있어야 한다.
- 일반 치료·반복 사용이 부위 최대 HP를 줄이지 않는다.
- 최대 HP 감소는 수술 키트의 별도 규칙으로 둔다.

예를 들어 정상 최대 HP가 100인 부위는 일반 처치 후 100까지 회복할 수 있다. 나중에 수술 결과 최대 HP가 80이 됐다면 그 부위의 회복 목표는 80이다. 이 숫자는 규칙 설명용이며 실제 부위 수치나 수술 감소율이 아니다.

부위 HP 회복, 지혈, 혈액량 회복, 장기·골절·절단의 복구는 서로 다른 효과다. HP가 회복됐다는 이유만으로 다른 손상을 모두 해제하지 않는다. 혈액량이 부족하면 HP 회복 뒤에도 그에 따른 불이익은 남을 수 있다.

### 1.5 지혈대

- 팔·다리에만 사용할 수 있다.
- 각 사지에 최대 하나씩 장착한다.
- 장착 중에는 해당 사지 부위의 모든 출혈을 일시적으로 막는다.
- 상처 자체가 치료된 것으로 기록하지 않는다.
- 제거하면 아직 제어되지 않은 상처에서 출혈이 다시 발생할 수 있다.
- 장착 중에도 다른 의료품으로 상처를 치료할 수 있다.

추가 피격의 직접 HP 피해를 막는 효과는 없다. 기존의 정밀한 감는 위치 선택과 두 번째 지혈대 적용은 새 규칙에서 정리한다. 장착에 따른 통증·기능 불이익의 구체적인 정도는 튜닝 대상으로 남긴다.

### 1.6 제거할 흉부 계통

흉부 씰·감압 키트·NPA를 플레이 의료품에서 제거한다. 폐를 독립적인 기능 손상 대상으로 처리하는 계통과 기흉 진행을 제거하고, 해당 흉부 부상은 스태미나 감소 등 단순한 부위 불이익으로 연결한다.

아이템과 화면만 제거하고 기존 폐·기흉 계산이 계속 악화되게 두면 안 된다. 폐 손상에서 발생하던 호흡 저하·산소 저하·기흉 진행과 관련 진단·치료 후보 생성도 함께 확인한다.

관통 계산에 쓰이는 조직 재질·형상과 게임 의료 상태는 구분한다. 기존 내부 형상이 탄도 입력으로 필요하다면 재사용할 수 있으나, 그것으로 폐 손상·기흉 전용 상태를 다시 만들지 않는다. 실제 혈관 손상과 일반적인 흉부 혈액 손실은 보존하며 새 흉부 표현과 중복 합산하지 않는다.

이 변경이 다른 장기의 모든 치명상이나 전신 순환계를 없애는 것은 아니다.

### 1.7 TXA, 지혈 폼, OTFC

- **TXA:** 주사기 형태. 전신의 자연지혈 진행을 빠르게 하는 효과로 변경한다.
- **지혈 폼:** 기존 복부 폼을 범용 지혈품으로 변경한다. 범용 주입기보다 큰 치료 용량이나 좋은 내구도 대비 성능을 갖는다.
- **OTFC:** 유지한다. 진통제 중 가장 강력한 효과와 부작용을 가진 물품으로 조정한다.

이들의 정확한 사용시간·용량·효율·발현·지속·부작용 수치는 아직 확정하지 않았다.

## 3 첫 구현을 위한 기본안

이 절은 확정 요구를 구현할 때 필요한 작은 동작 규칙의 제안이다. 확정 수치로 취급하지 않으며 구현 대장에 채택 여부를 남긴다.

### 3.1 사용과 자원 소비

첫 구현은 붕대 한 종류와 명시적인 대상 상처 하나로 제한한다.

1. 대상·적합성·물품 소유권·잔량·자가 사용 가능 여부를 확인한다.
2. 물품과 대상 상처를 사용 행동에 예약한다.
3. 고정 사용시간 동안 행동을 진행한다.
4. 완료 시 실제 필요한 자원을 차감하고 상처 지혈 진행을 함께 갱신한다.
5. 그 뒤 해당 부위의 회복을 진행한다.

완료 전에 취소한 경우 효과와 치료 자원 소비가 모두 없는 방식을 첫 기본안으로 한다. 효과는 남기고 자원만 되돌리는 상태는 허용하지 않는다. 물품 개봉 손실 같은 추가 현실 절차는 첫 단계에 넣지 않는다.

잔량 부족으로 부분 지혈하는 경우에도 해당 물품의 고정 사용시간을 사용한다. 이는 치료 자원이 부족한 경우이며, 도중 취소로 미완료된 행동과 구분한다.

행동 도중 대상이 사라지거나 이미 완치되면 다른 상처로 몰래 바꾸지 않는다. 완료 시 필요량을 다시 확인하고, 사용하지 않은 예약분을 해제한다. 한 아이템이 이동·판매·다른 치료와 동시에 소비되지 않게 한다.

### 3.2 회복 곡선과 정확한 완료

처치 후 회복 활성 상태를 부위별로 소유한다. 표시용 타이머나 아이템 잔량 복사본으로 HP를 관리하지 않는다.

간단한 착수 기본안은 남은 HP 비율이 작아질수록 회복속도를 낮추되, 작은 양의 최소 회복속도를 두고 마지막에 현재 최대 HP로 제한하는 것이다. 이렇게 하면 끝없이 최대치에 접근만 하고 도달하지 않는 문제가 없다.

- HP가 같고 다른 조건이 같으면 같은 회복속도를 사용한다.
- 최대 HP에 가까운 상태가 더 빠르게 회복되는 역전은 없어야 한다.
- 일반 처치는 현재 최대 HP를 바꾸지 않는다.
- 동일 부위에 같은 처치를 반복해 회복속도를 무한 합산하지 않는다.
- 사용 완료 전의 시간에 회복을 소급 적용하지 않는다.
- 새 피격은 독립 상처와 직접 피해를 생성한다. 이전 처치가 신규 손상을 자동 지혈하지 않는다.

첫 구현은 처치 뒤의 회복만 다룬다. 미처치 상태의 기본 재생, 추가 피격 시 회복 중단·재개 조건, 골절·장기 손상에서의 회복 한계는 별도 정책으로 기록하며 임의의 최대 HP 감소로 대신하지 않는다.

### 3.3 지혈대와 자연지혈

지혈대는 상처의 영구 지혈 진행과 별도의 착용 상태를 가진다. 착용 때문에 유량이 0인 상태를 치료 완료로 오인하지 않는다.

착용 중에도 기존 상처의 자연지혈·직접 치료 진행은 별도로 유지하는 방식을 기본안으로 한다. 제거 시 그 시점의 남은 상처 상태로 유량을 재계산한다. 착용 중 생긴 신규 사지 상처도 착용 효과의 범위에 포함하되 직접 피해는 그대로 받는다.

자연지혈에 제한이 있는 큰 출혈은 TXA가 무조건 완전히 치료하는 것으로 만들지 않는다. TXA의 속도 가속과 직접 지혈품의 치료량은 구분한다. 약효 지속·재사용 중첩 방식은 TXA 단계에서 정한다.

새 회복 상태는 별도 작은 모듈로 분리할 수 있다. 피해 계산과 치료 규칙을 함께 큰 폭으로 리팩터링하지 않는다.

현재 공유 출혈원은 일부 유량 귀속에 원래 lesion 면적·손상 비율을 사용하고 처치 routing은 처치 후 share를 별도로 가진다. 첫 구현에서는 두 상처 중 하나만 치료한 경우의 귀속을 반드시 검증한다. 이 항목은 코드에서 확인한 검증 필요 경계이며, 아직 런타임 오류로 재현한 것으로 기록하지 않는다.

폐·기흉 제거는 아이템 파일 하나의 편집으로 끝나지 않는다. 기존 포트의 `updateChestTrauma`, 상처 생성기의 `chestTraumaModel`, S1 폐 효과, B1 혈흉 호흡 상한, 관련 HUD·진단까지 호출 경로를 따라 확인한다. 결과 필드만 매 틱 강제로 정상값으로 덮는 방식은 사용하지 않는다.

## 5 구현을 나눌 순서

| 단계 | 범위 | 완료 판정 |
| --- | --- | --- |
| 치료 1 | 붕대 한 종류: 고정 시간·자원 소비·상처별 부분 지혈·처치 후 부위 회복 | 하나의 실제 피격에서 사용부터 회복 완료까지 연결 |
| 치료 2 | 지혈대의 사지별 단일 장착·전체 일시 지혈·제거 | 다중 상처·추가 피격·제거 시 남은 출혈 검증 |
| 치료 3 | 거즈·범용 주입기·지혈 폼 | 같은 사용 계약으로 적합성·효율·용량 차이 검증 |
| 치료 4 | TXA·OTFC 등 약물 | 자연지혈 가속과 진통·부작용·혈액량 효과 분리 |
| 흉부 정리 | 씰·감압·NPA, 폐 손상·기흉 제거와 흉부 스태미나 불이익 | 숨은 악화·상태 재생성 없이 부위 피해와 연결 |
| 통합 | 초기 지급·인벤토리·표시·설정의 단일 정책 | 두 화면에서 대표 치료 흐름과 회귀 통과 |

각 단계는 같은 작업 브랜치에서 작은 커밋으로 진행한다. 전환 중인 브랜치를 의료 개편 완료판으로 배포하지 않는다. 신규 게임 모드 선택지를 추가해 병렬 제품 규칙으로 유지하지 않는다.

수술 키트·골절 키트·장기 복구 키트, 다운·기절 재설계, 상점·파밍·레이드 정산은 이번 첫 구현에 넣지 않는다. 수술 최대 HP 감소는 상태 구조가 이를 덮어쓰지 않게 준비하되 실제 수술 기능과 감소율은 후속 단계에서 구현한다.

## 6 치료 1의 필수 검증

| 검증 | 기대 결과 |
| --- | --- |
| 사용시간 | 같은 붕대는 부상·통증 조건이 달라도 같은 적용 시간 |
| 완료 전 | 지혈 효과·HP 회복이 미리 적용되지 않음 |
| 자원 충분·부족 | 필요량만 소비. 부족해도 완료 후 부분 지혈 |
| 중단·연타 | 자원과 효과가 불일치하거나 중복 적용되지 않음 |
| 같은 부위 두 상처 | 선택한 상처의 지혈만 개선 |
| 같은 혈관 두 lesion | 공유 유량 중복 없음, 상처별 최종 기여분 합 일치 |
| 반복 치료 | 영구 지혈 진행 유지, 다른 아이템으로 이어서 완료 가능 |
| 회복 시작 | 완료 이후 선택 부위에서 서서히 시작 |
| 회복 곡선 | 최대치에 가까울수록 느림, 결국 최대치에 정확히 도달 |
| 최대 HP | 일반 처치·반복 처치로 감소하지 않음 |
| 감소된 최대 HP 입력 | 그 값까지 회복하며 원래 최대치로 임의 복원하지 않음 |
| 혈액량 | 지혈·부위 HP 회복으로 혈액을 추가하지 않음 |
| 새 피격 | 독립 상처와 직접 피해 유지, 이전 지혈이 신규 상처를 치료하지 않음 |
| 상태 재계산 | 다음 의료 틱에서 회복 HP가 원본 피격값으로 덮이지 않음 |
| 결정성 | 같은 고정 틱 입력은 같은 결과. 렌더 FPS와 분리 |
| 화면 | 1280×720과 844×390에서 사용·취소·잔량·회복 확인 |

기존 무처치 피격·관통·방호 기준은 가능한 범위에서 보존한다. 의도적으로 바꾼 치료·흉부 결과는 새 계약의 검사로 교체하고, 과거 골든 값을 자동 갱신해서 차이를 숨기지 않는다.

실제 제품 변경 단계의 기본 실행은 `npm ci` → `npm run build` → `npm test` 순서다. 필요한 2D 보존·의도적 v69 차이 비교·브라우저 검사를 뒤이어 한다. 같은 dist를 쓰는 빌드와 테스트는 병렬 실행하지 않는다. GitHub Actions는 사용하지 않고 커밋 메시지에 `[skip ci]`를 넣는다.

## 7 수치와 아직 좁혀야 할 세부 정책

사용시간·자원 최대치·상처 작업량 가중치·지혈 효율·출혈 등급 임계값·회복속도·흉부 스태미나 계수·약효 지속·수술 감소율은 튜닝 미정이다. 기존 현실 모드 수치를 신규 기본값으로 자동 복사하지 않는다.

첫 구현에서 필요한 값은 하나의 정책 데이터에 모으고 `튜닝`으로 분류한다. 대표 상처에서 치료 시간·사용 자원·지혈 전후 유량·회복 완료 시간을 함께 기록해 조절한다.

수술 대상 상태, HP 0 부위와 구조 파괴의 복구 가능 범위, 추가 피격 시 회복 재개 조건, 지혈대 착용 불이익·회수 소모, TXA 반복 사용, OTFC 부작용의 항목·강도는 해당 단계에서 좁힌다. 기존 사망·치명상 판정을 일반 붕대 회복으로 해제하지 않는다.

## 8 준비 상태

- 원격 작업 브랜치와 main이 기준 코드에서 시작함을 확인했다.
- 아이템·사용·인벤토리·출혈·약물·HP 초기화·흉부 호출 경계를 소스로 조사했다.
- 이번 변경은 이 계약과 인계·색인 연결 문서뿐이다.
- 새 제품 코드·의료 수치·테스트 결과는 아직 없다.
- 첫 진입점은 치료 1이다. 전혈·약물·흉부·다운 판정을 동시에 변경하지 않는다.
