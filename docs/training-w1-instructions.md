RG1 빌드(v68) 위에서 작업한다. 3D는 2D와 분리된 상태다. 2D 원본은 바꾸지 않는다. 바꾼 항목은 대장에 출처/원본/튜닝/사용자 설계값/게임 허용과 `2D 역이식 후보`를 표시한다.

### 할 일
- 위 구간을 실제 키 데이터로 다시 확인한다. 정확한 자를 지점(자세가 대기와 같아지는 프레임)을 찾아 클립으로 나눈다. 구간이 다르면 보고한다.
- **팔:** AK 때처럼 원본 팔 메시·텍스처는 버리고, 공용 팔(JUST, 113관절)에 손바닥·손가락 동작만 옮긴다(해부학 손 좌표계 리타깃, AK 방식).
  - 이 모델의 85관절 뼈대가 AK 원본(Cransh, FP-ARMS)과 같은 계열인지 확인한다. 같으면 AK 변환기를 재사용하고, 다르면 차이를 보고한다.
- **기존 방식 유지:** 몸통 고정 어깨 + 2관절 팔 IK, 원본 사격 반동·카메라 움직임 제외(게임 조준·반동이 우선), 키 축소 허용 오차(0.01 mm, 1e-5, 1e-4 rad), 클립 끝점 보존.
- **사격:** 연발 600발/분이면 발 사이 0.1 s다. 장전손잡이 왕복이 발사 간격 안에 끝나게 맞춘다(M4·AK 방식). 마지막 발 뒤 탄창이 비면 노리쇠가 뒤에 걸린 상태로 남고, 빈 탄창 재장전 끝에 풀린다.
- **재장전 시간:** 나눈 클립 길이를 그대로 쓴다(사용자 설계값). 대략 전술 2.7 s, 빈 탄창 3.7 s다. 실제 값을 보고한다. 2D 값(2.4 / 3.0 s)은 대장에 원본으로만 적는다.

### 탄창
- 로우폴리에는 탄창 메시가 2개 있다.

  - `76251 ar10 20rnd (scar)_11`: 옆에 눕혀둔 전시용, 탄 보임
- 총에 꽂힌 탄창은 남은 탄에 따라 보여준다. 1발 이상이면 탄 있는 메시를 꽂힌 위치로 옮겨 쓰고, 0발이면 빈 메시를 쓴다. 전술 재장전 때 빼는 탄창에 탄이 보이게 하는 것이다.

### 지우는 것

## 4. 절차적 재질 (질감)

로우폴리는 텍스처가 없고 색만 칠한 재질 9개다. UV가 부품 안에서 심하게 겹쳐 있다(검수 측정: 몸통 일부 70–100% 겹침). 그래서 그림 텍스처를 붙이지 않는다.

- **원래 색·금속성·거칠기 값은 유지한다.** 그 위에 아래를 더한다. 전부 튜닝이다.
  - **표면 얼룩:** 총 좌표계 기준 삼면 투영 노이즈로 거칠기·색을 미세하게 바꾼다. 총이 움직여도 무늬가 따라간다.
  - **미세 요철:** 같은 노이즈로 노멀을 살짝 흔든다. 폴리머는 결이 보이게, 금속은 더 매끈하게.
  - **모서리 닳음:** 빌드 때 볼록한 모서리 정도(곡률)를 정점에 구워 둔다. 날카로운 모서리를 밝고 덜 거칠게 한다.
    - 재질별로 다르게 한다. 윗총몸은 알루미늄에 FDE 경질 양극산화라 닳으면 은색 금속이 살짝 드러난다. 폴리머 부품은 금속이 안 드러나고 밝게 긁힌 정도만. 검정 강철은 거의 안 바뀐다. 재질 사실관계는 출처로 확인한다.
  - **오목한 곳:** 빌드 때 차폐(AO)를 정점에 구워 둔다. 홈·틈을 어둡게 하고 먼지 느낌을 아주 약하게 준다.
- 효과 세기는 설정 하나로 조절할 수 있게 하고, 0이면 원래 모습과 같아야 한다.
- 기존 조명·후처리·조준경 렌더(배율 화면 안)에서도 정상이어야 한다.
- **비용:** 모바일(844×390)에서 셰이더 비용을 잰다. 효과 켬/끔 프레임 시간을 비교한다.

## 5. 무기 데이터

2D `WEAPON_REGISTRY.scar_h`를 원본으로 쓴다. 바꾸는 것만 적는다.

| 항목 | 2D 원본 | 3D | 표시 |
|---|---|---|---|
| 발사 모드 | 단발/점사/연발 | 단발/연발 | 사용자 설계값(실제 SCAR-H 선택 사격 방식 출처 확인), 2D 역이식 후보 |
| 발사 속도 | 600발/분 | FN 공식 출처 확인. 다르면 출처값 | 출처 / 원본 |
| 무게 | 3.70 kg | FN 공식 STD 무게(탄창 제외) 확인. 다르면 출처값 | 출처 / 원본 |
| 탄창 | 20발 | 20발. 빈 탄창 질량은 출처, 탄 질량은 탄약 데이터 | 원본 / 출처 |
| 재장전 | 3.0 / 2.4 s | 애니 클립 길이 | 사용자 설계값 |
| 총열 길이 | 없음 | STD 총열 길이 FN 공식 출처(16인치로 알려짐, 확인) | 출처 |

- 다른 값(반동 기본값, 산포, 조작성 등)은 2D 값을 그대로 기존 3D 변환 규칙에 넣는다.
- **반동 점검:** 같은 거리·자세에서 M4와 SCAR-H의 첫 발 반동·연발 산포를 비교한다. 물리 확인으로 탄 운동량(탄두 질량×속도 + 장약 기체 몫) 비율도 같이 낸다. 수치를 바꾸지는 말고 보고만 한다.
- **인벤토리:** 탄창 크기 1×2. 무기 질량은 M6 총 질량과 D2로 이어진다.
- **얻는 방법:** 투입 패널 무기 선택에 SCAR-H를 추가한다. 리그·벨트 탄창 배치는 고른 무기 탄창으로 채운다. 기존 탄약 상자에 7.62×51 탄창·탄을 추가한다. 적 무기에는 넣지 않는다.

## 6. 탄속과 탄도

- **기준 탄속:** 각 탄의 공식 규격 탄속과 그 측정 조건(시험 총열 길이, 측정 거리)을 출처로 찾는다. 예: 미 육군 소화기 탄약 자료(TM 43-0001-27 등), 군 규격.
  - 2D 탄속(.308 850, M80 833, M80A1 850, M61 855, M993 910, M62 830, M948 1210 m/s)은 원본으로 대장에 남긴다.
- **총열 보정:** 측정 총열 길이 → SCAR-H STD 총열 길이로 보정한다.
  - 우선순위: 실측 총열 길이별 탄속 자료(같은 탄 또는 7.62×51/.308 동급) → 내탄도 근사.
  - 탄마다 자료가 없으면 같은 비율을 적용하고 튜닝으로 표시한다.
  - M948 SLAP은 사보탄이라 따로 본다. 자료가 없으면 보고하고 같은 비율 + 튜닝.
- **비행:** 탄도계수는 공개 출처(예: G7 BC)를 우선 쓴다. 없으면 2D 항력 분류(`rifle_heavy`, `ap_streamlined`)를 그대로 쓴다. 기존 RK4·중력 식은 바꾸지 않는다.
- **영점**
  - 접이식 가늠자는 FN 매뉴얼의 영점 권고를 찾는다. 없으면 보고하고 M4 가늠자 규칙(300 m)을 임시로 쓴다.
  - 광학은 기존 광학별 영점 규칙을 SCAR-H 탄도로 다시 푼다.
  - ACOG 레티클은 5.56용이라 7.62에서는 낙차가 안 맞는다. 현실 그대로 두고 어긋남을 표로 보고한다.

## 7. 조준경 장착

- 광학 3종(Vudu, XPS3, ACOG)의 `weaponIds`에 SCAR-H를 추가한다.
- 레일 위 장착 위치는 실제 SCAR-H 윗레일 위에 놓는다. 눈 거리 값은 기존과 같다.
- 광학을 달면 접이식 가늠자는 접힌 상태로 표시한다(실제 운용, 출처 확인). 자세 변경이 불가능하면 보고한다.
- 조준 때 광축과 눈 정렬을 캡처로 확인한다.

## 8. 7.62×51 정밀화 (S3 확장)

5.56/5.45 방식을 7.62×51에 그대로 적용한다. **체력 환산 계수 C = 0.09174725695886135는 바꾸지 않는다.**

- **기준 곡선:** S1에 이미 있는 `m80` 젤라틴 기준 곡선을 같은 구경 기준으로 쓴다. 출처 그림, 현재 값(16 cm까지 똑바로, 50 cm 근처 90°, 67 cm 뒤집힘)을 대장에 다시 적는다.
- **종류는 2D `AMMO_TERMINAL_EFFECT`를 그대로 쓴다.**

  | 탄 | 2D 종류 | 문턱 탄속 |
  |---|---|---|
  | .308 FMJ, M80, M62 예광 | `full_power` | 600 / 600 / 620 |
  | M80A1 | `controlled_fragment` | 620 |
  | M61, M993 | `penetrator` | 600 |
  | M948 SLAP | `sabot_penetrator` | 900 |

- **새 종류 기본값 (지금 3D에 없음)**
  - `full_power`: 같은 구경 기준(M80) 눕기 곡선, 파편 없음, 확장·항력·공동 배율 1. 2D 위·아래 문턱 배율은 S3 물리 HP 계산에 쓰지 않는다(5.56 `yaw` 규칙과 같음).
  - `sabot_penetrator`: 관통자 지름·길이·질량을 출처로 찾는다. 상처 통로는 관통자 기준으로 좁고 깊게, 파편 없음. 눕기 곡선은 자료가 없으면 튜닝으로 표시한다.
- **기존 종류의 7.62 적용**
  - `controlled_fragment`(M80A1): 지금 기본값은 5.56 기준(M193 기준, 시작 깊이 0.12 m)이다. M80A1 젤라틴·상처 자료를 찾는다(미 육군 EPR 발표, 공개 젤 시험 등). 없으면 7.62 길이 비율로 환산한 튜닝으로 표시하고 근거를 적는다.
  - `penetrator`(M61, M993): 기존 기본값을 7.62 길이 비율로 쓴다. 강심·텅스텐 관통자 자료가 있으면 같이 적는다.
- **길이 비율:** 7.62×51 구경 × 종류 평균 길이 비율. 5.56/5.45 방식 그대로.
- **M62 예광:** 예광제 연소로 무게중심이 옮겨지는 영향 자료가 있으면 보고만 하고, 이번엔 `full_power` 그대로 둔다.
- **방호:** 2D 관통·재질 상성·내구도 값은 그대로 쓴다. 바꾸지 않는다.
- **보조 계산표(S2 조회표):** 7.62×51 7종이 새 종류 곡선으로 다시 만들어지는지 확인한다. 조회표 크기 변화를 보고한다.

## 9. 총소리
