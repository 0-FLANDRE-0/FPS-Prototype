## 2. 3D 의료 독립

`medical-v2`와 후속 모듈은 3D 전용이다. 출처와 근거를 기록하면 의료 수식을 바꿀 수 있다. 원본 2D의 선언과 함수는 재사용 가능한 legacy 기반이며 3D 변경을 막는 기준은 아니다.

## 3. 2D 보존과 legacy

3D 작업에서 원본 `src/**`를 수정하지 않고 2D baseline 바이트 비교를 계속 실행한다. legacy 선택은 유지한다. S0의 의료 보완은 legacy 모드에 설치하지 않는다. 탄도·관통·방호와 애니메이션·래그돌 물리는 이번 범위에서 보존한다.

## 4. 변경과 역이식

항목마다 출처 / 원본 / 튜닝을 나누고 `2D 역이식 후보: 예/아니오`를 기록한다. 실제 역이식은 사용자의 별도 지시가 있어야 한다. 자료의 위치를 확인하지 못한 수치는 설계 기대로 표시한다. 결과가 기대에 못 미치거나 기존 모델의 문제가 남으면 그대로 공개한다.

[S0 원문](training-s0-instructions.md), [S0 대장](medical-s0-ledger.json), [누적 의료 대장](medical-v2-ledger.md)을 함께 따른다.

S1/v39에서는 상처 통로·공동·부위별 피해 배율과 장기 손상 심각도를 독립3D 의료에 연결한다. 원래 탄 데미지·부위HP와 실제 탄 비행·방호·인체 출구/정지 계산은 유지한다. 각 부위는 자기 통과 구간과 기존 인체 저항이 넘겨준 진입 속도를 사용하며, 앞 부위의 손상량을 합쳐 배율을 재사용하지 않는다. 상세 계약·출처·튜닝은 `docs/medical-s1-ledger.json`을 따른다.
