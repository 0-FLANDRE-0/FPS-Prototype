# CQB Training 지시서 W — AK-74M·1인칭 팔

Oct 11, 2026 · @다고쿠

## 개요와 원칙

AK-74M을 두 번째 무기로 넣고, 사용자가 제공한 FPS 애니메이션 팩의 1인칭 팔을 AK와 기존 M4 모두에 쓴다. AK는 애니메이션 팩에 들어 있는 순정 AK-74M 메시를 쓴다. 젠잇코 모델은 이번에 쓰지 않는다. 의료·방호·인체 판정은 건드리지 않는다.

**책임 분담 (가장 중요).**

| 누가 정하나 | 항목 |
| --- | --- |
| 기존 시스템 (변경 없음) | 조준 방향, 탄도 출발점·방향, ADS 진행도, 반동, 흔들림, 발걸음 충격, 카메라·렌즈, 탄약·장전 상태와 시간 |
| 애니메이션 팩 | 팔·손·손가락 동작, 탄창·방아쇠·조정간 뼈의 움직임, 재장전 중 총의 기울임 같은 보이는 동작 |

팔을 붙여도 M4의 탄이 나가는 방향과 화면은 지금과 바이트 단위로 같아야 한다. 애니메이션 클립이 총을 움직여도 탄의 방향은 바뀌지 않는다.

**기타 원칙.** 원본 `src/**`·원본 HTML·원본 모델 파일은 무수정이다. 파생 GLB는 별도 파일로 만든다. 새 수치는 출처 / 원본(2D) / 튜닝값으로 구분한다. 현실성이 편의보다 우선이다. 표현이 갈리면 실제 총기의 동작을 따른다.

## W0 사전 조사 (코드 변경 없이 먼저 보고)

`docs/training-w0-survey.md`에 기록한다. 검수 쪽에서 확인한 사실은 아래와 같고, 실제로 다르면 실제를 따른다.

**애니메이션 팩** (`fps_ak-74m_animations.glb`, Cransh, CC BY 4.0, Sketchfab)

- 메시 3개(팔, AK 본체, 예비 탄창), 삼각형 약 40k, 스킨 1개, 1024 PNG 텍스처 7장(약 6.8 MB). `KHR_materials_specular` 사용.
- 뼈: 양팔(어깨·상완·전완·비틀림 3개·손·손가락), IK 컨트롤·폴 타깃, `Head_Cam`, 총 뼈 `Rif`(본체), `Trigger`, `Safety`(조정간), `Pmag`(타창), `Pmag2`(새 타창), `PBody`.
- 클립 8개: Idle 1.98초, Draw 0.65, Walk 0.98, Run 0.40, Shot 0.31, Reload 2.65, Reload\_var2 2.82, Reload\_full 3.50.
- **없는 것:** ADS 클립, 노리쇠(볼트 캐리어)·장전 손잡이 뼈. AK 본체는 한 메시다.

**2D 원본** (생성된 무기 레지스트리)

- `ak74`(AK-74)가 있다. 5.45×39 탄종 13개(`545_ps_gs`, `545_pp_gs`, `545_bp_gs`, `545_bs_gs`, `545_7n40` 등), 30발, 650발/분, 발사 모드 semi/burst/full, 재장전 2.7/2.1초, 3.3 kg.

**조사해서 보고할 것**

1. 현재 M4 뷰모델 파이프라인: 총 변환을 계산하는 곳, ADS 가늠자 정렬 방식(마커), 탄도 출발점·방향의 출처(AimState인지 모델인지), 반동·흔들림·발걸음 충격이 들어가는 지점, 벽에 총이 닿을 때의 처리, 렌즈 패스 적용 여부.
2. 재장전·탄약: 2D 인벤토리의 전술/빈 탄창 재장전 판단, 시간, 탄창이 빠지고 들어가는 시점의 이벤트.
3. 무기 교체: 현재 빌드에 무기 슬롯·교체 입력이 있는지.
4. 팩의 단위·축·최소 스케일: AK 메시의 전체 길이를 실제 AK-74M 치수와 비교한다. 클립 프레임레이트, `Head_Cam` 클립 움직임의 크기.
5. 2D `ak74`와 실제 AK-74M의 차이(W2).

## W1 팔 리그·뷰모델 레이어

팔과 총을 한 뷰모델로 묶고, 그 루트 변환은 지금 M4 루트에 적용하는 변환(조준·반동·흔들림·걸음)을 그대로 받는다.

- **W1-a 파생 GLB.** 팩에서 팔 메시·스킨·뼈, AK 본체·예비 탄창, 클립 8개만 남긴 파생 GLB를 만든다. 카메라 노드 등 표시용 노드는 뺀다. 단위는 m, 축은 게임 좌표계로 맞춘다. 텍스처는 P1·R5 규칙(WebP, 노멀은 무손실, ORM은 렌더 화면 비교 SSIM ≥ 0.97)을 따른다. 해상도는 줄이지 않는다. 원본 GLB는 덮어쓰지 않는다.
- **W1-b 스케일.** AK 메시의 전체 길이를 실제 AK-74M 치수(개면식 개스톡, 출처 표시)와 맞춘다. 팔은 같은 배율로 따라간다. 배율과 근거를 기록한다.
- **W1-c 카메라.** 클립의 `Head_Cam` 움직임은 카메라에 적용하지 않는다. 카메라는 기존 바디캠 시스템이 맡는다. 뷰모델은 `Head_Cam`을 기준점으로 카메라에 붙이되, 그 뼈의 클립 움직임을 상쇄해서 화면이 이중으로 흔들리지 않게 한다.
- **W1-d 렌즈·근접 클리핑.** 뷰모델은 지금 M4와 같은 렌더 경로(바디캠 렌즈 패스 포함)를 탄다. 카메라 근평면에 팔이 잘리지 않게 하고, 벽에 닿을 때는 W0에서 확인한 현재 M4 처리 방식을 그대로 쓴다.
- **W1-e 팔 외관.** 팔 메시의 재질·색은 원본 그대로 둔다(복장 변경은 범위 밖).

## W2 AK-74M 무기 데이터·가늠자

2D `ak74`를 기반으로 새 무기 `ak74m`을 만들고, 실제 AK-74M과 다른 부분만 출처를 달아 바꾼다. 2D 원본 `ak74` 자체는 바꾸지 않는다.

- **W2-a 탄약.** 2D `ak74`의 허용 탄종 13개와 각 탄의 탄도·관통·의료 값을 그대로 쓴다. 기본 탄은 `545_ps_gs`(7N6 계열)다. 방호·인체 경로는 M4와 같은 3D 파이프라인을 탄다. 탄약상자에 5.45 탄과 AK 탄창을 추가한다(2D 인벤토리 형식).
- **W2-b 발사 모드.** 실제 AK-74M 조정간은 안전 → 연발 → 단발 순서이고 점사가 없는 것으로 알려져 있다. 제조사(Kalashnikov Group) 자료나 교범을 우선 출처로 확인하고, 못 찾으면 2차 출처임을 표시한다. 확인되면 burst를 빼고 조정간 순서를 그대로 따른다. `Safety` 뼈는 이 세 위치로 돌아간다.
- **W2-c 제원.** 발사속도, 무게, 전체 길이는 위와 같은 출처 순서로 확인해 2D 값과 다르면 바꾼다. 반동·확산 같은 핸들링 값은 2D `ak74` 그대로 두고 튜닝하지 않는다.
- **W2-d 마커.** AK 메시에 가늠자 홈, 가늠쇠 끝, 총구, 배출구 위치를 저작한다. M4의 기존 마커 방식과 같은 형식을 쓴다. 탄도 출발점은 M4와 같은 규칙을 따른다.
- **W2-e 영점.** 가늠자 기본 설정과 영점 거리는 현재 M4에 적용된 규칙과 동일한 방식으로 넣는다. AK 가늠자의 기본 설정(“П”)과 그 거리는 교범 출처를 찾아서 쓰고, 못 찾으면 M4와 같은 영점을 튜닝값으로 둔다. 가늠자 조절 UI는 이번에 만들지 않는다.

## W3 애니메이션 연결

클립은 기존 상태에 맞춰 재생만 한다. 상태와 시간은 기존 시스템이 정한다.

| 상태 | 클립 | 규칙 |
| --- | --- | --- |
| 정지 | Idle | 반복 |
| 걷기 / 달리기 | Walk / Run | 이동 속도로 블렌드. 재생 위상을 기존 발걸음 충격의 gaitPhase에 맞춘다 |
| 무기 꺼내기 | Draw | 무기 전환 끝에 1회 |
| 사격 | Shot의 손가락·`Trigger`만 | 총의 반동 움직임은 기존 반동 시스템이 맡는다. Shot 클립의 `Rif` 움직임은 쓰지 않는다 |
| 재장전 (탄 남음) | Reload 또는 Reload\_var2 | 둘 중 하나를 골라 이유를 기록하거나 번갈아 재생 |
| 재장전 (빈 탄창) | Reload\_full | 장전 손잡이를 당기는 동작 포함 |
| 조준(ADS) | 없음 → 절차적 | W3-b |

- **W3-a 재장전 시간.** 재장전 시간은 2D 값이 기준이다. 클립을 그 시간에 맞게 늘이거나 줄이되, 차이가 ±15%를 넘으면 바꾸지 말고 보고한다. 탄창이 빠지는 순간과 새 탄창이 들어가는 순간을 클립에서 찾아 이벤트로 만들고, 인벤토리의 탄수 갱신은 새 탄창이 들어간 이벤트에 맞춘다. 빼낸 탄창의 남은 탄은 기존 탄약 보존 규칙을 따른다. 탄창을 바닥에 떨어뜨리는 물리는 만들지 않는다.
- **W3-b ADS.** 뷰모델 루트를 가늠자 홈과 가늠쇠 끝을 잇는 선이 카메라 중심을 지나도록 옮긴다. ADS 진행도는 기존 AimState가 정하고, 팔은 총과 같이 움직인다. ADS 중에도 Idle·Walk의 팔 동작은 작게 남길 수 있지만, 가늠자 정렬을 흔들면 안 된다(흔들림은 기존 시스템만).
- **W3-c 조정간.** 발사 모드를 바꿀 때 `Safety` 뼈를 해당 위치로 짧게 옮긴다. 손가락 동작 클립은 없으므로 조정간만 움직인다.
- **W3-d 노리쇠.** 뼈가 없으므로 이번에는 움직이지 않는다. 탄피 배출은 배출구 마커에서 M4와 같은 방식으로 한다(AK는 오른쪽 배출).

## W4 M4에 같은 팔

M4도 같은 팔로 든다. 손 위치는 M4 마커에 맞추고, AK와 다른 조작은 억지로 AK 동작을 흉내내지 않는다.

- **W4-a 손 기준점.** M4에 권총손잡이(오른손)·핸드가드(왼손)·탄창우물·볼트 캐치 마커를 저작한다. AK의 대응 위치(클립에서 손이 잡는 곳)도 마커로 두고, 두 마커의 차이만큼 손 목표를 옮긴 뒤 팔을 2관절 IK로 맞춘다. 손가락 모양은 클립 그대로다.
- **W4-b 대기·걷기·달리기·사격·ADS.** AK와 같은 클립을 쓰되 총 메시는 M4다. M4의 화면 위치·ADS 정렬·탄도는 지금과 바이트 단위로 같아야 한다. 팔이 M4를 따라가고, M4가 팔을 따라가지 않는다.
- **W4-c 재장전.** 탄 남은 재장전은 AK Reload 클립을 쓰고, 왼손 경로를 AK 탄창 위치에서 M4 탄창우물 위치로 옮긴다. `Pmag`·`Pmag2`가 M4 탄창을 움직인다. AK의 탄창 앞쪽을 걸고 돌리는 동작은 M4에서는 직선 삽입이므로, 탄창 회전 성분은 M4에서 뺀다.
- **W4-d 빈 탄창 재장전.** Reload\_full의 장전 손잡이(오른쪽 측면) 동작은 M4에 맞지 않는다. M4는 탄 남은 재장전 클립 + 끝에 왼손으로 볼트 캐치를 누르는 짧은 IK 동작을 붙인다. 자연스럽지 않은 구간은 숨기지 말고 화면과 함께 보고한다.
- **W4-e 기존 M4 테스트.** 팔을 끄는 설정을 두지 않는다. 대신 기존 600틱/6발·fixture 회귀는 팔이 있는 상태에서도 동일해야 한다(검증 절).

## W5 무기 전환·용량·라이선스

- **W5-a 무기 전환.** W0에서 확인한 기존 무기 슬롯이 있으면 그걸 쓴다. 없으면 주무기 2슬롯(M4, AK-74M)과 전환 입력을 추가한다. PC는 1/2 키와 마우스 휠, 터치는 무기 버튼 1개다. 버튼 위치는 v14 HUD 규칙(터치 영역 44px 이상, 이동 중 동시 입력 가능)을 따른다. 전환 시간은 넣기(내리기)+Draw이며, 전환 중에는 사격·ADS가 안 된다. 재장전 중 전환하면 재장전은 취소되고 탄약은 기존 재장전 취소 규칙을 따른다. 훈련 시작 무기는 지금처럼 M4다.
- **W5-b 용량.** 팩 원본은 15.1 MB다. W1-a의 파생 GLB와 WebP 변환 후 HTML이 얼마나 늘었는지 항목별로 기록한다. 하나의 HTML 구조는 유지한다. 부팅 시간(P1과 같은 방식 3회)과 평균 프레임 시간을 전후 비교한다.
- **W5-c 라이선스.** 팩은 CC BY 4.0이다. 기존 modelCredits와 같은 형식으로 제작자(Cransh)·출처 링크·라이선스·바꾼 내용(노드 제거, 텍스처 WebP, 마커 추가)을 빌드 정보와 게임 내 크레딧에 넣는다.

## 검증

팔은 보이는 것만 바꾼다는 것을 먼저 증명하고, 그다음 AK를 검증한다.

**회귀 (바뀌면 안 됨)**

1. 공식 `npm test` 전체 통과, 원본 baseline 바이트 동일, legacy P2/P3/Q 행 완전 일치.
2. **M4 + 팔** 상태에서 600틱/6발의 총구·방향·카메라·걸음·반동이 v19와 바이트 단위 동일.
3. 기존 14개 M4 fixture의 탄도·방호·인체·몸속 교차·의료 기록이 v19와 동일.

**AK-74M**

4. 5.45 탄종 13개 × 재질 3 × 방호값 4의 원본 VM 잔여·내구도 대조(v10의 M4 144건과 같은 방식).
5. AK production 사격 fixture 4개 이상: 맨살 팔뚝, Br4 판 정면, 소프트 관통 몸통, 대퇴 동맥. 같은 seed 2회 일치. 탄도·방호·몸속 교차·의료 전환을 기록한다(값 튜닝 없음).
6. 발사 모드·조정간 순서가 W2-b 출처와 같다. 재장전 전후 탄수·탄창이 2D 인벤토리 규칙과 같다(전술/빈 탄창/전환 중 취소).

**화면·팔**

7. ADS 정착 시 가늠자 홈과 가늠쇠 끝의 화면 투영이 1280×720에서 중심 ±1 px 안(렌즈 0). 렌즈 70에서는 lensProject 기준으로 같은 검사. 두 무기 모두.
8. 손 뼈와 손잡이 마커의 거리가 대기·걷기·ADS에서 1 cm 이하(두 무기). 팔 삼각형이 카메라 근평면에 잘리지 않는다.
9. 화면 묶음: 무기별 비조준 대기, 걷기, 달리기, ADS(렌즈 0/70), 재장전 탄창 빠진 프레임·들어간 프레임, 꺼내기, 조정간 3위치. 실제 AimState·렌즈 값을 JSON에 남기고 같은 무기 안 서로 다른 상태의 화면이 픽셀 해시로 다른지 검사한다(Q6 방식). M4 빈 탄창 재장전(W4-d)은 연속 프레임을 따로 남긴다.
10. 무기 전환: PC 1/2·휠, 터치 버튼, 이동 중 동시 입력, 재장전 중 취소. 오프라인 844×390 / 1280×720, 오류 0·외부 요청 0.
11. HTML 용량·부팅 시간·프레임 시간 전후 비교. S24 실기기 미검증 명시.
