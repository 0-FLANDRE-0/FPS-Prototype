## 조작과 독립 상태

메뉴의 **전투 구역 · Sector 04**로 이동하면 대기 통로에서 시작한다. 왼쪽 벽 패널 근처에 중앙보다 조금 오른쪽인 기존 상호작용 버튼으로 **적 투입 [F]**가 표시된다. 적은 1명이며 스폰 공간→옆 개구부→방 안 경로로 걸어온다. 살아 있으면 재투입할 수 없다. 쓰러지면 **정리 [F]**로 바뀌고 시신·낙하 AK·그 배우의 판정과 내구도 상태를 제거한다.

전투 방은6×8m 튜닝이며 기존 사로와 떨어진 x71–77 구역이다. 뒤쪽 스폰 공간은 관통 불가 콘크리트와 꺾인 차폐 벽 두 겹으로 가리고, 개구부의 플레이어 전용 이동 센서가 진입을 막는다. 출입구에는 문짝이 없다. 전면 벽은 석고25mm·합판18mm이며 콘크리트 엄폐물이 있다. 벽 메시와 Rapier 충돌 판정은 같은 치수다.

H01은 A자 고정 표적으로 유지한다. E01…과 P01은 같은 모델/21부위/내부 해부/기본 방호의 별도 인스턴스이며 각자 `TrainingMedical(v2)`와 `ArmorCondition`을 가진다. 부위·방호 센서는 기존 총알 경로에 등록하고 자기 사격에서 자기 센서만 제외한다. 전투 센서는 광선 판정만 사용하므로 물리 접촉 이벤트 생성은 끈다(질의 판정은 유지). 출입구 이동 필터는 캐시된 센서 종류를 읽어 Rapier 콜백 안에서 Rust 객체를 다시 빌리지 않는다. 기존 방호 저지/체내 저항/도탄 수식을 재작성하지 않았다. H01의 legacy 의료 설정은 유지하고 전투 적/플레이어는 의료 v2를 사용한다.

메뉴 의료 패널의 대상 선택에서 **나의 의료(P01)** 또는 적을 볼 수 있다. 적 근처에서도 기존 F/터치 의료 상호작용을 사용한다. 피격 시 방향 표시와 짧은 화면 충격, 의료 의식 소실·다리 기능 상실·심정지·사망 시 원인과 재시작 화면을 보여준다. 의료 보기에서 원인을 확인한 뒤 계속/재시작하면 Sector01 바깥으로 초기화한다. 메뉴·인벤토리 동안 전투 시계·적/플레이어 의료·래그돌 물리가 정지한다. 기존 인벤토리 장전/탄약 작업 타이머는 계속 동작하며 H01 사로 동작은 유지한다. 플레이어가 쓰러진 동안에도 메뉴에서 현재 의료 기록을 볼 수 있다.

## AI 모듈 인터페이스

- `combat-senses.js`: 실제 적 눈→플레이어 대리 몸 머리/가슴/골반 시야 광선. 환경 벽에 가려지면 미탐지. 몸 정면120°는 튜닝. 출력은 visible/rays/target.
- `combat-decision.js`: 감각 결과·시간·탄수·의료 기능 입력으로 move/aim/fire/reloaded/target/state 의도를 출력한다. 반응0.25–0.45초, 추가 조준 획득0.4초, 단발0.25–0.5초, 탄창30발/장전/마지막 위치 주시를 처리한다. 시야를 잃은 뒤 마지막 지점을 겨누되 사격하지 않는다.
- `combat-actions.js`/`combat-weapon.js`: 경로 이동, 분산 조준, 기존 AK 메시만 손에 장착, 반동, 실제 `traceShot()` 사격. 7N6/AK П 영점은 v31 그대로이며 공기·벽·몸·방호 경로가 플레이어/H01과 같다. 사격음은 거리 감쇠, 탄피는 배우 속도+배출 속도를 사용한다.

후속 원본 2D 판단 이식은 두 번째 모듈의 입력/출력 계약을 유지하며 교체한다. 경로 찾기·엄폐 선택·적 린·여러 명 협동·쓰러진 채 사격·수류탄은 구현하지 않았다.

## 질량과 수동 래그돌

사용자가 지정한 **기본 체중80kg**은 튜닝이다. 원본 레지스트리의 6B45본체5.3kg + 앞/뒤 Granit Br4 각각2.7kg +6B47 1.15kg +목0.45kg +낭심0.55kg +어깨 한 쌍0.85kg = 보호 장비13.7kg이다. 래그돌은 **93.7kg**, 총을 들고 있을 때 AK3.6kg까지 **97.3kg**이며 AK는 독립 강체로 떨어진다. 목의 전후 메시·양 어깨 메시를 각각 중복 장비로 세지 않는다. 장식 파우치/무릎 보호대에 원본 장비 아이템이 없어 무게를 지어내지 않았다. 탄약·인벤토리 전체 무게는 후속이며, 이 물리 질량이 기존 의료 혈량 수식을 바꾸지는 않는다.

Winter2009 Table4.1 p86의 Dempster 계열 분절 비율을 쓴다. 흉부0.216/복부0.139/골반0.142/머리+목0.081, 각 상완0.028/전완0.016/손0.006/대퇴0.100/하퇴0.0465/발0.0145로 합1. 머리+목은 합을 유지하고 실제 캡슐 부피로 두 강체에 나눈다. 표의 흉부PC·복부/골반LC 원본 방법 표기를 유지하며 모든 값이 직접 측정된 동일한 표본이라는 주장을 하지 않는다.

주요17강체/16관절을 두고 AAOS/Norkin&White 공개 재인용표의 팔꿈치0–150°·무릎0–135° 등 범위를 제한한다. 원서가 아니라 공개 참조표를 확인했다. 몸통은 DSHS13-585A 등 굽힘90°/폄25°/측방25°를 두 관절에 절반씩 나눈 공간 튜닝이다. 해당 자료에 없는 몸통 축회전은 1단계에서 현재 자세에 잠그며 ‘해부학0°’로 표기하지 않는다. 단순 리그의 다축 중립 자세 변환은 완전한 근골격 모델이 아니다.

전환 직전 두 실제 틱의 각 뼈 위치/회전으로 선·각속도를 계산하고, 뼈 원점 속도를 `v_COM = v_bone + ω×r`로 운반한다. 정지로 재시작하거나 초기 자세를 A자로 바꾸지 않는다. 낙하 AK도 오른손의 선·각속도를 이어받는다. 이후 탄의 운동량 충격은 초기 인계 기록 뒤 적용한다.

손·발·하퇴 캡슐에 마찰1.1, 반발0, CCD, 추가 솔버32회, 선 감쇠2/각 감쇠4를 사용한다(튜닝). 주변 바닥과 마찰로 걸리며 관절 겹침을 줄이기 위해 자기 래그돌끼리의 접촉은 끈다. `PassiveJoint.setPD(axis,targetRad,{kp,kd,maxForce,strength})`를 관절마다 남기고 1단계 모든 값0, 근력0이다. Rapier0.21 rawSet의 실제 한계/모터 최대힘을 설정하고 스냅샷에 읽어 확인한다. 후속 근력 단계는 이 인터페이스로 목표 자세와 힘을 추가한다.

## 플레이어 대리 몸

같은24본 모델을 만들되 모든 병사 메시를 숨김 레이어4로 분리해 메인/렌즈 카메라에서 그리지 않는다. 기존 공통 FPS 팔/손가락/장전 동작은 그대로다. 발 위치/시점 방향/서기·aim·crouch의 고정 프레임을 사용하고 허리/가슴/목에 상하 조준을 나눈다. 기존 린의 골반 회전을 적용하고 루트 위치를 보정해 눈을 실제 카메라 위치에 맞춘다. 다리는 기존 발목 바닥 기준점으로 IK를 한다. 원본 병사 눈 높이와 기존 플레이어 시점1.43m가 다르므로 숨김 대리 몸의 서기에도 무릎 굽힘이 생긴다. 몸통 비율을 축소하거나 기존 카메라 높이를 바꾸지는 않았다. 손 목표는 실제 렌더된 FPS 손목이며 손 위치를 잘라 맞추지 않는다. 도달 길이가 모자랄 때만 최소 근위부 보정이 있다. 손가락 형상/관절은 대리 몸에 없어서 손목 허용오차와 손가락별 판정 정합을 구분한다.

기존 부위·골격·내부·방호 표시 체크박스는 P01에도 적용되며 기본 꺼짐이다. 이 디버그 형상은 별도 기본 레이어의 반투명 메시다. 자기 이동은 대리 몸 센서와 충돌하지 않고 자기 사격은 자신을 제외한다. 플레이어/들고 있는 적/낙하 총의 탄 피격 볼륨은 1단계에서 제외했으며, 떨어진 총은 환경 물리 충돌만 한다.

## 검증과 한계

검증 스크립트·JSON·화면은 `scripts/check-training-ai1-*.mjs`, `tests/training-combat.test.mjs`, `downloads/checks-ai1-v32`에 남긴다. 래그돌 시험은 부위별 초기 선·각속도 오차,17/16 구조·93.7kg·모터0·관절 한계·낙하와10–20초 손/발/하퇴 정착을 확인한다. 부위/벽 시험의 고정 발사 fixture는 실제 모델·기존 traceShot·의료 계산을 사용하지만 일반 플레이의 손 조준 정확도나 자동 벽 뒤 사격을 주장하지 않는다. 실제 투입/진입/사격/플레이어 피격 화면과 fixture 결과는 분리한다.
