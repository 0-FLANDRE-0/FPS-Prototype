# M4: 처치 모드·흉부 씰·바늘 감압·복부 키트

v59(M3) 위에서 작업한다. 3D는 2D와 분리된 상태다. 2D 원본은 바꾸지 않는다. 바꾼 항목은 대장에 출처/원본/튜닝/사용자 설계값/게임 허용과 `2D 역이식 후보`를 표시한다.

## 전체 순서

| 단계 | 내용 |
|---|---|
| M1–M3 | 완료 |
| **M4 (이번)** | 처치 모드 3단계, 사용 횟수, 흉부 씰, 바늘 감압, 복부 키트 |
| M5 | 타인 치료 (NPA·기도 포함) |
| M6 | 장비별 격자 |

의료 물품 추가는 이번 M4에서 일단 멈춘다(사용자 방향). 처치 대상은 본인만이다.

## 1. 처치 모드 (사용자 설계값)

- 설정에 **"의료 처치: 게임 / 리얼리스틱 / 현실"** 을 둔다.
  - **기본값은 리얼리스틱.**
  - 저장되는 설정이다.
- **모드가 바꾸는 것:** 처치 시간, 처치 효과 계수, 사용 횟수, 바늘 감압 방식, 복부 키트 효과.
- **모드가 바꾸지 않는 것**
  - 출혈 모델(유량, 혈액량, 의식, 심정지)
  - 처치 중 이동·사격 불가, 피격 시 중단
  - 다친 팔·한 손·통증·떨림 시간 배율
  - 몸통 안 출혈에 붕대·거즈 효과 없음
- **바꾸는 시점:** 진행 중인 처치는 시작할 때 모드를 유지한다. 새로 시작하는 처치부터 바뀐 모드를 쓴다.
- **대장 분류**
  - 현실 = 출처값(M3 그대로)
  - 리얼리스틱 = 튜닝·게임 허용
  - 게임 = 게임 허용

### 1-1. 지혈대·거즈·붕대 (M3 물품)

| | 게임 | 리얼리스틱 | 현실 (= v59) |
|---|---|---|---|
| 지혈대 다리 / 팔 | 약 5 s / 4 s | 15 s / 12 s | 37.5 s / 28 s |
| 거즈 채우기 + 압박 | 약 4 s + 10 s | 10 s + 45 s | 30 s + 180 s |
| 압박붕대 | 약 5 s | 12 s | 30 s |
| 맞는 처치 완료 | 대상 출혈원 계수 0 | 거의 멈춤 | M3 계수 |
| 붕대를 동맥에 | 상당히 줄어듦(예: 0.3) | 0.5 | 0.8 |
| 거즈만 완료(붕대 없이) | 계수 0 | 살 수 있을 정도(검증 3번으로 확인) | M3 계수 |
| 덜 조인 지혈대 | 효과 없음, 손해 없음(계수 1) | 출혈 증가(M3 식) | 출혈 증가(M3 식) |

- **"맞는 처치"**
  - 팔다리 동맥 → 지혈대
  - 접합부(목·사타구니·겨드랑이) → 거즈
  - 정맥·삼출 → 붕대 또는 거즈
- 게임 모드에서도 잘못 고른 처치(붕대로 동맥)는 완벽하지 않다.
- 중단된 거즈·붕대는 모든 모드에서 진행도에 비례해 약한 효과만 낸다.

### 1-2. 사용 횟수 (게임 허용: 여러 개 들어 있다고 침, 무게·칸은 그대로)

| 아이템 | 게임 | 리얼리스틱 | 현실 |
|---|---:|---:|---:|
| 압박붕대 | 3 | 2 | 1 |
| 지혈거즈 | 3 | 2 | 1 |
| 바늘 감압 키트 | 3 | 2 | 1 |
| 흉부 씰 | 4장 | 2장 | 2장 |
| 지혈대 | 2개 | 2개 | 2개 |

- 아이템에 남은 횟수를 표시한다(M2의 2/2 방식).
- 한 번 쓰면 1회가 줄고, 0이 되면 아이템이 사라진다.
- 지혈대는 지금처럼 개수 기반이며, 풀면 회수된다.
- 모드를 바꾸면 남은 횟수는 "새 모드 최대치 − 이미 쓴 횟수"(0 미만은 0)로 맞춘다.

## 2. 흉부 씰 (통기형)

- **대상:** 가슴 개방창(`chestWallOpen`)이 있는 쪽 가슴의 피부 구멍(M1 마커: 입구·출구).
- **효과**
  - 그쪽 가슴의 **열린 구멍을 모두** 막으면 밖에서 공기가 빨려 들어가는 게 멈춘다. 개방창에 의한 기흉 진행이 멈춘다.
  - 통기형이라 안에 찬 공기는 빠져나갈 수 있다. 긴장성 기흉 위험 증가를 줄인다.
  - 관통상에서 하나만 막으면 반쪽 효과(튜닝)다. 둘 다 막아야 완전 효과다.
  - 혈흉(`hemothoraxMl`)에는 효과가 없다.
- **구현:** 기존 흉부 모델(`chestCompartments`, 기존 2D 이식 흉부 위험 코드)의 진행 입력에 처치 계수로 작용한다. 흉부 식 자체를 다시 쓰지 않는다. 어디에 연결했는지 코드 경로를 보고한다.
- **본인 등쪽 구멍**
  - 현실: 혼자 붙일 수 없다(타인 처치 M5).
  - 리얼리스틱: 느리게(배율 튜닝) 가능하다.
  - 게임: 가능하다.
- **시간:** 현실은 출처값, 없으면 튜닝. 리얼리스틱·게임은 1-1과 같은 비율로 줄인다.

## 3. 바늘 감압

- **대상:** 긴장성 기흉이 있는 쪽 가슴(`tensionAir`). 화면에는 M1의 "숨이 점점 힘듦"으로만 드러난다(진단 정보를 직접 보여주지 않음).
- **효과:** 성공하면 그쪽 `tensionAir`가 빠르게 내려간다. 호흡·혈역학은 기존 식으로 회복된다.

### 모드별 방식 (사용자 설계값)

| | 방식 |
|---|---|
| **게임** | 가슴을 누르면 자동으로 올바른 위치에 사용. 다시 차오름 없음 |
| **리얼리스틱** | 위치를 두 개 중 선택: 쇄골 중간선 2번째 갈비뼈 사이 / 옆구리 4–5번째 갈비뼈 사이. 둘 다 성공. 다시 차오름 없음 |
| **현실** | 가슴 그림(앞·옆)에서 **정확한 점을 직접 찍는다.** 아래 참고 |

**현실 모드 세부**
- 허용 범위 안이면 성공, 밖이면 효과 없음(키트는 소모).
- 두 위치의 성공률 차이(흉벽 두께 때문에 쇄골 쪽 실패가 더 많다는 CT 연구 등)를 출처로 찾아 반영 방식을 보고한다.
- **다시 차오름:** 바늘이 막히거나 꺾이면 긴장이 다시 쌓인다. 발생 확률과 시간은 출처 또는 튜닝이고, 결정론 난수를 쓴다.
- 다시 감압하려면 새 키트가 필요하다. 현실 모드는 1개뿐이다.
- 긴장성 기흉이 없는 가슴에 찌르면 작은 기흉이 생긴다(출처 확인, 없으면 튜닝).
- 리얼리스틱·게임에서 긴장이 없는 가슴에 쓰면 효과 없음이고 횟수만 쓴다.

- **시간:** 현실은 출처값, 없으면 튜닝. 나머지 모드는 비율로 줄인다.

## 4. 복부 키트 (사용자 설계값: TXA + 폼, AAJT 제외)

- **컨테이너:** 가방에 별도 파우치 하나(이름 예: 위생병 파우치). IFAK과 같은 더블 탭 창을 쓴다.
  - IFAK은 표준 구성이라 건드리지 않는다.
  - 바깥·안쪽 크기는 실제 물품 크기로 정하고 보고한다(튜닝).
  - 의료 물품만 넣을 수 있다.
### 4-1. 설계 기준: "처치 후 버틸 수 있는 시간" (사용자 설계값)

이 게임의 목표는 파밍·탈출이다. 몸통 안 출혈 처치의 효과를 퍼센트가 아니라 **제대로 처치한 뒤 남은 출혈로 얼마나 더 움직일 수 있는지**로 정한다. 계수는 이 목표 시간이 나오도록 역산한다(튜닝).

| 기준 사례: 간 중앙 소총 피격(7N6·M855), 폼 + TXA 적용 | 목표 |
|---|---|
| 게임 | 출혈이 사실상 멎는다. 디버프만 안고 계속 움직인다 |
| 리얼리스틱 | 약하게 계속 새서 **약 30–60분** 안에 탈출해야 한다(목표 약 45분) |
| 현실 | 문헌 값(몇 분~수십 분). 하드코어 |

- 이동·달리기에 따른 D2 운동 생리는 그대로 적용한다. 가만히 있을 때와 계속 걷거나 뛸 때의 차이를 함께 보고한다.
- 복부 피격이라도 부위마다 결과가 다른 기존 모델(간·신장·비장·장)은 그대로 둔다.

### 4-2. TXA
- 실제 약이다.
- 부상 후 3시간 안에만 효과가 있다(CRASH-2 등 출처). 세 모드 모두 같다.
- 대상은 환자 전체다. 정맥·실질 장기·삼출 출혈을 줄인다.
- 투여 경로(근육 주사 등)는 출처를 확인하고, 현장 투여의 단순화는 게임 허용으로 적는다.
- 1회 투여다. 모드별 사용 횟수는 TXA 1로 고정이다.

| | 게임 | 리얼리스틱 | 현실 |
|---|---|---|---|
| 효과 나타나기까지 | 약 5 s | 약 30 s | 출처값 |
| 정맥·장기·삼출 출혈 감소 | 약 50% | 약 25% | 작게(CRASH-2 수준, 출처 근거) |
| 동맥 | 약간 | 거의 없음 | 거의 없음 |

### 4-3. 복부 지혈 폼
- DARPA 연구의 실험 기술이다(돼지 실험 단계). 출처를 확인해 단다.
- 대상은 복부다.
- 복강(`peritoneal`) 출혈을 줄인다. 후복막(신장·하대정맥)에는 **모든 모드에서** 효과가 없다(폼은 복강 안에 주입하므로).
- 복부 통증이 오른다(튜닝).
- 사용 횟수는 모든 모드에서 1회다.

| | 게임 | 리얼리스틱 | 현실 |
|---|---|---|---|
| 효과 나타나기까지 | 약 3 s | 약 15 s | — |
| 복강 출혈(간·비장 실질, 복강 정맥) 감소 | 약 90% 이상(4-1 목표에 맞춤) | 약 60% 안팎(4-1 목표 45분에 맞춤) | 아주 약하게(약 10%, 실전 배치되지 않은 기술) |
| 대동맥 같은 큰 동맥 | 약 50% | 약 20% | 거의 없음 |

표의 퍼센트는 시작점이다. 최종 계수는 4-1 목표 시간이 나오도록 조정하고, 조정한 값을 대장에 적는다.

## 5. 화면

- 설정의 모드 선택(기본 리얼리스틱)을 둔다.
- 아이템의 남은 횟수를 표시한다.
- 흉부 씰을 붙인 구멍 마커는 "처치됨"으로 표시하고 씰 아이콘을 둔다.
- 바늘 감압 위치 선택:
  - 리얼리스틱: 선택지 2개
  - 현실: 가슴 그림 찍기
  - 게임: 자동
- M1 현황 문구가 처치 후 실제 변화를 읽는다. 예: 씰 후 "공기 새는 소리" 사라짐, 감압 후 "숨이 점점 힘듦" 완화.

## 6. 하지 않는 것

- NPA·기도 처치, 타인 치료(M5)
- AAJT, 그 밖의 새 의료 물품
- 진통제(아세트아미노펜·멜록시캄·OTFC·케타민), 수액·수혈, 탈출(후송) 치료: 다음 단계에서 따로 논의한다
- 장비별 격자(M6), AI 처치
- 지혈대 장시간 손상, 구획 증후군
- 출혈 모델·흉부 모델 식 자체, 탄도·관통·방호·HP·상처

## 7. 검증

1. **현실 모드 = v59:** M3의 모든 처치 사례가 현실 모드에서 v59와 바이트 동일해야 한다.
2. **모드별 M3 사례:** 대퇴동맥 지혈대(완전 / 중단 / 2개), 목 거즈(거즈만 / 거즈+붕대 / 중단), 위팔 동맥 붕대를 세 모드로 돌린다. 완료 시각, 생존 여부, 남은 혈액량을 표로 낸다.
3. **리얼리스틱 거즈만:** 목 거즈만 완료한 경우 1800 s 생존을 확인한다.
4. **사용 횟수:** 모드별 소모, 0이 되면 사라짐, 모드 변경 시 남은 횟수 조정.
5. **흉부 씰:** 가슴 관통 개방창에서 처치 없음 / 씰 1장(입구만) / 2장(입구+출구)을 비교한다. 기흉 진행, 호흡 효율, 의식 시간축. 모드별 등 쪽 구멍 규칙도 확인한다.
6. **바늘 감압:** 긴장성 기흉 사례(실사격으로 안 나오면 기존 흉부 모델 시험 경로로 만들고 그 방법을 밝힌다)에서 다음을 확인한다.
   - 처치 없음 / 모드별 감압
   - 현실 모드의 다시 차오름, 잘못된 위치, 긴장 없는 가슴에 찌름
7. **복부**
   - 간 중앙(7N6·M855)·비장 단독 사격에서 처치 없음 / TXA / 폼 / 둘 다를 모드별로 돌린다.
   - 출혈원 유량과 의식 소실·심정지 시각을 최대 3600 s까지 관찰한다.
   - 4-1 목표 시간 충족 여부를 표로 낸다(가만히 있을 때 / 계속 걸을 때).
   - 신장(후복막)에는 폼 효과가 없는지 확인한다.
8. **불변:** 처치를 안 한 사례는 v59와 바이트 동일해야 한다.
9. **화면:** 1280×720과 844×390에서 모드 설정, 횟수 표시, 씰 아이콘, 바늘 위치 선택(세 방식), 복부 파우치 창을 캡처한다.
10. **기존 회귀:** 전체 테스트, 2D baseline 바이트 비교, 600틱 동일, S0 240조건·684채널 동일, 포인터 잠금, 두 화면 오프라인 실행.
