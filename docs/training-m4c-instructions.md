# M4c 사용자 지시: 처치 시간 정리

v61 위에서 작업. 3D만, 2D 원본 불변. 대장에 출처/원본/튜닝/사용자 설계값/게임 허용 표시.

1. 부상 시간 배율은 손 쓰는 동작에만 적용한다. 지혈대, 거즈 채우기, 붕대, 씰, 바늘, TXA/폼/약 투여, OTFC 물기, 수혈 연결은 손 동작이다. 거즈 압박, 수혈 주입, 약 효과 시작, OTFC 용해는 고정 시간이다. 한 손 압박은 시간은 같고 완료 효과만 조금 약하게 한다(튜닝). 게임 모드는 약화 없음. 현실 압박180초 고정.
2. 게임 부상 배율 최대1.2, 한 손 포함1.5. 리얼리스틱 최대1.5, 한 손 포함2.2. 현실 상한 없음.
3. 리얼리스틱 기본 시간: CAT 다리/팔10/8초, 붕대8초, 거즈 채우기8초+압박20초, 씰1장6초(등1.8배), 바늘8초, TXA8초, 폼12초. 게임도 같은 비율 이하로 단축하고 TXA/폼/씰/바늘은 리얼리스틱보다 짧게. 현실 기본 시간 유지.
4. 달리기 재출혈30% 목표 미달은 유지/기록. 위 한 손 압박 예외 외에 처치 효과 계수, 약효 시작/지속, 모드별 수혈 주입 속도, 출혈/흉부/생리 식은 유지.
5. 검증: 세 모드 × 건강/한 팔 기능 거의0/한 손 분쇄/심한 통증·떨림에서 각 처치 시간 표. 리얼리스틱 한 손 거즈 약35초. 건강 리얼리스틱 CAT+거즈+붕대+씰 총합. 한 손 효과 약화 모드별 검증. 무처치 v61 바이트 동일. 현실 손 동작 v61 동일(고정 시간만 변경). 전체 테스트/2D baseline/600틱/S0240/684채널/두 화면 오프라인.

이 문서는 사용자가 요청한 게임 시뮬레이터 변경 범위이며 실제 의료 지침이 아니다. 기존 출처와 새 게임 튜닝은 별도 대장에 구분한다.
