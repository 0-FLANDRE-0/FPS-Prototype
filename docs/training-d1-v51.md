# D1 v51 — 통증·각성·출혈 시야·AI 연결

v50 `9e1d4cfd50fa049e4d2eeb597f1388d95fbef1dc` 위 런타임 `0971a7fa0823aaf4ed9806514976d993b5161109`. 기존 의료의 느끼는 통증/부위 통증/아드레날린/공황/탈진과 성능 배율을 읽어 총·조준선, 동작 속도, 이동/절뚝임/달리기 제한, 한 개의 기존 렌즈 패스와 AI에 연결했다. 의료·탄 비행·관통·방호·HP·쓰러짐 수식과 원본2D는 바이트 보존했다.

플레이어에게 추가 탄 분산이나 입력 지연은 없다. 총과 조준선이 실제로 움직이며 무기/카메라 프리셋과 weaponMotion으로 이 의료 흔들림을 줄일 수 없다. 설정의 **화면 효과 강도**(기본100%,0–100%)는 화면 효과에만 적용한다. ACOG/Vudu PiP를 합성한 뒤 같은 렌즈 패스를 거치며 lensStrength0도 동일 패스의 identity 경로를 쓴다. UI는 가리지 않는다. 의료 기록의 D1 항목에 느끼는/부위 통증, 가림, 각성·탈진, 시야, 원인별 흔들림, 배율과 AI 환산값을 표시한다.

## 출처와 튜닝

생리적 떨림의8–12Hz 대역은 Lenka/Jankovic2021(PMC8350038), 망막 관류와 점진적 시각 소실→의식 소실은 PMC5306326/FAA Acceleration 자료에서 확인했다. 색 빠짐을 앞에 둔 것은 사용자 설계다. Artwohl2002의 공식 OJP 초록은157명 조사에서 소리 감소84%/증폭16%를 확인한다. 원문 PDF와 터널비전 비율은 확인하지 못했다. 초기 기립성 문헌(PMC8437071)은 기립15초 이내와 시각 증상을 설명하며1.5초 상승/30초 회복은 튜닝이다. 각 문턱·동작/각도/AI 변환식은 [대장](medical-d1-ledger.json)에 출처/원본/사용자 설계/튜닝과2D 역이식 후보를 표시했다. 원본2D 자동 역이식은 하지 않았다.

## 확인 한계

- 시야·각도·주파수 선택·청각 감쇠·AI 변환 및 동작 계수는 게임 튜닝이다. 임상적 출혈량/혈압의 증상 문턱이나 실측 명중률을 재현한 값으로 해석하지 않는다.
- Artwohl 원문 PDF는 접근 제한으로 확보하지 못했다. 공식 OJP NCJ197365 초록에서157명 조사와 소리 감소84%/증폭16%만 확인했다. 터널비전 보고 비율은 확인하지 못해 인용하지 않았고 이 비율을 게임 발생 확률로 쓰지 않는다.
- 항공의학의 점진적 +Gz 시각 소실 순서를 설계 근거로 삼았다. 모든 상황에서 시각 전조가 의식 소실에 앞선다는 임상 법칙은 아니다. 색 빠짐을 맨 앞에 둔 것과 MAP/관류/산소 문턱은 사용자 설계와 튜닝이다.
- 기립성 문헌에서 기립15초 이내 발생과 시각 증상은 확인했다.1.5초 상승·30초 회복은 확인한 문헌의 지속시간 수치가 아니며 튜닝이다.0/20/35% 손실은 기존 생리 보상30초 후에 시험했다.
- 화면 캡처는 실제 사격으로 생성한 의료 상태를 P01 표시 소비자에 재생한 것이다. 동작 시간 측정도 같은 부상 입력을 고정해 악화가 타이밍 비교에 섞이지 않게 했다. 최종 HTML의 실제 적 사격→플레이어 피격→의료 흐름은 별도 offline.json/PNG로 검증했다.
- 앉기/서기 시간은 기존 시점 높이 전환 속도를 줄인다. 기존 이동 캡슐의 높이 교체 시점은 보존했다. 플레이어 표현은 직전 고정 틱의 의료 결과를 사용하므로 최대1틱(16.7ms) 표시 지연이 있다. 입력 반응 지연은 없다.
- 총알 추가 분산은 없다. 조준선/총구가 움직인 현재 총 자세가 발사 방향을 정한다. 적은 기존 AI 각도 오차 경로를 의료 배율로 바꾸며 v50의 별도 부상 가산식은 제거해 이중 벌점을 피했다.
- 팔/다리의 작은 단독 근육상은 위협 종료 후 통증 가림이 풀려도 기존 생리가 탈진을 만들지 않을 수 있다. 복부 근육상/출혈 사례에서는 기존 crash가 나타났다. HP0 복부는 통증 바닥95라도 기존 아드레날린 가림 후 느끼는 통증을 쓰며95를 강제로 느끼게 하지 않는다.
- 소리 PCM·전파·물리 노출/청력 누적·이명은 보존했다. 건강 상태의 네이티브 WebAudio 출력은 부동소수 처리 오차를 수치로 보고하며 바이트 동일 PCM 출력이라고 주장하지 않는다. 부상 상태의 청각 출력/AI 문턱 변화는 의도한 D1 효과다.
- 성능은 Chromium ANGLE SwiftShader의 render+gl.finish 표본이다. 실행별 변동이 있어 효과가 켜졌을 때 더 빠른 수치도 개선으로 주장하지 않는다. 실제 Android/iOS 조작감·GPU/발열·실시간 연사 성능은 미검증이다.

상세 CSV/그래프/화면 비교는 [검증 보고](../downloads/checks-d1-v51/report.html), 출처의 정확한 URL·확인 바이트/SHA는 [출처 대장](medical-d1-sources.json)을 따른다. 원시 JSON.gz·개별 PNG·최종 HTML 오프라인 기록은 저장소 checks-d1-v51 폴더에 보존한다.
