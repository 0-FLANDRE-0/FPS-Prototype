## 장기 출혈 통합

간·비장·좌우 신장마다 `parenchymal/<geometryId>` 출혈원 하나를 둔다. 여러 상처는 각 출혈원의 `lesions`와 `woundIds`에 연결한다. 합친 심각도는 `1−Π(1−severity)`로 계산한다. 이는 겹침을 근사하는 튜닝이며, 창상 부피의 정확한 공간 합집합은 아니다.

출혈량은 **현재 장기 관류 × 사용자 설계 2/3 × 합친 유효 심각도**다. 이전 gain 3은 활성 경로에서 제거했다. B1b의 옛 값과 함수는 과거 호환용으로 남지만 새 유량 계산에는 쓰지 않는다.

간 25%·비장 4.8%·신장 각 10%의 심박출량(CO) 비율과 자연 지혈 문턱 0.10·시정수 180초는 유지한다. 합친 기본 심각도로 지혈 가능 여부를 정하고, 작은 손상은 각 lesion의 유효 심각도를 지수적으로 줄인다. 새 상처가 문턱을 넘겨도 이미 닫힌 옛 상처를 재개방하지 않는다. 상처·부위별 호환 표시는 현재 lesion의 손상 비율로 배분하며, 전역 혈액량은 한 번만 적분한다.

다른 등가 미세혈관상은 이미 장기별 ID를 공유했지만 손상 면적을 단순 합산하고 있었다. 이를 `8 mm² × 합친 유효 심각도`로 바꾸고 현재 가정 관류 `0.20 × CO`를 상한으로 둔다. 기존 정맥압 5 mmHg, 45초 누적 노출에 따른 지혈, 저혈압 응고, 지역 유량 상한 ×1.7은 유지한다. 현재 해당 도형은 좌우 폐·심장·장이다. 위·방광은 처리 코드만 있고 현재 몸속 도형은 없다.

## 간 주변 혈관

간정맥 대표 줄기와 문맥을 복부·척추 기준 비율 좌표의 캡슐 사슬로 추가했다. 기본 체형에서 지름은 각각 약 9.45 mm다. 문헌 대표치와 실제 모델 피팅값을 구분한다.

- 문맥: 성인 남성 231명의 표에서 지름 `9±2 mm`를 확인했다.
- 간정맥: 성인 19–60세 CT 90명(남 56·여 34)의 우간정맥 `8.59±2.73 / 9.28±1.98 mm`를 참고했다. **성별을 분리한 남성 평균은 확보하지 못했다.** 모델의 9.45 mm와 경로는 튜닝으로 표시한다. 별도 문헌의 공통 줄기 지름 `5.7±2.0 mm`·길이 `8.8±3.9 mm`를 모델 전체 배액 경로 길이로 사용하지 않는다.
- 하대정맥: 성인 남성 2,336명의 평균은 호기 `17.4±3.5 mm`, 흡기 `10.8±2.1 mm`다. 모델의 원래 비율 피팅은 호흡에 따른 혈관 지름 변화를 재현하지 않는다.

세 체형 검사에서 키 1.1 체형의 기존 하대정맥이 간 상단 뒤쪽 범위를 충분히 덮지 못했다. 기존 `abdominal-vena-cava` 사슬의 정규화 상단 0.85에서 0.97까지 12구간을 이어 붙였다. 원래 12구간의 지름·경로와 나머지 75개 도형은 정확히 보존했다. 같은 혈관 ID와 출혈원을 유지하므로 하대정맥 출혈원이 중복되지 않는다. 총 도형 수는 76개에서 78개로 늘었다.

연장 구간은 원래 반경 비율 0.09를 상속하고, 기존 R1 피팅으로 몸 밖에 나오지 않게 조정한다. 기본 체형의 연장 구간 지름은 약 11.52–18.90 mm다. 체형별 값은 `geometry.csv`와 `retrohepatic-coverage.csv`에 기록했다.

간정맥·문맥의 출혈은 `peritoneal / intra_abdominal`, 하대정맥은 원래 `retroperitoneal`로 분류한다. 기존 정맥 오리피스 식 `Cd·A·√(2P/ρ)`, 지역 상한 ×1.7, 전역 출혈 합계 ≤ 현재 CO를 재사용한다. 문맥압 8 mmHg는 문헌 범위 5–10 안의 튜닝이며, 간정맥압 5 mmHg는 B1 값을 유지한다. 정상 유량 참고는 간정맥 0.25·문맥 0.20 × 기준 CO로 근사했다. 문맥 비율은 간 공급 25% 중 문맥 80%를 따른 튜닝이다.

두 새 혈관은 주요 정맥으로 자연 지혈을 적용하지 않는다. 영구 통로가 닿지 않고 순간 공동만 닿으면 타박 기록만 남긴다. 새 2D 식별자 문자열은 호환 표시이며 원본 2D 선언은 수정하지 않았다.

## 단일 사격·복수 피격

실제 사격 56조건을 v44와 비교했다. 서기·5 m·7N6/M855로 간 스침·중앙·후방·문맥, 비장·양 신장, 경동맥·대퇴동맥 부분/완전·흉부 대동맥·하대정맥·심장·팔 근육을 시험했다. 후방 사격의 간+간정맥+하대정맥 직접 교차와 문맥 사격의 간+문맥 직접 교차를 실제 `traceShot()`에서 확인했다. 스침은 영구 통로의 기하학적 교차를 뜻하며 순간 공동 심각도가 작다는 뜻은 아니다. 동반 장기 손상도 `single-injuries.csv`에 모두 남겼다.

같은 간 경로 1·2·3발은 경과 시간 없이 CO를 고정해 시험했다. B1c의 간 출혈원은 항상 1개, lesion은 1·2·3개이며 유량은 2/3 상한을 향해 증가한다. v44의 출혈원 3개와 `liver-multihit.csv`에서 비교할 수 있다.

순수 출혈 대조 16개는 실제 사격에서 얻은 출혈원 하나를 건강한 인스턴스로 복사한 별도 생리 대조다. 추가 실제 총상으로 세지 않는다. B1c의 간·경동맥·대퇴동맥 부분/완전 대조 8개 모두 1,800초 안에 심정지에 이르렀으며 손실은 45.53–45.62%였다. 팔·다리 근육만 맞힌 실제 4조건은 1,800초 동안 쓰러짐·심정지가 없었다.

## 배포와 한계

실행 ZIP은 20 MB 미만이며 `dist/CQB_Training.html`에 모든 게임 자산이 내장되어 있다. 요약표·보고서·SVG를 동봉하고, 전체 JSON.gz·시계열 CSV·화면은 GitHub `downloads/checks-b1c-v45`에 보관한다. 모든 커밋은 `[skip ci]`로 전달하며 GitHub Actions 없이 로컬에서 빌드·검증한다.

장기 중첩은 확률 합집합 근사이고, 해부 경로와 여러 계수는 튜닝이다. 시계열의 심정지 뒤 평탄 구간은 혈액순환 중단에 따른 것으로 자연 지혈을 뜻하지 않는다. 수치는 게임 시뮬레이터 결과다. Android/iOS 실기기와 전체 게임 FPS는 측정하지 않았으며 이전 젤라틴 도판 재현·사격 성능의 한계는 남아 있다.

**2D 역이식 후보: 예. 자동 역이식: 없음.** 출처·원본·튜닝·사용자 설계 분류와 상세 값은 대장을 따른다.
