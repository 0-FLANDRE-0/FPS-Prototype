# AI1 / v67 — 감각·반응·조준·Sector05

v66 `9ad55d107967e6efb44ce218bd1a8a9bc978b505` 비교. 3D만 변경하며 원본2D·의료·탄도·관통·방호·손가락 자산은 보존했다.

## 사용
메뉴에서 **Sector05 · 킬하우스** → 현관 벽 패널 가까이에서 **F / 화면 상호작용** → 인원1–4·신병/일반/정예·방 분산/중앙/복도 끝 선택 → 투입. 순찰 또는 위치 지키기, 서기/앉기/좌우 기울이기 시험 자세를 고른다. Sector04의1명 진입 훈련도 새 감각·조준을 쓴다. 적 모두 쓰러지면 같은 패널에서 기존 M7 확인을 거쳐 정리한다. 의료 선택기에 각 적이 별도로 나온다. 설정의 **AI 표시**는 기본 꺼짐이며 저장/기본값 복원을 지원한다.

## 연결 구조
- **감각** `AI1Senses`: 실제 눈→9개 몸 지점의120° 시야, 10Hz·최대9레이/회. 방·벽·창틀·엄폐에 가린 점은 관측을 만들지 않는다. 노출·거리·주변각·관측된 이동·자세·D1 상태에 따라 발견이 누적된다. 마지막 관측의 위치/시각/신뢰도만 기억한다. SND1의 오차가 있는 소리 위치 증거만 받는다.
- **판단** `AI1Brain.step({time,senses,arrived,rounds,medical,behavior,reloadDurationS,canReload})`: 현재 플레이어·물리·숨은 좌표를 받지 않는다. 발견→알아봄→결정→조준→사격/장전. 시야를 잃으면 사격을 멈추고 기억/소리 방향만 주시한다. AI2가 교체할 경계이며, 원본2D utility 뇌 이식을 완료했다고 주장하지 않는다.
- **행동** `AI1Aim` → `mountAI1AK` → `fireAI1`: 인지 위치 오차→관측 속도의 부족한 앞보기→피츠 계열/과회전 동작→**플레이어 AimState/RecoilState/D1**→어깨 기준 총 배치→양팔IK→실제 총 자세의 shotPose→같은 traceShot. 발사 뒤 총 방향을 탄 방향으로 맞추는 구형 시각 보정은 새 경로에서 쓰지 않는다.

피격·의료·방호·쓰러짐·고정 손가락은 기존 연결이다. 인벤토리·시체 수색·장비 표시·의료 선택을 여러 적 인스턴스로 확장했다. 적 신체/의료/탄창 상태는 독립이다. 서 있을 때는 기존 애니메이션+짧은 움찔이며, 의료가 쓰러짐을 판정해야 래그돌로 전환한다.

## 사격과 자세
지향/빠른 견착/ADS는 준비 시간·인지 위치의 불확실성·견착 위치가 다르다. 별도 명중 주사위/사후 탄 방향 오차 원뿔은 없다. 동일한 탄/총/shot ID/자세의 반동 충격과 적분은 플레이어와 정확히 같고, 숙련도 회복은 플레이어의 수동 보정 인터페이스로 구현했다. 앉기/거치는 같은 흔들림 식의 입력 배율이다. 가까이2발0.25s·먼 거리 재조준은 튜닝이고, 극근접 연사는 원본 AK650RPM이다.

**기존3D에는 레지스트리 MOA를 별도로 샘플링하는 단계가 없다.** 이번에도 플레이어를 바꾸거나 AI에게만 산포를 더하지 않았다. 2D MOA 값은 불변이다. 이것을 새로 완성한3D 무기 자체 산포로 설명하면 안 된다.

몸→쇄골 바깥쪽 어깨 포켓→개머리판→총 자세→양팔IK 순서다. ADS 눈은 기존 마커를 목 회전으로 조준축에 맞춘다. 뼈 위치를 옮기거나 길이를 늘리지 않는다. 확인한8개 자세/화면의 접점 오차 최대 0.000e+0m, 눈–광축 거리 최대 4.428e-15m. 이는 점–직선 수치이며 실제 눈/조준기 접촉 표면 검증과 구분한다. 측정된 눈–뒤가늠자 축방향 거리는 약0.33–0.37m다. 기울이기는 머리 구체쓸기·여유2cm로 제한하며 기운 총구에 기존 막힘 판정이 적용된다. 자동 빼꼼은 없다.
