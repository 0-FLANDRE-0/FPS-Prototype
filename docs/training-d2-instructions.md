# D2: 뇌진탕·스태미나·운동 심박·상태 UI

v54 위에서 작업한다. 3D는 2D와 분리된 상태다. 2D 원본은 바꾸지 않는다. 바꾼 항목은 대장에 출처/원본/튜닝/사용자 설계값/게임 허용과 `2D 역이식 후보`를 표시한다.

공통 규칙(D1·D1b)은 그대로다.
- 흔들림 난수는 결정론이다.
- 화면 효과는 "화면 효과 강도" 설정을 따른다. 몸 효과는 이 설정으로 바뀌지 않는다.
- 통증·MAP만으로는 쓰러지지 않는다.

이번에는 **3절(운동 심박)에서 생리 계산을 바꾼다.** 운동 강도가 0이면 v54와 결과가 정확히 같아야 한다.

## 0. 보완: 눈꺼풀 위로 잔상이 보임

v54 셰이더 순서가 문제다.
- 지금: 블랙아웃 어둡게 → 눈꺼풀 → 20% 잔상 더하기(`c += remnant × …`)
- 그래서 눈을 감아도 잔상이 위에 그려진다.

잔상을 먼저 더하고, 눈꺼풀을 마지막(의식 소실 검정 직전)에 덮는다. 감긴 부분에는 잔상도 보이지 않아야 한다.

## 1. 뇌진탕

정신 잃음과 비틀거림은 넣지 않는다(사용자 설계값).

- **입력**
  - S2가 기록만 하는 `concussionRisk`(두개골이 막은 순간 공동 에너지)를 쓴다. 심각도 변환은 튜닝이다.
  - 나중에 헬멧 둔상·폭발을 붙일 수 있게 입력을 하나의 함수로 둔다.
- **효과**
  - **이명:** v46 청력 시스템의 이명 채널을 재사용한다. 따로 소리를 만들지 않는다.
  - **흐림:** 화면 전체가 약하게 흐리고, 세기가 천천히 오르내린다.
  - **초점 지연:** 시점을 빠르게 돌리거나 가까운 곳↔먼 곳을 번갈아 볼 때 잠깐 더 흐려졌다가 맞는다.
  - **빛 예민:** 밝은 부분이 더 밝게 번진다.
  - **멍함:** 플레이어는 `weaponHandling`·장전·조준 진입이 느려진다. AI는 반응 시간·조준 수렴이 느려지고 청각 문턱이 오른다.
- **근거:** 뇌진탕 증상 목록(SCAT5 등)에서 흐림, 빛·소리 예민, 느려짐 항목을 확인해 단다. 이명이 목록에 없으면 별도 출처를 찾거나 튜닝으로 적는다.
- **지속:** 실제 증상은 수 시간~수 일이지만, 게임에서는 몇 분에 걸쳐 줄어든다(게임 허용, 튜닝). 여러 번 맞으면 누적된다.

## 2. 스태미나

### 다리 스태미나 (달릴 수 있는 양)
- **소모와 회복**
  - 달리면 닳는다.
  - 걸을 때는 천천히, 서기·앉기에서는 빠르게 회복한다.
  - 0이 되면 달리기를 막는다. 일정량(튜닝, 예 25%)까지 회복해야 다시 달릴 수 있다(깜빡임 방지).
- **영향 요인**
  - 장비 무게: 지금 13.7 kg. 인벤토리 업데이트 때 실제 총 질량으로 바꿀 수 있게 입력을 분리한다.
  - 다리 기능, 다리 통증, 혈액 손실, 산소 공급(3절)
  - 이 요인들은 최대치와 회복 속도를 함께 낮춘다.
- **달릴 수 있는 시간:** 군장 상태 전력질주 지속 시간의 출처를 찾고, 못 찾으면 튜닝이다. 정한 값과 이유를 대장에 적는다.

### 팔 스태미나 (조준 유지)
- **소모와 회복:** 조준 중에 닳고, 총을 내리면(비조준) 회복한다.
- **소모 속도**
  - 총 무게(부착물·광학 포함)와 앞쪽 쏠림(무게중심까지 팔 길이)으로 팔이 버티는 부담을 계산한다.
  - 정적 근지구력 곡선(Rohmert 1960: 최대 근력 대비 비율 → 유지 가능 시간)의 모양을 출처로 쓴다. 팔 근력 기준값은 튜닝이다.
  - 앉기는 조금 덜 닳는다(튜닝). 엄폐물에 거치하는 기능은 아직 없다.
  - 팔 기능, 팔 통증, 혈액 손실, 산소 공급에 따라 더 빨리 닳는다.
- **효과**
  - 0에 가까워질수록 흔들림이 점점 커진다. 0에서 크게 흔들린다. D1b 조준 유지 서보의 교란을 키우고 유지력을 낮추는 방식이다.
  - 조준을 강제로 풀지는 않는다.
- **AI:** 적도 조준 유지 시간이 길어지면 같은 규칙으로 조준 수렴이 나빠진다. 지금 AI는 달리지 않으므로 다리 스태미나는 데이터만 둔다.

## 3. 운동 심박·심박출량 (사용자 설계값: 현실 방향)

달리기·걷기에 따른 운동 강도(0–1)를 만들어 의료 계산에 넣는다. 강도는 이동 속도와 장비 무게로 정한다(튜닝). 서 있으면 0이다.

### v54 코드에서 주의할 점
2D식 혈역학은 심박이 오르면 박출량을 깎는다.
- 심박 > 100이면 SV 최대 −45%, > 170이면 ×0.7
- 심박 > 145이면 충만 시간 감소

운동 심박을 `hrTarget`에 그냥 더하기만 하면, **뛸수록 심박출량과 혈압이 떨어지는** 반대 결과가 된다. 실제 운동에서는 근육 펌프와 교감 신경 때문에 SV가 유지되거나 늘어나고, 심박출량이 오른다.

### 바꿀 것
- **심박**
  - 운동 강도에 따른 심박 상승을 기존 `hrTarget`에 넣는다. 상한 190(원본)은 유지한다.
  - 오르는 속도와 운동 후 회복 속도는 문헌 값을 찾는다. 예: 운동 직후 1분 심박 회복(Cole 1999 NEJM). 못 찾으면 튜닝이다.
  - 군장 상태 달리기 정상 상태 심박의 목표 범위를 출처와 함께 정한다(대략 150–180 bpm).
- **박출량**
  - 운동으로 오른 심박 몫에는 위의 빈맥 SV 감소와 충만 시간 감소를 적용하지 않는다.
  - 근육 펌프에 따른 전부하 증가와 수축력 증가를 운동 강도에 비례해 더한다.
  - 건강한 사람의 달리기 심박출량 배율 목표를 운동생리 문헌(최대 운동 시 심박출량 등)에서 정한다.
- **혈액량이 적을 때**
  - 운동으로 늘릴 수 있는 심박출량은 기존 전부하(혈액량 비율)로 제한한다(튜닝).
  - 출혈 쇼크 상태에서 뛰면 심박만 오르고 심박출량은 거의 못 오른다.
- **혈류 재분배**
  - 운동 중에는 내장(간·비장)과 신장 혈류가 줄고, 근육 혈류가 늘어난다(Rowell 1974 등 출처 확인).
  - 실질 장기 출혈의 장기 관류: 기존 CO 비율에 운동 재분배 계수를 곱한다. 간·비장·신장 출혈은 뛰어도 늘지 않거나 줄어든다.
  - 팔다리 근육·삼출 출혈: 근육 혈류 증가 계수를 곱한다. 다친 팔다리로 뛰면 더 샌다.
  - 동맥 출혈은 기존대로 MAP 기반 오리피스 식이다(운동에 따른 혈압 변화만 반영된다).
  - 전체 출혈 합 ≤ 현재 CO 상한은 유지한다.
- **산소 수요**
  - 운동 강도에 따라 산소 수요를 올린다.
  - 의식·시야(D1b 관류 기준)가 쓰는 산소 지표는 공급/수요 비율로 계산한다.
  - 쇼크 상태에서 뛰면 더 빨리 시야가 꺼지고 의식이 떨어진다. 수요 계수는 튜닝이다.
- **숨참**
  - D1b 숨 흔들림의 빠르기·크기 입력에 운동 강도와 다리 스태미나 소모량을 더한다.
  - 운동 후 심박이 높게 남아 있으면 2D 조준 페널티(심박 > 150, 원본)와 D1b 심박 펄스가 자연히 커진다.
- **AI:** 같은 의료 계산이 적에게도 적용된다. 적의 걷기(1.4 m/s)는 낮은 운동 강도다.

## 4. 상태 UI

### 좌측 상단 정리
- 로고(`CQB FIELD LAB / CAMERA & WEAPON / 01`)와 `TRAINING GROUND / SECTOR / STANDING` 글자를 지운다.
- 디버그 탄약 선택 버튼은 무기 표시 쪽(`3 · DBG AK` 버튼 근처)으로 옮긴다. 기능은 그대로 둔다.
- 빈 자리에 아래 UI를 넣는다.

### 부위 체력 실루엣
- 사용자 참고 이미지처럼 어두운 반투명 몸 실루엣이다. 부위마다 빛나는 외곽선을 둔다.
- **부위:** 머리, 목, 가슴, 복부, 왼팔, 오른팔, 왼다리, 오른다리.
- **색:** 부위 HP 비율에 따른다. 구간은 튜닝이다.

  | HP 비율 | 색 |
  |---|---|
  | 100–75% | 초록 |
  | 75–50% | 노랑 |
  | 50–25% | 주황 |
  | 25–0% | 빨강 |
  | 0 (파괴) | 검정 |

- 검정 부위도 형태는 보이게 외곽선을 희미하게 남긴다.
- 맞은 부위는 잠깐 밝게 깜빡인다.

### 자세 표시와 스태미나 게이지
- 사용자 참고 이미지처럼 실루엣 아래에 지금 자세의 작은 실루엣을 둔다: 서기, 앉기, 왼쪽·오른쪽 기울이기, 달리기.
- 그 아래에 파란 게이지 2개: **팔 스태미나**, **다리 스태미나**.
- 부상으로 줄어든 최대치는 게이지 끝을 어둡게 표시한다.

### 배치와 표시
- 항상 표시한다.
- 화면 효과(흑백·블랙아웃 등)를 받지 않는 HUD 층에 그린다.
- 쓰러짐 이후는 기존 흐름대로 숨긴다.
- 844×390에서 이동 패드·버튼·무기 표시와 겹치지 않게 한다. 1280×720과 함께 확인한다.

## 5. 하지 않는 것

- 뇌진탕 정신 잃음, 비틀거림
- 엄폐물 거치, 인벤토리 총 질량 연동(입력 자리만)
- 치료, 진통제
- 탄도·관통·방호·HP·상처

## 6. 검증

1. **눈꺼풀 순서:** 블랙아웃 + 졸음형·찡그림 눈꺼풀이 겹친 프레임에서 감긴 부분에 잔상이 0인지 캡처로 확인한다.
2. **뇌진탕:** 머리 피격(헬멧 유무)의 `concussionRisk`와 심각도, 효과별 세기의 시간축. 정신 잃음이 없는지 확인한다. AI 반응·수렴 변화.
3. **다리 스태미나:** 건강·다리 부상·출혈 상태에서 달리기 지속 시간, 회복 시간, 재시작 문턱.
4. **팔 스태미나:** M4(광학 유무)·AK별 조준 유지 시간, 흔들림 RMS가 시간에 따라 커지는 곡선, 팔 부상 시 변화.
5. **운동 생리**
   - 건강 상태로 걷기·달리기 60 s 후 심박, CO, MAP과 회복 곡선
   - 같은 부상(대퇴동맥, 팔 근육, 간)을 서서 있을 때와 계속 달릴 때 비교: 출혈원별 유량, 쓰러짐·의식 소실·심정지 시각
   - 간·신장 출혈이 달리기로 늘지 않는지, 팔다리 근육 출혈은 늘어나는지
   - 쇼크 상태에서 달리기의 심박·CO·산소 공급/수요
6. **운동 0 불변:** 정지 600틱, S0 240조건, 출혈 단일 손상 표(정지 조건)가 v54와 바이트 동일. 걷기가 들어간 기존 시험은 차이를 표로 보고한다.
7. **UI:** 부위 색 구간 5단계, 자세 6종, 게이지(최대치 감소 포함)를 두 화면 크기로 캡처한다. 겹침 없음, 디버그 탄약 버튼 동작을 확인한다.
8. **성능:** 두 화면 크기의 프레임 시간(UI·뇌진탕 화면 효과 포함).
9. **기존 회귀:** 전체 테스트, 2D baseline 바이트 비교, 두 화면 오프라인 실행.
