# S1(v39) 상처 통로·공동 모델·피해 배율

기준은 v38 `5f1236aa84c9a9a5da5a907ec7a7b417aac223de`이며, S1 런타임은 `4e4f6bc326fe350ce18f1ba9f1ec777d0c58bbee`에 고정했다. 도판 수치는 확인한 출처 관측값이고, 모델 출력과 대장 해시는 이 고정 소스에서 추출했다. 240조건·거리·Q6·전체270테스트·CPU성능·기존600틱·두 화면 오프라인 검증을 완료했다. **전체 도판 형상, 별도 실제 얼굴 피격의 조기 쓰러짐, 엄격한0.1ms최대치와 일부 전체 발사 프레임 목표가 미달인 시험판이다.** 실행/보존 검사 통과와 모델·성능 목표 충족을 구분한다.

3D 의료는 [현재 브리프](training-brief.md)대로 2D와 분리되어 있다. 2D `src/**`와 legacy, 탄 비행·관통·방호 수식, 실제 인체 정지·출구속도·잔여탄은 보존 대상이다. 탄약 데미지와 부위 HP는 변경하지 않는다. 자동 역이식도 하지 않는다. [출처](medical-s1-sources.json), [도판 보정 입력](medical-s1-calibration-inputs.json), [변경 대장](medical-s1-ledger.json)에 원본·출처·튜닝과 `2D 역이식 후보`를 구분했다.

## 실제 탄 경로와 새 의료 계산

기존 `traceShot()`의 점유 인체 경로와 몸속 레이어 교차를 사용한다. 새 모델은 깊이 5 mm 간격의 1D 계산으로 속도·질량·yaw·파편 상태, 에너지 전달, 영구 공동·순간 공동·파편 범위를 추정한다. 이 속도와 질량은 **의료 계산용 그림자 상태**다. 모델이 추정한 정지 깊이와 출구속도가 실제 탄 상태에 쓰이지 않는다.

한 발이 팔→몸통→반대 팔처럼 여러 부위를 지나면 각 부위는 **자기 점유 구간만** 적분한다. `m`을 사람 전체에서 한 번 계산하여 모든 부위에 복사하지 않는다. 다음 부위는 기존 인체 저항이 계산한 `part.velocityInMps`에서 시작한다. 앞 부위의 새 모델 출구속도로 대체하지 않는다. 조직에서 누적된 yaw·파편의 별도 상태를 이어 쓰더라도 부위 사이 공기 틈은 조직 깊이에 더하지 않는다.

방호 관통 뒤에도 총구 속도나 탄약 프리셋 속도를 다시 사용하지 않는다. 기존 3D 방호 어댑터의 잔여속도와, 그 뒤 실제 비행에서 감소한 속도로 인체에 들어간다. 기존 원본 방호 패킷은 `residualIntegrity`, `residualBreakup`, `residualKind`, 안정성 등의 분류 정보를 전달하며 일부 특수탄은 yaw 위험 힌트도 가진다. 그러나 일반 탄의 확정적인 변형 직경·길이, 파편별 잔여 질량, 실제 yaw 각도를 일관되게 넘기지는 않는다. S1은 요청대로 이 정보를 초기 탄두 변형이나 yaw로 바꾸지 않는다. 방호가 이미 바꾼 탄의 **진행 방향**은 실제 경로에 그대로 남는다. 자세한 필드·생성 지점은 [파이프라인 조사](training-s1-pipeline-audit.md)에 있다.

## 1D 모델의 의미와 근사

저항은 `F=½ρCdAv²` 형태이고, 투영 단면은 앞면 원 단면과 옆면 `구경×길이`를 yaw에 따라 섞는다. `Cd`, yaw 곡선, 젤라틴 밀도, 임계 정지속도는 보정 튜닝이다. 근육 참조밀도 1,050 kg/m³는 Geant4 공식 참조표 구현에 근거하지만, 밀도만으로 인체 항력이나 손상량이 결정되는 것은 아니다.

순간 공동 반경은 `r=k√(dE/dx)`이며 `k`를 균질 젤라틴 도판에 맞춘다. 문헌은 simulant에서 공동 크기와 전달 에너지의 연관을 설명한다. 이 함수와 계수를 모든 인체 조직에 적용하는 것은 게임 근사다. Fackler 원문은 같은 에너지 전달량도 조직과 파편화에 따라 손상이 크게 달라진다고 경고하므로, 전달 에너지 자체를 손상량과 같다고 취급하지 않는다.

원래 `nearMisses`는 직접 교차하지 않은 구조 중 약 2 cm 안쪽만 담는다. S1의 최대 공동 반경 15 cm를 포괄하도록 **같은 1회 3D 조회**에서 `cavityCandidates`를 추가한다. 원래 `internalHits`와 `nearMisses`는 그대로 남긴다. 캐시에 깊이 구간·최소 표면거리·기존 콜라이더 체적을 저장하고 셀 계산에서 재사용한다. 셀마다 3D 조회는 하지 않는다.

타원체 체적과 캡슐 체인 체적은 기존 fitted collider의 기하 체적이다. 사람 장기를 실측한 체적이 아니다. 하나의 최소 표면거리와 깊이 구간으로 각 깊이의 단면 겹침을 추정하므로, 장기의 정확한 3D 부피 교차를 적분한 값도 아니다. 캡슐 체인의 곡선·접합 중복 역시 근사다.

순간 공동에만 조직 계수를 적용한다. 폐 0.15, 근육·피부·지방·장·심장 0.4, 주요 혈관 0.12, 간·비장·신장 0.9, 뇌·뇌간 1.0은 **고정된 S1 튜닝**이다. 문헌은 탄력 조직과 실질 장기의 상대 차이를 지지하며, 이 숫자나 정확한 폐↔근육 비율을 제공하지 않는다. 영구 공동과 파편 손상은 계수 1이다. 순간 공동으로 뼈 골절을 추가하지 않는다.

도판의 깊이는 cm 축에서 읽고, 지름은 가로·세로 축척이 같다는 가정으로 읽었다. 별도 세로 눈금이 없어 지름의 불확실성이 크다. 표의 오차는 선의 흐림·도트·봉우리 폭을 포함하며 정밀 계측 오차가 아니다. 축약 EWS 그림은 M193 끝축이 35 cm, M80 끝축이 65 cm로 보이지만 원 Fackler Fig2/3의 끝 라벨 **36/64 cm**를 채택했다.

AK74는 첫 공동 뒤 깊이 약 37±3 cm·지름 12±2 cm의 두 번째 공동이 보인다. AK47도 약 28 cm와 41 cm 부근에 두 봉우리가 있다. 전체 최대값을 맞추는 것과 두 봉우리 모양을 모두 재현하는 것은 다른 검증이다. 고정 소스에서 AK74의 두 번째 공동 최대는 깊이34.25 cm·지름2.516 cm였다. 도판의37±3 cm·12±2 cm 대비 지름이9.484 cm 작아 **두 번째 공동 재현은 불합격**이다. AK47은 넓은 한 봉우리로 계산되어 도판의28/41 cm 두 봉우리를 분리해서 재현하지 못한다. 아래 네 소총의 전체 최대값·총 깊이가 판독 오차 안에 들어가더라도 전체 도판 형태까지 재현했다고 주장하지 않는다.

M855는 강철 관통자와 납 부분을 가진 62 gr 탄으로 M193과 구조·질량이 다르다. EWS가 유사한 패턴이라고 설명하지만 같은 도판이라는 뜻은 아니다. AK47 도판도 국가·로트·핵심재를 특정하지 않으므로 PS와 구조가 동일하다고 확정하지 않는다. 114개 레지스트리 탄의 직접 자료/차용 분류는 [보정 입력](medical-s1-calibration-inputs.json)에 있다. 팽창탄·현대 EPR·AP·산탄·대구경은 각 탄에 대한 실험 검증 없이 donor를 차용한 추정이다.

M193·M855의 **수치적인 파편화 문턱은 확인한 원문에서 검증하지 못했다.** 이번에 쓰는 M193 780 m/s와 M855 760 m/s는 원본 `terminalEffect.thresholdVelocity` 값을 새 의미로 차용한 튜닝이다. 특히 원래 M855의 타입은 `yaw`이며, 본래부터 파편화 문턱을 뜻한 값이 아니다. 문헌에서 확정한 보편 문턱이나 모든 로트의 실측값으로 표시하지 않는다. 원본 2D 레지스트리는 바꾸지 않는다.

## 피해 배율과 장기 심각도

부위 유효 손상량은 영구 공동 부피 + 파편 손상 부피 + 조직 계수로 가중한 순간 공동 부피다. `m=clamp(유효 손상량/부위 기준 부피,0.1,1)`을 적용한다. 기준 부피는 S2의 탄 데미지/HP 보정과 분리한 **S1 튜닝**이다.

| 부위 | 현재 기준 부피 |
| --- | ---: |
| 머리 | 450 cm³ |
| 목 | 250 cm³ |
| 가슴·복부 | 각각1,000 cm³ |
| 팔 | 각각450 cm³ |
| 다리 | 각각800 cm³ |

HP 입력은 `기존 part.damageIn × 기존 ammoMedicalProfile.tissueDamageMul × m`이다. 기존 rawDamage와 부위 HP 정의는 그대로이고, `m=1`이면 기존 조직손상 배율까지 포함한 HP 입력과 같다. 최종240쌍에서 기존 인체·방호 결과는 같았고212채널의 m은0.1–1이었다. 각 채널의 시작속도 차이는0, 다음 부위의 기존 속도 연결 최대 오차는1.14×10⁻¹³m/s였다. HP 감소·장기 심각도는 새 모델로 바뀌며 각 행에 전후값을 기록했다.

장기 심각도는 `clamp(그 장기 안 유효 손상 부피/기존 형상 체적 × gain,0,1)`이며 고정 gain은 1이다. 심각도 표시만 바꾸지 않고 폐·실질 장기·혈관 등의 실제 생리 효과와 집계도 같은 심각도로 다시 계산한다. 탄 직접 교차와 TC/파편만의 손상은 기록에서 구분한다. 직접 뇌/뇌간 무력화는 S0 조건을 유지하고, TC-only 뇌는 연속적인 의식 목표 영향만 준다. TC-only 척수는 기록만 하며 가짜 직접 교차·골절로 승격하지 않는다.

## 심장·대동맥·폐

심장은 S1의 부피 심각도에서 펌프 손실을 계산한다. 직접 관통에 대한 별도 감도, 펌프 잔량 누적, 8초 뇌혈류 예비 시정수는 S1 튜닝이다. Rossen·Kabat·Anderson1943의 평균6.8초는 뇌혈류 차단 실험으로 총상과 다른 조건이다. Patrick1989의10–15초도 모든 심장 손상에 대한 확정 시간이 아니다. **S1의7–15초는 이 자료를 참고한 게임 설계 목표**이며 최종 실제 trace 시각으로 확인한다. S1 입력이 없는 호환 경로는 S0 시정수4초를 보존한다.

대동맥은 기존 fitted collider 직경과 손상 심각도로 개구 면적을 추정하고, `Cd·A·√(2ΔP/ρ)` 흐름에 심박출량 기반 상한을 둔다. 고정된 유량 상한은 `5,250/60×1.7=148.75mL/s`다. 예비유량1.7은 초기1.6에서 조정한 게임 튜닝이며 문헌 실측 배수가 아니다. OpenStax의 휴식 심박출량5.25L/min은 문헌 참고이고, 개구 면적 비율·Cd·혈액밀도·예비유량·원본 출혈에 넣는 비율은 튜닝이다. **콜라이더 직경은 측정한 사람 대동맥 내경이 아니다.** 기존 MAP에 따른 출혈 pulse 경로를 유지한다. 약30초 이내 무력화는 사용자 설계 기대이며 문헌에서 도출한 임상 보장값이 아니다.

### 별도 실제 화면 얼굴 경로 — 목표 미달

기존 S0실제플레이 스크립트와 같은 얼굴 피격 경로에서 직접 뇌·뇌간 교차는0이었지만,S1은 **0.5833초 후 의식 소실·래그돌**로 이어졌다. v38은 같은 경로에서15초 동안 쓰러지지 않았다. 직접CNS즉시무력화 플래그는 생기지 않았고 초기 의식40이었으며,순간 공동이 뇌간에 닿았다는 계산이 머리 구간 심각도1·목 구간0.6737을 만들었다. 연속 의식 목표가0으로 내려가며 쓰러졌다. 약0.6초MAP126.4로,저혈압 때문에 쓰러진 결과가 아니다.

**얼굴 직접 교차만으로 즉시 쓰러지지 않는다는 목표의 추가 반례이며 미해결이다.** 고정240행렬의 얼굴 경로16개는 다른 기하이므로 그120초 통과 결과와 함께 기록한다. 고정 행렬이 모든 얼굴 경로의 무력화 없음을 증명한다고 해석하지 않는다. 근접 공동의 유효 부피·뇌 조직 계수1·의식 연결은 게임 근사이고,확인한 문헌이 이0.5833초 결과를 입증하지 않는다. 발견 뒤 런타임을 바꾸지 않았고 원시상태와 화면을 최종 [live.json](../downloads/checks-s1-v39/live.json)에 남긴다.

기존 **몸속 판정 표시**를 켜면 마지막 피격의 영구 통로, 깊이별 순간 공동, 파편 범위와 부위별 `m`을 보여준다. 계산에 사용한 원본 셀 배열과 화면용 샘플은 분리한다. 화면 표시를 켜거나 꺼도 계산이 달라져서는 안 된다. 1280×720·844×390의 실제 설정 체크박스로 세 색·부위별 배율을 확인했다. 표시 on/off의 최초 상태와60Hz 의료 경과가 같았고, 래그돌 뒤 뼈 추종 오차는 최대1.45×10⁻¹⁴m였다. ## 로드 시점 표와 보간 차이

초기 직접 계산은 실제 입력1,000개에서 중앙값0.1130 ms·p950.4877 ms로0.1 ms 예산을 넘었다. 이에 따라 **로드할 때 등록 탄114종×두 파편화 속도 클래스×깊이513표본**의 곡선/응답 표를 준비하도록 바꿨다. 사격 뒤 결과를 캐시하는 방식이 아니다. 깊이는5 mm 간격, 최대2.56 m, 숫자 배열은4,678,560 B다. 실행 중 깊이 보간과 기존 저항식의 속도 제곱 비례를 사용하며, 다음 부위에 기존 입사속도를 다시 넣는다. 정확한 고정 정보는 대장의 `lookupTable`에 있고 로드 시간은 환경 의존 측정값으로 따로 보고한다.

장기별 검색·축 구간·최소거리를 피격 시작에 캐시하고 셀의 반복 배열 생성을 제거한 직접 계산은 최적화 전과 수치 오차 범위에서 같았다. LUT 보간은 결과를 조금 바꾼다. 같은 실제 입력1,000개 비교에서 최대 차이는 `m`0.0019476, 계산용 출구속도0.6981m/s, 장기 심각도0.018588, TC반경1.9783mm였다. 파편화와 셀 수 차이는 없었다. **경계 장기 ID는3건 달랐다.** 작은 양의 유효 부피가 생기거나 없어지는 실제 경계 차이이며0잡음으로 버리지 않았다.

모든 부하 프레임에 탄이 있어 “사격 없는 평소” 대조는 동일 상처의 의료tick만 수행한 복제 인스턴스를 사용했다. 그CPU사건/의료-onlyquiet비율은25,776.98/24,023.62로1.5목표를 넘는다. **일반 게임 렌더 프레임과의 비교가 아니며 이 시험으로 게임 사격 프레임 목표를 검증했다고 주장하지 않는다.** 실제 브라우저 비용은 별도 결과를 우선한다. 전체 프레임·발사·생전/사후·ON/OFF기록은 [성능 보고](../downloads/checks-s1-v39/performance/performance-summary.md)와 [performance.json](../downloads/checks-s1-v39/performance/performance.json)에 있다.
