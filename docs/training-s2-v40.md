# S2(v40) 몸속 속도 통일·뼈 안 공동·부위 HP 의미

기준은v39 `7e91d9383e59d623709d51af8db62f18c1a7c638`이며 최종 런타임은 `fefede27e6abd9be538928b4cd06c85300d1fb64`에 고정했다. 피격 전체 합산 성능과 같은 한 발의 분리된 부위 구간 합산을 보완했다. 최종 고정 소스의 의료·탄 종단·UI·기존 회귀와 격리 성능 측정을 완료했다. **전체 피격 p95 0.1 ms 예산은 두 반복 모두 미달한 시험판이다.** 기존 S1의 전체 젤라틴 형상 한계도 남아 있으며, 실행·보존 검사 통과를 모든 목표 합격으로 표시하지 않는다. 최종 HTML은34,560,487 B, SHA256 `6eea90ecde132f7d4c3e3984ed5287e18b9aef6209227940a5f61c7b12acc065`이며v39보다47,892 B 늘었다. 3D 의료는 2D와 분리되어 있고 자동 역이식을 하지 않는다. [사용자 지시와 추가 디버그 요청](training-s2-instructions.md), [출처](medical-s2-sources.json), [변경 대장](medical-s2-ledger.json)에 원본·출처·튜닝과 `2D 역이식 후보`를 구분했다.

## 이번 변경의 의미

S1은 피해에 새 상처 모델을 쓰면서 실제 몸속 속도는 기존 인체 저항으로 정했다. S2는 **몸 안에서 한 번 계산한 채널**로 피해와 탄 속도·질량·yaw·파편·체내 정지·출구 상태를 함께 정한다. 같은 채널을 의료에 넘기므로 속도와 피해를 두 모델에서 따로 적분하지 않는다. 기존 인체 저항 구현은 삭제하지 않고 legacy와 전후 비교에 남긴다.

여러 부위를 지날 때 각 부위의 배율 `m`은 자기 점유 구간으로만 계산한다. 다음 부위는 앞 부위가 내보낸 새 속도·질량·yaw·변형·파편 상태에서 시작하며, 부위 사이 공기 틈은 조직 깊이로 더하지 않는다. 팔을 지나며 이미 누운 탄을 몸통 입구에서 원래 자세로 되돌리지 않는다. 다만 yaw 자체는 S1의 깊이 곡선을 확장한 상태 모델이다. 각운동량, 공중 프리세션·재안정화, 파편마다의 궤적을 재현했다고 주장하지 않는다.

방호를 관통한 탄은 기존 방호 계산의 잔여 속도로 들어간다. 방호 직후 변형 직경·초기 yaw를 새로 만들어 넣지 않는다. 몸 밖에서는 기존 비행·벽·방호 계산을 이어 쓴다. 새 주탄 에너지에 따라 잔여 관통/피해 패킷을 조정하는 연결 규칙은 3D 튜닝이며, 벽/방호 수식과 구분한다. 파편 구름은 같은 표적의 이어지는 부위 안에서만 에너지를 전달한다. 벽·방호·다른 표적 또는 trace 끝에 도달하면 추적하지 못한 파편 에너지를 `untracedFragmentEnergyJ`에 기록하고 주탄 속도에 더하지 않는다. 이들의 수식을 고치지 않더라도 인체 출구 속도가 달라지므로 뒤쪽 벽과 두 번째 표적 결과는 달라질 수 있다. 탄약 데미지와 부위 HP **정의값은 보존**한다.

## 조직별 저항과 출처

같은 내부 판정 한 번에서 얻은 깊이 구간을 캐시하고 등가 젤라틴 깊이로 환산한다. 각 5 mm 셀마다 3D 조회를 하지 않는다. 같은 입력의 직접 적분과 등가 깊이 LUT 출력 차이도 별도 비교한다.

| 조직 | 사용하는 밀도 | 값의 근거와 한계 |
| --- | ---: | --- |
| 근육 참조 | 1,050 kg/m³ | S1과 동일 Geant4 공식 `G4_MUSCLE_SKELETAL_ICRP`. 연조직의 저항 환산비는 1로 두어 기존 젤라틴 보정을 유지한다. |
| 공기 찬 폐 | 340 kg/m³ | Hopkins 등, 2007, 6명 정상인의 누운 자세·FRC 오른쪽 폐 평균 0.34±0.08 g/cm³. 모든 자세·흡기량에 고정하는 것은 게임 근사다. |
| 피질골 | 1,920 kg/m³ | 같은 Geant4 파일의 `G4_BONE_CORTICAL_ICRP`. 밀도비를 항력비로 바꾸는 식은 실측이 아닌 근사다. |

[Geant4 참조표](https://raw.githubusercontent.com/Geant4/geant4/master/source/materials/src/G4NistMaterialBuilder.cc)는 S1에서 사용한 파일과 SHA256까지 같다. 이 표의 `G4_LUNG_ICRP` 1,040 kg/m³는 `Adult Lung congested`로 적혀 있으므로 공기 찬 폐의 밀도로 쓰지 않는다. 폐의 340 kg/m³는 [Hopkins 연구의 원문 초록](https://pubmed.ncbi.nlm.nih.gov/17395757/)에서 직접 확인했다. 출판사 전문은 HTTP403, PMC는 CAPTCHA, EuropePMC 전문은 HTTP500이었고, 수치와 조건은 HTTP200의 MED 초록에서 확인했다.

기존 뼈 판정은 속이 찬 외곽 진단 도형이다. 저항 구간에서는 두개골·척추 외곽에서 직접 교차한 뇌·뇌간·척수 구간을 빼서 내부 신경조직 전체를 단단한 뼈로 세는 일을 피한다. 실제 피질 두께·골수층을 메시에 맞춰 재구성한 것은 아니다. 라이브의 기존 뼈 외곽은 균질 피질골 근사이며, 해면골 값은 그 종류가 명시된 입력에만 쓸 수 있다.

뼈 접촉이 변형과 이른 tumbling을 일으킬 수 있고 조각이 인접 조직에 영향을 준다는 정성적 근거는 있다. [2024년 인조 평판골 실험](https://pmc.ncbi.nlm.nih.gov/articles/PMC11490459/)은 뼈 조각이 일반적으로 순간 공동의 범위 안에서 움직이며, 독립된 고에너지 탄환처럼 새 통로를 만든다는 일반화를 경계한다. [2020년 돼지 갈비뼈/FSP 실험](https://pmc.ncbi.nlm.nih.gov/articles/PMC7295711/)은 형상·yaw와 전달 에너지에 따른 파괴 차이를 보였다. 두 연구 모두 이번 숫자나 사람 팔다리의 분쇄·절단 문턱을 제공하지 않는다.

S2의 추가 yaw 등가깊이 1.2 m/m, 변형 단면 증가 4/m·상한 1.8배, 국소 뼈 조각 반경 최대 2.5 cm, 추가 영구 손상 부피 `뼈 전달 J/(2×10⁷ J/m³)`는 **튜닝**이다. 국소 반경은 해당 TC 반경 이하로 제한한다. 독립 원거리 뼈 파편탄을 생성하지 않는다.

## 뼈 안 신경구조와 얼굴 경로

뇌는 두개골, 뇌간·척수는 두개골·척추뼈와 연결한 기존 ID를 사용한다. 탄이 실제로 그 뼈 안으로 진입했는지와 깊이 순서를 캐시로 확인한 뒤 내부 신경구조의 순간 공동을 허용한다. 직접 뇌·뇌간 교차에 대한 S0 즉시 무력화는 유지한다.

뼈 바깥 얼굴·턱·목 근육만 지나는 탄의 TC와 비직접 파편이 뼈 안 신경구조에 전달되는 배율은 0이다. 차단한 TC 부피를 해당 콜라이더 체적으로 나눈 값에 0.25를 곱해 `concussionRisk`(0–1)로 기록한다. 이것은 임상 뇌진탕 확률이 아닌 **게임용 기록값**이며, 이번에는 의식·혈압·호흡 등 생리에 연결하지 않는다.

v39 실제 얼굴 경로의 직접 뇌·뇌간 교차는 0이었지만 TC-only 뇌간 손상 때문에 0.5833 s에 쓰러졌다. 같은 경로를 재실행한 결과는 아래 화면과 스냅샷으로 확인했고, 별도의 고정 얼굴 벤치가 통과한다는 사실로 이 실제 경로를 대신하지 않는다.

## 부위 HP와 단발 분쇄·절단

HP는 구조 내구도다. 원본 탄 데미지와 부위 HP 숫자를 바꾸지 않는다.

| 부위/단계 | 의미 |
| --- | --- |
| 팔·다리 HP 0 | 해당 기능 0. 그것만으로 의식이나 생명을 직접 끊지 않는다. |
| 머리 HP 0 | `head_structure_destroyed` 기록. 생사는 직접 뇌·뇌간 손상과 기존 생리가 결정한다. |
| 목 HP 0 | 기존 `lifeStatus≤5` 제한 유지. 새 자동 심정지·사망 지름길을 넣지 않는다. |
| 가슴·복부 HP 0 | `torso_destroyed`로 기존 심정지에 진입하고 기존 300 s 심정지→사망 경로를 따른다. |
| 분쇄 | 같은 한 발·표적·부위의 실제 직접 교차 뼈에 전달한 에너지 합 ≥250 J. `comminuted`, 해당 부위 기능 0, 치료 없이 회복 불가를 기록하고 기존 분쇄 골절 출혈 경로를 사용한다. |
| 절단 | 같은 한 발·표적·팔다리의 분리 구간을 합산한 전달 에너지 ≥8,000 J. `amputated`, 기능 0. 구조적 혈관 절단을 기존 주요혈관 출혈 경로로 처리한다. 메시 분리 없음. |

분쇄의 기능 0은 팔다리에만 한정하지 않는다. 머리 분쇄 역시 직접 뇌·뇌간 손상 없이 자동 사망을 만들지 않는다.

250/8,000 J는 **게임 튜닝이며 의학적 절단 기준이 아니다.** 같은 `TrainingMedical.record(event)` 호출 안에서 표적ID와 canonical부위별 prefix를 합산한다. 한 발이 같은 팔의 떨어진 구간을 두 번 지나면 두 구간을 더하지만, 다른 발의 에너지는 더하지 않는다. 에너지 문턱의 첫 교차에서만 단계·출혈 경로를 새로 발생시키며, 이후 구간에서 같은 처리를 반복하지 않는다. 각 국소 상처 채널과 실제 탄의 에너지는 그대로이고 HP·생리를 과거 구간에 소급 적용하지 않는다. 원본 누적 파괴 점수의 `partial_traumatic_loss`·`traumatic_amputation` 명칭은 S2에서 `destroyed`로 억제하고 기존 값을 비교 증거로 남긴다. 이것과 S2 한 발 에너지 자격을 혼동하지 않는다. 쓰러짐은 기존 의료 요약 인터페이스로만 래그돌에 전달한다.

기준 총구속도의 전체 비12.7 레지스트리 탄 가운데 최대 입사 에너지는 .338LM TAC-X 약7,287.32 J로 문턱 아래다. 지정된 5.45·5.56·7.62×39·7.62×51·권총군 최대는 M61 AP 약3,582.02 J다. 12.7×55는 최대 약1,485 J이며, 12.7×99/108은 약14.79–18.21 kJ여서 입사 에너지상 절단 문턱을 넘을 수 있다. **입사 에너지와 한 팔다리의 실제 전달 에너지는 다르다.** 탄별 실제 전달 최대값·문턱 여유와 대구경 결과는 실행 표에 따로 기록한다. 수동 속도 디버그는 레지스트리 기준속도의 절단 0건 보증 범위가 아니다.

## 예약 3번 칸 디버그 AK

기존 AK 모델·반동·사격음을 사용하는 시험 도구를 일반 장비와 분리한 3번 칸에 둔다. PC의 3키와 모바일 `3 · DBG AK` 버튼으로 고를 수 있다. 버튼은 기존 무기 전환 버튼 오른쪽에 붙인 최소44 px 높이의 별도 버튼이다. DOM 검사에서844×390 기준 약78×44 px였으며 이동·사격·기울이기·조준 버튼과 겹치지 않았다. 이 칸은 일반 장비 저장 공간으로 쓰지 않는다.

좌상단 탄약 선택 탭의 표는 원본 2D 형식의 탄명·구경·탄두 질량·기준 총구속도·관통 스펙·방호등급별 판정 정보를 레지스트리에서 읽는다. 표는114탄·17열이며 원본의8재질과Class1–7 대표 방호값·0–6 관통 등급을 같은 생성 방호 함수로 계산한다. 기준·유효 관통력, 피해, 제압, 반동, 정확도 배율, 방호 피해도 원본 항목으로 표시한다. 새 수치를 만들지 않는다. 현재 탄을 강조하고 터치 행 선택으로 즉시 장전한다. 무한탄창이며 HUD에 탄명과 `∞`를 표시한다. 844×390 가로 화면에서는 표를 스크롤해 끝까지 고를 수 있어야 한다.

기본 발사속도는 선택 탄의 레지스트리 기준 총구속도다. 수동 입력은 1–5,000 m/s의 시험 입력이며 비우면 기준값으로 복귀한다. 기본 영점은 원래 AK П 설정을 유지한다. 기본 꺼짐인 `선택 탄 기준 자동 영점`은 같은 AK 기하·비행 모델에서 선택 탄과 속도로 푼다. 비행 한계 안에 영점 조건에 도달할 수 없는 속도는 계산 실패를 표시한다. 모델·반동·소리가 임의 탄종과 일치하지 않으므로 대장에 **디버그용, 현실값 아님**으로 표시한다. 사격은 일반 `traceShot()`과 같은 의료 경로를 사용한다. 12ga의 레지스트리 펠릿 질량·개수는 보존하지만, 기존 trace는 트리거당 한 발 경로다. 이번에 새 산탄 분산·다중 펠릿 시뮬레이션을 추가하지 않았다.

디버그 AK는 일반 탄창 인스턴스를 갖지 않으므로, 원래 FPS팔의 탄창 숨김 조건에 디버그 예외 한 개를 추가한다. 빌드는 정확히 이 예외만 제거한 전체 파일의 SHA가 기존 파생 손그립 원본과 같아야 통과한다. 실제 소스SHA와 `debugMagazineVisibilityOnly`를 빌드정보의 `handling.gripSourceValidation`에 기록한다. 손가락GLB·생성 그립 데이터와 그 밖의 자세 코드는 보존한다.

## 검증 범위와 해석

균질 젤라틴 결과는 S1과 수치 동일해야 한다. S1이 맞추지 못한 AK74 두 번째 공동 지름·AK47 두 봉우리 형상까지 새로 맞췄다고 보고하지 않는다. 출처 조사도 한 가지 정정한다. S1 문서에는 EWS 2018 Chapter1이 개별 소총 도판을 생략한다고 적었지만, 같은 원문 PDF의12–13쪽에 Fig1-6 AK47·Fig1-7 M16/55gr·Fig1-8 M80가 실려 있음을 재확인했다. ## 240조건과 HP 보정 표

[기록 비교 보고서](../downloads/checks-s2-v40/report.md)·[HTML 표](../downloads/checks-s2-v40/report.html)·[원시 비교](../downloads/checks-s2-v40/comparison.json)에 같은 시험선240쌍을 남겼다. 상처 채널은212→213개, HP감소가 달라진 조건은131개, 의료 전이 시간이 달라진 조건은53개다. 분류는 선언한 조건별 임상 기대를 충족한PASS48개, 값만 기록하는RECORDED165개, 목표 부위 미도달27개다. **240개 전부 임상 목표 합격이라는 뜻이 아니다.** 통과/정지 변화는 이번 몸속 상태 교체의 의도된 결과다.

직접 심장 교차8조건은8.650–8.667 s에 쓰러져7–15 s창을 유지했다. 직접 대동맥 교차8조건의 의식 소실은28.383–30.000 s였다. Q의 여섯 불변 조건은 실제17시나리오의1,101,785검사에서 위반0건이었다.

거리 검사는7경로×3탄×5/50/100 m의63조건이다. [5/50 m HP 보정 범위30그룹](../downloads/checks-s2-v40/hp-calibration-ranges.csv)과[178개 전후 부위행](../downloads/checks-s2-v40/hp-calibration-details.csv)에 팔·다리·가슴·복부·머리별 한 발 감소와HP0 산술 발수를 기록했다. 7N6는 원래AK890 m/s, M855는 원래M4 879 m/s, PS는 양쪽 엔진에서 디버그 레지스트리718 m/s로 동일하게 쐈다. 이 표 때문에 원본 탄 데미지·부위HP를 바꾸지 않았다.

HP0까지 발수는`ceil(시작HP/관측한발감소)`다. 반복 실사격의 생존 발수나 누적 장기 손상을 예측하지 않는다. 주표는 명명한 대표 경로에서 처음 실제로 맞은 해당 부위를 사용한다. 앞 부위 뒤의 반대편 스침 등은 [모든 부수 피격 범위](../downloads/checks-s2-v40/hp-calibration-all-crossed-ranges.csv)에 별도로 보존하며, 이 표에는 수천~수만 발처럼 큰 산술값이 나올 수 있다. 경로·부위명과 실제 감소값을 함께 보아야 한다.

[일반 HP 경로와 장기 전용 대조42쌍](../downloads/checks-s2-v40/hp-vs-organ.csv)은 같은 실제 탄도·상처 채널을 사용하며, QA 메모리 후크에서만HP를 최대치로 유지하고`torso_destroyed` 관문을 껐다. 제품 설정이 아니다. 대표 단발 중HP0이 나온 조건은13개지만 몸통HP0 심정지는0개였으므로, 이 범위의 단발 결과만으로 여러 발HP경로와 장기경로 중 어느 쪽이 먼저 올지 확정하지 않는다. 구조HP0 규칙은 별도의 단위·실제 화면 사례로 검증했다.

기존 사로의600틱·6발·플레이어12자세 비교는 최종 소스에서 통과했다. 기존플레이 검사에는 관측 시점만 한 곳 조정했다. S2의 석고 뒤 다리 피격이 분쇄를 일으켜 의료 쓰러짐을 먼저 판정하면서, 원래QA의 ‘아직 안 쓰러졌으면 머리 사격’ 루프가 생략됐다. 재료 시험 뒤 실제 전투 한 틱을 진행해 기존 오버레이·래그돌 전이를 확인하도록 QA만 고쳤다. 런타임 버그를 수정한 변경이 아니며 같은 고정 소스 해시를 유지한다.


게임 ZIP에는 오프라인으로 읽을 수 있는`downloads/checks-s2-v40/report.html`·Markdown 보고서, 요약JSON, 비교·HP·장기·거리CSV와 성능 요약을 포함한다. 대용량 원시JSON/GZIP과 스크린샷은 ZIP에서 제외하고 GitHub 저장소의 같은 검증 폴더에 남긴다. 이 문서의 원시 기록·화면 링크는 저장소에서 확인할 수 있다. 정확한 ZIP 크기·해시·전체 파일 대조는 ZIP 밖의 배포 영수증에 기록한다.


기존 play·플레이어 피격·재시작·서 있는 동작 검사도 모두 통과했다. 최종 독립 HTML을1280×720·844×390에서 직접 열어 네이티브 입력으로 실행했고 오류0·외부 요청0이었다. 이때의 HTML 해시는 위의 최종 빌드와 같다. 성능 검사도 별도로 격리해 완료했다.


## 최종 격리 CPU 성능과 직접 계산 오차

[성능 요약](../downloads/checks-s2-v40/performance/performance-summary.md)과[원시 측정](../downloads/checks-s2-v40/performance/performance.json)은 순서를 균형 있게 바꾼4회 실행이다. 각 실행은10논리 발사자×1,200 RPM×10 s, 실제600틱·2,000발·2,000인체 진입이다. 실제 탄도·상처·의료 기록과 의료tick을 썼다. 렌더·AI·래그돌·음향은 제외한 Node CPU 부하 시험이며60Hz 게임 실행을 달성했다는 뜻이 아니다.

비율1.5배 기준은 통과했다. v39는94발 뒤 사후 처리에 들어간 반면S2는2,000발 모두 사망 전이었으며, 의식·전투 가능 여부와 사망 여부는 다르다. 물리·의료 모델과 이력이 달라서 이 비율을 순수 계산 오버헤드로 해석하지 않는다. 최적화 전 전체 피격p95는0.169755/0.173090 ms였다. 같은 실제 고유 입력1,000개에서 직접 셀 적분과 환산 깊이LUT를 비교했다. 최대 차이는 출구속도0.964352 m/s, 정지/점유 깊이0.807897 mm, 피해배율m0.003064686, 장기 심각도0.013349602, 뼈 전달에너지3.168407 J였다. 정지 여부·파편 여부 차이는0이지만 장기ID 집합 차이는2조건, 셀 개수 차이는1조건이었다. 따라서 LUT와 직접 적분을 수치 동일하다고 부르지 않는다. 최적화 전후의 출력 동일성과 별개인 근사 오차다.
