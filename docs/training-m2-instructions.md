# M2: 의료 아이템·IFAK 창·장비 칸·출혈 방향

v57(M1) 위에서 작업한다. 3D는 2D와 분리된 상태다. 2D 원본은 바꾸지 않는다. 바꾼 항목은 대장에 출처/원본/튜닝/사용자 설계값/게임 허용과 `2D 역이식 후보`를 표시한다.

## 전체 순서

| 단계 | 내용 |
|---|---|
| M1 | 의료탭 화면 (완료) |
| **M2 (이번)** | 의료 아이템, IFAK 창, 장비 칸 정리, 출혈 방향 수정 |
| M3 | 처치 1차: 지혈대·압박붕대·지혈거즈 |
| M4 | 처치 2차: 흉부 씰·바늘 감압·복부 |
| M5 | 타인 치료 |
| M6 | 장비별 격자(조끼·벨트·배낭) |

이번에도 처치 효과는 구현하지 않는다.

## 1. 출혈 방향: 열린 상처 통로와 팔다리 구획 용량

### 문제
v57 관찰 기록의 대퇴동맥 사례를 보면:
- 동맥 출혈 87–111 mL/s가 **전부** `limb_compartment`로 간다.
- 밖으로 나오는 건 근육 삼출 0.3 mL/s뿐이라 화면에 "스며나옴"이 뜬다.
- 30초 뒤 허벅지 안에 1.7 L가 쌓이는데, 구획 용량에 상한이 없다.

현실에서는 피부까지 열린 총상 통로가 있으면 사지 동맥 출혈은 대부분 그 통로로 밖으로 쏟아진다. M3 지혈대를 넣기 전에 바로잡아야 한다.

### 바꿀 것
대상은 목적지가 `limb_compartment`인 팔다리 혈관 출혈원이다. 몸통(흉강·복강·후복막)은 바꾸지 않는다.

- **통로에 따른 분배**
  - 상처 통로가 피부로 열려 있으면 출혈을 밖(`external`)과 안(`limb_compartment`)으로 나눈다.
    - 관통상(입구 + 출구): 대부분 밖으로
    - 맹관상(입구만): 안에 더 많이 고임
  - M1에서 만든 입구·출구 판정을 쓴다.
  - 분배 비율은 튜닝이다. 입구·출구 크기를 반영할 수 있으면 반영한다.
- **구획 용량**
  - 부위 구획별로 고일 수 있는 양의 상한을 둔다. 예: 허벅지 약 1–1.5 L. 외상 교범의 닫힌 대퇴골 골절 출혈량 등 출처를 찾고, 다른 부위(아래다리, 위팔, 아래팔)도 찾는다. 못 찾으면 튜닝이다.
  - 구획이 찰수록 안으로 가는 비율을 줄인다(압력 상승). 넘치는 몫은 열린 통로로 밖으로 나간다.
  - 구획 압력(또는 충만도) 값을 저장한다. 구획 증후군은 나중 일이고, 이번에는 관찰 표시 "단단하게 부어오름"까지만 한다.
- **불변**
  - 출혈원별 유량과 전체 출혈량은 바꾸지 않는다. 목적지 분배만 바꾼다.
  - 혈액량·혈역학·의식·심정지 시간축은 v57과 **바이트 단위로 같아야** 한다. 바뀌는 것은 `bloodPoolsMl` 분배와 관찰 표시뿐이다.
- **표시:** 대퇴동맥 관통상은 M1 관찰에서 "뿜음"으로 보여야 한다.

## 2. 왼쪽 장비 칸 정리

지금 왼쪽은 주무기·조준경·전환 버튼·무게를 좁게 욱여넣어 잘린다. 타르코프식으로 다시 배치한다.

- **위: 몸에 끼는 장비**
  - 슬롯: 헬멧, 방탄복, 전술조끼, 벨트, 배낭
  - 헬멧·방탄복은 지금 P01 방호 구성을 카드로 보여준다(읽기 전용: 이름, 플레이트·소프트아머 구성).
  - 전술조끼·벨트·배낭은 빈 슬롯 자리만 둔다. 수납은 M6에서 한다.
- **아래: 총 2정**
  - 주무기(M4)와 두 번째 주무기(AK)를 길쭉한 카드 2개로 둔다.
  - 각 카드: 이름, 장착 탄창(탄 수), 조준경 슬롯
  - 기존 장착·분리·조준경 장착·무기 전환 동작은 그대로다.
  - 디버그 AK(3번)는 디버그가 켜졌을 때만 작게 표시한다.
- **맨 아래:** 총 무게
- **크기:** 1280×720과 844×390에서 잘림 없이 보여야 한다. 장비 탭과 의료 탭 모두 해당한다.

## 3. 의료 아이템

새 아이템 종류 `medicalSupply`를 만든다. 사용자 설계값으로 IFAK 안에 들어간다. 장갑·테이프는 넣지 않는다. 지혈대도 IFAK 안에 넣는다(밖에 따로 다는 건 나중 작업).

| 아이템 | 수량 | 비고 |
|---|---:|---|
| 지혈대 (CAT) | 1 | |
| 지혈거즈 (QuikClot Combat Gauze 등) | 1 | |
| 압박붕대 (이스라엘 붕대 / Emergency Trauma Dressing) | 1 | |
| 흉부 씰 (통기형, 2개 1세트) | 1세트 | |
| 바늘 감압 키트 (14G 등) | 1 | |
| 비인두 기도기(NPA) | 1 | 미군 IFAK II 구성에 있으면 넣고, 처치 기능은 후속 |

- 구성은 미군 IFAK II 공식·제조사 자료로 확인해 출처를 단다. 확인 결과가 위 목록과 다르면 보고한다.
- **아이템마다:** 실제 제품 사양으로 무게·크기를 정하고 출처를 단다. 격자 크기는 실제 크기에서 정한다(튜닝).
- **설명 정보:** 이름, 짧은 설명, 적용 대상 종류.

  | 적용 대상 | 해당 아이템 |
  |---|---|
  | 상처 | 거즈, 붕대 |
  | 팔다리 영역 | 지혈대 |
  | 가슴 상태 | 흉부 씰, 바늘 감압 |
  | 기도 | NPA |

  이번에는 정보만 보여준다.
- **수량형:** 흉부 씰처럼 세트인 아이템은 남은 개수를 표시한다.

## 4. IFAK

### 컨테이너
- IFAK은 가방 안 아이템이다.
- **바깥 크기 2×2**(사용자 설계값).
- **내부 격자 3×3**(임시 튜닝. 3절 아이템 크기로 들어가는지 보고, 안 맞으면 크기 조합과 함께 보고).
- 처음 상태: 가방에 IFAK 1개, 안에 3절 구성이 들어 있다.
- **수납 규칙**
  - IFAK 안에는 `medicalSupply`만 넣을 수 있다.
  - 컨테이너 안에 컨테이너를 넣을 수 없다(IFAK 안에 IFAK 금지).
  - 내용물 무게를 IFAK 무게에 합산해 총 무게에 표시한다. D2 장비 질량 13.7 kg 입력은 이번에 바꾸지 않는다(인벤토리 연동 때).
- **소유 구조**
  - 아이템은 항상 정확히 한 소유자다.
  - 컨테이너 안 아이템은 `container:<instanceId>` 같은 소유 표기를 쓴다.
  - 지금 `rootOwner()`는 `weapon:`만 이해하므로 컨테이너 경로를 추가한다.
  - 순환 소유, 자기 안에 넣기, 사라진 부모 참조를 막는다.

### 떠다니는 창
- **열기:** IFAK을 더블 클릭 또는 더블 탭하면 창이 열린다.
  - 한 번 탭은 지금처럼 선택이다.
  - 7 px 이상 움직이면 드래그(기존 규칙)다.
  - 더블 탭 간격은 튜닝이다.
- **조작**
  - 제목 표시줄을 끌면 창이 움직인다.
  - 창 안의 아이템 드래그와 제목 표시줄 드래그가 섞이지 않게 영역을 나눈다.
  - `X`로 닫으면 창만 닫히고 내용물은 유지된다.
- **비모달:** 창이 열려 있어도 뒤의 3열 화면을 계속 조작할 수 있다.
- **화면 안 유지:** 창이 화면 밖으로 밀려 `X`를 못 누르게 되면 안 된다.
- **위치 기억:** 같은 실행 중에는 창 위치를 기억한다.
- **창 개수:** 컨테이너 하나당 창 하나. 지금 컨테이너는 IFAK뿐이다.
- **이동:** IFAK 창 ↔ 가방 사이 아이템 이동을 기존 `InventoryUI` 선택·드래그 경로로 한다. 새 드래그 엔진을 만들지 않는다.
- **양쪽 탭:** 장비 탭과 의료 탭 모두에서 창이 동작한다.

## 5. 의료 탭 강조

- 오른쪽 물품에서 의료 아이템과 의료 컨테이너를 은은하게 강조한다. 비의료 물품도 그대로 보인다.
- 아이템 선택 시 3절의 설명 정보를 보여준다.
- 상처를 선택했을 때 맞는 아이템을 더 강조하는 것과 처치 실행은 M3에서 한다.

## 6. 하지 않는 것

- 처치 동작, 처치 시간, 처치 효과, `controlFactor` 연결
- 구획 증후군 효과(표시만)
- 조끼·벨트·배낭 수납, 타인 치료, 주변 인벤토리, 단축키
- 탄도·관통·방호·HP·상처 수식, 출혈원 유량식

## 7. 검증

1. **출혈 방향:** M1의 대퇴동맥·팔근육·간·가슴 개방·사지 구획 사례에 대퇴동맥 맹관상과 위팔 동맥 사례를 더해, v57과 나란히 낸다.
   - 출혈원별 목적지 분배, 구획 누적량과 상한 도달 시점, 관찰 표시 문구
   - 혈액량·의식·심정지 시간축이 v57과 바이트 동일한지
2. **장비 칸:** 두 탭 × 두 화면 크기 캡처. 잘림이 없는지, 기존 장착·분리·조준경·무기 전환이 동작하는지.
3. **IFAK**
   - 더블 탭 열기, 창 이동, `X` 닫고 다시 열어도 내용물·배치 유지
   - 비의료 아이템 넣기 거부, IFAK 안에 IFAK 거부, 순환 소유 거부
   - 창 ↔ 가방 이동, 빠른 연타 시 아이템 복제·분실 없음
   - 창 제목 표시줄 드래그와 아이템 드래그 구분
   - 화면 가장자리에서 창이 화면 안에 남는지
   - 두 화면 크기, 마우스와 터치 각각
4. **아이템 데이터:** 아이템별 무게·크기·출처 표, IFAK II 구성 확인 결과.
5. **기존 기능:** 탄창·탄약·조준경 이동, 장전, M1 의료탭 표시, 쓰러진 뒤 의료 화면.
6. **기존 회귀:** 전체 테스트, 2D baseline 바이트 비교, 600틱 동일, S0 240조건·684채널 동일, 두 화면 오프라인 실행.
