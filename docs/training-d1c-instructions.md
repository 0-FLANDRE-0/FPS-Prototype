# D1c — 블랙아웃 잔상 + 사격 계산 최적화

사용자 지시. v53 위에서 작업하며 2D 원본은 변경하지 않는다. 대장은 출처 / 원본 / 튜닝 / 사용자 설계값 / 게임 허용을 구분한다.

1. 의식이 남아 있으면 최대 블랙아웃에서도 중앙 작은 원에 원래 밝기의20%를 남긴다. 흑백·강한 흐림·낮은 대비로 형체와 움직임만 보이고 조준 정보는 없어야 한다. 기존 터널 가장자리 어둠을 유지하며, 실제 의식 소실 때만 완전 검정으로 전환한다. 이후 기존 쓰러짐 흐름을 유지한다. “실제 블랙아웃은 시야 완전 소실, 20% 잔상은 게임 허용”을 대장에 적는다.
2. 탄도 비행, 벽 관통, 방호, 몸 겉 교차, 몸속 도형 교차, 상처 통로5mm 진행, 공동·장기 손상, 출혈원 생성, 기록/디버그를 먼저 측정한다. 플레이어/적 및 명중/빗나감을 나눈다. 큰 단계부터 줄이며 결과는 바이트 단위로 같아야 한다. 계산 순서/반올림을 바꿔 결과가 달라지는 최적화는 버린다. 다음 프레임으로 미루지 않는다. 목표(튜닝)는 명중p95≤4ms, 빗나감≤1ms이며 미달이면 남은 병목을 보고한다.
3. 탄도·관통·방호·상처·HP·출혈·의료 수식, 디버프2차, 치료는 변경/추가하지 않는다.
4. 대퇴동맥/심장 단독 최대 블랙아웃과 의식 소실을1280×720·844×390에서 캡처하고20%/완전 검정을 확인한다. 같은 장비에서 전후 교대 측정한다. S0 240조건,114탄×3속도×2부위684채널, 젤라틴 참조와 실제 사격 단일 손상 표가v53과 바이트 동일해야 한다. 플레이어1200RPM5초+적 동시 사격의 발당/프레임 시간과 끊김을 기록한다. 전체 테스트,2D baseline,600틱 동일, 두 화면 오프라인 실행을 검증한다.
