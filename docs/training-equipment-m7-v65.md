# M7 / v65 — 플레이트 교체·사이드 판·적 수색

v64 `2d2c688b9deeb78c1aa0b8d574a65082b8e2bf26` 위 3D 업데이트다. 원본2D, 의료·탄도·관통·방호 계산식과 탄약/방호 레지스트리, 모델·손가락 자산은 보존한다. GitHub Actions 없이 로컬 빌드한다.

## 사용

인벤토리에서 6B45 카드를 두 번 누르면 이동 가능한 비모달 플레이트 창이 열린다. 착용/가방/바닥/수색한 시체 모두 같다. 앞·뒤2×2, 사이드1×2이며 판을 선택한 뒤 길게 끌어 파우치·열린 배낭·주변·빈 판 자리로 옮긴다. 착용 중 뒤판은 잠기며 리그를 벗으면 열린다. 교체 시간은 게임/리얼리스틱/현실에서 착용1.5/5/10초, 탈착1/3/5초다. 기존 M4c 손 부상 배율과 상한을 쓰고, 이동·사격·피격은 중단한다. 완료 전에는 소속을 바꾸지 않는다.

적을 죽이거나 의식 없게 만든 뒤 약1.5m에서 몸통을 바라보면 수색 F/화면 버튼이 나온다. 첫 수색1/3/5초 뒤 오른쪽 대상 탭에서 실제 파우치·IFAK·탄창을 옮긴다. 헬멧/리그 벗기에는 M6 시간이 들며 실제 메시가 떨어진다. 입은 시체의 뒤판도 잠긴다. 떨어진 AK는 주변에서 줍는다. 정리 F는 남은 물품 삭제 안내 후5초 안에 다시 눌러 확정하며, 이미 가져간 물품은 유지한다. 의료 대상 상태는 읽기 전용이고 타인 치료는 추가하지 않았다.

설정의 플레이트 영역 표시에서 판 종류별 색과 이름을 본다. 앞/뒤/양옆 모두 같은 실제 판정 형상을 쓴다. 몸속 판정 디버그를 켜면 다음 적 Br4/Br5 강제 선택도 나온다. 기본은 적 한 명당50:50이고 앞뒤는 같은 종류다. 일반 아이템 생성 메뉴는 만들지 않았다.

## 데이터와 연결

판 아이템이 기존 `current/max/material/sourceId/localZones` 조건 객체를 직접 소유하며, 방호 센서는 그 객체를 참조한다. 피격 이력은 별도 배열이다. 판을 다른 리그나 다른 착용자에게 옮겨도 국부 손상·내구도·기록이 따라간다. `slotType`의 frontBack/side/frontSet/back과 호환 거부는 원본 데이터로 제한하고 백커는 원래 `computeBackerResolution`을 그대로 호출한다.

형상 대장은37항목(없음3+실물34)이다. [표](../downloads/checks-equipment-m7-v65/plate-shapes.csv), [분류 대장](equipment-m7-ledger.json), [출처와 실패한 조회](equipment-m7-sources.json)를 함께 본다. 제조사에서 확인된4800 규격, SAPI 미디엄 준용, 현행RMA1155Gen2 추정, Colossus 다중곡면 확인을 구분한다. 러시아제와 다수 제품은 치수 출처를 확인하지 못해 비슷한 급의 튜닝으로 표시한다. 기존 Granit Br4 25×30cm도 출처 확인 없이 사실로 승격하지 않았다. 곡면 반경·모서리 비율·사이드 장착 위치는 전부 튜닝이다. 위키 방호 수치는 쓰지 않았다.

앞뒤 위치는 v64 그대로다. 사이드는 좌우[±.161,1.285,.012]m, yaw±90°이며 6B45 겨드랑이 아래 소프트 영역 안쪽이다. 장착 판의 별도 시각 메시는 없다. 느슨한 판도 보이지 않는 물리 프롭과 주변 목록으로 처리한다.

팔과 가슴이 이어진 인체 프록시가 그 안의 사이드 판을 건너뛰던 연결을 수정했다. 새 사이드 판의 **실제 재질 구간만** 인체 경로에서 분리하여 기존 `traceShot`이 팔→판→몸통 순으로 잔여 속도를 전달한다. 사이드가 없거나 닿지 않으면 기존 경로 객체를 그대로 반환한다. 기존 앞뒤 경로·방호·인체 수식은 변경하지 않았다.

적은 실제 헬멧/리그/4판/벨트, AK와 약실1+탄창29발, 예비30발 탄창4개, 기존 IFAK7물품을 가진다. 발사·빈 탄창 교환·무기 낙하·수색이 같은 아이템을 사용한다. 적당21아이템이다. 기존 결정론 LCG 두 표본의 합을 modulo1로 섞어 .5로 나누며 강제 선택도 같은2표본을 소비한다.

## 남은 한계

실제 휴대폰 하드웨어는 미검수다. 대부분 판의 치수/컷 및 모든 반경은 검증된 실측이 아니다. 준비된 래그돌 기본 장비 질량은 사이드 추가로18.3kg(인체80kg 합98.3kg)이지만, 수색 중 모든 탄창/판 변경을 분절 질량으로 매번 재분배하는 후속 기능은 없다. 플레이어 휴대 질량과 D2/발소리는 실제 아이템을 매번 읽는다. 기존 의료 출처 미확인과 달리기 재출혈 목표 미달은 유지한다.
