# S2 몸속 속도 통일: 3D 연결 계약

기준은 v39/S1이다. 기존 `training-s1-pipeline-audit.md`의 **계산용 속도와 실제 인체 출구속도를 분리한다**는 계약을 이번 S2에서 교체한다. `src/**`, 탄약 레지스트리의 데미지·질량, 부위 HP, 원본 생성 코드, 벽·방호·비행 수식은 수정하지 않는다.

## 한 번의 상처 계산

`traceShot()`이 실제 인체 진입점에 도착하면 `TrainingPhysics.describeBodyPath()`가 기존 내부 형상 조회를 한 번 실행한다. 입력은 실제 점유 인체 경로 전체이며, 이 시점에서는 최종 정지 깊이를 아직 모른다. 기존 직접 교차, 근접 교차, 공동 후보 외에 조직별 구간과 뼈 둘레 구조 식별자를 캐시한다.

새 `body-channel.js`의 `resolveBodyChannel()`은 점유 셀을 같은 부위의 연속 구간으로 합친 뒤 각 부위에 `computeWoundChannel()`을 한 번 호출한다. 결과는 `part.woundChannel`에 보존한다. `TrainingMedical.record()`는 이 객체를 재사용한다. 의료 단계에서 상처 곡선을 다시 계산하지 않는다.

각 부위는 직전 부위의 실제 출구속도, 남은 주 탄자 질량, yaw, 변형 면적, 파편 상태를 이어받는다. 분리된 인체 경로 사이에 공기가 있으면 기존 비행 모델이 감속한 속도를 다음 경로에 넣는다. 공기 틈은 조직 깊이에 더하지 않는다. 이미 팔에서 누운 탄의 yaw를 몸통에서 0으로 돌리지 않는 것은 물리적으로 타당한 연속성이다. 다만 현재 yaw는 1D 모델 상태이며, 공기 중 탄자 자세 운동이나 세차 운동을 계산하는 6자유도 모델은 아니다.

## 실제 출구와 에너지

| 필드 | S2 의미 |
| --- | --- |
| `part.velocityInMps`, `velocityOutMps` | 해당 부위의 실제 주 탄자 입사·출구속도 |
| `part.massInKg`, `massOutKg` | 해당 부위 전후 주 탄자 질량. 떨어져 나온 파편 질량은 주 탄자로 복원하지 않음 |
| `part.energyShareJ` | 같은 상처 모델이 이 부위에 전달한 에너지 |
| `projectileEnergyInJ`, `projectileEnergyOutJ` | `½mv²`로 계산한 주 탄자 에너지 |
| `fragmentEnergyInJ`, `fragmentEnergyOutJ` | 별도로 보존한 아직 조직에 전달되지 않은 파편 구름 에너지 |
| `energyInJ`, `energyOutJ` | 주 탄자와 파편 구름 에너지의 합계 |
| `stopDepthM` | 새 모델이 정한 실제 체내 정지 깊이. 비정지이면 `null` |
| `untracedFragmentEnergyJ` | 별도 파편 광선을 만들지 않으므로 뒤의 벽·다른 사람에 재사용하지 않은 잔여 파편 에너지 |

각 부위와 전체 경로에서 입사 에너지 = 조직 전달 에너지 + 출구 주 탄자 에너지 + 출구 파편 구름 에너지이다. 파편 구름의 에너지를 주 탄자 속도로 환산하지 않는다. 같은 사람의 연속 부위·경로에서는 구름 상태를 이어 쓰며, 방호·벽·다른 표적을 만나거나 추적을 마치면 미추적 파편 에너지로 기록하고 구름 에너지를 제거한다. 파편의 독립 궤적·공기저항·벽 관통은 이번 구현 범위 밖이다.

실제 체내 정지가 나오면 그 깊이에서 경로를 끝낸다. 앞서 얻은 직접 교차·조직 구간·공동 후보 캐시를 정지 깊이로 잘라 의료에 전달한다. 정지점 뒤의 뼈나 장기는 직접 피격으로 승격하지 않는다. 끝의 `annotateInternal()`은 이미 캐시한 S2 경로를 다시 조회하지 않는다.

## 벽·방호와 연결하는 3D 어댑터

기존 벽·방호 공식은 잔여 관통력·데미지·속도·탄약 객체를 입력으로 읽는다. 인체 뒤의 새 주 탄자 상태를 이 인터페이스에 연결하기 위해 부위마다 다음을 적용한다.

`r = clamp((m_out × v_out²) / (m_in × v_in²), 0, 1)`

`잔여 관통력 *= r`, `잔여 데미지 *= r`

이 비례 연결은 **3D 어댑터 튜닝**이며 실측 관통력 관계가 아니다. 레지스트리 데미지를 바꾼 것이 아니다. HP 감소에는 각 부위 입사 데미지 × 기존 의료 조직 배율 × 그 부위의 상처 배율을 한 번 적용한다. 인체 저항 비용을 이 비율 앞이나 뒤에 추가로 차감하지 않는다.

`s.velocity`와 `s.massKg`는 새 실제 주 탄자 상태다. `s.ammo`의 발사별 복사본에만 `projectileMassG`를 남은 주 탄자 질량으로 넣으므로 기존 방호 운동에너지·마모 도우미도 현재 질량을 읽는다. 원본 레지스트리는 수정하지 않는다. 기존 방호 결과가 내보내는 `residualMassPenalty` 등은 일반 탄의 실제 질량 값이 아니므로 새 질량으로 해석하지 않는다. 일반 방호 경로는 이번에도 수치적인 새 질량·yaw·변형 직경을 제공하지 않는다. 원래 방호가 남긴 속도는 그대로 몸에 들어가며, 새 방호 후 초기 yaw를 만들지 않는다.

소총 외 다중 산탄도 기존과 같이 한 번의 `traceShot()`은 한 탄자의 질량을 쓴다. 레지스트리의 `projectileCount`를 주 탄자 질량에 곱하거나 새 산포 광선을 생성하지 않는다. 디버그 총기의 산탄 선택이 완전한 다중 펠릿 시뮬레이션이라는 의미는 아니다.

## 조직과 뼈 둘레 캐시

폐·뼈 구간은 원래 직접 교차 구간에서 만든다. 뇌/뇌간은 `skull`, 목·가슴·복부 척수는 각각 `cervical-spine`, `thoracic-spine`, `lumbar-spine`에 대응한다. 뼈 진입 이력은 같은 사람 안에서만 유효하다. 다음 사람을 만나면 식별자 이력을 비워 앞사람의 두개골 관통이 뒷사람의 뇌 공동 피해를 허용하지 않게 한다.

기존 뼈 콜라이더는 속이 찬 포락 형상이다. S2 저항용 뼈 구간에서는 그 안의 실제 뇌·뇌간·척수 교차 구간을 빼 내부 전체가 피질골인 것처럼 계산하지 않는다. 원래 `internalHits`의 뼈 교차는 그대로 유지하므로 기존 골절 판정의 근거는 보존한다. 저항용 뼈 구간은 균일 피질골 근사이며 피질·해면골의 실제 분포를 측정한 모델이 아니다. 실제 장내 공기 도형이 없으므로 새로운 빈 공간을 지어내지 않는다.

뼈 진입 전의 바깥 경로가 만드는 신경 구조 공동 피해는 S2의 차폐 계수를 적용하고 `concussionRisk`로만 기록한다. 이 위험도는 이번에 어지러움이나 별도 생리 효과를 만들지 않는다. 직접 뇌·뇌간 교차의 S0 규칙은 유지한다.

## 비교 경로와 검증

기존 `protection.js:resolveBodyPath()`와 `BODY_EXIT_RULE_ID`는 수정하지 않았다. `traceShot(..., {bodyModel:'legacy'})` 또는 `createPhysics({bodyModel:'legacy'})`로 명시적으로 실행한다. 선택한 의료 모델이 legacy이면 게임 사로도 이 경로를 쓴다. 전투 적과 플레이어의 v2 의료 사격 및 전투 예열은 S2 경로를 명시한다.

`tests/training-body-s2.test.mjs`는 부위 상태 이어짐과 에너지 보존, 새 정지 깊이와 미방문 부위 제외, 뼈 내부 구간 분리, 캐시 clipping, legacy 분리, 두 번째 사람의 잔여 질량·속도 및 파편 에너지 중복 방지를 확인한다. 보호 경로의 원본 문턱 시험은 명시적 legacy 설정으로 계속 검증한다. 실제 새 모델의 관통·정지 결과는 S2 비교 대장에 별도로 남긴다.

2D 역이식 후보: 상처 모델을 속도·에너지의 단일 출처로 쓰는 설계와 부위 상태 전달은 **예**. 3D 형상 조회·캐시와 현재 잔여 관통력 연결값은 **자동 역이식하지 않음**. 특히 잔여 관통력 비례식은 후속 검토가 필요한 튜닝이다.
