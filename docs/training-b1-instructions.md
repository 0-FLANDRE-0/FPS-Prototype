# B1: 출혈 모델 고도화 (치료 연결 준비 포함)

v42 위에서 작업한다. 3D 의료는 2D와 분리된 상태다. 바꾼 항목은 대장에 출처/원본/튜닝과 `2D 역이식 후보`를 표시한다. 2D 원본은 바꾸지 않는다.

## 배경

v42의 서기 복부 M855 3발 시험(S3b `actual-M855-abdomen`)에서 첫 1초 출혈이 약 230 ml/s였다.
- 이 값은 분당 13.8 L로, 안정 시 심박출량(약 5 L/min)은 물론 심박 150 상태의 심박출량보다도 크다.
- 그 결과 쓰러짐 10.5 s, 출혈성 심정지 15 s로, 직접 대동맥 손상(의식 소실 약 28 s)보다 빨랐다.

원인 후보는 두 가지다.
- 상처별 출혈률을 더하기만 하고 전체 합에는 상한이 없다. S1의 148.75 ml/s 상한은 대동맥 하나에만 걸려 있다.
- 순간 공동이 닿기만 한 혈관도 계수 0.12로 열린 출혈 상처가 된다.

이번에는 출혈 모델을 정리하고, 나중에 치료 탭이 바로 연결될 수 있게 출혈원 구조를 만든다. **치료 자체는 만들지 않는다.**

## 1. 출혈원 구조

손상된 혈관마다 출혈원(bleed source) 하나를 만든다. 근육·모세혈관 삼출은 상처마다 별도 출혈원 하나로 둔다. 각 출혈원은 다음 필드를 가진다.

| 필드 | 내용 |
|---|---|
| `id`, 혈관 이름, 2D 식별자 | 기존 몸속 레이어 대응 |
| `vesselKind` | artery / vein / capillary |
| `injuryType` | `partial_laceration` / `complete_transection` / `ooze` |
| `orificeAreaMm2` | 현재 유효 구멍 면적 |
| `destination` | `external` / `thoracic_left` / `thoracic_right` / `peritoneal` / `retroperitoneal` / `limb_compartment` |
| `controlClass` | `limb_compressible` / `junctional`(사타구니·겨드랑이·목) / `intra_abdominal` / `intra_thoracic` / `none` |
| 위치 | 부위와 뼈 기준 위치. 팔다리는 그보다 위쪽(심장 쪽) 지점을 함께 기록한다(나중에 지혈대 위치 판정용). |
| `flowMlPerS`, `cumulativeMl` | 현재 출혈률, 누적량 |
| `controlFactor` | 0–1, 기본 1. 나중에 치료가 곱하는 자리. 이번에는 항상 1이다. |

- `intra_thoracic`은 개인 처치 불가 분류다. 대장에 "사용자 설계"로 적는다.
- 기존 상처·의료 기록에서 출혈원 목록을 볼 수 있게 한다.

## 2. 흐름 계산 통일

모든 혈관 출혈원을 S1 대동맥과 같은 방식으로 계산한다.

- **Q = Cd · A · √(2ΔP/ρ)**
  - 동맥의 ΔP는 현재 MAP다.
  - 정맥의 ΔP는 정맥압이다. 값은 출처를 찾고, 못 찾으면 튜닝으로 둔다.
- **혈관별 상한:** 그 혈관의 정상 혈류 × 예비 배율. 혈관별 정상 혈류는 생리학 자료에서 출처를 찾는다. 못 찾으면 혈관 지름 기반 추정·튜닝으로 표시한다.
- **전체 상한:** 모든 출혈원의 합이 그 순간 기존 혈역학이 계산한 심박출량을 넘지 않는다. 넘으면 출혈원별로 비례 축소한다. 이것은 "심장이 내보낸 것보다 많이 샐 수 없다"는 물리 조건이다.
- 2D 시절 혈관 등급별 출혈표(major_named / named_branch 등)를 쓰던 혈관도 이 식으로 바꾼다. 근육·모세혈관 삼출(`ooze`)은 기존 R3-a 방식(작은 값, 수 분 안에 대부분 멈춤)을 유지한다.
- 심장 펌프 손상(S0·S1)은 이번 범위가 아니다. 심장 7–15 s 결과가 유지돼야 한다.

## 3. 부분 손상과 완전 절단

- 탄의 영구 공동이 혈관을 가로지른 비율(S1 교차 정보)로 나눈다.
  - 일부만 가로지르면 `partial_laceration`이다.
  - 혈관 지름 대부분을 지나가면 `complete_transection`이다.
  - 나누는 기준은 튜닝이다.
- 완전 절단된 동맥은 양끝이 오그라들고 수축해 시간이 지나며 유효 구멍이 줄어들 수 있다. 부분 손상은 그렇지 않아 계속 출혈한다. 외상 문헌에서 출처를 찾는다. 감소 속도는 튜닝이다.
- 주요 명명 동맥의 완전 절단도 자연적으로 0이 되지는 않게 한다. 하한은 튜닝이다.

## 4. 순간 공동이 닿은 혈관 = 타박

- 탄이 직접 지나가지 않고 순간 공동만 닿은 혈관은 출혈원을 만들지 않는다. 대신 `vesselContusion`(혈관, 심각도)으로 기록한다.
- 이번에는 생리 효과가 없다. 나중에 혈전·말단 혈류 장애와 연결할 자리다.
- 근거는 "탄력 있는 혈관은 순간 공동에 찢어지기보다 타박·내막 손상을 입는 경우가 많다"는 정성 자료다. 출처를 찾으면 달고, 못 찾으면 설계 기대로 적는다.
- S1의 혈관 조직 계수 0.12 중 출혈 쪽 연결을 이 규칙으로 바꾼다. 유효 손상량(HP 계산)은 그대로 둔다.

## 5. 피가 고이는 곳 추적

- `destination`별 누적 혈액량을 따로 쌓는다.
- **혈흉:** 좌우 흉강에 고인 양만큼 그쪽 폐의 호흡 효율을 떨어뜨린다. 기존 호흡 입력에 연결한다.
  - 기준점으로 "대량 혈흉 > 1,500 mL"(ATLS 등 외상 교범) 같은 출처를 찾아 단다. 곡선 모양은 튜닝이다.
- **기흉과 분리:** 혈흉(피)과 기흉(공기)은 서로 다른 필드로 둔다. 나중에 바늘 감압은 공기에만, 흉부 밀봉(삼면 밀폐 드레싱, 배출 밸브형/비배출형)은 흉벽 개방 상태에만 작용하게 하기 위해서다.
  - 기존 흉부 외상 모델의 필드를 조사해 보고한다.
  - 필요하면 다음 필드를 추가만 한다: 흉벽 개방(`chestWallOpen`), 긴장성 공기량(`tensionAir`), 혈흉량(`hemothoraxMl`).
  - 이번에는 처치 효과를 넣지 않는다.
- 복강·후복막·팔다리 구획에 고인 양은 기록만 한다.

## 6. 자연 지혈

- 작은 혈관·분지: 시간이 지나면 유효 구멍이 줄어든다. MAP가 낮을수록 더 빨리 줄어든다. 정맥은 동맥보다 쉽게 멈춘다.
- 주요 명명 동맥: 기존 R3-c대로 자연 지혈이 없다(3번 완전 절단의 수축 효과는 별도).
- 시간 상수는 튜닝이다. 기존 R3 대장 항목과의 대응을 적는다.

## 7. 디버그 표시

기존 "몸속 판정 표시"를 켜면 다음을 보여준다.
- 출혈원 목록: 혈관, 유형, 고이는 곳, 처치 분류, 현재 ml/s
- 출혈 합계와 현재 심박출량 상한
- 고이는 곳별 누적량(혈흉 좌/우 포함)

## 8. 하지 않는 것

- 치료 아이템과 처치 동작(지혈대, 압박, 지혈제, 폼, 복부 대동맥 압박대, TXA, 흉부 밀봉, 바늘 감압)
- 응고장애, 체온 저하, 혈전·말단 혈류 장애 효과, 구획 증후군
- 바닥 핏자국 등 화면 표현
- 탄도·관통·방호·상처 통로·HP 계산

## 9. 검증

1. **복부 M855 3발 재실행(S3b와 같은 조건):**
   - 수정 전후 출혈원별 내역(직접/공동, 혈관, ml/s)을 표로 낸다.
   - 전체 출혈이 심박출량을 넘지 않는지 확인한다.
   - 쓰러짐·심정지 시각 변화를 보고한다.
2. **단일 손상 시나리오:**
   - 대퇴동맥 부분 손상과 완전 절단 비교
   - 경동맥
   - 흉부 대동맥(약 30 s 유지 여부)
   - 간
   - 하대정맥(도형이 있으면)
   - 폐(혈흉 누적과 호흡 저하)
   - 심장(7–15 s 유지)
   - 팔 근육만(삼출이 수 분 안에 멎는지)
3. **여러 발 부하:** 몸통 5발, 팔다리 5발에서 전체 상한이 걸리는지, 출혈원 비례 축소가 맞는지 확인한다.
4. **불변 조건:**
   - R2 "심정지 시점 손실 40–60%"
   - R의 "혈관 안 건드린 팔다리 상처는 비치명, 주요 동맥은 치명"
   - Q의 6개
5. **S0 시험장 240개 재실행:** v42 대비 변화.
6. **성능:** 출혈원이 많을 때(20개 이상) 의료 틱 시간.
7. **기존 회귀 검사:** 전체 테스트, 2D baseline 바이트 비교, 600틱 비교, 두 화면 오프라인 실행.
