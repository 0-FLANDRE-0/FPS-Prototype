# D1: 통증·아드레날린·출혈 시야·AI 적용

v50 위에서 작업한다. 3D는 2D와 분리된 상태다. 2D 원본은 바꾸지 않는다. 바꾼 항목은 대장에 출처/원본/튜닝/사용자 설계값과 `2D 역이식 후보`를 표시한다.

## 배경

2D에서 넘어온 의료 계산이 3D에서도 매 틱 돈다. 하지만 몸과 화면에는 아무것도 걸려 있지 않다.

- **상태값**
  - `pain`(4단계 0–30/30–60/60–80/80+), 부위별 `bodyParts.*.pain`, `painFloor`
  - `stressResponse`: `threatDrive`, `combatArousal`, `adrenaline`, `panic`, `painMasking`, `perceivedPain`, `postCombatCrash`
  - `consciousness`, `shock`, `systolicBP`, `heartRate`, `breathingEfficiency`, `tissuePerfusion`, `oxygenDelivery`
- **성능 배율**
  - `aimMul`, `moveMul`, `reactionMul`, `reloadMul`, `stanceChangeMul`, `weaponHandlingMul`
  - 지금은 `aimPerformance` 같은 요약 수치에만 쓰인다.
- **이미 몸에 걸린 것**
  - v46 청력 저하·이명
  - 기능 0이 된 다리·척수의 쓰러짐(v34 래그돌)

이번 작업은 새 생리 계산을 만드는 것이 아니다. **이미 있는 상태값을 플레이어 몸·화면과 적 AI 행동에 연결한다.** 생리 수식은 바꾸지 않는다.

## 공통 규칙

- **입력은 느끼는 통증이다.** 실제 `pain`이 아니라 `perceivedPain`(아드레날린 가림 반영)을 쓴다. 교전 중엔 버티고, 끝나고 탈진·통증이 몰려오는 흐름이 그대로 나와야 한다.
- **통증·MAP만으로는 쓰러지지 않는다.** v34 규칙을 유지한다. 쓰러짐은 기존 의식·기능·심정지 경로만 쓴다.
- **건강하고 평온한 상태에서는 v50과 결과가 정확히 같다.** 모든 효과는 입력이 기준값일 때 0이다.
- **흔들림 난수는 결정론이다.** 시간 기반 노이즈나 기존 결정론 난수를 쓴다. `Math.random`은 쓰지 않는다.

## 1. 조준: 탄 퍼짐이 아니라 총 흔들림

2D의 `aimMul`은 탑뷰에서 탄 퍼짐을 뜻한다. 3D 플레이어에게는 **총과 조준선의 실제 흔들림**으로 바꾼다. 탄 자체의 퍼짐은 추가하지 않는다.

2D `aimMul` 계산 안의 기여 항목별로 흔들림 종류를 나눈다. 각 기여의 크기는 2D 식에서 그대로 읽는다.

| 원인 (2D 항목) | 흔들림 |
|---|---|
| 아드레날린 0.7 초과 | 빠른 잔떨림. 생리적 떨림 대역(대략 8–12 Hz)은 출처를 찾는다 |
| 공황 | 잔떨림 + 불규칙한 튐 |
| 느끼는 통증 | 느리고 큰 흔들림 |
| 팔 기능(`armFn`) | 느린 흔들림 + 처짐(총이 아래로 내려옴) |
| 호흡 효율 | 기존 `breath` 흔들림의 크기·빠르기 증가 |
| 심박 150 초과 | 심박 주기에 맞춘 작은 맥동 |
| 의식·조직 관류 | 느린 표류 |

- `aimMul`과 흔들림 크기의 관계 곡선은 튜닝이다. 곡선은 대장에 적는다.
- 흔들림은 기존 조준 시스템(`breath`, `walkSway`, `freeAim`, `weaponResponse`) 위에 더한다. 카메라 움직임 프리셋(안정형/중간/바디캠)과 `weaponMotion` 설정으로 줄일 수 없다.
- `weaponHandlingMul`은 무기 반응(`weaponResponse`)과 조준 진입 속도를 늦춘다. `reloadMul`은 장전 동작 시간을, `stanceChangeMul`은 앉기·일어서기 시간을 늘린다.
- `reactionMul`은 플레이어에게 쓰지 않는다. 사람의 반응을 입력 지연으로 흉내 내지 않는다. AI에만 쓴다.

## 2. 부위별 통증

부위별 `bodyParts.*.pain`(없으면 그 부위 상처에서 나눠 만든 값, 튜닝)과 통증 단계를 쓴다. 가림은 전체와 같은 `painMasking`을 적용한다.

- **팔:** 1절의 흔들림·처짐 증가, 장전·조준 진입이 느려진다. 다친 쪽 팔이 더 크게 반영된다.
- **다리:**
  - `moveMul`로 걷기·달리기 최고 속도를 제한한다.
  - 다친 쪽으로 절뚝인다: 걸음 위상 비대칭, 다친 발 디딜 때 시점이 처진다.
  - 통증 단계 2 이상이거나 다리 기능이 문턱 아래면 달리기를 막는다(문턱 튜닝).
- **가슴·복부:** 호흡이 얕고 빨라진다(1절 호흡 흔들림). 달리기 중이면 더 커진다. 복부 HP 0의 통증 바닥 95(S3b)도 여기로 이어진다.
- **통증 4단계(80+):** 2D는 "거의 활동 불가"다. 쓰러뜨리지 않고 모든 동작 속도와 흔들림을 최대 쪽으로 보낸다.
- 머리·목 통증은 이번에 따로 처리하지 않는다(뇌진탕은 다음 단계).

## 3. 아드레날린·공황·탈진

2D `stressResponse` 값을 그대로 쓴다.

- **잔떨림:** 1절. 아드레날린이 적당하면(0.3–0.7) 2D 반응 향상(+최대 6%)은 AI에만 적용한다.
- **터널비전(주의 협착):** 주변이 조금 흐려지고 어두워진다. 출혈 터널(4절)보다 약하고 성질이 다르다(어두워지는 게 아니라 흐려짐 위주).
- **소리 안 들림(청각 배제):**
  - 각성이 높으면 들리는 소리 전체가 작아지고 먹먹해진다(최대 감소량 튜닝).
  - Artwohl(2002, FBI Law Enforcement Bulletin)의 총격 경찰관 지각 왜곡 보고 비율(소리 감소, 터널비전 등)을 출처로 확인해서 단다.
  - v46 청력 저하와 곱해서 이중으로 깎이지 않게 합친다. 합치는 방식은 대장에 적는다.
- **탈진(`postCombatCrash`):** 떨림이 느리고 크게 바뀐다. 조준 진입·장전이 느려진다. 2D의 이동 −15%는 이미 `moveMul`에 들어 있다.
- 시간이 느려지는 현상(slow motion)은 넣지 않는다.

## 4. 출혈·저혈압 시야

항공의학의 G-LOC 순서를 따른다: **색 빠짐 → 주변 어두워짐 → 터널 → 블랙아웃 → 의식 소실.** 망막이 뇌보다 관류 저하에 먼저 반응해서, 시야가 먼저 꺼지고 의식은 나중에 잃는다. 이 순서와 근거를 항공의학 자료에서 찾아 단다.

- **입력:** 기존 MAP(혈압), `tissuePerfusion`, `oxygenDelivery`, `consciousness`.
  - 단계별 문턱은 출처를 찾고, 못 찾으면 튜닝이다.
  - 블랙아웃은 기존 의식 소실 시각보다 앞서야 한다. 의식 판정 자체는 바꾸지 않는다.
- **일어설 때 하얗게 날아감(기립성):**
  - 앉기·엎드림 → 서기 전환 때, 혈액 손실과 저혈압 정도에 비례해 잠깐 시야 단계를 올린다.
  - 지속 시간은 초기 기립성 저혈압 문헌 값을 찾아 쓰고, 없으면 튜닝이다.
- **눈 감김:**
  - 의식이 떨어지면 눈이 느리게 감겼다 뜨는 효과를 낸다. 의식이 낮을수록 길고 잦다(튜닝).
  - 평상시 깜빡임은 넣지 않는다(바디캠 화면).
- **의식 소실·사망:** 기존 전투 불능 화면 흐름을 따른다. 그 앞까지 끊기지 않게 이어지게만 한다.

## 5. 화면 효과 구현

- 기존 바디캠 렌즈 처리(`lensStrength` 렌즈 왜곡 단계)에 붙인다. 새 전체 화면 패스가 필요하면 하나만 추가한다.
- 효과 종류: 채도 저하, 주변 어둡게(반경·부드러움), 주변 흐림, 전체 어둡게(블랙아웃), 눈꺼풀 닫힘, 하얗게 날림.
- 설정에 **"화면 효과 강도" 0–100%** 를 둔다(기본 100%).
  - 화면 효과에만 적용한다.
  - 흔들림·속도·동작 시간 같은 몸 효과는 이 설정으로 바뀌지 않는다.
- 조준경(ACOG·Vudu 등) 화면에도 같은 효과가 걸려야 한다.

## 6. 적 AI 적용

같은 의료 값을 적 AI의 기존 행동 값에 곱한다. Sector04 적 설정(`reactionS`, `aimStartDeg`, `aimFloorDeg`, `aimConvergencePerS`, `shotIntervalS`, `walkSpeedMps`, `visionFovDeg`)을 기준으로 한다.

| 의료 값 | AI 행동 |
|---|---|
| `aimMul` | 조준 수렴 속도 ↓, 최소 오차(`aimFloorDeg`) ↑ |
| `reactionMul` | 반응 시간 ↑ (아드레날린 적정 시 향상 포함, 2D 원본) |
| `weaponHandlingMul`, `reloadMul` | 사격 간격·장전 시간 ↑ |
| `moveMul` | 걷기 속도 ↓, 절뚝임은 애니메이션 재생률·위상으로 |
| 터널비전 | 시야각 ↓ (감소량 튜닝) |
| 청각 배제 | v46 청각 판정 문턱 ↑ |
| 출혈 시야 단계 | 시야 거리·감지 ↓ |

- 배율→행동 값 변환은 튜닝이다.
- AI 확률은 기존 결정론 난수를 쓴다.

## 7. 디버그 표시

기존 의료 기록 화면에 다음을 추가한다.
- 느끼는 통증, 부위별 통증, 아드레날린·공황·탈진, 시야 단계, 청각 배제 dB
- 흔들림 원인별 크기
- AI의 현재 배율과 변환된 행동 값

## 8. 하지 않는 것

- 뇌진탕(어지러움·흐림·비틀거림), 팔·다리 지구력, 숨참, 의료 상태 UI → 다음 단계
- 시간 느려짐, 심장 박동·숨소리 소리
- 치료, 진통제
- 의료 생리 수식, 쓰러짐·심정지 판정, 탄도·관통·방호·HP

## 9. 검증

1. **기준 상태:** 건강·평온에서 v50 대비 600틱·6발의 카메라·총구·방향·반동·스프링이 정확히 같다.
2. **아드레날린 0→1 스윕:** 흔들림 크기, 주파수 스펙트럼(잔떨림 대역 피크), `aimMul`과의 관계.
3. **부위별 통증(실제 사격, 근육만):**
   - 팔, 다리, 복부(HP 0 포함) 각각
   - 흔들림, 장전 시간, 조준 진입 시간, 최고 속도, 절뚝임, 달리기 막힘
   - 교전 중(가림) → 위협 종료 후(탈진·통증 증가) 시간축
4. **출혈 시야:** 대퇴동맥·간 단독 사격의 MAP·의식·시야 단계 시각을 표로 낸다. 블랙아웃이 의식 소실보다 먼저인지 확인한다. 단계별 화면을 두 화면 크기(1280×720, 844×390)로 캡처한다.
5. **기립성:** 혈액 손실 0/20/35%에서 앉기→서기 전환의 시야 단계와 지속 시간.
6. **AI:** 같은 부상을 입힌 적의 행동 값과, 고정 표적에 대한 N발 명중률을 부상 전후로 비교한다.
7. **화면 효과 강도:** 0/50/100%에서 화면만 바뀌고 흔들림·속도는 같은지 확인한다. 조준경 화면 포함.
8. **성능:** 화면 효과 추가 전후 두 화면 크기의 프레임 시간.
9. **기존 회귀:** 전체 테스트, 2D baseline 바이트 비교, 두 화면 오프라인 실행, 의료·소리 결과 불변.
