# D1b: 눈꺼풀·관류 시야·떨림 파형·아드레날린 화면

v52 위에서 작업한다. 3D는 2D와 분리된 상태다. 2D 원본은 바꾸지 않는다. 바꾼 항목은 대장에 출처/원본/튜닝/사용자 설계값과 `2D 역이식 후보`를 표시한다.

공통 규칙(D1)은 그대로다.
- 생리 수식, 쓰러짐·심정지 판정은 바꾸지 않는다.
- 건강하고 평온한 상태에서는 v52와 결과가 정확히 같다.
- 흔들림 난수는 결정론이다.
- 화면 효과는 "화면 효과 강도" 설정을 따른다. 몸 효과는 이 설정으로 바뀌지 않는다.

## 1. 눈꺼풀: 의식 처짐과 통증 찡그림

### v52의 문제
- **모양:** 위아래 직선 막대(`abs(vUv.y-0.5)`, 경계 0.018)라 레터박스처럼 보인다.
- **움직임:** 의식 < 75에서 6 s → 2 s 간격의 sin² 곡선을 정확히 반복한다. 감기·뜨기 속도가 같다.

### 모양 (두 종류 공통)
- 눈 모양 곡선이다.
  - 위 눈꺼풀이 둥근 호로 크게 내려온다. 아래 눈꺼풀은 조금만 올라온다.
  - 화면 비율과 상관없이 같은 모양을 유지한다.
- 렌즈 바로 앞이라 초점이 안 맞는다. 경계는 넓고 흐릿하게 한다.
- 감길수록 남은 화면도 조금 어두워지고 흐려진다.

### 의식 처짐 (졸음형)
- **켜지는 조건:** 의식이 **천천히** 떨어질 때만 켠다.
  - 의식 하강 속도(몇 초 평활)가 문턱보다 빠르면 끈다. 이때는 2절 시야 암전만 쓴다.
  - 근거: 급성 실신은 대부분 눈을 뜬 채 의식을 잃는다(Lempert 1994, 실신 56건 영상 분석). 원문을 확인해 단다.
  - 문턱은 튜닝이다. 심장 펌프 손실·뇌간·대동맥 단독 사례가 "급하게"로, 대퇴동맥·간 단독 사례 대부분이 "천천히"로 분류되는지 확인한다.
- **진행 순서:** 의식이 낮아질수록 뒤 단계로 간다.
  1. 가끔 깜빡임
  2. 깜빡임이 길어짐
  3. 반쯤 처져 감길 듯 말 듯 버팀(작은 떨림)
  4. 천천히 감김
  5. 번쩍 뜸(덜 뜨일 때도 있음)
  6. 다시 처짐
- **시간 특성:**
  - 감기는 느리고, 뜨기는 빠르다. 간격과 지속은 불규칙하다(결정론 잡음).
  - 깜빡임 지속시간과 다시 뜨는 시간이 졸음에 따라 늘어나는 측정값(Caffier 2003 등)을 출처로 찾아 쓴다. 못 찾은 값은 튜닝이다.
- **끝:** 의식 소실 시점에 마지막으로 완전히 감기고, 기존 전투 불능 흐름으로 넘어간다.

### 통증 찡그림
- **입력:** 느끼는 통증(`perceivedPain`)과 그 상승 속도.
- **근거:** 통증 표정에는 눈 감기와 눈가 조이기가 포함된다(Prkachin 1992, PSPI). 출처를 확인해 단다.
- **동작:**
  - 피격 순간과 통증이 빠르게 오를 때 질끈 감았다가 바로 뜬다. 짧고 빠르다.
  - 통증이 높게 유지되면 눈이 좁혀진 상태가 계속된다. 통증 단계가 높을수록 더 좁다.
  - 찡그림은 위아래 눈꺼풀이 같이 조여 가늘어진다. 졸음형처럼 위만 처지지 않는다.
  - 아드레날린 가림이 그대로 반영된다. 교전 중엔 약하고, 탈진 때 강하다.
- **겹칠 때:** 두 종류가 동시에 오면 더 많이 감긴 쪽을 쓴다.

## 2. 터널·블랙아웃: 실혈량과 관류 중 큰 쪽

### v52의 문제
- 흑백화·주변 어둠·터널·블랙아웃 네 개 모두 혈액 부족률(`1-bloodMl/bloodMax`)로만 계산한다.
- 그래서 피를 거의 안 흘리고 혈압이 떨어지는 경우에 시야 변화가 없다.
  - 심장 펌프 손실(약 8.7 s 의식 소실)
  - 긴장성 기흉
  - 혈흉

### 바꿀 것
- **흑백화·주변 어둠:** 혈액 부족률 그대로 둔다(사용자 설계값).
- **터널·블랙아웃:** `max(부족률 기준, 관류 기준)`으로 계산한다.
  - **부족률 기준:** v52 값 그대로(터널 0.30–0.445, 암전 0.38–0.445).
  - **관류 기준:** 망막 관류로 계산한다.
    - 입력: 기존 혈압(MAP 또는 수축기), `tissuePerfusion`, `oxygenDelivery`.
    - 눈 높이 보정: 서기·앉기는 심장보다 눈이 높아 정수압(ρgh)만큼 눈 쪽 압력이 낮다. 누우면 보정이 거의 없다. 래그돌 쓰러짐 뒤에도 같은 원리로 계산한다.
    - 단계 문턱은 항공의학의 눈 높이 혈압 기준(회색 시야 → 블랙아웃)을 출처로 찾는다. 못 찾으면 튜닝이다.
    - 건강한 상태에서는 0이어야 한다.
- 블랙아웃은 기존 의식 소실보다 먼저 와야 한다. 심장 펌프 손실처럼 빠른 경우에도 몇 초라도 앞서는지 확인한다.
- 기립성 하얗게 날림(v52)은 그대로 별도 효과로 둔다.

## 3. 떨림·흔들림 파형

### v52의 문제
- **잔떨림이 사실상 없다.**
  - 크기가 `(amplitudes.adrenaline + panic×0.5) × 0.25`이고, 아드레날린 기여는 2D 식대로 0.7 초과에서만 생긴다.
  - 아드레날린 0.8에서 약 0.09 mrad라 안 보인다.
- **잔떨림이 기계적이다.** 10 Hz·10.7 Hz 순수 사인파다.
- **숨·심박 흔들림도 순수 사인파다.**
- **조준 유지 서보 교란 합에 아드레날린·공황·숨·심박이 빠져 있다.**

### 바꿀 것
- **잔떨림(생리적 떨림)**
  - 8–12 Hz 대역 잡음을 쓴다. 대역 폭과 중심 주파수는 D1 출처를 따른다.
  - 세기를 천천히 출렁이게 한다(진폭 변조).
  - 크기는 `adrenaline`에 **연속 비례**하고, `panic`을 더한다. 2D의 0.7 문턱은 AI 조준 배율(`aimMul`) 계산에만 남긴다.
  - 크기는 작게: 조준점 끝이 살짝 자글거리는 정도(튜닝). 기준값으로 아드레날린 0.5와 1.0의 RMS(mrad)를 정해 대장에 적는다.
- **큰 흔들림**
  - 통증·팔·의식·관류·탈진의 교란은 지금 단일 대역 값 잡음이다. 2–3 옥타브 저주파 잡음으로 바꿔 덜 규칙적으로 만든다.
  - v52의 RMS 크기는 유지한다. 파형만 바꾼다.
- **숨**
  - 사인파 대신 들숨·날숨이 비대칭인 숨 파형을 쓴다. 숨 주기도 조금씩 흔들린다.
  - 빠르기와 크기 입력은 v52 그대로다(호흡 효율, 가슴 통증, 달리기).
- **심박**
  - 사인파 대신 박동마다 짧은 펄스를 준다. 주기는 `heartRate`이고 박동 간격이 약간 흔들린다.
- **조준 유지 서보**
  - 지금 구조(놓쳤다 다시 잡기, 정렬 손실)는 그대로 둔다.
  - 잔떨림은 서보 바깥에서 더한다(근육 떨림이라 보정으로 지워지지 않음).

## 4. 아드레날린 화면

근거: Artwohl(2002, FBI Law Enforcement Bulletin) 총격 경찰관 조사의 "시야가 비정상적으로 선명해짐" 보고 비율을 원문에서 확인해 단다.

- **입력:** `adrenaline`(필요하면 `combatArousal` 포함). smoothstep 구간은 튜닝이다. 공황의 주변 흐림·주의 협착(v52)은 그대로 둔다.
- **선명도:** 화면 가운데 쪽에 샤프닝(언샤프 마스크)을 세게 건다. 가장자리로 갈수록 약해진다.
- **하얀 외곽:** 샤프닝의 밝은 쪽 넘침을 살려 경계에 밝은 테두리가 생기게 한다. 어두운 쪽 넘침은 약하게 한다. 국부 대비를 약간 올린다.
- **미세 떨림:** 화면 전체를 3절 잔떨림 신호로 미세하게 흔든다. 기준 해상도에서 1픽셀 안팎이고, 해상도가 달라도 같은 크기로 보여야 한다.
- **결과 구도:** 가운데는 쨍하고 바깥은 흐리다(v52 주변 흐림과 함께).
- **조준경:** 조준경 화면에도 같은 효과가 걸린다.
- **비용:** 샤프닝은 추가 텍스처 샘플이 든다. 효과가 0이면 셰이더 분기에서 건너뛴다.

## 5. 하지 않는 것

- 뇌진탕, 팔·다리 지구력, 숨참, 의료 상태 UI → 다음 단계
- AI 행동 배율 변경(D1 그대로)
- 의료 생리 수식, 쓰러짐·심정지 판정, 탄도·관통·방호·HP

## 6. 검증

1. **눈꺼풀 분류:** 심장·뇌간·대동맥·대퇴동맥·간 단독 사격에서 의식 하강 속도, 졸음형 켜짐 여부, 마지막 감김과 의식 소실 시각을 표로 낸다.
2. **눈꺼풀 화면:** 졸음형 6단계와 찡그림(피격 순간, 높은 통증 유지)을 두 화면 크기(1280×720, 844×390)로 캡처한다. 연속 프레임 시트로 감기·뜨기 속도 차이를 보인다.
3. **관류 시야:** 심장 펌프 손실, 긴장성 기흉 또는 혈흉 사례, 대퇴동맥 단독에서 다음을 표로 낸다.
   - 부족률 기준과 관류 기준 각각의 터널·블랙아웃 값, 실제 사용된 쪽
   - 블랙아웃이 의식 소실보다 앞서는 시간
   - 서기/누움 눈 높이 보정 차이
4. **떨림 스펙트럼:** 아드레날린 0 / 0.3 / 0.5 / 0.8 / 1.0의 조준선 RMS와 스펙트럼. 8–12 Hz 대역 피크가 있고 단일 주파수 선이 없어야 한다. v52와 나란히 낸다.
5. **큰 흔들림:** 팔 1발·심한 팔 부상에서 v52와 RMS가 비슷하고, 파형이 덜 규칙적인지 확인한다(자기상관 등).
6. **아드레날린 화면:** 아드레날린 0 / 0.5 / 1.0의 화면(조준경 포함)을 두 화면 크기로 캡처한다. 화면 효과 강도 0/50/100%도 같이 낸다.
7. **성능:** 효과 0과 최대에서 두 화면 크기의 프레임 시간.
8. **기존 회귀:** 전체 테스트, 2D baseline 바이트 비교, 건강·평온 600틱 정확 동일, 두 화면 오프라인 실행, 의료·소리 결과 불변.
